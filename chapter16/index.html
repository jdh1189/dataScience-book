    프로젝트 2 - 지혜로운 어부 생활: 환경·수산 데이터 분석¶

    🎯 이 장에서 배우는 것¶

    • 환경·수산 분야의 시계열 데이터를 수집하고 전처리할 수 있다
    • 시계열 데이터의 추세와 계절성을 시각화하여 해석할 수 있다
    • 군집 분석(K-Means)으로 지역별 어업 특성을 분류할 수 있다
    • 분석 결과를 종합하여 '지혜로운 어부를 위한 데이터 리포트'를 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: "바다 수온이 올라가면 어획량은 어떻게 변할까?"

    뉴스에서 "올해 오징어가 안 잡힌다", "명태가 사라졌다"는 이야기를 들어본 적 있나요? 이런 현상의 이면에는 해수면 온도 상승, 해류 변화, 남획 같은 복합적인 원인이 숨어 있습니다.

    옛날 어부들은 오랜 경험과 감으로 물고기가 많이 잡히는 시기와 장소를 알았습니다. 하지만 기후변화로 바다 환경이 빠르게 변하는 오늘날, 경험만으로는 부족합니다. 이제는 데이터가 지혜로운 어부의 새로운 나침반이 됩니다.

    이 프로젝트에서 여러분은 실제 환경·수산 데이터를 분석하여:

    • 수온 변화의 장기 추세를 파악하고
    • 어획량과 수온의 관계를 탐색하며
    • 지역별 어업 특성을 군집 분석으로 분류하고
    • 최종적으로 지속가능한 어업을 위한 제언을 담은 데이터 리포트를 완성합니다

    이전 챕터에서 배운 pandas, matplotlib 등의 도구를 실전 프로젝트에 통합 적용하는 경험이 될 것입니다.

    📚 핵심 개념¶

    개념 1: 시계열 데이터와 추세 분석¶

    🎣 비유로 시작

    낚시 일기를 10년간 매일 썼다고 상상해보세요. "오늘 몇 마리 잡았다, 수온은 몇 도였다"를 기록한 것입니다. 이 일기를 쭉 펼쳐보면 "여름에 많이 잡히고 겨울에 적게 잡히는 패턴"(계절성)이 보이고, "해가 갈수록 전체적으로 줄어드는 흐름"(추세)이 보일 수 있습니다. 이것이 바로 시계열 분석입니다.

    📖 정확한 정의

    시계열 데이터(Time Series Data): 시간 순서에 따라 일정한 간격으로 기록된 데이터입니다. 시계열 데이터에서 발견할 수 있는 주요 패턴은 다음과 같습니다.

    • 추세(Trend): 장기적으로 올라가거나 내려가는 방향성. 예) 10년간 수온이 서서히 상승
    • 계절성(Seasonality): 일정한 주기로 반복되는 패턴. 예) 매년 여름 어획량 증가, 겨울 감소
    • 불규칙 변동(Noise): 예측 불가능한 무작위 변동. 예) 태풍으로 인한 갑작스러운 어획량 급감
    graph LR A[시계열 데이터] --> B[추세<br/>장기적 방향] A --> C[계절성<br/>반복 패턴] A --> D[불규칙 변동<br/>랜덤 노이즈] B --> E[이동평균으로 파악] C --> F[월별 그룹화로 파악] D --> G[원본-추세-계절성<br/>으로 분리]

    이동평균(Moving Average): 일정 기간의 평균을 구해 데이터를 "부드럽게" 만드는 기법입니다. 12개월 이동평균을 사용하면 계절 변동이 사라지고 장기 추세만 남습니다.

    ✅ 예시로 확인

    import pandas as pd

# 월별 수온 데이터가 있다고 가정
# 12개월 이동평균 = 최근 12개월의 평균값
df['수온_12개월평균'] = df['수온'].rolling(window=12).mean()
# → 계절 변동이 사라지고, 수온이 해마다 조금씩 오르는 추세가 보임

    개념 2: 상관 분석 — 두 변수의 관계 파악¶

    🎣 비유로 시작

    "수온이 높은 달에 고등어가 많이 잡히더라." 어부의 이런 경험담을 숫자로 증명하려면 어떻게 할까요? 수온과 고등어 어획량을 나란히 놓고 "둘이 같이 움직이는지"를 확인하면 됩니다. 같이 올라가면 양의 상관, 하나가 오를 때 다른 하나가 내려가면 음의 상관입니다.

    📖 정확한 정의

    상관계수(Correlation Coefficient): 두 변수가 함께 변하는 정도를 -1에서 +1 사이의 숫자로 표현한 값입니다.

    • +1에 가까울수록: 강한 양의 상관 (하나 오르면 다른 것도 오름)
    • -1에 가까울수록: 강한 음의 상관 (하나 오르면 다른 것은 내림)
    • 0에 가까울수록: 상관 없음 (서로 관련 없이 움직임)

    ⚠️ 주의: 상관관계 ≠ 인과관계입니다! "아이스크림 판매량"과 "익사 사고"는 양의 상관이지만, 아이스크림이 익사를 일으키는 것이 아닙니다. 둘 다 "더운 날씨"라는 공통 원인 때문입니다.

    ✅ 예시로 확인

    # 수온과 어획량의 상관계수 계산
correlation = df['수온'].corr(df['어획량'])
print(f"상관계수: {correlation:.2f}")
# 결과 예시: 0.65 → 수온이 높을수록 어획량도 많은 경향

    개념 3: 군집 분석(K-Means) — 비슷한 것끼리 묶기¶

    🎣 비유로 시작

    전국 항구를 방문한다고 상상해보세요. 어떤 항구는 수온이 높고 난류성 어종(고등어, 멸치)이 많이 잡힙니다. 어떤 항구는 수온이 낮고 한류성 어종(명태, 대구)이 주력입니다. 또 어떤 항구는 양식업이 주를 이룹니다. 이렇게 비슷한 특성의 항구끼리 자동으로 묶어주는 것이 군집 분석입니다.

    📖 정확한 정의

    K-Means 군집 분석: 데이터를 K개의 그룹(군집)으로 나누는 알고리즘입니다. 각 데이터 포인트를 가장 가까운 군집 중심(centroid)에 배정하고, 중심을 다시 계산하는 과정을 반복합니다.

    graph TD A["1단계: K개 중심점을<br/>랜덤 배치"] --> B["2단계: 각 데이터를<br/>가장 가까운 중심에 배정"] B --> C["3단계: 각 군집의<br/>새로운 중심 계산"] C --> D{"중심이<br/>변했는가?"} D -- "예" --> B D -- "아니오" --> E["완료: K개 군집 확정"]

    ✅ 예시로 확인

    from sklearn.cluster import KMeans

# 지역별 [평균수온, 총어획량] 데이터로 3개 군집 생성
kmeans = KMeans(n_clusters=3, random_state=42)
df['군집'] = kmeans.fit_predict(df[['평균수온', '총어획량']])
# → 군집 0: 고수온·고어획, 군집 1: 저수온·중어획, 군집 2: 중수온·저어획

    개념 4: 데이터 리포트 — 분석에서 제언까지¶

    🎣 비유로 시작

    의사가 건강검진 결과만 주고 "알아서 하세요"라고 하면 곤란하겠죠? 수치를 해석하고, 위험 요인을 짚어주고, "이렇게 생활하세요"라는 처방까지 해줘야 합니다. 데이터 리포트도 마찬가지입니다. 분석 결과를 보여주는 것에 그치지 않고, "그래서 어떻게 해야 하는가?"까지 제안하는 것이 완전한 리포트입니다.

    📖 정확한 정의

    데이터 리포트: 데이터 분석의 전 과정(문제 정의 → 데이터 수집 → 분석 → 결론 → 제언)을 체계적으로 정리한 문서입니다.

    리포트의 필수 구성요소:

    • 배경과 목적: 왜 이 분석을 하는가?
    • 데이터 설명: 어떤 데이터를 사용했는가?
    • 분석 방법: 어떤 기법을 적용했는가?
    • 결과와 해석: 무엇을 발견했는가?
    • 제언: 이 결과를 바탕으로 무엇을 해야 하는가?

    정리하기 📌: 이 프로젝트에서는 시계열 분석(추세·계절성), 상관 분석(변수 관계), 군집 분석(그룹 분류)을 모두 활용하여 환경·수산 데이터를 종합적으로 분석합니다.

    🔨 따라하기¶

    프로젝트 전체 흐름¶

    graph LR S1["Step 1<br/>데이터 준비"] --> S2["Step 2<br/>시계열 시각화"] S2 --> S3["Step 3<br/>상관 분석"] S3 --> S4["Step 4<br/>군집 분석"] S4 --> S5["Step 5<br/>종합 시각화"] S5 --> S6["Step 6<br/>리포트 작성"]

    Step 1: 환경·수산 데이터 준비하기¶

    실제 프로젝트에서는 해양수산부 공공데이터 포털에서 데이터를 다운로드하지만, 학습을 위해 실제 패턴을 반영한 시뮬레이션 데이터를 생성합니다.

    알아보기 🔍: 실제 데이터를 사용하고 싶다면 아래 사이트를 참고하세요. - 국가통계포털(KOSIS): kosis.kr — 수산물 생산량 통계 - 해양환경정보포털: www.meis.go.kr — 해양 수온, 오염도 데이터

    import pandas as pd
import numpy as np

# 재현 가능한 랜덤 시드 설정
np.random.seed(42)

# === 1. 월별 수온·어획량 시계열 데이터 (2014~2023, 10년) ===
dates = pd.date_range('2014-01', '2023-12', freq='MS')  # 월초(Month Start)
n_months = len(dates)

# 수온: 기본 계절 패턴 + 장기 상승 추세 + 랜덤 노이즈
month_num = np.arange(n_months)
계절패턴_수온 = 7 * np.sin(2 * np.pi * month_num / 12)  # 여름 높고 겨울 낮음
상승추세_수온 = 0.01 * month_num                          # 매달 0.01도씩 장기 상승
기본수온 = 15.0                                            # 연평균 기준
노이즈_수온 = np.random.normal(0, 0.8, n_months)
수온 = 기본수온 + 계절패턴_수온 + 상승추세_수온 + 노이즈_수온

# 어획량: 수온과 관련 + 감소 추세 + 계절성
계절패턴_어획 = 3000 * np.sin(2 * np.pi * (month_num - 2) / 12)  # 수온보다 살짝 지연
감소추세_어획 = -8 * month_num                               # 장기적으로 감소
기본어획 = 15000
노이즈_어획 = np.random.normal(0, 800, n_months)
어획량 = 기본어획 + 계절패턴_어획 + 감소추세_어획 + 노이즈_어획
어획량 = np.maximum(어획량, 2000)  # 최소값 보장

# 해양오염지수: 수온과 약한 양의 상관

    # === 최적 K 찾기: 엘보우 방법 ===

    # === 자동 리포트 생성 ===
from datetime import datetime

def generate_report(df_monthly, df_region, 상관행렬, 군집이름):
    """분석 결과를 종합한 텍스트 리포트를 자동 생성합니다."""

    # 핵심 통계 계산
    이동평균 = df_monthly['수온_이동평균'].dropna()
    수온변화 = 이동평균.iloc[-1] - 이동평균.iloc[0]

    이동평균_어획 = df_monthly['어획량_이동평균'].dropna()
    어획변화율 = (이동평균_어획.iloc[-1] - 이동평균_어획.iloc[0]) / 이동평균_어획.iloc[0] * 100

    최고수온월 = df_monthly.groupby('월')['수온'].mean().idxmax()
    최고어획월 = df_monthly.groupby('월')['어획량'].mean().idxmax()

    r_수온어획 = 상관행렬.loc['수온', '어획량']

    report = f"""
{'='*60}
    🐟 지혜로운 어부를 위한 데이터 리포트
{'='*60}

📅 작성일: {datetime.now().strftime('%Y년 %m월 %d일')}
📊 분석 기간: 2014년 1월 ~ 2023년 12월 (10년)
📍 분석 대상: 전국 {len(df_region)}개 주요 어항

{'─'*60}
1. 배경 및 목적
{'─'*60}
  기후변화에 따른 해수면 온도 상승이 수산업에 미치는 영향을
  데이터 기반으로 분석하여, 지속가능한 어업 전략 수립에
  필요한 근거를 제공합니다.

{'─'*60}
2. 주요 발견
{'─'*60}

  [발견 1] 해수면 온도 상승 추세 확인
  - 10년간 평균 수온이 약 {수온변화:+.1f}°C 상승했습니다.
  - 가장 수온이 높은 달: {최고수온월}월

  [발견 2] 어획량 감소 추세 확인
  - 10년간 어획량이 약 {어획변화율:.1f}% 변화했습니다.
  - 가장 어획량이 많은 달: {최고어획월}월

  [발견 3] 수온과 어획량의 상관관계
  - 상관계수: {r_수온어획:.3f}
  - 해석: 월별 수온과 어획량 사이에 {'양' if r_수온어획 > 0 else '음'}의 상관이 존재하며,
    이는 계절적 패턴이 공통으로 작용하기 때문입니다.
  - 단, 장기 추세에서는 수온 상승에도 어획량은 감소하는
    역방향 현상이 관찰됩니다.

  [발견 4] 지역별 3개 어업 군집 식별
"""
    for c in sorted(df_region['군집'].unique()):
        지역들 = df_region[df_region['군집'] == c]['지역'].tolist()
        report += f"  - {군집이름[c]}: {', '.join(지역들)}\n"

    report += f"""

3. 제언: 지속가능한 어업을 위하여
{'─'*60}

  ✅ 단기 전략 (1~2년)
  - 수온 모니터링 기반 어획 시기 최적화
  - 군집별 특성에 맞는 차별화된 어업 지원 정책

  ✅ 중기 전략 (3~5년)
  - 난류성 어종(고등어, 오징어 등) 양식 기술 개발
  - 서해권 양식 노하우를 동해·남해에 확산

  ✅ 장기 전략 (5~10년)
  - 해양오염 저감을 위한 연안 관리 강화
  - 기후변화 시나리오별 수산자원 예측 모델 구축
  - 데이터 기반 스마트 어업 시스템 전국 확대

{'─'*60}
4. 분석의 한계
{'─'*60}
  - 시뮬레이션 데이터를 사용하여 실제와 차이가 있을 수 있음
  - 어획량에 영향을 주는 다른 변수(어선 수, 정책 변화 등) 미반영
  - 인과관계가 아닌 상관관계 수준의 분석

{'='*60}
  📌 "데이터는 바다의 새로운 나침반입니다.
      지혜로운 어부는 경험과 데이터를 함께 읽습니다."
{'='*60}
"""
    return report

# 리포트 생성 및 출력
report = generate_report(df_monthly, df_region, 상관행렬, 군집이름)

    Chapter 16: 데이터 과학 적용과 데이터 적합성¶

    🎯 이 장에서 배우는 것¶

    • 데이터 과학 프로젝트에서 문제 정의 → 데이터 수집 → 적합성 판단의 흐름을 설계할 수 있다
    • 수집한 데이터가 분석 목적에 적합한지 4가지 기준(충분성, 신뢰성, 관련성, 최신성)으로 평가할 수 있다
    • 부적합한 데이터를 발견했을 때 개선하거나 대체 데이터를 탐색하는 전략을 수립할 수 있다
    • Python 코드로 데이터 적합성 체크리스트를 실제로 적용할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    "질병 예측 AI를 만들고 싶다. 인터넷에서 건강 관련 데이터를 아무거나 다운받아서 넣으면 될까?"

    정답은 "절대 아니오" 입니다.

    실제로 2020년, 한 연구팀이 코로나19 진단 AI를 개발하면서 인터넷에서 수집한 흉부 X-ray 이미지를 학습 데이터로 사용했습니다. 나중에 밝혀진 사실은, AI가 질병이 아니라 "어느 병원에서 촬영했는지"를 학습하고 있었다는 것입니다. 데이터에 병원별 촬영 스타일 차이가 섞여 있었기 때문입니다.

    이처럼 좋은 질문 + 잘못된 데이터 = 잘못된 결론입니다. 데이터 과학에서 가장 중요한 능력 중 하나는 "이 데이터가 내 질문에 답하기에 적합한가?"를 판단하는 것입니다.

    이번 장에서는 데이터를 무작정 분석하기 전에, 한 발 물러서서 데이터의 적합성을 평가하는 눈을 기르겠습니다.

    📚 핵심 개념¶

    개념 1: 데이터 과학 프로젝트의 흐름¶

    🎒 비유: 요리 프로젝트

    요리를 한다고 생각해보세요. "맛있는 걸 만들자!"라고 냉장고를 열기 전에, 먼저 무엇을 만들지(문제 정의)를 정하고, 필요한 재료(데이터 수집)를 확인하고, 재료가 신선하고 적절한지(적합성 판단)를 확인해야 합니다. 상한 재료로는 아무리 솜씨가 좋아도 맛있는 요리를 만들 수 없습니다.

    📖 정확한 정의

    데이터 과학 프로젝트는 다음 흐름을 따릅니다.

    flowchart LR A["1️⃣ 문제 정의"] --> B["2️⃣ 데이터 수집"] B --> C["3️⃣ 적합성 판단"] C -->|적합| D["4️⃣ 분석 및 모델링"] C -->|부적합| E["데이터 개선/대체"] E --> B D --> F["5️⃣ 결과 해석"]

    각 단계의 핵심은 다음과 같습니다.

    • 1️⃣ 문제 정의: "무엇을 알고 싶은가?"를 구체적으로 정한다
    • 2️⃣ 데이터 수집: 문제에 답할 수 있는 데이터를 모은다
    • 3️⃣ 적합성 판단: 수집한 데이터가 정말 쓸 만한지 검증한다
    • 4️⃣ 분석/모델링: 적합한 데이터로 분석을 진행한다
    • 5️⃣ 결과 해석: 분석 결과를 문제에 대한 답으로 연결한다

    💡 예시로 확인

    • 나쁜 예: "건강에 대해 알아보자" → 너무 막연함
    • 좋은 예: "흡연 여부가 폐활량에 영향을 미치는가?" → 구체적이고 데이터로 답할 수 있음

    정리하기 📌

    프로젝트의 성패는 첫 단계인 문제 정의에서 결정됩니다. 문제가 구체적이어야 필요한 데이터가 무엇인지 명확해집니다.

    개념 2: 데이터 적합성의 4가지 기준¶

    🎒 비유: 시험공부 자료 고르기

    시험공부를 한다고 할 때, 좋은 참고서를 고르는 기준을 생각해보세요.

    • 내용이 충분히 있는가? (2페이지짜리 요약본으로 시험 준비가 될까?)
    • 신뢰할 수 있는 출처인가? (출처 불명의 블로그 vs 공식 교과서)
    • 시험 범위와 관련 있는가? (수학 시험인데 국어 참고서를 펼치면?)
    • 최신 교육과정에 맞는가? (10년 전 참고서는 범위가 다를 수 있음)

    데이터 적합성 판단도 정확히 같은 원리입니다.

    📖 정확한 정의

    데이터 적합성(Data Fitness)이란 수집한 데이터가 분석 목적에 부합하는 정도를 말합니다. 4가지 기준으로 평가합니다.

    • 충분성(Sufficiency): 데이터의 양이 분석하기에 충분한가? 행(데이터 건수)과 열(변수 종류) 모두 확인
    • 신뢰성(Reliability): 데이터의 출처가 믿을 만하고, 결측값이나 오류가 적은가?
    • 관련성(Relevance): 데이터의 변수(컬럼)가 우리 질문에 답하는 데 실제로 도움이 되는가?
    • 최신성(Timeliness): 데이터가 현재 상황을 반영하는가? 너무 오래된 데이터는 아닌가?
    flowchart TB Q["🔍 이 데이터, 쓸 수 있을까?"] Q --> S["📊 충분성<br/>데이터가 충분한가?"] Q --> R["🔒 신뢰성<br/>출처가 믿을 만한가?"] Q --> V["🎯 관련성<br/>질문과 관련 있는가?"] Q --> T["🕐 최신성<br/>시점이 적절한가?"] S --> OK["✅ 4가지 모두 통과해야<br/>분석에 적합"] R --> OK V --> OK T --> OK

    💡 예시로 확인

    "우리 학교 학생들의 수면 시간이 성적에 영향을 미치는가?"라는 질문에 대해 다음 데이터를 평가해봅시다.

    • 충분성: 5명의 데이터 → ❌ 너무 적다. 최소 수십 명 이상 필요
    • 신뢰성: 학생이 자가 보고한 수면 시간 → ⚠️ 부정확할 수 있음(스마트워치 데이터가 더 신뢰성 높음)
    • 관련성: 수면 시간, 성적 데이터가 있음 → ✅ 직접 관련됨
    • 최신성: 올해 수집한 데이터 → ✅ 최신

    개념 3: 적합성 체크리스트 실전 적용¶

    🎒 비유: 비행기 이륙 전 체크리스트

    조종사는 이륙 전에 반드시 체크리스트를 하나하나 확인합니다. "아마 괜찮겠지"라고 넘어가면 큰 사고로 이어질 수 있습니다. 데이터 분석도 마찬가지입니다. 체크리스트를 만들고 체계적으로 확인하는 습관이 중요합니다.

    📖 정확한 정의

    데이터 적합성 체크리스트는 분석 전에 데이터를 정량적·정성적으로 검토하는 표준화된 절차입니다. 코드로 자동화할 수 있는 항목(결측값 비율, 데이터 크기 등)과 사람이 판단해야 하는 항목(출처의 신뢰성, 변수의 의미 등)이 함께 포함됩니다.

    💡 예시: 체크리스트 항목

    • 충분성 점검 → 행 수 1,000개 이상? 주요 변수(열)가 모두 포함?
    • 신뢰성 점검 → 결측값 비율 20% 이하? 이상치(outlier) 비율 확인? 출처가 공신력 있는 기관?
    • 관련성 점검 → 종속변수(알고 싶은 것)가 데이터에 존재? 독립변수(원인으로 추정하는 것)도 포함?
    • 최신성 점검 → 수집 시점이 5년 이내? 분석 대상 시기와 일치?

    개념 4: 부적합 데이터의 개선 전략¶

    🎒 비유: 퍼즐 조각이 안 맞을 때

    퍼즐을 맞추다가 조각이 부족하거나 다른 퍼즐 조각이 섞여 있다면? 세 가지 선택이 있습니다. ① 부족한 조각을 찾아온다 ② 섞인 조각을 골라낸다 ③ 아예 다른 퍼즐 세트를 구한다. 데이터도 마찬가지입니다.

    📖 정확한 정의

    부적합 데이터를 만났을 때 사용할 수 있는 3가지 전략은 다음과 같습니다.

    • 보완(Supplement): 부족한 데이터를 추가 수집하거나, 다른 데이터셋과 병합(merge)한다
    • 정제(Clean): 결측값 처리, 이상치 제거, 중복 제거 등으로 기존 데이터의 품질을 높인다
    • 대체(Replace): 근본적으로 부적합한 경우, 더 적합한 다른 데이터셋을 탐색한다
    flowchart TD P["❌ 데이터가 부적합!"] P --> Q1{"문제 유형은?"} Q1 -->|양이 부족| A["📥 보완<br/>추가 수집 또는 병합"] Q1 -->|품질이 낮음| B["🧹 정제<br/>결측값·이상치·중복 처리"] Q1 -->|근본적 불일치| C["🔄 대체<br/>다른 데이터셋 탐색"] A --> R["재평가"] B --> R C --> R R --> OK["✅ 적합성 기준 통과!"]

    💡 예시로 확인

    "서울시 미세먼지와 호흡기 질환 관계"를 분석하려는데, 미세먼지 데이터만 있고 호흡기 질환 데이터가 없다면?

    • 보완: 건강보험공단의 호흡기 질환 통계 데이터를 추가로 수집하여 병합
    • 정제: 미세먼지 데이터에서 센서 오류로 인한 음수 값 제거
    • 대체: 서울시 데이터가 부실하면, 더 정비가 잘 된 환경부 공식 데이터로 교체

    🔨 따라하기¶

    🎯 실습 목표: 건강 검진 데이터를 로드하여 적합성 체크리스트를 코드로 적용해보기

    이 실습은 Google Colab에서 진행합니다.

    Step 1: 데이터 준비 및 로드¶

    건강 검진 샘플 데이터를 직접 생성하여 실습합니다.

    import pandas as pd
import numpy as np

# 건강 검진 샘플 데이터 생성
np.random.seed(42)
n = 500

data = {
    '이름': [f'환자_{i}' for i in range(1, n+1)],
    '나이': np.random.randint(20, 80, n),
    '성별': np.random.choice(['남', '여'], n),
    '흡연여부': np.random.choice(['예', '아니오', None], n, p=[0.3, 0.6, 0.1]),
    '키(cm)': np.round(np.random.normal(167, 10, n), 1),
    '몸무게(kg)': np.round(np.random.normal(68, 15, n), 1),
    '혈압_수축기': np.random.randint(90, 180, n),
    '혈당(mg/dL)': np.where(
        np.random.random(n) < 0.08,  # 8% 결측
        np.nan,
        np.random.randint(70, 200, n)
    ),
    '폐활량(L)': np.round(np.random.normal(3.5, 0.8, n), 2),
    '검진년도': np.random.choice([2019, 2020, 2021, 2022, 2023], n)
}

df = pd.DataFrame(data)

# 일부러 이상치 삽입 (현실적인 데이터처럼)
df.loc[3, '키(cm)'] = 250.0    # 비현실적 키
df.loc[10, '몸무게(kg)'] = -5.0  # 음수 몸무게
df.loc[50, '나이'] = 150         # 비현실적 나이

print("✅ 데이터 로드 완료!")
print(f"행(환자 수): {df.shape[0]}개")
print(f"열(변수 수): {df.shape[1]}개")

    알아보기 💡

    교란변수(confounding variable)란 독립변수와 종속변수 모두에 영향을 미쳐 분석 결과를 왜곡할 수 있는 변수입니다. 예를 들어, 나이가 많을수록 흡연 이력이 길고 폐활량도 자연 감소하므로, 나이를 통제하지 않으면 흡연의 효과를 과대평가할 수 있습니다.

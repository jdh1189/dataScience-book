    📖 Chapter 2: 데이터의 형태와 속성¶

    Part 1 | [1권] 데이터 과학의 이해 — 2차시

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 정형 데이터와 비정형 데이터를 구분할 수 있다
    • 수치형·범주형 데이터의 차이를 설명하고 예시를 들 수 있다
    • 데이터의 척도(명목·순서·구간·비율)를 구별할 수 있다
    • Python으로 데이터의 형태와 속성을 직접 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 요리를 한다고 상상해 보세요. 재료가 고체인지, 액체인지, 가루인지에 따라 다루는 방법이 완전히 달라집니다. 고체는 칼로 자르고, 액체는 계량컵으로 재고, 가루는 체로 치죠.

    데이터도 마찬가지입니다. 데이터의 형태와 속성을 알아야 어떤 분석 도구를 쓸지, 어떤 그래프로 시각화할지, 어떤 통계 기법을 적용할지 결정할 수 있습니다. 형태를 무시하고 분석하면, 마치 물을 칼로 자르려는 것처럼 엉뚱한 결과가 나옵니다.

    이번 장은 데이터 과학의 "재료 분류법"을 익히는 시간입니다.

    📚 핵심 개념¶

    개념 1: 정형 데이터 vs 비정형 데이터¶

    🔹 비유로 시작

    도서관을 떠올려 보세요. 책이 분류번호에 따라 서가에 깔끔하게 꽂혀 있으면 원하는 책을 금방 찾을 수 있습니다. 그런데 모든 책이 바닥에 쏟아져 있다면? 찾기가 매우 어렵겠죠.

    • 정형 데이터 = 깔끔하게 정리된 서가 📚
    • 비정형 데이터 = 바닥에 쏟아진 책더미 📦

    🔹 정확한 정의

    • 정형 데이터(Structured Data): 행(row)과 열(column)로 구성된, 미리 정해진 틀에 맞춰 저장된 데이터입니다. 엑셀 스프레드시트나 데이터베이스 테이블이 대표적입니다.
    • 비정형 데이터(Unstructured Data): 고정된 틀 없이 자유로운 형식으로 존재하는 데이터입니다. 텍스트 문서, 이미지, 영상, 음성 파일 등이 해당합니다.
    • 반정형 데이터(Semi-structured Data): 완전한 표 형태는 아니지만 태그(tag)나 키(key)로 일정한 구조를 가진 데이터입니다. JSON, XML, HTML 등이 여기에 속합니다.

    🔹 예시로 확인

    graph LR A[데이터의 형태] --> B["정형 데이터<br/>📊 엑셀, DB 테이블<br/>성적표, 매출 기록"] A --> C["반정형 데이터<br/>🏷️ JSON, XML, HTML<br/>웹페이지, API 응답"] A --> D["비정형 데이터<br/>🎨 텍스트, 이미지, 영상<br/>SNS 게시글, 유튜브 영상"]

    🔍 알아보기: 현재 전 세계 데이터의 약 80~90%가 비정형 데이터라고 알려져 있습니다. 우리가 매일 올리는 사진, 채팅 메시지, 유튜브 영상 모두 비정형 데이터입니다. 그래서 비정형 데이터를 다루는 기술(자연어 처리, 컴퓨터 비전 등)이 점점 중요해지고 있죠.

    개념 2: 수치형 데이터 vs 범주형 데이터¶

    🔹 비유로 시작

    학생증을 꺼내 보세요. 거기에는 학번(20250301), 이름(김민수), 학년(2학년), 키(172.5cm) 같은 정보가 있습니다.

    이 중 키는 숫자로 계산(평균, 합계)할 수 있지만, 이름은 숫자로 계산할 수 없습니다. "김민수 + 이영희 = ?"는 의미가 없으니까요. 이처럼 데이터에는 셈이 되는 것과 셈이 안 되는 것이 있습니다.

    🔹 정확한 정의

    • 수치형 데이터(Numerical Data): 크기를 나타내며, 사칙연산이 의미 있는 데이터
    • 연속형(Continuous): 소수점까지 무한히 세밀하게 측정 가능 → 키(172.5cm), 온도(36.7°C), 시간(2.5시간)

    • 이산형(Discrete): 딱 떨어지는 정수로만 존재 → 학생 수(35명), 형제 수(2명), 골 수(3골)

    • 범주형 데이터(Categorical Data): 종류나 그룹을 나타내며, 사칙연산이 의미 없는 데이터

    • 명목형(Nominal): 순서 없이 단순 분류 → 혈액형(A, B, O, AB), 성별(남, 여)
    • 순서형(Ordinal): 순서는 있지만 간격이 일정하지 않음 → 학점(A > B > C), 만족도(매우 만족 > 만족 > 불만족)

    🔹 예시로 확인

    graph TD A[데이터 유형] --> B[수치형 데이터] A --> C[범주형 데이터] B --> D["연속형<br/>키: 172.5cm<br/>몸무게: 65.3kg"] B --> E["이산형<br/>학생 수: 35명<br/>시험 점수: 88점"] C --> F["명목형<br/>혈액형: A, B, O, AB<br/>과목: 수학, 영어, 과학"] C --> G["순서형<br/>학점: A, B, C<br/>옷 사이즈: S, M, L, XL"]

    💬 생각해보기: "전화번호 010-1234-5678"은 숫자로 이루어져 있지만, 수치형 데이터일까요? 아닙니다! 전화번호끼리 더하거나 평균을 내는 것은 의미가 없으므로, 범주형(명목형) 데이터입니다. 숫자로 되어 있다고 무조건 수치형이 아니라는 점, 꼭 기억하세요!

    개념 3: 데이터의 측정 척도 — 명목·순서·구간·비율¶

    🔹 비유로 시작

    자(ruler)에도 종류가 있습니다. 이름표처럼 그냥 라벨만 붙이는 자, 등수만 매기는 자, 눈금 간격이 일정한 자, 그리고 절대 영점이 있는 자. 데이터를 측정하는 "자"의 수준을 척도(Scale)라고 합니다.

    🔹 정확한 정의

    네 가지 척도를 아래에서 위로 올라갈수록 더 많은 정보를 담고, 더 다양한 계산이 가능합니다.

    graph BT A["명목 척도 (Nominal)<br/>분류만 가능<br/>예: 혈액형, 우편번호"] B["순서 척도 (Ordinal)<br/>분류 + 순서<br/>예: 학점, 군대 계급"] C["구간 척도 (Interval)<br/>분류 + 순서 + 동일 간격<br/>예: 온도(℃), 연도"] D["비율 척도 (Ratio)<br/>분류 + 순서 + 동일 간격 + 절대 영점<br/>예: 키, 몸무게, 나이"] A --> B --> C --> D

    각 척도의 특징을 정리하면 다음과 같습니다.

    • 명목 척도: 같은지 다른지만 판단 가능. "A형 ≠ B형"은 되지만 "A형 > B형"은 안 됨
    • 순서 척도: 크고 작음 비교 가능. "A학점 > B학점"은 되지만, A와 B의 차이가 B와 C의 차이와 같다고 할 수 없음
    • 구간 척도: 차이(간격) 계산 가능. "30℃ - 20℃ = 10℃"는 의미 있음. 하지만 "20℃는 10℃의 2배로 덥다"고 말할 수 없음 (0℃가 "온도 없음"을 뜻하지 않으므로)
    • 비율 척도: 비율 계산까지 가능. "100kg은 50kg의 2배"라고 말할 수 있음. 0이 진짜 "없음"을 의미

    🔹 예시로 확인

    • 교실 번호(1반, 2반, 3반) → 명목 척도 (3반이 1반의 3배가 아님!)
    • 영화 별점(★~★★★★★) → 순서 척도
    • 섭씨 온도(10℃, 20℃, 30℃) → 구간 척도
    • 학생의 키(150cm, 160cm, 170cm) → 비율 척도

    🔍 알아보기: 왜 이걸 구분할까요? 척도에 따라 사용할 수 있는 통계 기법이 달라지기 때문입니다. 명목 척도에는 평균을 구할 수 없고(혈액형의 평균?), 비율 척도에서만 "몇 배"라는 표현이 가능합니다.

    개념 4: Python에서 데이터 타입 확인하기¶

    🔹 비유로 시작

    마트에서 물건을 사면 바코드를 찍어 종류를 확인하죠. Python에서도 데이터를 받으면 가장 먼저 "이 데이터가 뭔지" 확인하는 과정이 필요합니다. 이것이 바로 dtype을 확인하는 것입니다.

    🔹 정확한 정의

    Python의 pandas 라이브러리에서 데이터를 다룰 때, 각 열(column)에는 데이터 타입(dtype)이 지정됩니다.

    • int64: 정수 (이산형 수치 데이터)
    • float64: 실수, 소수점 포함 (연속형 수치 데이터)
    • object: 문자열 (주로 범주형 데이터)
    • category: pandas에서 범주형으로 명시적 지정
    • bool: 참/거짓 (True/False)
    • datetime64: 날짜와 시간

    🔹 예시로 확인

    import pandas as pd

# 학생 데이터 만들기
data = {
    '이름': ['민수', '영희', '철수', '지은'],
    '학년': [1, 2, 1, 3],
    '키': [172.5, 163.2, 178.0, 158.7],
    '혈액형': ['A', 'B', 'O', 'AB'],
    '안경착용': [True, False, True, False]
}

df = pd.DataFrame(data)
print(df.dtypes)

    실행 결과:

    이름       object
학년        int64
키        float64
혈액형     object
안경착용      bool
dtype: object

    여기서 '학년'이 int64(숫자)로 인식되었지만, 실제로는 순서형 범주 데이터에 가깝습니다. 이처럼 컴퓨터가 자동으로 판단한 타입과 데이터의 실제 성격이 다를 수 있으므로, 우리가 직접 확인하고 필요하면 변환해 주어야 합니다.

    🔨 따라하기: 학생 성적 데이터의 형태와 속성 파악하기¶

    이번 실습에서는 가상의 학생 데이터를 만들고, 각 항목의 데이터 유형과 척도를 직접 확인해 봅니다.

    Step 1: 데이터 준비하기¶

    import pandas as pd

# 가상의 학생 설문 데이터
student_data = {
    '학번': ['2025001', '2025002', '2025003', '2025004', '2025005'],
    '이름': ['김민수', '이영희', '박철수', '최지은', '정하늘'],
    '학년': [1, 2, 1, 3, 2],
    '수학점수': [85, 92, 78, 95, 88],
    '키': [172.5, 163.2, 178.0, 158.7, 175.3],
    '혈액형': ['A', 'B', 'O', 'AB', 'A'],
    '만족도': ['만족', '매우만족', '보통', '만족', '불만족']
}

df = pd.DataFrame(student_data)
print(df)

    Step 2: 데이터 타입 확인하기¶

    # 각 열의 데이터 타입 확인
print("=== 데이터 타입 ===")
print(df.dtypes)
print()

# 데이터의 기본 정보 한눈에 보기
print("=== 기본 정보 ===")
print(df.info())

    💬 생각해보기: df.dtypes 결과에서 '학번'이 object(문자열)로 나오는 이유는 무엇일까요? 앞에 0이 붙을 수 있는 번호이고, 사칙연산이 의미 없으므로 문자열로 저장하는 것이 맞습니다.

    Step 3: 수치형 데이터만 골라서 통계 살펴보기¶

    # 수치형 데이터의 기본 통계
print("=== 수치형 데이터 통계 ===")
print(df.describe())

    describe()는 수치형 열에 대해 평균, 표준편차, 최솟값, 최댓값 등을 자동으로 계산합니다. 범주형 열('이름', '혈액형' 등)은 여기에 나타나지 않습니다.

    Step 4: 범주형 데이터 분석하기¶

    # 범주형 데이터의 빈도 확인
print("=== 혈액형 빈도 ===")
print(df['혈액형'].value_counts())
print()

print("=== 만족도 빈도 ===")
print(df['만족도'].value_counts())

    Step 5: 데이터 타입 변환하기¶

    # '만족도'를 순서가 있는 범주형으로 변환
satisfaction_order = ['불만족', '보통', '만족', '매우만족']
df['만족도'] = pd.Categorical(
    df['만족도'], 
    categories=satisfaction_order, 
    ordered=True
)

print("=== 변환 후 만족도 타입 ===")
print(df['만족도'].dtype)
print()

# 순서 비교가 가능해짐!
print("만족도가 '만족' 이상인 학생:")
print(df[df['만족도'] >= '만족'][['이름', '만족도']])

    Step 6: 데이터 유형 분류표 만들기¶

    # 각 열의 유형을 직접 분류해 봅시다
analysis = {
    '열이름': ['학번', '이름', '학년', '수학점수', '키', '혈액형', '만족도'],
    '컴퓨터타입': ['object', 'object', 'int64', 'int64', 'float64', 'object', 'category'],
    '데이터유형': ['범주형', '범주형', '범주형', '수치형', '수치형', '범주형', '범주형'],
    '세부유형': ['명목형', '명목형', '순서형', '이산형', '연속형', '명목형', '순서형'],
    '척도': ['명목', '명목', '순서', '비율', '비율', '명목', '순서']
}

result = pd.DataFrame(analysis)
print("=== 데이터 유형 분류 결과 ===")
print(result.to_string(index=False))

    📌 정리하기: '학년'과 '수학점수'는 둘 다 컴퓨터에서 int64로 인식되지만, 학년은 순서형 범주, 수학점수는 비율 척도 수치입니다. 컴퓨터의 판단을 맹신하지 말고, 데이터의 의미를 생각해서 직접 분류하는 습관을 들이세요!

    ⚠️ 자주 하는 실수¶

    실수 1: "숫자 = 수치형 데이터"라고 단정짓기 🚫¶

    우편번호(04524), 전화번호(01012345678), 학번(2025001)은 모두 숫자이지만 범주형(명목형) 데이터입니다. 핵심 질문: "이 숫자를 더하거나 평균 내는 것이 의미가 있는가?" 답이 "아니오"면 범주형입니다.

    실수 2: 순서 척도에서 간격이 같다고 착각하기 🚫¶

    "매우 불만족(1) → 불만족(2) → 보통(3) → 만족(4) → 매우 만족(5)"에서 1과 2의 차이가 4와 5의 차이와 같다고 보장할 수 없습니다. 그래서 순서형 데이터의 평균을 구하는 것은 통계적으로 주의가 필요합니다.

    실수 3: dtype만 보고 데이터 유형을 판단하기 🚫¶

    pandas가 자동 인식한 int64나 float64는 컴퓨터의 저장 형식일 뿐, 데이터의 의미적 유형과 다를 수 있습니다. 위 실습에서 본 것처럼 '학년'은 int64이지만 순서형 범주입니다. 항상 "이 데이터가 현실에서 무엇을 의미하는가"를 먼저 생각하세요.

    실수 4: 구간 척도와 비율 척도를 혼동하기 🚫¶

    둘 다 숫자 간격이 동일하지만, 0의 의미가 다릅니다. 온도 0℃는 "온도가 없다"가 아니라 "물이 어는 온도"입니다(구간 척도). 반면 키 0cm는 "키가 없다"를 의미합니다(비율 척도). "0이 진짜 '없음'을 뜻하는가?"로 구분하세요.

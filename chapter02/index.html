    Chapter 02. 데이터의 형태와 속성¶

    Part 1: 데이터 과학의 이해 | 2차시

    🎯 이 장에서 배우는 것¶

    • 정형·반정형·비정형 데이터를 구분하고 각각의 예시를 들 수 있다
    • 범주형 데이터와 수치형 데이터의 차이를 설명할 수 있다
    • 수치형 데이터를 이산형과 연속형으로 나눌 수 있다
    • 주어진 데이터셋에서 각 속성의 형태를 판별할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 요리를 한다고 상상해보세요. 냉장고를 열었더니 재료가 잔뜩 있습니다. 그런데 고기, 채소, 양념이 전부 하나의 비닐봉지에 뒤섞여 있다면? 요리를 시작하기도 전에 재료를 종류별로 분류하는 것이 먼저겠죠.

    데이터도 마찬가지입니다. 세상에는 숫자, 텍스트, 사진, 영상, 표 등 다양한 형태의 데이터가 있습니다. 이 데이터들을 올바르게 분류하고 성질을 파악하는 것이 데이터 분석의 첫걸음입니다. 데이터의 형태를 모르면 어떤 분석 방법을 써야 하는지, 어떤 그래프를 그려야 하는지 결정할 수 없습니다.

    🤔 생각해보기: 인스타그램 피드를 한번 떠올려보세요. 거기에는 어떤 종류의 데이터가 있을까요? 사진, 동영상, 캡션 텍스트, 좋아요 숫자, 해시태그, 위치 정보… 이 모든 것이 서로 다른 형태의 데이터입니다!

    📚 핵심 개념¶

    개념 1: 데이터의 세 가지 형태 — 정형·반정형·비정형¶

    1. 비유로 시작 📦¶

    데이터를 짐 정리에 비유해봅시다.

    • 정형 데이터 → 칸이 나뉜 서랍장에 깔끔하게 정리된 짐. 양말은 양말 칸, 속옷은 속옷 칸에 딱딱 들어가 있습니다.
    • 반정형 데이터 → 라벨이 붙은 상자에 담긴 짐. 완벽한 서랍장은 아니지만, 상자마다 "겨울옷", "여름옷" 같은 태그(이름표)가 있어서 어느 정도 구조를 파악할 수 있습니다.
    • 비정형 데이터 → 바닥에 흩어진 짐. 사진, 편지, 인형 등 형태도 크기도 다 다릅니다.

    2. 정확한 정의 📖¶

    정형 데이터(Structured Data)는 행(가로)과 열(세로)로 이루어진 표(테이블) 형태로 깔끔하게 정리된 데이터입니다. 엑셀 스프레드시트나 데이터베이스가 대표적입니다.

    반정형 데이터(Semi-structured Data)는 표처럼 딱 떨어지지는 않지만, 태그(tag)나 키(key) 같은 구조적 요소를 가진 데이터입니다. JSON, XML, HTML 파일이 여기에 해당합니다.

    비정형 데이터(Unstructured Data)는 정해진 구조가 없는 데이터입니다. 텍스트 문서, 이미지, 음성, 동영상 등이 이에 해당합니다. 전체 데이터의 약 80% 이상이 비정형 데이터라고 알려져 있습니다.

    3. 예시로 확인 👀¶

    graph TD A["🗂️ 데이터의 형태"] --> B["📊 정형 데이터"] A --> C["🏷️ 반정형 데이터"] A --> D["🎨 비정형 데이터"] B --> B1["엑셀 성적표"] B --> B2["출석부"] B --> B3["수강신청 DB"] C --> C1["JSON 파일"] C --> C2["XML 문서"] C --> C3["웹페이지 HTML"] D --> D1["셀카 사진"] D --> D2["유튜브 영상"] D --> D3["카톡 음성메시지"]

    📌 알아보기: JSON이란 무엇일까요?

    JSON(JavaScript Object Notation)은 데이터를 "키": "값" 쌍으로 저장하는 형식입니다. 예를 들어 한 학생의 정보를 JSON으로 표현하면 이렇습니다: 

    {
  "이름": "김하늘",
  "나이": 17,
  "취미": ["독서", "게임", "음악감상"]
}
    표처럼 딱딱하진 않지만, "이름", "나이" 같은 키(key) 덕분에 어떤 정보인지 알 수 있죠. 그래서 반(半)정형이라고 부릅니다.

    개념 2: 수치형 데이터 vs 범주형 데이터¶

    1. 비유로 시작 🎒¶

    학교에서 친구의 프로필 카드를 만든다고 해봅시다.

    • "키 172cm, 몸무게 58kg" → 이건 숫자로 측정한 값이고, 더하거나 빼거나 평균을 구할 수 있습니다.
    • "혈액형 A형, 좋아하는 색 파란색" → 이건 카테고리(범주) 를 나타내는 값이고, 평균을 구한다는 건 말이 안 됩니다. ("A형 + B형 = AB형"이 아니잖아요! 😄)

    2. 정확한 정의 📖¶

    수치형 데이터(Numerical Data) 는 숫자로 표현되며 수학적 연산(덧셈, 평균 등)이 의미 있는 데이터입니다.

    범주형 데이터(Categorical Data) 는 몇 개의 범주(카테고리) 로 나뉘며, 숫자를 부여하더라도 수학적 연산이 의미 없는 데이터입니다.

    ⚡ 핵심 구분법: "이 숫자들의 평균을 구하면 의미가 있는가?"를 물어보세요. 의미가 있으면 수치형, 없으면 범주형입니다.

    3. 예시로 확인 👀¶

    수치형 데이터의 예 - 키(cm), 몸무게(kg), 시험 점수, 기온, 연봉, 하루 걸음 수

    범주형 데이터의 예 - 혈액형(A/B/O/AB), 성별, 학과, 좋아하는 음식, 휴대폰 브랜드

    🤔 생각해보기: "학번 20250101"은 숫자처럼 보이지만, 학번의 평균을 구하면 의미가 있을까요? 아닙니다! 학번은 학생을 구분하기 위한 식별자일 뿐이므로 범주형에 가깝습니다. 이처럼 숫자라고 무조건 수치형이 아닙니다!

    개념 3: 수치형 데이터의 세분화 — 이산형과 연속형¶

    1. 비유로 시작 🎯¶

    • 이산형 → 계단: 한 칸, 두 칸… 딱딱 끊어지는 값만 존재합니다.
    • 연속형 → 경사로(슬로프): 어떤 지점이든 값이 존재할 수 있습니다. 1.5도, 1.53도, 1.534도…

    2. 정확한 정의 📖¶

    이산형 데이터(Discrete Data) 는 셀 수 있는 값으로, 정수처럼 딱 떨어지는 값을 가집니다. - 예: 형제 수(0명, 1명, 2명…), 반 학생 수, 인스타 팔로워 수

    연속형 데이터(Continuous Data) 는 측정 가능한 값으로, 소수점 이하 무한히 세밀한 값을 가질 수 있습니다. - 예: 키(172.3cm), 몸무게(58.45kg), 기온(23.7°C)

    3. 예시로 확인 👀¶

    graph TD N["🔢 수치형 데이터"] --> D["이산형<br/>Discrete"] N --> C["연속형<br/>Continuous"] D --> D1["🎲 주사위 눈: 1,2,3,4,5,6"] D --> D2["👨‍👩‍👧‍👦 형제 수: 0,1,2,3..."] D --> D3["📱 앱 다운로드 수"] C --> C1["📏 키: 165.3cm"] C --> C2["🌡️ 체온: 36.52°C"] C --> C3["⏱️ 100m 달리기: 11.23초"]

    개념 4: 범주형 데이터의 세분화 — 명목형과 순서형¶

    1. 비유로 시작 🏅¶

    • 명목형 → 사물함 번호: 1번, 2번, 3번… 번호에 순서의 의미가 있을까요? 1번이 2번보다 "낫다"거나 "크다"는 의미가 없습니다. 그냥 이름표일 뿐입니다.
    • 순서형 → 영화 별점: ⭐1점, ⭐⭐2점, ⭐⭐⭐3점. 3점이 1점보다 "더 좋다"는 의미가 있습니다. 순서(대소 관계)가 존재합니다.

    2. 정확한 정의 📖¶

    명목형 데이터(Nominal Data) 는 범주 사이에 순서나 크기 관계가 없는 데이터입니다. - 예: 혈액형, 성별, 좋아하는 색, 사는 지역

    순서형 데이터(Ordinal Data) 는 범주 사이에 순서(등급)가 있는 데이터입니다. 다만, 간격이 균등하지는 않습니다. - 예: 학점(A > B > C), 만족도(매우 만족 > 만족 > 보통 > 불만족), 교육 수준(대학원 > 대학 > 고등학교)

    3. 예시로 확인 👀¶

    graph TD Cat["🏷️ 범주형 데이터"] --> Nom["명목형<br/>Nominal"] Cat --> Ord["순서형<br/>Ordinal"] Nom --> N1["🩸 혈액형: A, B, O, AB"] Nom --> N2["📱 통신사: SKT, KT, LGU+"] Ord --> O1["⭐ 별점: 1~5점"] Ord --> O2["🏆 등급: 금/은/동"]

    📌 정리하기: 데이터 유형의 전체 구조를 한눈에 봅시다!

    graph LR A["📦 데이터"] --> B["🔢 수치형"] A --> C["🏷️ 범주형"] B --> B1["이산형<br/>형제 수, 골 수"] B --> B2["연속형<br/>키, 몸무게, 온도"] C --> C1["명목형<br/>혈액형, 성별"] C --> C2["순서형<br/>학점, 별점"]

    🔨 따라하기: K-POP 아이돌 프로필 데이터 탐색¶

    이제 Google Colab에서 실제 데이터를 만들고, 각 열(속성)의 데이터 형태를 판별해봅시다!

    Step 1: 데이터 준비하기 🎤¶

    K-POP 아이돌의 가상 프로필 데이터를 직접 만들어봅니다. pandas 라이브러리의 DataFrame을 사용합니다.

    import pandas as pd

    pandas에서 dtypes 속성을 사용하면 각 열의 데이터 타입을 확인할 수 있습니다.

    Step 3: 우리가 직접 데이터 형태를 분류하기 🧠¶

    여기서 중요한 포인트! 컴퓨터가 인식하는 타입(dtype)과 데이터의 실제 형태는 다를 수 있습니다.

    # 우리가 분류한 데이터 형태를 정리해봅시다
classification = {
    '열 이름': ['이름', '그룹', '키(cm)', '나이', '혈액형', '인스타팔로워(만)', '매력도(1~5)'],
    'dtype': ['object', 'object', 'float64', 'int64', 'object', 'int64', 'int64'],
    '수치/범주': ['범주형', '범주형', '수치형', '수치형', '범주형', '수치형', '범주형'],
    '세부분류': ['명목형', '명목형', '연속형', '이산형', '명목형', '이산형', '순서형']
}

result = pd.DataFrame(classification)
print(result)

    실행 결과: 

              열 이름    dtype 수치/범주 세부분류

3          나이    int64   수치형   이산형
4         혈액형   object   범주형   명목형

    ⚡ 주목! 매력도(1~5)는 컴퓨터가 int64(정수)로 인식했지만, 실제로는 순서형 범주 데이터입니다. 1~5의 숫자는 "등급"을 나타낼 뿐, "매력도 5 - 매력도 4 = 매력도 1"이라는 연산은 의미가 없습니다. 숫자라고 무조건 수치형이 아니라는 것, 꼭 기억하세요!

    ⚠️ 자주 하는 실수¶

    실수 1: "숫자면 무조건 수치형이다" 🚫

    전화번호 010-1234-5678, 우편번호 06236, 학번 20250101… 전부 숫자이지만 범주형(명목형) 입니다. 핵심 질문: "이 숫자들의 평균을 구하면 의미가 있는가?" 의미 없으면 범주형입니다.

    실수 2: "순서형과 이산형을 혼동한다" 🚫

    별점 1~5점은 숫자이고 순서도 있지만, 순서형 범주 데이터입니다. "5점 - 3점 = 2점"이라는 연산이 실질적 의미가 없기 때문입니다. 반면 "형제 3명 - 1명 = 2명"은 의미가 있으므로 이산형 수치 데이터입니다.

    실수 3: "dtype만 보고 데이터 형태를 판단한다" 🚫

    pandas의 dtype은 컴퓨터가 저장하는 방식일 뿐, 데이터의 의미적 분류와 다를 수 있습니다. 매력도(1~5)가 int64로 표시되어도 실제로는 순서형 범주입니다. 항상 데이터의 의미를 먼저 생각하세요.

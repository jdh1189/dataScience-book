    Chapter 2. 데이터의 형태와 속성¶

    🎯 이 장에서 배우는 것¶

    • 정형·반정형·비정형 데이터의 차이를 예시와 함께 구별할 수 있다
    • 범주형 데이터와 수치형 데이터를 구분하고 각각의 활용 상황을 설명할 수 있다
    • Python pandas로 데이터프레임의 컬럼 타입을 확인하고 변환할 수 있다
    • 실생활에서 접하는 데이터를 형태별로 분류할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    인스타그램 사진, 급식 메뉴표, 시험 성적표—이 셋은 모두 데이터일까요?

    정답부터 말하면, 셋 다 데이터입니다. 하지만 이 세 가지 데이터는 생김새가 완전히 다릅니다. 시험 성적표는 깔끔한 표로 정리되어 있고, 급식 메뉴표는 날짜·메뉴·영양소 정보가 일정한 형식으로 적혀 있습니다. 반면 인스타그램 사진은 표로 정리할 수 없는 이미지 파일이죠.

    데이터를 분석하려면 "이 데이터가 어떤 형태이고, 어떤 속성을 가지고 있는가?" 를 먼저 파악해야 합니다. 요리를 하기 전에 재료가 고기인지 채소인지 확인하는 것처럼, 데이터 분석의 첫 단계는 데이터의 정체를 파악하는 것입니다.

    이번 장에서는 데이터를 형태와 속성 두 가지 관점에서 분류하는 방법을 배웁니다. 이것을 알면 앞으로 어떤 데이터를 만나더라도 "아, 이건 이런 종류의 데이터니까 이렇게 다루면 되겠구나!" 하고 판단할 수 있게 됩니다.

    📚 핵심 개념¶

    개념 1: 데이터의 세 가지 형태 — 정형·반정형·비정형¶

    1. 비유로 시작 🏠¶

    데이터의 형태를 방 정리에 비유해 봅시다.

    • 정형 데이터 = 🗄️ 서랍장에 정리된 옷: 양말은 양말 칸, 셔츠는 셔츠 칸. 모든 것이 정해진 자리에 있어서 원하는 걸 바로 찾을 수 있습니다.
    • 반정형 데이터 = 🏷️ 이름표가 붙은 상자들: 상자마다 크기와 모양이 다르지만, 이름표(태그)가 있어서 뭐가 들었는지 알 수 있습니다.
    • 비정형 데이터 = 🎒 뒤죽박죽 가방 안: 이어폰, 영수증, 과자 부스러기가 섞여 있어서 하나하나 꺼내 확인해야 합니다.

    2. 정확한 정의 📖¶

    정형 데이터(Structured Data)

    행(row)과 열(column)로 이루어진 표(table) 형식의 데이터입니다. 엑셀 스프레드시트나 데이터베이스 테이블이 대표적입니다. 각 열은 이름과 데이터 타입이 정해져 있고, 모든 행은 같은 구조를 따릅니다.

    반정형 데이터(Semi-structured Data)

    표 형식은 아니지만, 태그(tag)나 키(key) 같은 구조적 요소를 가진 데이터입니다. JSON, XML, HTML 파일이 대표적입니다. 일정한 규칙은 있지만, 행마다 포함하는 정보의 종류나 개수가 다를 수 있습니다.

    비정형 데이터(Unstructured Data)

    정해진 구조 없이 자유로운 형태로 존재하는 데이터입니다. 텍스트 문서, 이미지, 동영상, 음성 파일 등이 해당됩니다. 전체 데이터의 약 80% 이상이 비정형 데이터라고 알려져 있습니다.

    3. 예시로 확인 ✅¶

    graph TB A["🗂️ 데이터의 형태"] A --> B["📊 정형 데이터"] A --> C["🏷️ 반정형 데이터"] A --> D["🎨 비정형 데이터"] B --> B1["시험 성적표 (엑셀)"] B --> B2["출석부 (데이터베이스)"] B --> B3["급식 영양 정보 (CSV)"] C --> C1["급식 메뉴 (JSON)"] C --> C2["웹페이지 (HTML)"] C --> C3["이메일 (XML)"] D --> D1["인스타그램 사진"] D --> D2["유튜브 동영상"] D --> D3["카카오톡 대화"]

    알아보기 📌

    우리 학교에서 만나는 데이터 예시

    • 정형: 수행평가 점수표, 학생 인적사항, 도서관 대출 기록
    • 반정형: 학교 홈페이지(HTML), 나이스(NEIS) API 응답(JSON)
    • 비정형: 교실 CCTV 영상, 선생님 수업 녹음, 학생 자유 에세이

    개념 2: 데이터의 속성 — 범주형 vs 수치형¶

    1. 비유로 시작 🎯¶

    편의점에서 아르바이트한다고 상상해 봅시다.

    • 범주형 데이터 = 상품의 카테고리 분류: "음료", "과자", "도시락"처럼 이름으로 구분하는 것
    • 수치형 데이터 = 상품의 가격, 무게, 재고 수량: 숫자로 크기를 비교하고 계산할 수 있는 것

    핵심 차이는 이것입니다: 그 숫자로 덧셈·뺄셈을 할 수 있는가?

    2. 정확한 정의 📖¶

    범주형 데이터(Categorical Data)

    값이 카테고리(그룹) 를 나타내는 데이터입니다. 더하거나 평균을 내는 것이 의미 없습니다. 범주형 데이터는 다시 두 가지로 나뉩니다.

    • 명목형(Nominal): 순서가 없는 범주. 예) 혈액형(A, B, O, AB), 좋아하는 과목(수학, 영어, 과학)
    • 순서형(Ordinal): 순서가 있는 범주. 예) 학년(1학년 < 2학년 < 3학년), 만족도(불만족 < 보통 < 만족)

    수치형 데이터(Numerical Data)

    값이 수량을 나타내며, 사칙연산이 가능한 데이터입니다. 수치형 데이터도 두 가지로 나뉩니다.

    • 이산형(Discrete): 셀 수 있는 정수. 예) 가족 수(3명), 과목 수(8과목)
    • 연속형(Continuous): 연속적인 실수. 예) 키(168.5cm), 몸무게(55.2kg), 기온(23.7℃)

    3. 예시로 확인 ✅¶

    graph TB A["📋 데이터의 속성"] A --> B["🏷️ 범주형 데이터<br/>카테고리를 나타냄"] A --> C["🔢 수치형 데이터<br/>수량을 나타냄"] B --> B1["명목형 (Nominal)<br/>순서 없음<br/>예: 혈액형, 성별"] B --> B2["순서형 (Ordinal)<br/>순서 있음<br/>예: 학년, 등급"] C --> C1["이산형 (Discrete)<br/>셀 수 있음<br/>예: 인원수, 횟수"] C --> C2["연속형 (Continuous)<br/>연속적 측정<br/>예: 키, 몸무게"]

    생각해보기 🤔

    "학번 20301"은 수치형 데이터일까요, 범주형 데이터일까요?

    숫자로 되어 있지만, 학번끼리 더하거나 평균을 내는 것은 의미가 없죠. "20301 + 20302 = 40603"은 아무 의미도 없습니다! 따라서 학번은 범주형 데이터(명목형) 입니다.

    이처럼 숫자라고 무조건 수치형이 아닙니다. 전화번호, 우편번호, 주민번호 등도 모두 범주형입니다.

    개념 3: 정형 데이터의 구조 — 행, 열, 값¶

    정형 데이터는 데이터프레임(DataFrame) 이라는 2차원 표 구조로 다룹니다. 이 구조를 이해하는 것이 데이터 분석의 기본입니다.

    1. 비유로 시작 📋¶

    교실의 좌석 배치표를 떠올려 보세요.

    • 행(Row) = 학생 한 명의 정보 (1번 김철수의 모든 정보)
    • 열(Column) = 정보의 종류 (이름, 성별, 키, 몸무게...)
    • 값(Value) = 특정 학생의 특정 정보 (김철수의 키 = 172cm)

    2. 정확한 정의 📖¶

    • 행(Row): 관측값(observation) 하나를 의미합니다. "레코드(record)"라고도 부릅니다.
    • 열(Column): 변수(variable) 하나를 의미합니다. "피처(feature)" 또는 "속성(attribute)"이라고도 부릅니다.
    • 값(Value): 특정 행과 특정 열이 만나는 지점의 데이터입니다.

    3. 예시로 확인 ✅¶

    학교 급식 영양 데이터를 예로 들어 봅시다.

    graph LR subgraph 데이터프레임 구조 direction TB A["열(Column) = 변수<br/>날짜 | 메뉴 | 칼로리 | 단백질"] B["행(Row) = 관측값<br/>2024-03-04 | 비빔밥 | 650 | 18.5<br/>2024-03-05 | 돈까스 | 780 | 25.3<br/>2024-03-06 | 김치찌개 | 520 | 15.8"] end C["값(Value)<br/>예: 650은<br/>비빔밥의 칼로리"] B --> C

    여기서 각 열의 데이터 속성을 구분하면 이렇습니다.

    • 날짜: 범주형 또는 날짜형(특수)
    • 메뉴: 범주형(명목형) — 메뉴 이름은 카테고리
    • 칼로리: 수치형(연속형) — 숫자로 계산 가능
    • 단백질: 수치형(연속형) — 숫자로 계산 가능

    개념 4: pandas의 데이터 타입(dtype)¶

    Python의 pandas 라이브러리는 각 열에 데이터 타입(dtype) 을 자동으로 지정합니다. 이 dtype을 이해하면 데이터를 올바르게 다룰 수 있습니다.

    1. 비유로 시작 🎪¶

    스마트폰에서 파일을 열 때, 확장자에 따라 다른 앱이 실행되죠?

    • .mp3 → 음악 앱
    • .jpg → 갤러리 앱
    • .pdf → 문서 뷰어

    pandas의 dtype도 마찬가지입니다. 데이터 타입에 따라 pandas가 다른 방식으로 데이터를 처리합니다.

    2. 정확한 정의 📖¶

    pandas에서 자주 만나는 주요 dtype은 다음과 같습니다.

    • int64: 정수형 — 소수점 없는 숫자 (예: 1, 42, -7)
    • float64: 실수형 — 소수점 있는 숫자 (예: 3.14, 98.6)
    • object: 문자열 — 텍스트 데이터 (예: "비빔밥", "서울")
    • bool: 불리언 — 참/거짓 (True, False)
    • category: 범주형 — 제한된 종류의 값 (명시적으로 변환 필요)

    3. 예시로 확인 ✅¶

    알아보기 📌

    dtype이 왜 중요할까요?

    pandas는 dtype에 따라 연산 방식을 결정합니다. 예를 들어, 칼로리 열이 object(문자열)로 인식되면 평균을 구할 수 없습니다. "650"이라는 숫자가 문자로 저장되어 있기 때문이죠. 이럴 때는 dtype을 float64로 변환해야 합니다.

    정리하기 📝

    이 장의 네 가지 핵심 개념

    1️⃣ 데이터의 형태: 정형(표) / 반정형(태그) / 비정형(자유형)

    2️⃣ 데이터의 속성: 범주형(카테고리) / 수치형(수량)

    3️⃣ 정형 데이터의 구조: 행(관측값) × 열(변수) = 값

    4️⃣ pandas dtype: 컴퓨터가 데이터를 인식하는 방식 (int64, float64, object, category 등)

    🔨 따라하기¶

    이제 Google Colab에서 직접 데이터를 다뤄봅시다! 학교 급식 영양 데이터를 만들고, 데이터 타입을 확인하고, 변환하는 실습을 진행합니다.

    Step 1: 급식 영양 데이터 만들기¶

    먼저 실습용 급식 데이터를 직접 만들어 보겠습니다.

    # pandas 라이브러리 불러오기
import pandas as pd

# 급식 영양 데이터 만들기
data = {
    '날짜': ['2024-03-04', '2024-03-05', '2024-03-06', '2024-03-07', '2024-03-08'],
    '메뉴': ['비빔밥', '돈까스', '김치찌개', '스파게티', '제육볶음'],
    '칼로리': [650, 780, 520, 710, 690],
    '단백질_g': [18.5, 25.3, 15.8, 20.1, 28.7],
    '만족도': ['보통', '만족', '불만족', '만족', '만족'],
    '잔반량_kg': ['2.1', '0.8', '3.5', '1.2', '0.5']
}

df = pd.DataFrame(data)
print(df)

    Step 3: 잘못된 데이터 타입 변환하기¶

    잔반량_kg이 문자열(object)로 되어 있으니, 실수형(float64)으로 바꿔야 평균 등을 계산할 수 있습니다.

    # 잔반량_kg을 실수형으로 변환
df['잔반량_kg'] = df['잔반량_kg'].astype(float)

# 변환 확인
print(df.dtypes)
print()
print(f"잔반량 평균: {df['잔반량_kg'].mean():.1f} kg")

    알아보기 📌

    astype() 메서드는 데이터 타입을 변환하는 핵심 도구입니다.

    • df['열이름'].astype(int) → 정수형으로 변환
    • df['열이름'].astype(float) → 실수형으로 변환
    • df['열이름'].astype(str) → 문자열로 변환
    • df['열이름'].astype('category') → 범주형으로 변환

    Step 4: 범주형 데이터로 변환하기¶

    만족도 열은 "불만족 < 보통 < 만족"이라는 순서가 있는 순서형 범주 데이터입니다. 이것을 pandas의 category 타입으로 변환하면 메모리도 절약되고, 순서 정보도 활용할 수 있습니다.

    # 만족도를 순서가 있는 범주형으로 변환
satisfaction_order = pd.CategoricalDtype(
    categories=['불만족', '보통', '만족'], 
    ordered=True  # 순서가 있음을 명시
)

df['만족도'] = df['만족도'].astype(satisfaction_order)

# 변환 확인
print(df.dtypes)
print()
print(df['만족도'])

    데이터프레임에서 특정 타입의 열만 골라내는 방법도 알아두면 유용합니다.

    # 수치형 열만 선택
numeric_cols = df.select_dtypes(include=['int64', 'float64'])
print("🔢 수치형 열:")
print(numeric_cols.columns.tolist())
print(numeric_cols)
print()

# 범주형/문자열 열만 선택
category_cols = df.select_dtypes(include=['object', 'category'])
print("🏷️ 범주형/문자열 열:")
print(category_cols.columns.tolist())
print(category_cols)

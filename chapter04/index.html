    📊 Chapter 4. 세상을 바꾸는 데이터 과학¶

    Part 1: [1권] 데이터 과학의 이해 | 4차시 | ⏱️ 약 2시간

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 데이터 과학이 무엇인지 자신의 말로 설명할 수 있다
    • 데이터 과학이 실생활에서 어떻게 활용되는지 3가지 이상 예를 들 수 있다
    • 데이터 수집 → 분석 → 시각화의 기본 흐름을 코드로 실행할 수 있다
    • 간단한 데이터셋을 불러와 의미 있는 정보를 발견할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 오늘 아침에도 이미 데이터 과학의 혜택을 받았습니다.

    🌅 여러분의 하루를 떠올려 보세요.

    알람 앱이 수면 패턴을 분석해 가장 개운한 시점에 깨워주고, 날씨 앱이 수천 개의 기상 관측 데이터를 분석해 "오늘 오후 비 올 확률 80%"라고 알려줍니다. 등교 길에 음악 앱은 내 취향을 분석해 새로운 노래를 추천하고, SNS는 내가 좋아할 만한 게시물을 골라 보여줍니다.

    이 모든 것의 뒤에는 데이터 과학이 있습니다.

    데이터 과학은 이제 특정 전문가만의 영역이 아닙니다. 의사는 환자 데이터를 분석해 질병을 조기에 발견하고, 농부는 토양·기후 데이터로 수확량을 예측하며, 운동선수는 경기 데이터를 분석해 전략을 세웁니다. 어떤 분야를 선택하든, 데이터를 읽고 해석하는 능력은 여러분의 강력한 무기가 될 것입니다.

    이번 장에서는 데이터 과학의 큰 그림을 이해하고, 직접 데이터를 다뤄보며 "아, 데이터에서 이런 걸 발견할 수 있구나!"라는 경험을 해보겠습니다.

    📚 핵심 개념¶

    개념 1: 데이터 과학이란?¶

    🎨 비유로 시작하기

    거대한 퍼즐 상자를 상상해 보세요. 수천, 수만 조각의 퍼즐이 뒤섞여 있습니다. 각 조각만 봐서는 무슨 그림인지 전혀 알 수 없죠. 하지만 조각들을 정리하고, 분류하고, 맞춰 나가면 숨겨진 멋진 그림이 드러납니다.

    데이터 과학은 바로 이 과정입니다. 세상에 흩어진 수많은 데이터 조각에서 의미 있는 패턴과 지식을 찾아내는 것이죠.

    📖 정확한 정의

    데이터 과학(Data Science) 이란, 다양한 형태의 데이터를 수집·정리·분석·시각화하여 유용한 정보와 지식을 발견하고, 이를 바탕으로 더 나은 의사결정을 내리는 학문입니다.

    데이터 과학은 세 가지 영역이 만나는 곳에 존재합니다.

    graph TD A["🔢 수학·통계<br/>패턴을 찾는 도구"] --> D["⭐ 데이터 과학"] B["💻 컴퓨터 과학<br/>대량 데이터 처리 능력"] --> D C["🏢 분야 전문지식<br/>의미 있는 질문을 던지는 힘"] --> D style D fill:#FFD700,stroke:#333,stroke-width:3px,color:#333 style A fill:#87CEEB,stroke:#333,color:#333 style B fill:#98FB98,stroke:#333,color:#333 style C fill:#FFB6C1,stroke:#333,color:#333

    ✅ 예시로 확인

    • 수학·통계: "이 반 학생들의 평균 키는 165cm이고, 대부분 160~170cm 사이에 있어"
    • 컴퓨터 과학: "전교생 1,000명의 키 데이터를 프로그램으로 1초 만에 계산할 수 있어"
    • 분야 전문지식: "청소년기에 키 성장이 빠르니까, 학년별로 나눠서 분석하면 더 의미 있겠다"

    이 세 가지가 합쳐질 때 진정한 데이터 과학이 됩니다!

    개념 2: 데이터 과학의 작업 흐름¶

    🎨 비유로 시작하기

    요리를 할 때를 생각해 보세요. 재료를 사 오고(수집) → 씻고 다듬고(정리) → 볶고 끓이고(분석) → 예쁘게 담아내고(시각화) → 맛을 보고 레시피를 기록합니다(인사이트 도출). 데이터 과학도 정확히 이런 순서로 진행됩니다.

    📖 정확한 정의

    graph LR A["1️⃣ 질문 정의<br/>무엇을 알고 싶은가?"] --> B["2️⃣ 데이터 수집<br/>필요한 데이터 모으기"] B --> C["3️⃣ 데이터 정리<br/>오류 제거, 형태 통일"] C --> D["4️⃣ 데이터 분석<br/>통계·패턴 발견"] D --> E["5️⃣ 시각화·전달<br/>그래프로 보여주기"] E --> F["6️⃣ 의사결정<br/>행동으로 옮기기"] style A fill:#E8F5E9,stroke:#333,color:#333 style B fill:#E3F2FD,stroke:#333,color:#333 style C fill:#FFF3E0,stroke:#333,color:#333 style D fill:#F3E5F5,stroke:#333,color:#333 style E fill:#FCE4EC,stroke:#333,color:#333 style F fill:#FFFDE7,stroke:#333,color:#333

    ✅ 예시로 확인 — "우리 반 간식 선호도 조사"

    • 1️⃣ 질문 정의: "학교 축제에서 어떤 간식 부스를 열면 가장 인기 있을까?"
    • 2️⃣ 데이터 수집: 반 친구 30명에게 좋아하는 간식 설문조사
    • 3️⃣ 데이터 정리: "떡볶이"와 "떡뽁이"를 같은 것으로 통일, 빈 응답 처리
    • 4️⃣ 데이터 분석: 간식별 응답 수 세기, 가장 인기 있는 간식 찾기
    • 5️⃣ 시각화: 막대그래프로 한눈에 보기
    • 6️⃣ 의사결정: "떡볶이 부스를 열자!"

    📌 알아보기: 이 6단계 중 실무에서 가장 많은 시간이 걸리는 단계는 무엇일까요? 바로 3단계 데이터 정리입니다! 전체 작업 시간의 60~80%를 차지한다고 합니다. 현실의 데이터는 빈칸, 오타, 중복 등이 가득하기 때문이죠.

    개념 3: 데이터 과학이 바꾸는 세상¶

    🎨 비유로 시작하기

    과거에 의사는 환자의 증상만 보고 진단했습니다. 마치 어두운 방에서 손전등 하나로 물건을 찾는 것과 같았죠. 하지만 데이터 과학은 방 전체에 불을 켜는 것과 같습니다. 수십만 명의 환자 기록, 유전자 정보, 생활 습관 데이터를 한꺼번에 분석해서 훨씬 정확한 진단을 내릴 수 있게 해줍니다.

    📖 분야별 활용 사례

    mindmap root(("🌍 데이터 과학의<br/>활용 분야")) 🏥 의료·건강 질병 조기 발견 신약 개발 맞춤형 치료 🎵 엔터테인먼트 음악·영상 추천 게임 밸런스 조정 흥행 예측 🌱 환경·농업 기후 변화 예측 스마트 농업 자연재해 조기 경보 🏫 교육 학습 패턴 분석 맞춤형 교육 학습 효과 측정

    ✅ 구체적 사례로 확인

    • 넷플릭스: 2억 명 이상의 시청 데이터를 분석해 추천 알고리즘을 만듭니다. 여러분이 보는 콘텐츠의 80%가 이 추천을 통해 선택된다고 합니다!
    • 기상청: 전국 수백 개 관측소의 온도·습도·기압·풍속 데이터를 실시간으로 수집·분석해 날씨를 예보합니다
    • 스포츠: 야구에서 타자의 타격 각도, 공의 회전수, 주자의 스피드 등을 분석해 전략을 세웁니다 (영화 〈머니볼〉의 실화!)

    💭 생각해보기: 여러분이 관심 있는 분야에서 데이터 과학이 어떻게 활용될 수 있을지 한 가지만 상상해 보세요.

    개념 4: 데이터 과학의 핵심 도구 — Python¶

    🎨 비유로 시작하기

    목수에게 망치와 톱이 있듯, 데이터 과학자에게는 Python(파이썬) 이 있습니다. Python은 쉬운 문법으로 데이터를 수집하고, 분석하고, 시각화하는 모든 과정을 한 곳에서 할 수 있는 강력한 도구입니다.

    📖 데이터 과학에서 사용하는 주요 Python 라이브러리

    graph TD P["🐍 Python"] --> A["📊 pandas<br/>데이터 정리·분석"] P --> B["📈 matplotlib<br/>그래프·차트 그리기"] P --> C["🔢 numpy<br/>수학·통계 계산"] A --> D["표 형태로 데이터 다루기<br/>엑셀과 비슷하지만 더 강력!"] B --> E["막대그래프, 선그래프,<br/>원그래프 등 시각화"] C --> F["평균, 합계, 표준편차 등<br/>빠른 수치 계산"] style P fill:#306998,stroke:#333,color:#fff style A fill:#E8F5E9,stroke:#333,color:#333 style B fill:#E3F2FD,stroke:#333,color:#333 style C fill:#FFF3E0,stroke:#333,color:#333

    ✅ 예시로 확인 — 첫 만남

    # 데이터 과학의 3대 도구 불러오기
import pandas as pd          # 데이터 정리·분석
import matplotlib.pyplot as plt  # 시각화
import numpy as np            # 수학 계산

print("데이터 과학 도구 준비 완료! 🎉")

    📌 알아보기: import는 "도구 상자에서 도구를 꺼내온다"는 뜻입니다. as pd는 "앞으로 pandas를 pd라는 짧은 이름으로 부르겠다"는 약속이에요. 매번 긴 이름을 쓰면 힘드니까요!

    🔨 따라하기: 우리 반 시험 성적 분석하기¶

    이제 직접 데이터 과학의 전체 흐름을 체험해 봅시다. 가상의 "우리 반 시험 성적" 데이터를 만들고, 분석하고, 시각화해 보겠습니다.

    Step 1: 데이터 만들기 (수집 단계)¶

    현실에서는 설문, 센서, 웹사이트 등에서 데이터를 수집하지만, 지금은 직접 만들어 보겠습니다.

    import pandas as pd

# 우리 반 학생들의 시험 성적 데이터 만들기
data = {
    '이름': ['민수', '지영', '현우', '서연', '태호', '수빈', '준서', '하은'],
    '국어': [85, 92, 78, 95, 88, 76, 90, 82],
    '수학': [90, 88, 95, 82, 76, 92, 85, 78],
    '영어': [82, 95, 80, 90, 85, 88, 78, 92]
}

# 데이터프레임(표) 만들기
df = pd.DataFrame(data)
print(df)

    • min/max: 최저점과 최고점

    Step 3: 데이터 분석하기¶

    이제 좀 더 깊이 들어가 봅시다. 각 학생의 총점과 평균을 구해보겠습니다.

    # 총점과 평균 계산
df['총점'] = df['국어'] + df['수학'] + df['영어']

# 평균 기준으로 정렬 (높은 순)
df_sorted = df.sort_values('평균', ascending=False)
print("=== 성적 순위 ===")
print(df_sorted[['이름', '총점', '평균']])

    📌 정리하기

    • 데이터 과학 = 데이터에서 의미 있는 지식을 발견하는 학문
    • 작업 흐름: 질문 → 수집 → 정리 → 분석 → 시각화 → 의사결정
    • 핵심 도구: Python + pandas(정리) + matplotlib(시각화)
    • 데이터 과학은 의료, 교육, 환경, 엔터테인먼트 등 거의 모든 분야에서 활용됨

    다음 장에서는 데이터를 더 깊이 다루기 위한 데이터 전처리와 탐색적 데이터 분석(EDA) 을 배웁니다. 현실의 데이터는 오늘 다룬 것처럼 깔끔하지 않습니다. 빈 값, 이상한 값, 중복 데이터 등 온갖 문제가 가득하죠. 이런 "지저분한" 데이터를 분석 가능한 상태로 만드는 기술을 익혀 보겠습니다! 🧹✨

    Chapter 4. 세상을 바꾸는 데이터 과학¶

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 의료·환경·스포츠·문화 분야에서 데이터 과학이 활용되는 실제 사례를 3가지 이상 설명할 수 있다.
    • 추천 시스템의 기본 원리를 이해하고, 간단한 영화 평점 데이터를 탐색할 수 있다.
    • 데이터 과학의 윤리적 쟁점(개인정보 보호, 알고리즘 편향)을 이해하고 자신의 의견을 표현할 수 있다.
    • 데이터 과학이 자신의 진로·관심 분야에 어떻게 연결되는지 탐색하고 아이디어를 정리할 수 있다.

    💡 왜 이걸 배우나요?¶

    넷플릭스는 어떻게 내가 좋아할 영화를 알까?¶

    금요일 저녁, 넷플릭스를 켰더니 화면 맨 위에 "OO님을 위한 추천" 이라는 목록이 뜹니다. 신기하게도 거기 있는 영화들이 정말 내 취향입니다. 어떻게 이런 일이 가능할까요?

    비밀은 바로 데이터에 있습니다. 넷플릭스는 전 세계 2억 명이 넘는 사용자가 어떤 영화를 봤는지, 언제 멈췄는지, 어떤 장면을 되감기했는지까지 모두 기록합니다. 이 엄청난 데이터를 분석해서 "이 사람은 다음에 이 영화를 좋아할 확률이 높다" 고 예측하는 것이죠.

    이것이 바로 데이터 과학의 힘입니다.

    🤔 생각해보기: 오늘 하루 동안 여러분이 만든 데이터는 무엇이 있을까요? 스마트폰 검색 기록, 카드 결제 내역, SNS 좋아요, 걸음 수… 우리는 매일 수백 개의 데이터를 만들어내고 있습니다.

    데이터 과학은 더 이상 과학자들만의 이야기가 아닙니다. 의사가 환자를 진단할 때, 기상청이 태풍 경로를 예측할 때, 축구 감독이 선수를 선발할 때, 심지어 작곡가가 히트곡을 만들 때도 데이터 과학이 활용됩니다. 이번 장에서는 데이터 과학이 세상의 다양한 분야를 어떻게 바꾸고 있는지 생생한 사례와 함께 알아보겠습니다.

    📚 핵심 개념¶

    개념 1: 데이터 과학의 실제 활용 — 의료 분야 🏥¶

    1. 비유로 시작¶

    여러분이 감기에 걸려 병원에 갔다고 상상해봅시다. 의사 선생님은 여러분의 증상을 듣고, 체온을 재고, 목 안쪽을 살펴봅니다. 그런데 만약 의사 선생님이 전 세계 수백만 명의 환자 기록을 순식간에 참고할 수 있다면 어떨까요? "이 증상 조합이라면 90% 확률로 A 질환이고, 이 약이 가장 효과적이었다"는 것을 바로 알 수 있겠죠.

    이것이 바로 의료 데이터 과학이 하는 일입니다. 마치 수백만 명의 경험을 가진 슈퍼 의사를 옆에 두는 것과 같습니다.

    2. 정확한 정의¶

    의료 데이터 과학이란, 환자의 진료 기록, 의료 영상(X-ray, CT, MRI), 유전자 정보, 생활 습관 데이터 등을 수집·분석하여 질병의 예측, 진단, 치료 방법 결정에 활용하는 분야입니다.

    3. 예시로 확인¶

    사례 ① 피부암 진단 AI

    2017년 스탠퍼드 대학교 연구팀은 약 13만 장의 피부 병변(피부에 생긴 이상 부위) 사진을 AI에게 학습시켰습니다. 결과는 놀라웠습니다. AI의 피부암 판별 정확도가 전문 피부과 의사 21명과 동등한 수준이었습니다.

    사례 ② 코로나19 감염병 예측

    2020년 코로나19가 전 세계로 퍼질 때, 캐나다의 AI 기업 '블루닷(BlueDot)'은 WHO(세계보건기구)보다 9일 먼저 감염병 확산을 경고했습니다. 항공권 예매 데이터, 뉴스 기사, 동물 질병 보고서 등 다양한 데이터를 종합 분석한 덕분이었습니다.

    flowchart LR A["🗂️ 데이터 수집\n진료 기록, 의료 영상\n유전자 정보"] --> B["🔍 데이터 분석\n패턴 발견\n이상 징후 탐지"] B --> C["🤖 AI 모델\n질병 예측\n진단 보조"] C --> D["💊 의료 현장 적용\n조기 진단\n맞춤형 치료"]

    📌 알아보기: "맞춤형 의료(Precision Medicine)"란 환자 개개인의 유전자, 생활환경, 생활 습관 데이터를 분석하여 그 사람에게 가장 적합한 치료법을 찾아주는 의료 방식입니다. 같은 암이라도 환자마다 효과적인 약이 다를 수 있기 때문입니다.

    개념 2: 데이터 과학의 실제 활용 — 환경·스포츠·문화 🌍⚽🎵¶

    1. 비유로 시작¶

    데이터 과학을 만능 돋보기에 비유해 봅시다. 돋보기를 어디에 갖다 대느냐에 따라 보이는 것이 달라지죠? 돋보기를 지구에 갖다 대면 환경 문제가 보이고, 운동장에 대면 선수들의 움직임이 보이고, 무대에 대면 사람들의 취향이 보입니다.

    2. 정확한 정의¶

    데이터 과학은 특정 분야에 국한되지 않는 범용 도구(general-purpose tool) 입니다. 어떤 분야든 데이터가 존재하는 곳이라면 데이터 과학을 적용하여 새로운 통찰(insight) 을 얻을 수 있습니다. 통찰이란 "데이터 속에 숨어 있는 의미 있는 발견"을 뜻합니다.

    3. 예시로 확인¶

    🌿 환경 분야 — 산불 예측과 대기오염 분석

    미국 캘리포니아에서는 위성 사진, 온도, 습도, 바람 방향 데이터를 분석해 산불 발생 위험 지역을 미리 예측합니다. 한국에서도 미세먼지 데이터를 분석하여 "내일 어느 지역의 공기질이 나쁠지"를 예보하고 있습니다.

    ⚽ 스포츠 분야 — 머니볼 혁명

    2002년 미국 프로야구 오클랜드 어슬레틱스 팀은 리그에서 가장 적은 예산을 가지고 있었습니다. 단장 빌리 빈은 선수들의 통계 데이터를 철저히 분석하여, 다른 팀이 주목하지 않는 저평가된 선수들을 영입했습니다. 결과는? 20연승이라는 역사적 기록을 세웠습니다. 이 이야기는 영화 <머니볼>로도 만들어졌죠.

    현재 축구에서도 선수의 달리기 거리, 패스 성공률, 슈팅 각도 등을 실시간으로 추적하여 전술을 세웁니다. 2022 카타르 월드컵에서는 반자동 오프사이드 판독 기술(SAOT) 이 도입되어, 선수 신체의 29개 포인트를 초당 50회 추적했습니다.

    🎵 문화 분야 — 음악 추천과 콘텐츠 제작

    스포티파이(Spotify)는 사용자가 어떤 노래를 듣고, 어디서 건너뛰고, 어떤 플레이리스트에 저장하는지 분석합니다. 이 데이터로 매주 월요일 "Discover Weekly" 라는 개인 맞춤 플레이리스트를 만들어주는데, 전 세계 사용자의 30억 개 이상의 플레이리스트 데이터가 활용됩니다.

    flowchart TB CENTER["🔍 데이터 과학"] CENTER --> ENV["🌿 환경\n산불 예측\n대기오염 분석\n기후변화 모니터링"] CENTER --> SPORTS["⚽ 스포츠\n선수 성과 분석\n전술 최적화\n부상 예방"] CENTER --> CULTURE["🎵 문화\n음악·영화 추천\n트렌드 분석\n관객 반응 예측"] CENTER --> MEDICAL["🏥 의료\n질병 예측\n신약 개발\n맞춤형 치료"]

    🤔 생각해보기: 여러분의 관심 분야(게임, 요리, 패션, 여행 등)에 데이터 과학이 어떻게 활용될 수 있을까요? 30초만 생각해 보세요!

    개념 3: 추천 시스템의 원리 🎬¶

    1. 비유로 시작¶

    학교에서 점심 메뉴를 고를 때, 가장 친한 친구가 "이거 진짜 맛있어!"라고 추천하면 믿음이 가죠? 그런데 만약 나와 입맛이 비슷한 친구 100명이 모두 "이거 맛있어!"라고 한다면요? 거의 확신하게 됩니다.

    추천 시스템도 정확히 같은 원리입니다. 나와 취향이 비슷한 수천, 수만 명의 사람들이 좋아한 것을 찾아서 "너도 이거 좋아할 거야"라고 알려주는 것이죠.

    2. 정확한 정의¶

    추천 시스템(Recommendation System) 이란, 사용자의 과거 행동 데이터(클릭, 구매, 평점 등)를 분석하여 해당 사용자가 아직 접하지 않았지만 좋아할 만한 항목을 예측하고 제안하는 시스템입니다.

    대표적인 추천 방식은 크게 두 가지입니다.

    ① 협업 필터링(Collaborative Filtering) — "나와 비슷한 사람은 뭘 좋아했지?"

    • 나와 비슷한 취향의 사용자 그룹을 찾습니다.
    • 그 그룹이 높게 평가했지만 내가 아직 보지 않은 항목을 추천합니다.
    • 핵심 가정: 과거에 비슷한 취향을 보인 사람들은 미래에도 비슷한 취향을 가질 것이다.

    ② 콘텐츠 기반 필터링(Content-based Filtering) — "내가 좋아한 것과 비슷한 건 뭐지?"

    • 내가 좋아한 항목의 특성(장르, 감독, 키워드 등) 을 분석합니다.
    • 그 특성과 유사한 다른 항목을 추천합니다.

    3. 예시로 확인¶

    flowchart LR subgraph 협업필터링["🤝 협업 필터링"] U1["👤 나\n액션 ⭐5 로맨스 ⭐2"] U2["👥 비슷한 취향의 사용자\n액션 ⭐5 로맨스 ⭐2\nSF ⭐5"] U1 -->|"취향 유사!"| U2 U2 -->|"SF 영화 추천"| U1 end subgraph 콘텐츠기반["📋 콘텐츠 기반 필터링"] M1["🎬 내가 좋아한 영화\n장르: 액션\n감독: A"] M2["🎬 비슷한 영화\n장르: 액션\n감독: A"] M1 -->|"특성 유사!"| M2 end

    더 구체적인 예를 들어볼까요?

    • 영희는 영화 A에 ⭐5점, 영화 B에 ⭐4점, 영화 C에 ⭐1점을 줬습니다.
    • 철수는 영화 A에 ⭐5점, 영화 B에 ⭐5점을 줬는데, 영화 C는 아직 보지 않았습니다.
    • 민수는 영화 A에 ⭐1점, 영화 B에 ⭐2점, 영화 C에 ⭐5점을 줬습니다.

    협업 필터링 시스템은 이렇게 판단합니다: - 철수는 영희와 취향이 비슷하다 (A, B 평점이 유사). - 영희는 영화 C에 1점을 줬다. - 따라서 철수에게는 영화 C를 추천하지 않는다.

    📌 알아보기: 넷플릭스는 2006년에 "추천 알고리즘의 정확도를 10% 이상 개선하는 팀에게 100만 달러(약 13억 원)를 주겠다"는 대회를 열었습니다. 3년 후 한 팀이 이 상금을 받았는데, 이 대회가 추천 시스템 기술 발전에 큰 기여를 했습니다.

    개념 4: 데이터 과학의 윤리 ⚖️¶

    1. 비유로 시작¶

    칼은 요리할 때 쓰면 맛있는 음식을 만들 수 있지만, 잘못 사용하면 다칠 수 있습니다. 데이터 과학도 마찬가지입니다. 강력한 도구일수록 어떻게 사용하느냐가 중요합니다.

    2. 정확한 정의¶

    데이터 윤리(Data Ethics) 란, 데이터를 수집·저장·분석·활용하는 모든 과정에서 개인의 권리를 보호하고, 공정성을 유지하며, 사회에 해를 끼치지 않도록 지켜야 할 도덕적 원칙과 기준을 말합니다.

    주요 쟁점은 다음과 같습니다.

    🔒 쟁점 1: 개인정보 보호

    • 우리가 앱을 사용할 때 동의하는 "개인정보 처리방침"을 끝까지 읽어본 적이 있나요?
    • 2018년 페이스북의 캠브리지 애널리티카 사건에서 약 8,700만 명의 사용자 데이터가 동의 없이 정치 캠페인에 활용되었습니다.
    • 한국에서는 개인정보보호법으로 개인정보 수집·이용에 반드시 본인의 동의를 받도록 규정하고 있습니다.

    ⚖️ 쟁점 2: 알고리즘 편향(Bias)

    • AI가 학습하는 데이터에 편향이 있으면, AI의 판단도 편향됩니다.
    • 미국의 한 채용 AI가 과거 채용 데이터(남성 비율이 높은)를 학습한 결과, 여성 지원자에게 불리한 점수를 매기는 문제가 발생했습니다.
    • 얼굴 인식 AI가 피부색이 어두운 사람을 잘 인식하지 못하는 문제도 보고되었습니다.

    🫧 쟁점 3: 필터 버블(Filter Bubble)

    • 추천 시스템이 내가 좋아하는 것만 계속 보여주면, 마치 거품 속에 갇힌 것처럼 다양한 관점을 접할 기회가 줄어듭니다.
    • 뉴스 추천에서 이 문제가 심각할 수 있습니다. 내 생각과 같은 뉴스만 계속 보게 되면, 세상을 균형 있게 바라보기 어려워집니다.

    3. 예시로 확인¶

    flowchart TB DATA["📊 데이터 과학의 힘"] DATA --> GOOD["✅ 긍정적 활용"] DATA --> BAD["❌ 부정적 위험"] GOOD --> G1["질병 조기 발견으로\n생명 구하기"] GOOD --> G2["환경 오염 감시로\n지구 보호"] GOOD --> G3["맞춤형 교육으로\n학습 효율 향상"] BAD --> B1["개인정보 유출\n사생활 침해"] BAD --> B2["편향된 AI\n차별 강화"] BAD --> B3["필터 버블\n시야 축소"]

    🤔 생각해보기: "더 좋은 추천을 받기 위해 나의 모든 인터넷 사용 기록을 기업에 제공해도 괜찮을까?" 여러분의 생각은 어떤가요? 정답은 없습니다. 중요한 것은 이 문제에 대해 스스로 생각해보는 것입니다.

    🔨 따라하기: 영화 평점 데이터로 추천의 원리 맛보기¶

    이번 실습에서는 Google Colab에서 간단한 영화 평점 데이터를 만들고, "나와 취향이 비슷한 사람" 을 찾아보겠습니다. 추천 시스템의 핵심 원리인 협업 필터링을 직접 체험하는 것이 목표입니다.

    Step 1: 영화 평점 데이터 만들기 🎬¶

    먼저, 5명의 사용자가 6편의 영화에 매긴 평점 데이터를 만들어봅시다.

    # pandas 라이브러리를 불러옵니다
import pandas as pd

# 5명의 사용자가 6편의 영화에 매긴 평점 (1~5점, 0은 아직 안 봄)
data = {
    '사용자': ['영희', '철수', '민수', '지은', '태호'],
    '어벤져스': [5, 5, 1, 4, 2],
    '타이타닉': [2, 1, 5, 2, 5],
    '인터스텔라': [5, 4, 2, 5, 1],
    '노트북': [1, 2, 5, 1, 4],
    '다크나이트': [4, 5, 1, 4, 2],
    '라라랜드': [2, 0, 4, 0, 5]  # 0 = 아직 보지 않음
}

# 데이터프레임 만들기
df = pd.DataFrame(data)
df = df.set_index('사용자')

print("🎬 영화 평점 데이터")
print(df)

    💡 코드 설명: set_index('사용자')는 '사용자' 열을 행의 이름(인덱스)으로 지정합니다. 이렇게 하면 "영희의 어벤져스 평점"처럼 직관적으로 데이터를 찾을 수 있습니다.

    Step 2: 평점을 시각화하기 📊¶

    숫자만 보면 패턴을 파악하기 어려울 수 있습니다. 히트맵(Heatmap) 으로 시각화하면 한눈에 볼 수 있습니다.

    import matplotlib.pyplot as plt
import seaborn as sns

# 한글 폰트 설정 (Colab 환경)

plt.figure(figsize=(10, 5))
sns.heatmap(df, annot=True, cmap='YlOrRd', fmt='d', 
            linewidths=0.5, cbar_kws={'label': '평점'})

    💡 코드 설명: - sns.heatmap(): 숫자를 색상의 진하기로 표현합니다. 평점이 높을수록 진한 색! - annot=True: 각 칸에 숫자를 표시합니다. - cmap='YlOrRd': 노란색(낮음)→빨간색(높음)으로 색상을 표현합니다.

    히트맵을 보면, 비슷한 색깔 패턴을 가진 사용자들이 눈에 들어올 것입니다!

    Step 3: "나와 취향이 비슷한 사람" 찾기 🤝¶

    추천 시스템의 핵심! 사용자 간의 유사도를 계산해봅시다. 여기서는 코사인 유사도(Cosine Similarity) 라는 방법을 사용합니다.

    코사인 유사도란 쉽게 말해 "두 사람의 평점 패턴이 얼마나 같은 방향을 가리키는지" 를 측정하는 것입니다. 1에 가까우면 취향이 비슷하고, 0에 가까우면 관련이 없고, -1에 가까우면 취향이 정반대입니다.

    from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# 0(안 봄)을 제외하고 유사도를 계산하기 위해, 
# 여기서는 간단히 0을 포함하여 계산합니다
similarity = cosine_similarity(df)

# 유사도 결과를 데이터프레임으로 만들기
sim_df = pd.DataFrame(similarity, 
                       index=df.index, 
                       columns=df.index)

print("🤝 사용자 간 취향 유사도 (코사인 유사도)")
print(sim_df.round(2))  # 소수점 2자리까지 표시

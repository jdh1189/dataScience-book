    📖 Chapter 01: 데이터 과학이란 무엇일까?¶

    Part 1 · [1권] 데이터 과학의 이해 · 1차시 / 총 18차시

    🎯 이 장에서 배우는 것¶

    • 데이터 과학이 무엇인지 자신의 말로 설명할 수 있다
    • 데이터 기반 의사결정과 직감 기반 의사결정의 차이를 비교할 수 있다
    • 데이터 과학 문제 해결 5단계를 순서대로 나열할 수 있다
    • 코랩에서 간단한 데이터를 불러와 결과를 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    오늘 점심 메뉴를 어떻게 골랐나요?

    "그냥 먹고 싶은 거 먹었는데요?" — 맞습니다. 대부분 느낌(직감)으로 결정합니다. 그런데 잠깐, 정말 아무 정보 없이 골랐을까요?

    • 급식 게시판에서 오늘의 메뉴를 확인하지 않았나요?
    • 친구가 "오늘 돈까스 맛있대!"라고 한 후기를 듣지 않았나요?
    • 지갑 속 남은 돈, 즉 예산 데이터를 떠올리지 않았나요?

    우리는 이미 매일 데이터를 활용하고 있습니다. 다만 그 과정을 체계적으로 인식하지 못할 뿐이에요. 데이터 과학은 이 과정을 누구나 반복 가능하고, 더 정확하게 만드는 방법을 연구하는 학문입니다.

    넷플릭스가 "이 영화 좋아하실걸요?"라고 추천하는 것도, 프로야구 구단이 선수를 영입할 때 타율·출루율을 분석하는 것도 모두 데이터 과학입니다. 이 장에서는 데이터 과학의 세계에 첫 발을 내딛어 봅시다! 🚀

    📚 핵심 개념¶

    개념 1: 데이터란? 📦¶

    1) 비유로 시작

    레고 블록 한 조각을 상상해보세요. 블록 하나만으로는 무엇을 만들 수 없지만, 수백 개가 모이면 성(城)도 만들 수 있습니다. 데이터는 바로 이 레고 블록 한 조각과 같습니다.

    2) 정확한 정의

    데이터(data): 관찰이나 측정을 통해 얻은 사실이나 값. 숫자, 문자, 이미지, 소리 등 다양한 형태를 가집니다.

    3) 예시로 확인

    • 🌡️ "오늘 기온 28 °C" → 숫자 데이터
    • 💬 "급식 만족도 설문 응답: 맛있다" → 텍스트 데이터
    • 📸 급식 사진 → 이미지 데이터
    • 🎵 음악 스트리밍 재생 기록 → 시간·횟수 데이터

    알아보기 💡

    데이터의 영어 data는 라틴어 datum(주어진 것)의 복수형입니다. 하나의 값은 데이텀, 여러 값의 모음은 데이터라고 부릅니다. 보통은 구분 없이 데이터라고 통칭합니다.

    개념 2: 데이터 과학이란? 🔬¶

    1) 비유로 시작

    탐정을 떠올려 보세요. 탐정은 단서(데이터)를 수집하고, 분석하고, 사건의 진실(결론)을 밝혀냅니다. 데이터 과학자는 디지털 세계의 탐정입니다.

    2) 정확한 정의

    데이터 과학(Data Science): 데이터를 수집·정리·분석·시각화하여 유용한 지식과 통찰을 얻고, 이를 바탕으로 문제를 해결하는 학문 분야입니다.

    3) 예시로 확인

    • 넷플릭스 🎬 — 수억 명의 시청 기록을 분석해 "당신이 좋아할 영화"를 추천합니다.
    • 프로야구 세이버메트릭스 ⚾ — 타율, 출루율, 장타율 등 수십 가지 지표로 선수 가치를 평가합니다. 영화 〈머니볼〉이 바로 이 이야기예요!
    • 날씨 예보 🌦️ — 전 세계 관측소의 기온·풍속·습도 데이터를 분석하여 내일 비가 올 확률을 계산합니다.
    mindmap root((데이터 과학)) 수학·통계 확률 평균·분산 컴퓨터 과학 프로그래밍 알고리즘 도메인 지식 해당 분야 전문성 비즈니스 이해

    데이터 과학은 위 세 가지 영역이 만나는 곳에 있습니다. 이 교재에서는 프로그래밍(Python)을 도구로, 통계적 사고를 무기로, 다양한 실생활 문제를 다뤄볼 거예요.

    개념 3: 직감 vs 데이터 기반 의사결정 ⚖️¶

    점심 메뉴를 고르는 두 가지 방법을 비교해 봅시다.

    직감 기반 의사결정 - 👤 "느낌이 좋으니까 짜장면!" - 경험과 감에 의존 - 빠르지만 편향(치우침)이 생기기 쉬움 - 같은 상황에서도 사람마다 결과가 다름

    데이터 기반 의사결정 - 📊 "지난 한 달 급식 만족도 조사에서 짜장면 4.5점, 카레 3.2점 → 짜장면 선택" - 수집된 데이터와 분석에 의존 - 시간이 더 걸리지만 근거가 명확 - 누가 하든 비슷한 결론에 도달

    flowchart LR A["❓ 문제 발생"] --> B{"의사결정 방식"} B -- "직감 기반" --> C["경험·감각으로 판단"] B -- "데이터 기반" --> D["데이터 수집 → 분석 → 판단"] C --> E["결과: 개인차 큼"] D --> F["결과: 근거 명확"]

    생각해보기 🤔

    직감 기반 의사결정이 항상 나쁜 걸까요? — 아닙니다! 긴급 상황(화재 대피 등)에서는 직감이 더 빠르고 효과적일 수 있어요. 중요한 것은 상황에 맞는 방법을 선택하는 것이며, 데이터 과학은 "데이터를 활용할 수 있는 상황"에서 훨씬 강력합니다.

    개념 4: 데이터 과학 문제 해결 5단계 🪜¶

    데이터 과학으로 문제를 해결하는 데는 다섯 단계의 절차가 있습니다. 이 과정을 외워두면 앞으로 모든 프로젝트에서 길잡이가 됩니다!

    flowchart TD S1["1️⃣ 문제 정의\n무엇을 알고 싶은가?"] S2["2️⃣ 데이터 수집\n필요한 데이터를 모은다"] S3["3️⃣ 데이터 분석\n정리하고 패턴을 찾는다"] S4["4️⃣ 시각화\n결과를 그래프 등으로 표현한다"] S5["5️⃣ 의사결정\n분석 결과로 판단한다"] S1 --> S2 --> S3 --> S4 --> S5 S5 -.->|"새로운 질문 발생"| S1

    각 단계를 "우리 반 최애 간식 찾기" 예제로 살펴봅시다.

    1️⃣ 문제 정의 — "우리 반에서 가장 인기 있는 간식은 무엇일까?"

    2️⃣ 데이터 수집 — 반 친구들에게 좋아하는 간식을 설문 조사합니다.

    3️⃣ 데이터 분석 — 간식별 응답 수를 세고, 가장 많은 것을 찾습니다.

    4️⃣ 시각화 — 막대그래프로 순위를 한눈에 보여줍니다.

    5️⃣ 의사결정 — "학급 파티 간식은 1위인 ○○으로 결정!"

    정리하기 📌

    문정수시의 — 문제 정의 → 정보(데이터) 수집 → 수치 분석 → 시각화 → 의사결정. 앞 글자를 따서 외워보세요!

    🔨 따라하기: "우리 반 최애 간식" 분석¶

    지금부터 Google Colab(코랩)에서 직접 코드를 실행해봅니다. 코랩은 웹 브라우저만 있으면 Python 코드를 실행할 수 있는 무료 도구입니다.

    Step 1: 코랩 열기 🌐¶

    1. 브라우저에서 colab.research.google.com 에 접속합니다.
    2. Google 계정으로 로그인합니다.
    3. "새 노트" 버튼을 클릭합니다.
    4. 노트 이름을 chapter01_간식분석.ipynb으로 바꿔주세요.

    Step 2: 데이터 만들기 📋¶

    코드 셀에 아래 코드를 입력하고 ▶ 실행 버튼(또는 Shift + Enter)을 누르세요.

    # 1단계: 문제 정의 - "우리 반 최애 간식은?"
# 2단계: 데이터 수집 - 설문 결과를 직접 입력합니다

snacks = [
    "떡볶이", "떡볶이", "떡볶이", "떡볶이", "떡볶이",
    "초코칩쿠키", "초코칩쿠키", "초코칩쿠키", "초코칩쿠키",
    "감자칩", "감자칩", "감자칩",
    "젤리", "젤리", "젤리", "젤리", "젤리", "젤리",
    "아이스크림", "아이스크림"
]

print(f"총 응답 수: {len(snacks)}명")

    실행하면 총 응답 수: 20명이 출력됩니다. 우리 반 20명이 좋아하는 간식을 조사한 결과입니다!

    Step 3: 데이터 분석하기 📊¶

    # 3단계: 데이터 분석 - 간식별 응답 수 세기
from collections import Counter

counts = Counter(snacks)

print("=== 간식별 응답 수 ===")
for snack, count in counts.most_common():
    print(f"  {snack}: {count}명")

    알아보기 💡

    Counter는 Python에 기본 내장된 도구로, 리스트(목록) 안의 항목을 자동으로 세어 줍니다. most_common()은 많은 순서대로 정렬해줍니다.

    Step 4: 시각화하기 📈¶

    # 4단계: 시각화 - 막대그래프 그리기
import matplotlib.pyplot as plt

# 한글 폰트 설정 (코랩 환경)
plt.rc('font', family='NanumBarunGothic')
plt.rcParams['axes.unicode_minus'] = False

# 데이터 준비
snack_names = [item[0] for item in counts.most_common()]
snack_counts = [item[1] for item in counts.most_common()]
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#96CEB4', '#FFEAA7']

# 그래프 그리기
plt.figure(figsize=(8, 5))
plt.bar(snack_names, snack_counts, color=colors)
plt.title('🍿 우리 반 최애 간식 순위', fontsize=16)
plt.xlabel('간식')
plt.ylabel('응답 수 (명)')

# 막대 위에 숫자 표시
for i, v in enumerate(snack_counts):
    plt.text(i, v + 0.1, str(v), ha='center', fontweight='bold')

plt.tight_layout()
plt.show()

    실행하면 색깔이 있는 막대그래프가 나타납니다. 어떤 간식이 1위인가요?

    Step 5: 의사결정 내리기 🏆¶

    # 5단계: 의사결정
winner = counts.most_common(1)[0]
print(f"🏆 우리 반 최애 간식 1위: {winner[0]} ({winner[1]}명)")
print(f"→ 학급 파티 간식은 '{winner[0]}'(으)로 결정!")

    생각해보기 🤔

    만약 1위와 2위의 표 차이가 1표뿐이라면? 그래도 1위만 선택하는 것이 좋은 결정일까요? 데이터 과학에서는 이런 경우 "차이가 의미 있는지"도 함께 고민합니다. 이것은 앞으로 배울 통계와 연결되는 이야기입니다!

    Step 6: 한글이 깨진다면? 🔧¶

    📝 전체 코드¶

    아래는 위 실습의 전체 코드입니다. 코랩에 복사해서 바로 실행할 수 있습니다.

    # ================================================
# Chapter 01 - 우리 반 최애 간식 분석
# ================================================

# --- 한글 폰트 (코랩에서 첫 실행 시 필요하면 주석 해제) ---
# !apt-get -qq install fonts-nanum
# !fc-cache -fv
# → 설치 후 런타임 다시 시작!

# 1단계: 문제 정의
# "우리 반에서 가장 인기 있는 간식은 무엇일까?"

# 2단계: 데이터 수집
snacks = [
    "떡볶이", "떡볶이", "떡볶이", "떡볶이", "떡볶이",
    "초코칩쿠키", "초코칩쿠키", "초코칩쿠키", "초코칩쿠키",
    "감자칩", "감자칩", "감자칩",
    "젤리", "젤리", "젤리", "젤리", "젤리", "젤리",
    "아이스크림", "아이스크림"
]
print(f"총 응답 수: {len(snacks)}명\n")

# 3단계: 데이터 분석
from collections import Counter
counts = Counter(snacks)

print("=== 간식별 응답 수 ===")
for snack, count in counts.most_common():
    print(f"  {snack}: {count}명")

# 4단계: 시각화
import matplotlib.pyplot as plt
plt.rc('font', family='NanumBarunGothic')
plt.rcParams['axes.unicode_minus'] = False

snack_names = [item[0] for item in counts.most_common()]
snack_counts = [item[1] for item in counts.most_common()]
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#96CEB4', '#FFEAA7']

plt.figure(figsize=(8, 5))
plt.bar(snack_names, snack_counts, color=colors)
plt.title('🍿 우리 반 최애 간식 순위', fontsize=16)
plt.xlabel('간식')
plt.ylabel('응답 수 (명)')
for i, v in enumerate(snack_counts):
    plt.text(i, v + 0.1, str(v), ha='center', fontweight='bold')
plt.tight_layout()
plt.show()

# 5단계: 의사결정
winner = counts.most_common(1)[0]
print(f"\n🏆 우리 반 최애 간식 1위: {winner[0]} ({winner[1]}명)")
print(f"→ 학급 파티 간식은 '{winner[0]}'(으)로 결정!")

    ⚠️ 자주 하는 실수¶

    실수 1: 코랩에서 코드를 한꺼번에 실행하지 않기 🚫

    코드 셀을 위에서부터 순서대로 실행해야 합니다. Step 4(시각화)를 먼저 실행하면 snacks 변수가 아직 만들어지지 않아 NameError가 발생합니다. 프로그래밍에서 실행 순서는 매우 중요합니다!

    실수 2: 데이터 과학 = 프로그래밍이라고 오해하기 🚫

    프로그래밍은 데이터 과학의 도구일 뿐, 전부가 아닙니다. 요리사에게 칼이 중요하지만, 좋은 칼만 있다고 맛있는 요리가 나오지 않는 것과 같아요. 어떤 문제를 풀 것인지 정의하는 능력이 가장 중요합니다.

    실수 3: 문제 해결 5단계에서 1단계(문제 정의)를 건너뛰기 🚫

    "일단 데이터부터 모으자!"는 초보자가 가장 자주 하는 실수입니다. 목적지 없이 내비게이션을 켜는 것과 같아요. 무엇을 알고 싶은지 먼저 명확히 해야 어떤 데이터를 모을지 결정할 수 있습니다.

    ✅ 스스로 점검하기¶

    기본 문제¶

    문제 1. 다음 중 데이터에 해당하지 않는 것은?

    • ① 오늘 서울 최고 기온: 31°C
    • ② 내일은 좋은 일이 생길 것 같은 느낌
    • ③ 학교 도서관 월별 대출 권수
    • ④ 유튜브 영상 조회수: 152,340회
    정답 확인 **② 내일은 좋은 일이 생길 것 같은 느낌** 데이터는 관찰이나 측정을 통해 얻은 **사실이나 값**입니다. "느낌"은 주관적 감정이지 관찰·측정된 데이터가 아닙니다.

    문제 2. 데이터 과학 문제 해결 5단계를 올바른 순서로 나열하세요.

    • ㄱ. 시각화
    • ㄴ. 데이터 수집
    • ㄷ. 의사결정
    • ㄹ. 문제 정의
    • ㅁ. 데이터 분석
    정답 확인 **ㄹ → ㄴ → ㅁ → ㄱ → ㄷ** 문제 정의 → 데이터 수집 → 데이터 분석 → 시각화 → 의사결정 기억법: **문정수시의**!

    응용 문제¶

    문제 3. 다음 상황에서 직감 기반 의사결정과 데이터 기반 의사결정을 각각 구분하세요.

    • ① 축구 감독이 "이 선수, 눈빛이 다르다"며 선발 출전시킴
    • ② 쇼핑몰이 최근 3개월 판매량 분석 후 인기 상품을 전면 배치함
    • ③ 의사가 혈액검사 수치를 확인하고 약을 처방함
    • ④ "이번 시험은 5번이 많이 나올 것 같아"라며 5번을 많이 찍음
    정답 확인 - **직감 기반**: ①, ④ - **데이터 기반**: ②, ③ ①은 "눈빛"이라는 주관적 인상, ④는 근거 없는 감(感)에 의존합니다. ②는 판매량 데이터, ③은 혈액검사 수치라는 데이터를 기반으로 판단합니다.

    심화 문제¶

    문제 4. 아래 코드를 실행하면 어떤 결과가 나올지 직접 실행하지 않고 예측해보세요.

    from collections import Counter
fruits = ["사과", "바나나", "사과", "딸기", "바나나", "사과"]
result = Counter(fruits).most_common(1)
print(result[0][0])
    정답 확인 **사과** `Counter(fruits)`는 `{"사과": 3, "바나나": 2, "딸기": 1}`이 됩니다. `most_common(1)`은 가장 많은 1개를 리스트로 반환하므로 `[("사과", 3)]`입니다. `result[0][0]`은 첫 번째 항목의 첫 번째 요소, 즉 `"사과"`입니다.

    정리하기 📌

    이 장의 핵심 4가지

    1. 데이터 — 관찰·측정으로 얻은 사실이나 값 (레고 블록 🧱)
    2. 데이터 과학 — 데이터로 문제를 해결하는 학문 (디지털 탐정 🔍)
    3. 데이터 기반 의사결정 — 직감이 아닌 데이터와 분석에 근거한 판단
    4. 문제 해결 5단계 — 문제 정의 → 수집 → 분석 → 시각화 → 의사결정 (문정수시의)

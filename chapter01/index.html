    📖 Chapter 01: 데이터 과학과 문제 해결¶

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 데이터 과학이 무엇인지 자신의 말로 설명할 수 있다
    • 데이터 과학의 핵심 구성 요소 3가지를 구분할 수 있다
    • 데이터 기반 문제 해결 과정(CRISP-DM)의 흐름을 설명할 수 있다
    • Python으로 간단한 데이터를 불러와 기초 탐색을 수행할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 매일 데이터 속에서 살고 있습니다.

    아침에 스마트폰 알람이 울리면 수면 데이터가 기록되고, 등교길에 지도 앱은 실시간 교통 데이터를 분석해 최적 경로를 알려줍니다. 점심에 급식 메뉴가 정해지는 것도 과거 선호도 데이터를 참고한 결과일 수 있습니다.

    🤔 생각해보기: 넷플릭스는 어떻게 내가 좋아할 영화를 추천할까요? 날씨 예보는 어떻게 내일 비가 올 확률을 알려줄까요? 이 모든 것의 뒤에는 데이터 과학이 있습니다.

    데이터 과학을 배운다는 것은, 세상을 숫자와 패턴의 눈으로 바라보는 새로운 능력을 갖추는 것입니다. 이 첫 번째 장에서는 데이터 과학이란 무엇인지, 그리고 데이터로 문제를 어떻게 해결하는지 그 큰 그림을 그려보겠습니다.

    📚 핵심 개념¶

    개념 1: 데이터 과학이란?¶

    🎭 비유로 시작하기

    데이터 과학자는 탐정과 비슷합니다. 탐정이 사건 현장의 단서(지문, 목격자 진술, CCTV)를 모아서 사건의 진실을 밝혀내듯, 데이터 과학자는 데이터라는 단서를 모아서 숨겨진 패턴과 의미를 발견합니다.

    📖 정확한 정의

    데이터 과학(Data Science) 이란, 데이터를 수집·정리·분석·시각화하여 유용한 지식이나 인사이트(insight, 통찰)를 이끌어내는 학문 분야입니다.

    데이터 과학은 하나의 학문이 아니라 여러 분야가 만나는 교차점입니다.

    graph TD A["🔢 수학/통계학<br/>데이터를 요약하고<br/>패턴을 검증하는 도구"] B["💻 컴퓨터 과학<br/>데이터를 처리하고<br/>프로그래밍하는 기술"] C["🏢 도메인 지식<br/>해당 분야의 전문 지식<br/>의학, 경제, 환경 등"] D["⭐ 데이터 과학"] A --> D B --> D C --> D style D fill:#FFD700,stroke:#333,stroke-width:3px,color:#000 style A fill:#AED6F1,stroke:#333,color:#000 style B fill:#A9DFBF,stroke:#333,color:#000 style C fill:#F9CB9C,stroke:#333,color:#000

    ✏️ 예시로 확인

    병원에서 환자 데이터를 분석해 질병을 조기 발견하는 경우를 봅시다.

    • 수학/통계학 → 환자 수치의 평균, 이상치를 계산
    • 컴퓨터 과학 → Python으로 수만 건의 데이터를 처리
    • 도메인 지식 → 의사가 "이 수치가 높으면 위험하다"고 판단

    세 가지가 합쳐져야 비로소 의미 있는 결과가 나옵니다.

    개념 2: 데이터의 종류¶

    🎭 비유로 시작하기

    도서관의 책을 생각해보세요. 어떤 책은 숫자로 가득한 통계표이고, 어떤 책은 이야기로 가득한 소설입니다. 데이터도 마찬가지로 형태에 따라 나뉩니다.

    📖 정확한 정의

    • 정형 데이터(Structured Data) — 행과 열로 깔끔하게 정리된 데이터. 엑셀 스프레드시트처럼 생겼습니다. (예: 학생 성적표, 매출 기록)
    • 비정형 데이터(Unstructured Data) — 정해진 형식이 없는 데이터. (예: SNS 글, 사진, 동영상, 음성)
    • 반정형 데이터(Semi-structured Data) — 완전한 표는 아니지만 일정한 구조를 가진 데이터. (예: JSON, XML, 웹 로그)

    ✏️ 예시로 확인

    여러분의 학교 생활에서 데이터를 찾아볼까요?

    • 정형 → 중간고사 성적표 (이름, 과목, 점수가 표로 정리)
    • 반정형 → 학교 홈페이지의 공지사항 (제목, 날짜, 내용이 일정 형식)
    • 비정형 → 체육대회 때 찍은 사진과 동영상

    📌 알아보기: 현재 전 세계 데이터의 약 80%는 비정형 데이터라고 합니다. 이미지, 영상, 텍스트 등 형식 없는 데이터가 폭발적으로 늘어나고 있기 때문입니다.

    개념 3: 데이터 기반 문제 해결 과정 (CRISP-DM)¶

    🎭 비유로 시작하기

    요리를 할 때를 떠올려보세요. ① 무슨 요리를 할지 정하고 → ② 재료를 준비하고 → ③ 재료를 손질하고 → ④ 조리하고 → ⑤ 맛을 보고 → ⑥ 식탁에 내놓습니다. 데이터 과학도 이처럼 정해진 단계를 거칩니다.

    📖 정확한 정의

    CRISP-DM(Cross-Industry Standard Process for Data Mining)은 데이터 분석 프로젝트를 수행하는 표준 절차입니다. 6단계로 이루어지며, 필요하면 이전 단계로 돌아갈 수 있습니다.

    graph TD A["1️⃣ 비즈니스 이해<br/>어떤 문제를 풀 것인가?"] --> B["2️⃣ 데이터 이해<br/>어떤 데이터가 있는가?"] B --> C["3️⃣ 데이터 준비<br/>분석할 수 있게 정리"] C --> D["4️⃣ 모델링<br/>패턴을 찾고 예측"] D --> E["5️⃣ 평가<br/>결과가 쓸 만한가?"] E --> F["6️⃣ 배포<br/>현실에 적용"] E -.->|"결과 불만족 시" | A style A fill:#E8EAF6,stroke:#333,color:#000 style B fill:#E3F2FD,stroke:#333,color:#000 style C fill:#E0F7FA,stroke:#333,color:#000 style D fill:#E8F5E9,stroke:#333,color:#000 style E fill:#FFF8E1,stroke:#333,color:#000 style F fill:#FCE4EC,stroke:#333,color:#000

    ✏️ 예시로 확인 — "우리 반 중간고사 성적 분석"

    1. 비즈니스 이해 → "어떤 과목이 가장 어려웠고, 어떻게 하면 성적을 올릴 수 있을까?"
    2. 데이터 이해 → 반 학생 30명의 과목별 점수 데이터 확인
    3. 데이터 준비 → 빠진 점수 확인, 과목별로 정리
    4. 모델링 → 평균, 분포 확인, 과목 간 상관관계 분석
    5. 평가 → "수학과 과학 점수가 함께 오르내리는 경향이 있다"는 결론 검증
    6. 배포 → 선생님께 분석 보고서 제출, 학습 전략 제안

    개념 4: 데이터 과학의 도구 — Python¶

    🎭 비유로 시작하기

    목수에게 망치와 톱이 있듯, 데이터 과학자에게는 프로그래밍 언어가 있습니다. 그중 Python은 가장 인기 있는 도구입니다. 배우기 쉽고, 강력한 라이브러리(도구 모음)가 풍부하기 때문입니다.

    📖 핵심 라이브러리 3가지

    • pandas — 데이터를 표 형태로 다루는 도구 (엑셀 같은 역할)
    • matplotlib — 데이터를 그래프로 시각화하는 도구 (그림 그리기)
    • numpy — 수학 계산을 빠르게 처리하는 도구 (계산기 역할)
    graph LR P["🐍 Python"] --> A["pandas<br/>데이터 정리/탐색"] P --> B["matplotlib<br/>시각화/그래프"] P --> C["numpy<br/>수치 계산"] style P fill:#306998,stroke:#333,color:#FFD43B style A fill:#E8F5E9,stroke:#333,color:#000 style B fill:#FFF3E0,stroke:#333,color:#000 style C fill:#E3F2FD,stroke:#333,color:#000

    ✏️ 예시로 확인

    # pandas로 데이터를 만들고, 평균을 구하는 간단한 예시
import pandas as pd

scores = {"이름": ["민수", "지은", "태호"],
          "수학": [85, 92, 78],
          "영어": [90, 88, 95]}

df = pd.DataFrame(scores)
print(df)
print("수학 평균:", df["수학"].mean())

    이 코드를 실행하면 학생들의 성적표가 표로 출력되고, 수학 평균 점수가 계산됩니다. 걱정하지 마세요 — 지금부터 직접 따라 해보겠습니다!

    🔨 따라하기: 나의 첫 데이터 분석¶

    📌 목표: Python으로 간단한 데이터를 만들고, 기초 통계와 시각화를 수행합니다.

    Step 1: 환경 준비하기¶

    Google Colab(코랩)을 사용합니다. 설치가 필요 없고, 웹 브라우저만 있으면 됩니다.

    1. 웹 브라우저에서 colab.research.google.com 접속
    2. Google 계정으로 로그인
    3. "새 노트" 클릭

    💡 Tip: Colab의 각 칸을 "셀(cell)" 이라고 부릅니다. 셀에 코드를 입력하고 Shift + Enter를 누르면 실행됩니다.

    Step 2: 데이터 만들기¶

    우리 반 학생 5명의 시험 성적 데이터를 직접 만들어봅시다.

    import pandas as pd

# 학생 성적 데이터 만들기
data = {
    "이름": ["민수", "지은", "태호", "수빈", "하준"],
    "수학": [85, 92, 78, 95, 88],
    "영어": [90, 88, 95, 82, 91],
    "과학": [88, 95, 82, 90, 85]
}

df = pd.DataFrame(data)
print(df)

    실행 결과: 

       이름  수학  영어  과학
0  민수  85  90  88
1  지은  92  88  95
2  태호  78  95  82
3  수빈  95  82  90
4  하준  88  91  85

    📌 알아보기: pd.DataFrame()은 딕셔너리(dictionary) 형태의 데이터를 표(DataFrame) 로 변환해줍니다. 엑셀의 시트 하나라고 생각하면 됩니다.

    Step 3: 기초 통계 살펴보기¶

    데이터의 전체적인 모습을 한눈에 파악해봅시다.

    # 기초 통계 요약
print(df.describe())

    실행 결과: 

              수학     영어     과학
count   5.00   5.00   5.00
mean   87.60  89.20  88.00
std     6.43   4.76   4.95
min    78.00  82.00  82.00
25%    85.00  88.00  85.00
50%    88.00  90.00  88.00
75%    92.00  91.00  90.00
max    95.00  95.00  95.00

    각 항목의 의미를 알아봅시다.

    • count — 데이터 개수 (5명)
    • mean — 평균 (수학 평균 87.6점)
    • std — 표준편차, 점수가 얼마나 흩어져 있는지 (숫자가 클수록 편차가 큼)
    • min / max — 최솟값 / 최댓값
    • 25%, 50%, 75% — 데이터를 크기순으로 나열했을 때의 위치값

    Step 4: 과목별 평균 비교하기¶

    # 과목별 평균 계산
subject_mean = df[["수학", "영어", "과학"]].mean()
print("=== 과목별 평균 ===")
print(subject_mean)

    Step 5: 그래프로 시각화하기¶

    숫자만 보는 것보다 그래프로 보면 훨씬 직관적입니다.

    import matplotlib.pyplot as plt

# 한글 깨짐 방지 (Colab 환경)
plt.rcParams['font.family'] = 'DejaVu Sans'

# 과목별 평균 막대그래프
subjects = ['Math', 'English', 'Science']
means = [87.6, 89.2, 88.0]

plt.figure(figsize=(8, 5))
plt.bar(subjects, means, color=['#5B9BD5', '#ED7D31', '#70AD47'])
plt.title('Average Score by Subject', fontsize=16)
plt.ylabel('Score', fontsize=12)
plt.ylim(80, 95)

# 막대 위에 수치 표시
for i, v in enumerate(means):
    plt.text(i, v + 0.3, str(v), ha='center', fontsize=13, fontweight='bold')

plt.show()

    이 코드를 실행하면 세 과목의 평균 점수를 비교하는 막대 그래프가 나타납니다.

    Step 6: 학생별 총점과 등수 구하기¶

    # 총점 열 추가
df["총점"] = df["수학"] + df["영어"] + df["과학"]

# 총점 기준 내림차순 정렬
df_sorted = df.sort_values("총점", ascending=False).reset_index(drop=True)

# 등수 열 추가
df_sorted["등수"] = range(1, len(df_sorted) + 1)

print(df_sorted)

    📝 전체 코드¶

    아래 코드를 Colab 셀에 복사해서 한 번에 실행할 수 있습니다.

    # ============================
# Chapter 01: 나의 첫 데이터 분석
# ============================

import pandas as pd
import matplotlib.pyplot as plt

# 1. 데이터 만들기
data = {
    "이름": ["민수", "지은", "태호", "수빈", "하준"],
    "수학": [85, 92, 78, 95, 88],
    "영어": [90, 88, 95, 82, 91],
    "과학": [88, 95, 82, 90, 85]
}
df = pd.DataFrame(data)

# 2. 기초 통계
print("=== 기초 통계 ===")
print(df.describe())
print()

# 3. 과목별 평균
print("=== 과목별 평균 ===")
print(df[["수학", "영어", "과학"]].mean())
print()

# 4. 시각화
plt.rcParams['font.family'] = 'DejaVu Sans'
subjects = ['Math', 'English', 'Science']
means = [df["수학"].mean(), df["영어"].mean(), df["과학"].mean()]

plt.figure(figsize=(8, 5))
plt.bar(subjects, means, color=['#5B9BD5', '#ED7D31', '#70AD47'])
plt.title('Average Score by Subject', fontsize=16)
plt.ylabel('Score', fontsize=12)
plt.ylim(80, 95)
for i, v in enumerate(means):
    plt.text(i, v + 0.3, f'{v:.1f}', ha='center', fontsize=13, fontweight='bold')
plt.show()

# 5. 총점과 등수
df["총점"] = df["수학"] + df["영어"] + df["과학"]
df_sorted = df.sort_values("총점", ascending=False).reset_index(drop=True)
df_sorted["등수"] = range(1, len(df_sorted) + 1)
print("=== 최종 결과 ===")
print(df_sorted)

    ⚠️ 자주 하는 실수¶

    실수 1: 라이브러리 import를 빼먹는다¶

    # ❌ 오류 발생
df = pd.DataFrame(data)
# NameError: name 'pd' is not defined

# ✅ 올바른 방법
import pandas as pd  # 반드시 먼저 실행!
df = pd.DataFrame(data)

    💡 코드 파일의 맨 위에서 필요한 라이브러리를 모두 import하는 습관을 들이세요.

    실수 2: 대소문자를 구분하지 않는다¶

    # ❌ 오류 발생
Import Pandas as pd   # 'Import'와 'Pandas' 대문자 사용
DF = pd.dataframe(data)  # 'dataframe' 소문자

# ✅ 올바른 방법
import pandas as pd       # 모두 소문자
df = pd.DataFrame(data)   # DataFrame의 D와 F는 대문자

    💡 Python은 대소문자를 구분합니다. DataFrame과 dataframe은 완전히 다릅니다!

    실수 3: 열 이름을 따옴표 없이 사용한다¶

    # ❌ 오류 발생
print(df[수학])
# NameError: name '수학' is not defined

# ✅ 올바른 방법
print(df["수학"])  # 열 이름은 반드시 따옴표로 감싸기

    💡 DataFrame에서 열에 접근할 때는 문자열(따옴표 포함)로 열 이름을 지정해야 합니다.

    Chapter 15: 데이터 과학 프로젝트 2 — 지혜로운 어부 생활 🐟¶

    🎯 이 장에서 배우는 것¶

    • 수산·해양 관련 공공데이터를 수집하고 전처리할 수 있다
    • 시계열 데이터의 특성을 이해하고 탐색적 데이터 분석(EDA)을 수행할 수 있다
    • 회귀 모델을 적용하여 어획량을 예측할 수 있다
    • 분석 결과를 시각화하고 데이터 기반 '지혜로운 어부 가이드'를 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    "오늘 어시장에 갈치가 비싼 이유를 데이터로 설명할 수 있을까?"

    여러분이 좋아하는 생선구이, 회덮밥, 어묵의 가격은 어획량에 따라 크게 달라집니다. 어획량은 바다 수온, 계절, 해류, 기후변화 등 다양한 요인에 의해 변합니다. 만약 어부가 "다음 달에는 고등어가 많이 잡힐 거야"라고 데이터에 기반한 예측을 할 수 있다면 어떨까요?

    이번 프로젝트에서는 실제 공공데이터를 활용하여 어획량을 분석하고 예측하는 전체 과정을 경험합니다. 지금까지 배운 전처리, EDA, 시각화, 회귀 분석을 하나의 프로젝트로 엮는 마지막 여정입니다. 이 과정을 마치면 여러분은 어떤 데이터든 스스로 분석하고 인사이트를 도출할 수 있는 데이터 과학자가 됩니다.

    📚 핵심 개념¶

    개념 1: 수산 공공데이터의 이해 🗃️¶

    1) 비유로 시작

    도서관에 가면 책이 분류번호별로 정리되어 있듯이, 정부에서 공개하는 공공데이터도 분야별로 체계적으로 정리되어 있습니다. 수산 데이터는 마치 "바다의 일기장"과 같습니다. 언제, 어디서, 어떤 물고기가, 얼마나 잡혔는지를 꼼꼼히 기록해 놓은 것이죠.

    2) 정확한 정의

    수산 공공데이터란 정부 기관(통계청, 해양수산부, 국립수산과학원 등)이 수집·공개하는 수산업 관련 통계 데이터입니다. 대표적으로 다음과 같은 데이터가 있습니다.

    • 어업생산통계: 연도별·어종별·지역별 어획량 데이터
    • 수산물 가격 정보: 주요 수산시장의 일별·월별 가격 데이터
    • 해양환경 데이터: 바다 수온, 염분 농도, 해류 정보

    3) 예시로 확인

    이번 프로젝트에서는 연도별 주요 어종의 어획량 데이터를 직접 만들어 사용합니다. 실제 통계청 KOSIS(kosis.kr)에서 다운로드할 수 있는 데이터의 형태를 모사(模寫)한 것으로, 현실 데이터의 패턴을 반영하고 있습니다.

    알아보기 📖

    실제 공공데이터를 활용하고 싶다면 다음 사이트를 방문해 보세요. - 공공데이터포털: data.go.kr - 통계청 KOSIS: kosis.kr - 국립수산과학원: nifs.go.kr

    검색창에 "어업생산통계" 또는 "어획량"을 입력하면 다양한 데이터셋을 찾을 수 있습니다.

    개념 2: 시계열 데이터와 트렌드 📈¶

    1) 비유로 시작

    여러분의 키를 1학년부터 3학년까지 매년 측정해서 기록했다고 생각해 보세요. 이 데이터를 그래프로 그리면 "아, 나는 매년 꾸준히 커왔구나" 또는 "2학년 때 갑자기 많이 컸네"와 같은 시간에 따른 변화 패턴을 발견할 수 있습니다. 어획량 데이터도 마찬가지입니다.

    2) 정확한 정의

    시계열 데이터(Time Series Data) 란 일정한 시간 간격으로 측정된 데이터의 연속입니다. 시계열 데이터에서 발견할 수 있는 주요 패턴은 다음과 같습니다.

    • 트렌드(Trend): 장기적으로 증가하거나 감소하는 경향 — "최근 10년간 명태 어획량이 꾸준히 줄었다"
    • 계절성(Seasonality): 특정 시기에 반복되는 패턴 — "가을에 고등어가 많이 잡힌다"
    • 이상치(Outlier): 예상에서 크게 벗어난 값 — "2020년에 갑자기 어획량이 급감했다"

    3) 예시로 확인

    graph TD subgraph "시계열 데이터의 3가지 패턴" T["📉 트렌드<br/>장기적 방향성"] S["🔄 계절성<br/>반복 패턴"] O["⚡ 이상치<br/>돌발 변화"] end T --- 예시1["명태 어획량 10년간 감소"] S --- 예시2["고등어: 매년 9~11월 최대"] O --- 예시3["태풍으로 한 달 어획 중단"]

    개념 3: 어획량 예측을 위한 회귀 분석 🎯¶

    1) 비유로 시작

    시험 점수를 예측한다고 생각해 봅시다. "공부 시간이 1시간 늘면 점수가 약 5점 오른다"는 관계를 발견했다면, 공부 시간으로 점수를 예측할 수 있겠죠? 어획량도 마찬가지입니다. "바다 수온이 1도 오르면 고등어 어획량이 약 몇 톤 변한다"와 같은 관계를 찾는 것이 회귀 분석입니다.

    2) 정확한 정의

    회귀 분석(Regression Analysis) 은 독립변수(원인)와 종속변수(결과) 사이의 관계를 수학적으로 모델링하여 예측하는 통계 기법입니다.

    • 독립변수(X): 예측에 사용하는 변수 — 연도, 수온, 강수량 등
    • 종속변수(y): 예측하고자 하는 변수 — 어획량
    • 모델: y = β₀ + β₁X₁ + β₂X₂ + ... (선형 회귀의 경우)

    3) 예시로 확인

    이번 프로젝트에서 사용할 변수 관계를 정리하면 다음과 같습니다.

    • 예측 목표(y): 특정 어종의 연간 어획량(톤)
    • 독립변수(X): 연도, 평균 해수면 온도, 연간 강수량

    생각해보기 💭

    "연도"를 독립변수로 사용하면 어떤 의미일까요? → 연도는 그 자체가 원인이라기보다, 시간이 흐르면서 변하는 여러 환경 변화를 대표하는 변수 역할을 합니다. 기후변화, 어업 기술 발전, 수산 정책 변화 등이 "연도"에 녹아 있는 셈이죠.

    개념 4: 데이터 스토리텔링과 가이드 작성 📋¶

    1) 비유로 시작

    의사가 건강검진 결과를 환자에게 설명할 때, 숫자만 나열하지 않습니다. "콜레스테롤 수치가 높으니 기름진 음식을 줄이세요"처럼 데이터를 해석하고 행동 지침으로 바꿔줍니다. 데이터 과학자도 마찬가지입니다. 분석 결과를 누구나 이해할 수 있는 이야기로 전달하는 것이 중요합니다.

    2) 정확한 정의

    데이터 스토리텔링(Data Storytelling) 이란 데이터 분석 결과를 시각화, 내러티브(이야기), 맥락과 결합하여 의사결정자나 일반 대중이 이해하고 행동할 수 있도록 전달하는 기술입니다.

    좋은 데이터 스토리텔링의 세 가지 요소는 다음과 같습니다.

    • 데이터(Data): 신뢰할 수 있는 분석 결과
    • 시각화(Visualization): 한눈에 파악되는 그래프와 차트
    • 내러티브(Narrative): "그래서 어쩌란 말이야?"에 답하는 해석과 제안

    3) 예시로 확인

    🔨 따라하기: 지혜로운 어부 프로젝트 완성하기¶

    이제 본격적으로 프로젝트를 진행합니다. 6단계를 차근차근 따라가 봅시다!

    Step 1: 데이터 준비 — 바다의 일기장 만들기 📖¶

    실제 프로젝트에서는 공공데이터포털에서 CSV 파일을 다운로드하지만, 여기서는 현실적인 패턴을 반영한 데이터를 직접 생성합니다. 이 데이터는 실제 통계를 참고하여 만든 것으로, 분석 연습에 적합합니다.

    import pandas as pd
import numpy as np

# 재현 가능한 결과를 위해 시드 고정
np.random.seed(42)

# === 1. 연도별 어획량 데이터 생성 ===
years = list(range(2005, 2024))  # 2005년 ~ 2023년
n = len(years)

# 평균 해수면 온도 (점진적 상승 트렌드 + 랜덤 변동)
temperature = 15.0 + np.arange(n) * 0.08 + np.random.normal(0, 0.3, n)

# 연간 강수량 (mm, 랜덤 변동)
rainfall = 1200 + np.random.normal(0, 150, n)

# 어종별 어획량 (톤)
# 고등어: 수온 상승에 따라 약간 감소 추세
mackerel = 300000 - np.arange(n) * 5000 + temperature * 2000 + np.random.normal(0, 15000, n)

# 오징어: 수온에 민감, 최근 급감 추세
squid = 200000 - np.arange(n) * 8000 - (temperature - 15) * 10000 + np.random.normal(0, 10000, n)

# 멸치: 비교적 안정적
anchovy = 250000 + np.random.normal(0, 20000, n)

# 갈치: 완만한 감소

    Step 2: 데이터 전처리 — 깨끗한 데이터 만들기 🧹¶

    실제 공공데이터에는 결측값, 이상치, 형식 불일치 등이 흔합니다. 현실적인 연습을 위해 일부러 결측값과 이상치를 넣고 처리하는 과정을 경험해 봅시다.

    # === 2. 현실적인 전처리 연습 ===

# 결측값 인위적으로 추가 (현실 데이터 시뮬레이션)
df_raw = df.copy()
df_raw.loc[3, '오징어_어획량'] = np.nan   # 2008년 오징어 데이터 누락
df_raw.loc[7, '평균_해수면_온도'] = np.nan  # 2012년 수온 데이터 누락
df_raw.loc[12, '갈치_어획량'] = np.nan     # 2017년 갈치 데이터 누락

# 이상치 추가 (입력 오류 시뮬레이션)
df_raw.loc[5, '멸치_어획량'] = -5000  # 음수 어획량 (입력 오류)

print("=== 전처리 전 데이터 점검 ===")
print("\n1. 결측값 확인:")
print(df_raw.isnull().sum())

print("\n2. 음수값 확인:")
for col in ['고등어_어획량', '오징어_어획량', '멸치_어획량', '갈치_어획량']:
    neg_count = (df_raw[col] < 0).sum()
    if neg_count > 0:
        print(f"  ⚠️ {col}: {neg_count}개의 음수값 발견!")

    # === 전처리 수행 ===

df_clean = df_raw.copy()

# 1) 결측값 처리: 전후 연도의 평균으로 보간 (선형 보간)
df_clean = df_clean.interpolate(method='linear')
print("✅ 결측값 선형 보간 완료")
print(f"   남은 결측값: {df_clean.isnull().sum().sum()}개")

# 2) 음수값 처리: 어획량은 0 이상이어야 함
catch_cols = ['고등어_어획량', '오징어_어획량', '멸치_어획량', '갈치_어획량']
for col in catch_cols:
    neg_mask = df_clean[col] < 0
    if neg_mask.any():
        # 음수값을 전후 평균으로 대체
        for idx in df_clean[neg_mask].index:
            prev_val = df_clean.loc[max(0, idx-1), col]
            next_val = df_clean.loc[min(len(df_clean)-1, idx+1), col]
            df_clean.loc[idx, col] = (prev_val + next_val) / 2
        print(f"✅ {col}: 음수값 {neg_mask.sum()}개 수정 완료")

# 3) 데이터 타입 정리
df_clean['연도'] = df_clean['연도'].astype(int)
for col in catch_cols:
    df_clean[col] = df_clean[col].round(0).astype(int)

print("\n=== 전처리 후 기본 통계 ===")
print(df_clean.describe().round(1))

    모델 성능 지표 쉽게 이해하기

    • R² (결정계수): 0~1 사이 값. "모델이 데이터의 변동을 몇 %나 설명하는가?"
    • 0.9 = 90% 설명 → 매우 좋음
    • 0.7 = 70% 설명 → 좋음

    • 0.5 미만 = 50% 미만 → 개선 필요

    • RMSE: "예측이 실제와 평균적으로 얼마나 차이나는가?" (단위가 원래 데이터와 같음)

    • MAE: RMSE와 비슷하지만, 큰 오차에 덜 민감함

    # ============================================================
# 🐟 지혜로운 어부 생활 — 전체 코드

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score, mean_absolute_error

# --- 설정 ---
np.random.seed(42)
plt.rcParams['font.family'] = 'Malgun Gothic'  # Mac: 'AppleGothic'
plt.rcParams['axes.unicode_minus'] = False

# ============================================================
# STEP 1: 데이터 생성
# ============================================================
years = list(range(2005, 2024))
n = len(years)

temperature = 15.0 + np.arange(n) * 0.08 + np.random.normal(0, 0.3, n)
rainfall = 1200 + np.random.normal(0, 150, n)
mackerel = 300000 - np.arange(n)*5000 + temperature*2000 + np.random.normal(0, 15000, n)
squid = 200000 - np.arange(n)*8000 - (temperature-15)*10000 + np.random.normal(0, 10000, n)
anchovy = 250000 + np.random.normal(0, 20000, n)
hairtail = 100000 - np.arange(n)*2000 + np.random.normal(0, 8000, n)

df = pd.DataFrame({
    '연도': years,
    '평균_해수면_온도': np.round(temperature, 1),
    '연간_강수량': np.round(rainfall, 0),
    '고등어_어획량': np.round(mackerel, 0).astype(int),
    '오징어_어획량': np.round(np.maximum(squid, 10000), 0).astype(int),
    '멸치_어획량': np.round(anchovy, 0).astype(int),
    '갈치_어획량': np.round(np.maximum(hairtail, 10000), 0).astype(int)
})

# ============================================================
# STEP 2: 전처리
# ============================================================
df_raw = df.copy()
df_raw.loc[3, '오징어_어획량'] = np.nan
df_raw.loc[7, '평균_해수면_온도'] = np.nan
df_raw.loc[12, '갈치_어획량'] = np.nan
df_raw.loc[5, '멸치_어획량'] = -5000

df_clean = df_raw.copy()
df_clean = df_clean.interpolate(method='linear')

catch_cols = ['고등어_어획량', '오징어_어획량', '멸치_어획량', '갈치_어획량']
for col in catch_cols:
    neg_mask = df_clean[col] < 0
    if neg_mask.any():
        for idx in df_clean[neg_mask].index:
            prev_val = df_clean.loc[max(0, idx-1), col]
            next_val = df_clean.loc[min(len(df_clean)-1, idx+1), col]
            df_clean.loc[idx, col] = (prev_val + next_val) / 2

df_clean['연도'] = df_clean['연도'].astype(int)
for col in catch_cols:
    df_clean[col] = df_clean[col].round(0).astype(int)

# ============================================================

# ============================================================

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

fish_info = [

plt.tight_layout()

plt.show()

fig, ax = plt.subplots(figsize=(8, 6))
im = ax.imshow(corr_matrix.values, cmap='RdBu_r', vmin=-1, vmax=1)

X = df_clean[['연도', '평균_해수면_온도', '연간_강수량']]
y = df_clean['오징어_어획량']

X_train = X[X['연도'] <= 2019]
X_test = X[X['연도'] > 2019]
y_train = y[:len(X_train)]

model = LinearRegression()
model.fit(X_train, y_train)

y_pred_train = model.predict(X_train)
y_pred_test = model.predict(X_test)

r2_train = r2_score(y_train, y_pred_train)
r2_test = r2_score(y_test, y_pred_test)
rmse_test = np.sqrt(mean_squared_error(y_test, y_pred_test))
mae_test = mean_absolute_error(y_test, y_pred_test)

print(f"R² (학습): {r2_train:.4f}")
print(f"R² (테스트): {r2_test:.4f}")

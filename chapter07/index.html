    Chapter 07. 데이터 전처리 (1) — 결측치와 이상치 처리¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 결측치(NaN)가 무엇이고 왜 발생하는지 설명할 수 있다
    • isnull(), dropna(), fillna()로 결측치를 탐지하고 처리할 수 있다
    • IQR 방법으로 이상치를 탐지하고 제거할 수 있다
    • 전처리 전후 데이터를 비교하며 전처리의 필요성을 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: 설문 조사에서 100명에게 답을 받았는데, 20명이 나이를 빈칸으로 남겼습니다. 이 데이터로 "응답자의 평균 나이"를 구하려면 어떻게 해야 할까요?

    현실의 데이터는 완벽하지 않습니다. 센서 오류로 측정값이 빠지기도 하고, 사람의 실수로 엉뚱한 숫자가 들어가기도 합니다. 이런 데이터를 그대로 분석하면 결과가 왜곡됩니다.

    예를 들어, 우리 반 시험 점수를 분석하는데 한 학생의 점수가 -50점으로 입력되어 있다면? 평균이 확 낮아지겠죠. 이처럼 데이터를 분석하기 전에 먼저 "청소"하는 과정이 바로 데이터 전처리입니다.

    이번 장에서는 전처리의 가장 기본이 되는 두 가지, 결측치와 이상치 처리를 배웁니다.

    📚 핵심 개념¶

    개념 1: 결측치(Missing Value)란?¶

    1. 비유로 시작 📝

    시험지를 생각해보세요. 50문제 중 5문제를 아예 빈칸으로 제출했다면, 그 5문제의 점수는 "없음"입니다. 0점도 아니고, 틀린 것도 아니고, 그냥 답 자체가 없는 상태 — 이것이 결측치입니다.

    2. 정확한 정의

    결측치(Missing Value)란 데이터에서 값이 기록되지 않은 빈 항목을 말합니다. 판다스에서는 NaN(Not a Number)으로 표시됩니다.

    3. 결측치가 발생하는 이유

    • 수집 단계: 센서 고장, 설문 미응답, 통신 오류
    • 입력 단계: 사람의 실수, 형식 불일치
    • 변환 단계: 데이터를 합치는 과정에서 매칭 실패
    flowchart LR A["원본 데이터"] --> B{"결측치 존재?"} B -- "Yes" --> C["탐지<br/>isnull()"] C --> D{"얼마나 많은가?"} D -- "적음" --> E["삭제<br/>dropna()"] D -- "많음" --> F["대체<br/>fillna()"] B -- "No" --> G["다음 단계로"] E --> G F --> G

    개념 2: 결측치 처리 — 삭제와 대체¶

    결측치를 만나면 크게 두 가지 전략을 선택합니다.

    전략 1: 삭제 (dropna())

    빈칸이 있는 행(또는 열)을 통째로 지우는 방법입니다.

    • 장점: 간단하고 빠르다
    • 단점: 데이터가 줄어든다 (결측치가 많으면 데이터 대부분이 사라질 수 있음)
    • 적합한 경우: 전체 데이터 대비 결측치가 아주 적을 때 (보통 5% 이하)

    전략 2: 대체 (fillna())

    빈칸을 적절한 값으로 채우는 방법입니다.

    • 평균(mean)으로 채우기: 전체 경향을 반영하지만 이상치에 영향받음
    • 중앙값(median)으로 채우기: 이상치에 덜 민감, 가장 흔히 사용
    • 특정 값으로 채우기: 상황에 맞는 값 (예: 0, "없음" 등)

    알아보기 💡: 평균 vs 중앙값, 언제 뭘 쓸까?

    데이터에 극단적으로 크거나 작은 값이 있으면 평균이 왜곡됩니다. 예를 들어, 용돈이 [1만, 2만, 2만, 3만, 50만]이면 평균은 11.6만이지만 중앙값은 2만입니다. 이런 경우 중앙값이 더 안전한 선택입니다.

    개념 3: 이상치(Outlier)란?¶

    1. 비유로 시작 🎯

    우리 반 키를 측정했는데, 대부분 150~180cm인데 한 명이 350cm로 기록되었다면? 이건 거인이 아니라 입력 실수일 가능성이 높습니다. 이렇게 다른 데이터와 동떨어진 값을 이상치라고 합니다.

    2. 정확한 정의

    이상치(Outlier)란 데이터의 전반적인 패턴에서 비정상적으로 벗어난 극단값을 말합니다.

    3. 이상치의 두 가지 유형

    • 오류 이상치: 입력 실수, 센서 고장 등 → 제거해야 함
    • 진짜 이상치: 실제로 극단적인 값 (예: 빌 게이츠의 자산) → 분석 목적에 따라 판단

    개념 4: IQR 방법으로 이상치 탐지하기¶

    1. 비유로 시작 📦

    박스플롯(상자 그림)을 떠올려보세요. 상자 안에 데이터의 중간 50%가 들어 있고, 상자 밖으로 너무 멀리 떨어진 점들이 이상치입니다.

    2. IQR 방법의 원리

    • Q1 (25번째 백분위수): 데이터의 하위 25% 지점
    • Q3 (75번째 백분위수): 데이터의 상위 25% 지점
    • IQR = Q3 - Q1 (데이터 중간 50%의 범위)
    flowchart LR A["Q1 구하기<br/>(25%)"] --> B["Q3 구하기<br/>(75%)"] B --> C["IQR = Q3 - Q1"] C --> D["하한 = Q1 - 1.5×IQR"] C --> E["상한 = Q3 + 1.5×IQR"] D --> F["하한 미만 → 이상치"] E --> G["상한 초과 → 이상치"]

    3. 예시로 확인

    미세먼지 농도(PM2.5)가 다음과 같다고 합시다.

    • Q1 = 15, Q3 = 45이면 IQR = 30
    • 하한 = 15 - 1.5 × 30 = -30 (음수이므로 사실상 0 이하)
    • 상한 = 45 + 1.5 × 30 = 90
    • 따라서 90을 초과하는 값은 이상치로 의심!

    🔨 따라하기¶

    구글 코랩에서 직접 따라해봅시다. 대기질 데이터(미세먼지 측정치)를 만들어 결측치와 이상치를 처리합니다.

    Step 1: 실습용 데이터 만들기¶

    실제 상황을 흉내 낸 가상의 미세먼지 데이터를 만듭니다.

    import pandas as pd
import numpy as np

# 재현 가능하도록 시드 고정
np.random.seed(42)

# 가상 대기질 데이터 생성 (30일간 측정)
data = {
    '날짜': pd.date_range('2024-03-01', periods=30),
    'PM2.5': [25, 30, np.nan, 42, 38, 15, np.nan, 55, 28, 33,
              200, 22, 18, np.nan, 45, 50, 27, 31, np.nan, 40,
              35, 29, 48, 300, 20, np.nan, 37, 44, 26, 32],
    'PM10': [45, 60, 55, np.nan, 78, 30, 50, 90, np.nan, 65,
             350, 42, 38, 70, np.nan, 85, 52, 61, 48, 80,
             68, 55, 92, 500, 40, 58, np.nan, 88, 50, 63]
}

df = pd.DataFrame(data)
print("📊 원본 데이터 (처음 10행)")
print(df.head(10))
print(f"\n데이터 크기: {df.shape[0]}행 × {df.shape[1]}열")

    확인 포인트: NaN이 보이나요? 이것이 결측치입니다. 200, 300, 350, 500 같은 값은 이상치로 의심되는 값들입니다.

    Step 2: 결측치 탐지하기¶

    # 결측치 확인
print("🔍 결측치 현황")
print(df.isnull().sum())  # 각 열별 결측치 개수

print(f"\n전체 데이터 중 결측치 비율:")
print(round(df.isnull().sum() / len(df) * 100, 1))

    isnull()은 각 칸이 비어있으면 True, 아니면 False를 반환합니다. .sum()으로 True의 개수(= 결측치 수)를 셀 수 있습니다.

    Step 3: 결측치 처리하기 — 삭제와 대체 비교¶

    # 방법 1: 결측치가 있는 행 삭제
df_dropped = df.dropna()
print(f"✂️ 삭제 후 데이터 수: {len(df)} → {len(df_dropped)}행")

# 방법 2: 평균으로 채우기
df_mean = df.copy()
df_mean['PM2.5'] = df_mean['PM2.5'].fillna(df_mean['PM2.5'].mean())
df_mean['PM10'] = df_mean['PM10'].fillna(df_mean['PM10'].mean())
print(f"\n📊 평균으로 채운 후 PM2.5 평균: {df_mean['PM2.5'].mean():.1f}")

# 방법 3: 중앙값으로 채우기
df_median = df.copy()
df_median['PM2.5'] = df_median['PM2.5'].fillna(df_median['PM2.5'].median())
df_median['PM10'] = df_median['PM10'].fillna(df_median['PM10'].median())
print(f"📊 중앙값으로 채운 후 PM2.5 평균: {df_median['PM2.5'].mean():.1f}")

# 원본(결측치 제외)과 비교
print(f"\n📊 원본 PM2.5 평균 (결측치 제외): {df['PM2.5'].mean():.1f}")

    생각해보기 🤔: 평균으로 채웠을 때와 중앙값으로 채웠을 때, 결과가 다른가요? 왜 다를까요?

    Step 4: 이상치 탐지 — 박스플롯으로 눈에 보기¶

    import matplotlib.pyplot as plt

# 중앙값으로 결측치를 채운 데이터 사용
df_clean = df_median.copy()

# 박스플롯으로 이상치 시각적 확인
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].boxplot(df_clean['PM2.5'])
axes[0].set_title('PM2.5')
axes[0].set_ylabel('Concentration')

axes[1].boxplot(df_clean['PM10'])
axes[1].set_title('PM10')
axes[1].set_ylabel('Concentration')

plt.suptitle('Box Plot - Outlier Detection', fontsize=14)
plt.tight_layout()
plt.show()

    박스(상자) 바깥의 동그란 점이 바로 이상치입니다!

    Step 5: IQR 방법으로 이상치 제거하기¶

    def remove_outliers_iqr(dataframe, column):
    """IQR 방법으로 이상치를 제거하는 함수"""
    Q1 = dataframe[column].quantile(0.25)
    Q3 = dataframe[column].quantile(0.75)
    IQR = Q3 - Q1

    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    print(f"[{column}] Q1={Q1:.1f}, Q3={Q3:.1f}, IQR={IQR:.1f}")
    print(f"  → 정상 범위: {lower_bound:.1f} ~ {upper_bound:.1f}")

    # 이상치 개수 확인
    outliers = dataframe[
        (dataframe[column] < lower_bound) | (dataframe[column] > upper_bound)
    ]
    print(f"  → 이상치 {len(outliers)}개 발견: {outliers[column].tolist()}")

    # 정상 범위만 남기기
    mask = (dataframe[column] >= lower_bound) & (dataframe[column] <= upper_bound)
    return mask

print("🔎 이상치 탐지 결과")
mask_pm25 = remove_outliers_iqr(df_clean, 'PM2.5')
print()
mask_pm10 = remove_outliers_iqr(df_clean, 'PM10')

# 두 열 모두 정상인 행만 남기기
df_final = df_clean[mask_pm25 & mask_pm10].copy()
print(f"\n✅ 최종 데이터: {len(df_clean)}행 → {len(df_final)}행")

    Step 6: 전처리 전후 비교하기¶

    # 전처리 전후 비교
print("=" * 45)
print("📈 전처리 전후 비교")
print("=" * 45)

print(f"\n[데이터 수]")
print(f"  원본: {len(df)}행 (결측치 포함)")
print(f"  최종: {len(df_final)}행")

print(f"\n[PM2.5 평균]")
print(f"  원본 (결측 제외): {df['PM2.5'].mean():.1f}")
print(f"  전처리 후:        {df_final['PM2.5'].mean():.1f}")

print(f"\n[PM2.5 표준편차]")
print(f"  원본 (결측 제외): {df['PM2.5'].std():.1f}")
print(f"  전처리 후:        {df_final['PM2.5'].std():.1f}")

# 전후 박스플롯 비교
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].boxplot(df['PM2.5'].dropna())
axes[0].set_title('Before (Raw PM2.5)')

axes[1].boxplot(df_final['PM2.5'])
axes[1].set_title('After (Cleaned PM2.5)')

plt.suptitle('Before vs After Preprocessing', fontsize=14)
plt.tight_layout()
plt.show()

    정리하기 📌: 전처리 후 평균이 낮아지고 표준편차가 줄었다면, 이상치(200, 300 등)가 평균을 끌어올리고 데이터를 퍼뜨리고 있었다는 뜻입니다. 전처리를 통해 더 정확한 데이터를 얻게 된 것입니다!

    📝 전체 코드¶

    아래 코드를 코랩에 하나의 셀에 붙여넣으면 전체 과정을 한 번에 실행할 수 있습니다.

    import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 1. 데이터 생성
np.random.seed(42)
data = {
    '날짜': pd.date_range('2024-03-01', periods=30),
    'PM2.5': [25, 30, np.nan, 42, 38, 15, np.nan, 55, 28, 33,
              200, 22, 18, np.nan, 45, 50, 27, 31, np.nan, 40,
              35, 29, 48, 300, 20, np.nan, 37, 44, 26, 32],
    'PM10': [45, 60, 55, np.nan, 78, 30, 50, 90, np.nan, 65,
             350, 42, 38, 70, np.nan, 85, 52, 61, 48, 80,
             68, 55, 92, 500, 40, 58, np.nan, 88, 50, 63]
}
df = pd.DataFrame(data)

# 2. 결측치 확인
print("🔍 결측치 현황")
print(df.isnull().sum())

# 3. 결측치 처리 (중앙값 대체)
df_clean = df.copy()
df_clean['PM2.5'] = df_clean['PM2.5'].fillna(df_clean['PM2.5'].median())
df_clean['PM10'] = df_clean['PM10'].fillna(df_clean['PM10'].median())

# 4. 이상치 제거 (IQR)
def remove_outliers_iqr(dataframe, column):
    Q1 = dataframe[column].quantile(0.25)
    Q3 = dataframe[column].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    return (dataframe[column] >= lower) & (dataframe[column] <= upper)

mask = remove_outliers_iqr(df_clean, 'PM2.5') & remove_outliers_iqr(df_clean, 'PM10')
df_final = df_clean[mask].copy()

# 5. 전후 비교
print(f"\n✅ 원본: {len(df)}행 → 최종: {len(df_final)}행")
print(f"PM2.5 평균: {df['PM2.5'].mean():.1f} → {df_final['PM2.5'].mean():.1f}")

# 6. 시각화
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].boxplot(df['PM2.5'].dropna())
axes[0].set_title('Before')
axes[1].boxplot(df_final['PM2.5'])
axes[1].set_title('After')
plt.suptitle('PM2.5 Preprocessing Result')
plt.tight_layout()
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: fillna()를 했는데 원본이 안 바뀌어요!

    # ❌ 잘못된 방법 — 결과를 저장하지 않음
df['PM2.5'].fillna(0)       # 결과가 공중에 사라짐!

# ✅ 올바른 방법 — 결과를 다시 저장
df['PM2.5'] = df['PM2.5'].fillna(0)

    fillna()는 원본을 바꾸지 않고 새로운 결과를 반환합니다. 반드시 =로 저장하세요.

    실수 2: 결측치를 0으로 채우면 괜찮다고 생각하기

    미세먼지가 측정되지 않았다고 해서 0μg/m³인 것은 아닙니다. 0으로 채우면 평균이 부당하게 낮아집니다. 데이터의 의미를 생각해서 적절한 값을 선택하세요.

    실수 3: 이상치를 무조건 제거하기

    이상치라고 해서 무조건 지우면 안 됩니다. 만약 실제로 미세먼지가 200μg/m³까지 치솟은 날이 있었다면, 그건 의미 있는 데이터입니다. 항상 "이 값이 오류인가, 실제인가?"를 먼저 판단하세요.

    정답 보기 데이터의 60%가 삭제되어 **남은 데이터가 너무 적어집니다.** 분석 결과를 신뢰하기 어려워지므로, 이런 경우에는 `fillna()`로 대체하는 것이 더 적절합니다.

    응용 문제

    Q3. 아래 데이터에서 IQR 방법으로 이상치를 찾으세요.

    [10, 12, 14, 15, 16, 18, 20, 100]

    정답 보기 - Q1 = 13 (12와 14의 중간), Q3 = 19 (18과 20의 중간) - IQR = 19 - 13 = 6 - 하한 = 13 - 1.5 × 6 = 4 - 상한 = 19 + 1.5 × 6 = 28 - **100**은 28을 초과하므로 **이상치!** (계산 방식에 따라 Q1, Q3 값이 약간 다를 수 있지만, 100이 이상치라는 결론은 동일합니다.)

# 다양한 방법으로 채워보기
for method, value in [('0', 0), 
                       ('평균', df['PM2.5'].mean()),
                       ('중앙값', df['PM2.5'].median()),
                       ('최솟값', df['PM2.5'].min()),
                       ('최댓값', df['PM2.5'].max())]:
    filled = df['PM2.5'].fillna(value)
    print(f"  {method:5s}으로 채움 → 평균: {filled.mean():.1f}")

    Chapter 07. 데이터 속성 간의 관계 파악¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 상관관계의 개념을 이해하고, 상관계수의 값(-1~+1)을 해석할 수 있다
    • 산점도(scatter plot)를 그려 두 변수의 관계를 눈으로 확인할 수 있다
    • 히트맵(heatmap)으로 여러 변수 간 상관관계를 한눈에 파악할 수 있다
    • 상관관계와 인과관계의 차이를 구분하여 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    "아이스크림 판매량이 늘어나면, 익사 사고도 늘어난다."

    이 말이 사실이라면… 아이스크림이 위험한 음식일까요?

    당연히 아닙니다! 여름이라는 공통 원인 때문에 두 수치가 함께 올라간 것뿐이죠. 기온이 높아지면 아이스크림도 많이 팔리고, 물놀이를 하는 사람도 많아져 익사 사고가 느는 것입니다.

    이처럼 데이터를 다룰 때는 "두 속성이 함께 변하는 패턴(상관관계)" 을 찾아내는 능력이 필수입니다. 하지만 동시에 "함께 변한다고 해서 하나가 다른 하나의 원인은 아니다" 라는 사실도 알아야 합니다.

    이번 장에서는 데이터 속성 간의 관계를 숫자와 그래프로 파악하는 방법을 배웁니다. 이전 장에서 데이터를 정리하고 시각화하는 법을 익혔으니, 이제 한 걸음 더 나아가 속성들 사이에 숨겨진 패턴을 발견해 봅시다!

    📚 핵심 개념¶

    개념 1: 상관관계란? 🔗¶

    1) 비유로 시작

    놀이공원에서 롤러코스터 줄이 길어지면, 옆 매점의 음료 판매량도 올라가는 경향이 있습니다. 사람이 많이 오는 날은 줄도 길고, 음료도 많이 팔리니까요. 이렇게 두 값이 함께 변하는 경향을 "상관관계가 있다"고 합니다.

    2) 정확한 정의

    • 상관관계(Correlation): 두 변수가 함께 변하는 방향과 정도를 나타내는 통계적 관계
    • 양의 상관관계: 한 변수가 커지면 다른 변수도 커지는 경향 (예: 키↑ → 몸무게↑)
    • 음의 상관관계: 한 변수가 커지면 다른 변수는 작아지는 경향 (예: 결석일수↑ → 성적↓)
    • 상관관계 없음: 두 변수 사이에 뚜렷한 패턴이 없음 (예: 신발 사이즈와 수학 점수)

    3) 예시로 확인

    알아보기 📖

    • 기온과 아이스크림 판매량 → 양의 상관관계
    • 공부 시간과 게임 시간 → 음의 상관관계 (하루는 24시간이니까!)
    • 혈액형과 시험 점수 → 상관관계 없음

    개념 2: 상관계수 — 관계를 숫자로 표현하기 🔢¶

    1) 비유로 시작

    시험 점수가 0점~100점 사이인 것처럼, 두 변수의 관계 강도도 숫자로 매길 수 있습니다. 이 "관계 점수"가 바로 상관계수입니다.

    2) 정확한 정의

    • 피어슨 상관계수(r): 두 변수의 선형 관계를 -1에서 +1 사이의 숫자로 나타낸 값
    • r = +1: 완벽한 양의 상관 (한 점도 빗나가지 않고 직선 위에 올라감)
    • r = 0: 상관관계 없음
    • r = -1: 완벽한 음의 상관
    graph LR A["<b>-1</b><br/>완벽한 음의 상관"] --- B["<b>-0.7</b><br/>강한 음의 상관"] B --- C["<b>-0.3</b><br/>약한 음의 상관"] C --- D["<b>0</b><br/>상관 없음"] D --- E["<b>+0.3</b><br/>약한 양의 상관"] E --- F["<b>+0.7</b><br/>강한 양의 상관"] F --- G["<b>+1</b><br/>완벽한 양의 상관"]

    3) 해석 기준 (절댓값 기준)

    • 0.0 ~ 0.3: 거의 상관 없음
    • 0.3 ~ 0.7: 보통 수준의 상관
    • 0.7 ~ 1.0: 강한 상관

    알아보기 📖

    상관계수가 0.85라면? → "강한 양의 상관관계"가 있다고 해석합니다. 상관계수가 -0.45라면? → "보통 수준의 음의 상관관계"가 있다고 해석합니다.

    개념 3: 산점도와 히트맵 — 관계를 그림으로 보기 📊¶

    1) 비유로 시작

    숫자만 보면 감이 잘 안 올 때, 그림 한 장이면 바로 이해되죠? 상관관계도 마찬가지입니다.

    2) 정확한 정의

    • 산점도(Scatter Plot): 두 변수를 각각 x축, y축에 놓고 데이터를 점으로 찍은 그래프. 점들이 어떤 방향으로 모이는지 보면 관계를 알 수 있습니다.
    • 히트맵(Heatmap): 여러 변수 쌍의 상관계수를 색깔의 진하기로 표현한 표 형태 그래프. 빨간색이 진할수록 강한 양의 상관, 파란색이 진할수록 강한 음의 상관을 나타냅니다.

    3) 예시로 확인

    graph TD subgraph 산점도의_점_패턴 A["↗ 오른쪽 위로 모임<br/><b>양의 상관</b>"] B["↘ 오른쪽 아래로 모임<br/><b>음의 상관</b>"] C["● 흩어져 있음<br/><b>상관 없음</b>"] end

    산점도에서 점들이 좁은 띠 모양으로 모여 있을수록 상관이 강하고, 넓게 퍼져 있을수록 상관이 약합니다.

    개념 4: 상관관계 ≠ 인과관계 ⚠️¶

    1) 비유로 시작

    비가 오는 날 우산을 들고 다니는 사람이 많습니다. 그렇다고 "우산이 비를 내리게 한다"고 말하면 웃기겠죠? 함께 나타난다고 해서 원인과 결과는 아닙니다.

    2) 정확한 정의

    • 상관관계: 두 변수가 함께 변하는 패턴이 있다는 사실만 말함
    • 인과관계: 한 변수가 직접적으로 다른 변수를 변하게 만드는 관계

    3) 대표적인 오류 사례

    graph TD C["☀️ 여름 (기온 상승)"] C --> A["🍦 아이스크림 판매량 ↑"] C --> B["🏊 익사 사고 ↑"] A -. "상관관계는 있지만<br/>인과관계는 아님!" .-> B style C fill:#FFD700,stroke:#333,color:#000 style A fill:#FFB6C1,stroke:#333,color:#000 style B fill:#87CEEB,stroke:#333,color:#000

    정리하기 📝

    상관관계를 발견했을 때 반드시 물어야 할 질문 세 가지: 1. A가 B를 일으키는 건가? 2. B가 A를 일으키는 건가? 3. 제3의 변수(C)가 둘 다에 영향을 주는 건 아닌가?

    🔨 따라하기¶

    구글 코랩(Colab)에서 직접 코드를 실행하며 상관관계를 분석해 봅시다!

    Step 1: 데이터 준비하기¶

    학생 10명의 수면 시간, 공부 시간, 시험 점수 데이터를 만듭니다.

    import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 한글 폰트 설정 (코랩용)
plt.rc('font', family='NanumBarunGothic')
plt.rcParams['axes.unicode_minus'] = False

# 데이터 생성
data = {
    '수면시간': [8, 7, 6, 5, 7, 9, 6, 4, 8, 5],
    '공부시간': [2, 3, 4, 5, 3, 1, 4, 6, 2, 5],
    '시험점수': [72, 78, 85, 88, 80, 65, 82, 92, 70, 87]
}

df = pd.DataFrame(data)
print(df)

    알아보기 📖

    데이터를 보면 수면시간이 적은 학생이 공부시간이 많고, 공부시간이 많은 학생이 시험 점수가 높은 것 같지 않나요? 정말 그런지 숫자와 그래프로 확인해 봅시다!

    Step 2: 상관계수 계산하기¶

    pandas의 corr() 함수 하나로 모든 변수 쌍의 상관계수를 한꺼번에 구할 수 있습니다.

    # 상관계수 계산
correlation = df.corr()
print(correlation)

    출력 결과 해석:

    • 수면시간 ↔ 공부시간: 음수(약 -0.98) → 수면을 많이 할수록 공부 시간이 줄어드는 강한 음의 상관
    • 공부시간 ↔ 시험점수: 양수(약 +0.97) → 공부를 많이 할수록 점수가 높아지는 강한 양의 상관
    • 수면시간 ↔ 시험점수: 음수(약 -0.93) → 수면이 많을수록 점수가 낮아지는 강한 음의 상관

    생각해보기 🤔

    "수면시간이 늘면 시험 점수가 내려간다"고 해석해도 될까요? 아닙니다! 이 데이터에서는 수면시간이 긴 학생이 공부를 적게 했을 뿐입니다. 적절한 수면은 오히려 학습 효율을 높인다는 연구 결과가 많습니다. 상관관계 ≠ 인과관계를 기억하세요!

    Step 3: 산점도 그리기¶

    두 변수의 관계를 눈으로 확인해 봅시다.

    # 공부시간 vs 시험점수 산점도
plt.figure(figsize=(6, 4))
plt.scatter(df['공부시간'], df['시험점수'], color='dodgerblue', s=100, edgecolors='navy')
plt.xlabel('공부시간 (시간)')
plt.ylabel('시험점수 (점)')
plt.title('공부시간과 시험점수의 관계')
plt.grid(True, alpha=0.3)
plt.show()

    점들이 왼쪽 아래에서 오른쪽 위로 향하는 패턴이 보이면 양의 상관관계입니다. 점들이 직선에 가깝게 모여 있을수록 상관이 강합니다.

    Step 4: 히트맵으로 전체 관계 한눈에 보기¶

    변수가 3개 이상일 때는 산점도를 하나하나 그리기 번거롭습니다. 히트맵을 사용하면 모든 관계를 한 장에 볼 수 있습니다.

    # 상관관계 히트맵
plt.figure(figsize=(6, 5))
sns.heatmap(
    correlation,
    annot=True,          # 숫자 표시
    fmt='.2f',           # 소수점 2자리
    cmap='RdBu_r',       # 빨강(양) ~ 파랑(음) 색상
    vmin=-1, vmax=1,     # 색상 범위 고정
    square=True,
    linewidths=1
)
plt.title('변수 간 상관관계 히트맵')
plt.show()

    알아보기 📖

    • annot=True: 각 칸에 상관계수 숫자를 표시합니다
    • cmap='RdBu_r': 빨간색 = 양의 상관, 파란색 = 음의 상관, 흰색 = 상관 없음
    • vmin=-1, vmax=1: 상관계수의 범위에 맞춰 색상 기준을 고정합니다

    ⚠️ 자주 하는 실수¶

    실수 1: 상관계수가 크다고 "원인"이라고 결론 내리기 🚫

    "상관계수가 0.95니까 A가 B의 원인이다!" → ❌

    상관계수는 함께 변하는 정도만 알려줍니다. 원인을 밝히려면 실험 설계나 추가 분석이 필요합니다. 항상 "제3의 변수는 없는가?" 를 먼저 생각하세요.

    실수 2: 상관계수가 0이면 "아무 관계도 없다"고 생각하기 🚫

    피어슨 상관계수는 직선(선형) 관계만 측정합니다. U자 모양이나 곡선 관계가 있어도 상관계수는 0에 가깝게 나올 수 있습니다. 반드시 산점도를 함께 확인하세요!

    graph LR A["상관계수 = 0"] --> B{"산점도 확인!"} B -->|"점이 흩어져 있음"| C["진짜 관계 없음 ✅"] B -->|"U자 등 패턴 있음"| D["비선형 관계 존재! ⚠️"]

    실수 3: 데이터가 너무 적은데 상관계수를 믿기 🚫

    데이터가 3~4개뿐이면 우연히 높은 상관계수가 나올 수 있습니다. 최소 10개 이상의 데이터로 분석하는 것이 좋고, 데이터가 적을수록 결과를 조심스럽게 해석해야 합니다.

    ✅ 스스로 점검하기¶

    기본 문제¶

    Q1. 상관계수가 -0.82라면 어떤 의미인가요?

    정답 보기 **강한 음의 상관관계**입니다. 한 변수가 커지면 다른 변수가 작아지는 경향이 강하게 나타납니다. 절댓값이 0.7 이상이므로 "강한" 상관입니다.

    Q2. 다음 중 인과관계로 볼 수 있는 것은?

    • (가) 소방차 출동 횟수가 많은 날, 화재 피해 금액이 크다
    • (나) 광고비를 늘렸더니 매출이 올랐다 (통제된 실험 결과)
    • (다) 해적 수가 줄어들수록 지구 평균 기온이 올랐다
    정답 보기 **(나)** 만 인과관계입니다. (가)는 큰 화재일수록 소방차가 많이 출동한 것이고, (다)는 우연의 일치(허위 상관)입니다.

    심화 문제¶

    Q4. 두 변수의 산점도를 그렸더니 점들이 U자(포물선) 모양을 이루고 있습니다. 이때 피어슨 상관계수는 어떤 값에 가깝게 나올까요? 그 이유는 무엇인가요?

    정답 보기 **0에 가깝게** 나옵니다. 피어슨 상관계수는 **직선 관계**만 측정하기 때문입니다. U자 모양에서는 왼쪽 절반이 음의 기울기, 오른쪽 절반이 양의 기울기를 가져 서로 상쇄되어 0 근처 값이 나옵니다. 이런 경우에는 산점도를 반드시 눈으로 확인해야 합니다.

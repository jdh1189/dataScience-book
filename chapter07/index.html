    Chapter 07. 데이터 속성 간의 관계 파악¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 상관관계의 개념을 이해하고, 상관계수(피어슨)를 -1~+1 범위에서 해석할 수 있다
    • 산점도(scatter plot)를 그려 두 변수 간의 관계를 시각적으로 파악할 수 있다
    • 상관 히트맵(heatmap)을 활용하여 여러 변수 간의 관계를 한눈에 비교할 수 있다
    • 상관관계와 인과관계의 차이를 명확히 구분하여 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    🤔 생각해보기: "아이스크림 판매량이 늘어나면 익사 사고도 늘어난다." 이 말을 듣고 "아이스크림이 위험한 음식이구나!"라고 생각했다면, 큰 함정에 빠진 겁니다.

    실제로 아이스크림 판매량과 익사 사고 건수는 함께 증가합니다. 하지만 아이스크림이 익사를 일으킨 것은 아닙니다. 여름이라는 숨겨진 변수(기온)가 둘 다에 영향을 준 것이죠.

    데이터 분석에서 가장 중요한 능력 중 하나는 "이 데이터들이 서로 관련이 있는가?" 를 파악하는 것입니다. 이것을 상관관계 분석이라고 합니다.

    이 능력이 왜 중요할까요?

    • 📊 마케팅: 광고비와 매출 사이에 관계가 있을까?
    • 🏥 건강: 운동 시간과 체중 감소 사이에 관계가 있을까?
    • 📱 앱 개발: 앱 사용 시간과 구매율 사이에 관계가 있을까?
    • 🎓 학습: 수면 시간과 시험 성적 사이에 관계가 있을까?

    하지만 "관련이 있다"와 "원인이다"는 전혀 다릅니다. 이 차이를 모르면 잘못된 결론을 내리게 됩니다. 이번 장에서 이 핵심을 확실히 배워봅시다!

    📚 핵심 개념¶

    개념 1: 상관관계란 무엇인가? 🔗¶

    1. 비유로 시작

    학교에서 단짝 친구 두 명을 떠올려 보세요. 한 명이 웃으면 다른 한 명도 따라 웃고, 한 명이 슬퍼하면 다른 한 명도 같이 슬퍼합니다. 이 두 친구의 감정은 함께 움직이는 경향이 있죠. 이것이 바로 상관관계의 핵심입니다.

    반대로, 한 명이 웃을 때 다른 한 명은 꼭 찡그리는 친구 관계도 있을 수 있습니다. 이것은 반대 방향으로 함께 움직이는 경향입니다.

    2. 정확한 정의

    상관관계(Correlation) 란 두 변수가 함께 변하는 경향성을 말합니다. 한 변수가 변할 때 다른 변수도 일정한 패턴으로 변하면 "상관관계가 있다"고 합니다.

    상관관계에는 세 가지 유형이 있습니다.

    • 양의 상관관계(Positive Correlation): 한 변수가 증가하면 다른 변수도 증가 → 예) 키가 클수록 몸무게도 무거운 경향
    • 음의 상관관계(Negative Correlation): 한 변수가 증가하면 다른 변수는 감소 → 예) 결석 일수가 많을수록 성적이 낮아지는 경향
    • 상관관계 없음(No Correlation): 한 변수의 변화가 다른 변수와 아무런 패턴이 없음 → 예) 신발 사이즈와 수학 성적
    graph LR subgraph 양의 상관 A1["기온 ☀️ ↑"] --> A2["음료 판매량 🥤 ↑"] end subgraph 음의 상관 B1["게임 시간 🎮 ↑"] --> B2["수면 시간 😴 ↓"] end subgraph 상관 없음 C1["혈액형 🩸"] -.- C2["성적 📝"] end

    3. 예시로 확인

    학생 5명의 하루 공부 시간과 시험 점수를 살펴봅시다.

    • 민수: 공부 1시간 → 50점
    • 지영: 공부 2시간 → 60점
    • 태현: 공부 3시간 → 65점
    • 수아: 공부 4시간 → 80점
    • 준호: 공부 5시간 → 90점

    공부 시간이 늘어날수록 시험 점수도 올라가는 경향이 보이죠? 이것이 양의 상관관계입니다.

    개념 2: 상관계수 — 관계의 강도를 숫자로 📏¶

    1. 비유로 시작

    온도계가 온도를 숫자로 알려주듯이, 상관계수는 두 변수 사이의 관계를 숫자로 알려주는 측정 도구입니다. 온도계가 -40℃에서 +50℃까지 표시하듯이, 상관계수는 -1에서 +1까지 의 값을 가집니다.

    2. 정확한 정의

    피어슨 상관계수(Pearson Correlation Coefficient) 는 두 변수 간의 선형 관계의 강도와 방향을 나타내는 수치입니다. 기호로는 r을 사용하며, -1 ≤ r ≤ +1의 범위를 가집니다.

    상관계수 값의 의미를 정리하면 다음과 같습니다.

    • r = +1: 완벽한 양의 상관관계 (한 변수가 증가하면 다른 변수도 정확히 비례하여 증가)
    • r = +0.7 ~ +0.9: 강한 양의 상관관계
    • r = +0.4 ~ +0.6: 중간 정도의 양의 상관관계
    • r = +0.1 ~ +0.3: 약한 양의 상관관계
    • r = 0: 상관관계 없음
    • r = -0.1 ~ -0.3: 약한 음의 상관관계
    • r = -0.4 ~ -0.6: 중간 정도의 음의 상관관계
    • r = -0.7 ~ -0.9: 강한 음의 상관관계
    • r = -1: 완벽한 음의 상관관계
    graph LR A["r = -1<br/>완벽한 음의 상관"] --- B["r = 0<br/>상관 없음"] --- C["r = +1<br/>완벽한 양의 상관"] style A fill:#ff6b6b,color:#fff style B fill:#ffd93d,color:#333 style C fill:#6bcb77,color:#fff

    3. 예시로 확인

    • 키와 몸무게: r ≈ +0.7 (강한 양의 상관) → 키가 클수록 몸무게가 무거운 경향이 꽤 강하다
    • 공부 시간과 게임 시간: r ≈ -0.5 (중간 음의 상관) → 공부를 오래 할수록 게임 시간이 줄어드는 경향이 있다
    • 신발 사이즈와 좋아하는 숫자: r ≈ 0.02 (거의 없음) → 아무 관련이 없다

    📌 알아보기: 상관계수의 부호(+, -)는 방향을 알려주고, 절대값은 강도를 알려줍니다. r = -0.8은 r = +0.6보다 관계가 더 강합니다. 부호가 마이너스라고 약한 것이 아닙니다!

    개념 3: 산점도와 히트맵 — 관계를 눈으로 보기 👀¶

    1. 비유로 시작

    숫자만 늘어놓으면 관계가 잘 보이지 않습니다. 마치 칠판에 빼곡히 적힌 출석 번호만 보고 반 전체의 키 분포를 파악하기 어려운 것과 같죠. 하지만 학생들을 키 순서대로 세우면? 한눈에 패턴이 보입니다. 시각화가 바로 이런 역할을 합니다.

    2. 정확한 정의

    산점도(Scatter Plot) 는 두 변수의 값을 좌표 평면 위에 점으로 표시한 그래프입니다. x축에 한 변수, y축에 다른 변수를 놓고 각 데이터를 점으로 찍습니다.

    히트맵(Heatmap) 은 여러 변수 간의 상관계수를 색상의 진하기로 표현한 그래프입니다. 한 번에 여러 쌍의 상관관계를 비교할 수 있습니다.

    graph TD A["변수 간 관계 시각화"] --> B["산점도 Scatter Plot"] A --> C["히트맵 Heatmap"] B --> D["2개 변수 간 관계를<br/>점으로 표현"] C --> E["여러 변수 간 상관계수를<br/>색상으로 표현"] D --> F["점이 우상향 → 양의 상관<br/>점이 우하향 → 음의 상관<br/>점이 흩어짐 → 상관 없음"] E --> G["진한 빨강 → 강한 양의 상관<br/>진한 파랑 → 강한 음의 상관<br/>연한 색 → 약한 상관"]

    3. 예시로 확인

    산점도의 모양을 보면 상관관계를 직관적으로 알 수 있습니다.

    • 점들이 오른쪽 위로 모여 있으면 → 양의 상관관계
    • 점들이 오른쪽 아래로 모여 있으면 → 음의 상관관계
    • 점들이 사방으로 흩어져 있으면 → 상관관계 없음
    • 점들이 직선에 가깝게 모여 있을수록 → 상관관계가 강함

    개념 4: 상관관계 ≠ 인과관계 ⚠️¶

    1. 비유로 시작

    소방차가 많이 출동한 화재일수록 피해가 큽니다. 그렇다면 "소방차가 피해를 키운다"고 결론을 내려야 할까요? 당연히 아닙니다! 화재 규모가 크니까 소방차도 많이 출동하고, 피해도 큰 것이죠. 두 변수가 함께 움직인다고 해서 하나가 다른 하나의 원인이라고 단정할 수 없습니다.

    2. 정확한 정의

    상관관계(Correlation) 는 "두 변수가 함께 변한다"는 사실만 알려줍니다. 인과관계(Causation) 는 "한 변수가 다른 변수를 변하게 만든다"는 원인-결과 관계를 의미합니다.

    상관관계가 있지만 인과관계가 아닌 경우는 크게 세 가지입니다.

    • 제3의 변수(교란 변수): 숨겨진 다른 변수가 둘 다에 영향을 줌
    • 우연의 일치: 전혀 관련 없는 데이터가 우연히 비슷한 패턴을 보임
    • 역방향 인과: 원인과 결과가 반대일 수 있음
    graph TD subgraph 상관관계처럼 보이지만... A["아이스크림 판매량 🍦"] -.- B["익사 사고 건수 🏊"] end subgraph 실제 구조 C["기온 상승 ☀️"] --> D["아이스크림 판매량 ↑ 🍦"] C --> E["수영하는 사람 ↑ 🏊"] E --> F["익사 사고 ↑"] end style C fill:#ff9f43,color:#fff

    3. 예시로 확인

    유명한 상관-인과 오류 사례들을 살펴봅시다.

    • 니콜라스 케이지 출연 영화 수 ↔ 수영장 익사 사고: 실제로 상관계수가 높지만, 당연히 인과관계 없음 (우연의 일치)
    • 학교 수가 많은 도시 ↔ 범죄율이 높은 도시: 인구가 많은 도시이기 때문 (제3의 변수: 인구 수)
    • 병원에 자주 가는 사람 ↔ 사망률이 높음: 이미 아픈 사람이 병원에 가기 때문 (역방향 인과)

    📌 정리하기: 데이터 분석에서 "A와 B는 상관관계가 있다"고 말할 수 있지만, "A 때문에 B가 일어난다"고 결론 짓기 위해서는 통제된 실험 등 추가적인 근거가 필요합니다. 이것은 데이터 과학에서 가장 중요한 원칙 중 하나입니다!

axes[1].scatter(df_trap['temperature'], df_trap['icecream'],

axes[1].set_ylabel('Icecream Sales', fontsize=12, color='orange')

    ⚠️ 자주 하는 실수¶

    실수 1: 상관관계를 곧바로 인과관계로 해석하기 🚫¶

    잘못된 해석: "공부 시간과 성적의 상관계수가 0.85이므로, 공부 시간을 늘리면 성적이 오른다."

    이것은 가능성이 높지만, 상관계수만으로는 확정할 수 없습니다. 성적이 좋은 학생이 공부를 더 좋아해서 오래 하는 것일 수도 있고(역방향), 부모의 교육열이라는 제3의 변수가 있을 수도 있습니다.

    올바른 해석: "공부 시간과 성적 사이에 강한 양의 상관관계가 관찰된다. 인과관계 확인을 위해서는 추가 분석이 필요하다."

    실수 2: 상관계수의 부호와 강도를 혼동하기 🔄¶

    잘못된 생각: "r = -0.9는 음수니까 관계가 약한 거 아닌가요?"

    아닙니다! r = -0.9는 매우 강한 관계입니다. 단지 방향이 반대(음의 상관)일 뿐입니다.

    • r = +0.3 → 약한 양의 상관
    • r = -0.9 → 강한 음의 상관
    • 강도는 절대값으로 판단: |−0.9| = 0.9 > |+0.3| = 0.3

    실수 3: 소수의 데이터로 상관계수를 맹신하기 📉¶

    데이터가 3~4개뿐이라면 상관계수는 신뢰하기 어렵습니다. 우연히 높은 값이 나올 수 있기 때문입니다.

    # 위험한 예: 데이터 3개로 계산한 상관계수
tiny_df = pd.DataFrame({'x': [1, 2, 3], 'y': [10, 5, 20]})
print(f"데이터 3개의 상관계수: {tiny_df['x'].corr(tiny_df['y']):.2f}")
print("=> 데이터가 너무 적어 이 값을 신뢰하기 어렵습니다!")

    📌 기억하세요: 의미 있는 상관관계 분석을 위해서는 최소 20~30개 이상의 데이터가 필요합니다.

    실수 4: 비선형 관계를 상관계수로 판단하기 🎢¶

    피어슨 상관계수는 직선(선형) 관계만 측정합니다. U자형이나 곡선 관계는 상관계수가 0에 가깝게 나올 수 있지만, 실제로는 강한 관계가 존재합니다.

    # 비선형 관계 예시
x = np.linspace(-3, 3, 50)
y = x ** 2  # 포물선: 명백한 관계가 있음!

r_nonlinear = np.corrcoef(x, y)[0, 1]
print(f"포물선 데이터의 상관계수: {r_nonlinear:.4f}")
print("=> 0에 가깝지만, 산점도를 보면 명확한 관계가 있습니다!")

plt.figure(figsize=(6, 4))
plt.scatter(x, y, color='purple', s=40)
plt.title(f'Non-linear Relationship (r = {r_nonlinear:.2f})')
plt.xlabel('x')
plt.ylabel('y = x^2')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

    📌 교훈: 상관계수만 보지 말고, 반드시 산점도를 함께 확인하세요!

    ✅ 스스로 점검하기¶

    기본 문제 📗¶

    문제 1. 다음 중 양의 상관관계에 해당하는 것은? - (a) 운동 시간이 늘수록 체중이 줄어든다 - (b) 기온이 올라갈수록 난방비가 줄어든다 - (c) 키가 클수록 몸무게가 무거운 경향이 있다 - (d) 나이가 많을수록 100m 달리기 기록이 느려진다

    정답 확인 **(c)** 키가 클수록 몸무게가 무거운 경향이 있다. 두 변수가 같은 방향으로 움직이므로 양의 상관관계입니다. (a), (b), (d)는 한쪽이 증가할 때 다른 쪽이 감소하므로 음의 상관관계입니다.

    문제 2. 상관계수 r = -0.85의 의미를 올바르게 설명한 것은? - (a) 두 변수는 거의 관계가 없다 - (b) 두 변수는 강한 양의 상관관계가 있다 - (c) 두 변수는 강한 음의 상관관계가 있다 - (d) 한 변수가 다른 변수의 원인이다

    정답 확인 **(c)** 두 변수는 강한 음의 상관관계가 있다. |−0.85| = 0.85이므로 관계의 강도는 매우 강하고, 부호가 음(−)이므로 음의 상관관계입니다. (d)는 틀립니다 — 상관계수는 인과관계를 증명하지 않습니다.

    🏀 도전 과제: 스포츠 선수 데이터에서 숨겨진 관계 찾기¶

    아래 NBA 선수 스타일의 데이터에서 흥미로운 상관관계를 스스로 발견해 보세요!

    import pandas as pd
import numpy as np

np.random.seed(2024)
n = 25

player_data = pd.DataFrame({
    'height_cm': np.random.normal(195, 10, n).round(1),
    'weight_kg': np.random.normal(95, 12, n).round(1),
    'minutes_played': np.random.uniform(15, 38, n).round(1),
    'points': np.random.uniform(5, 30, n).round(1),
    'rebounds': np.random.uniform(2, 12, n).round(1),
    'assists': np.random.uniform(1, 10, n).round(1),
    'three_point_pct': np.random.uniform(25, 45, n).round(1)
})

# 현실적인 상관관계 추가
player_data['weight_kg'] = (player_data['height_cm'] * 0.6 - 20
                            + np.random.normal(0, 5, n)).round(1)
player_data['points'] = (player_data['minutes_played'] * 0.7
                         + np.random.normal(0, 3, n)).round(1)

print("=== Player Data (first 5) ===")
print(player_data.head())

    미션: 1. player_data.corr()로 상관계수 행렬을 확인하세요 2. 히트맵을 그려 시각적으로 분석하세요 3. 상관계수가 가장 높은 변수 쌍과 가장 낮은 변수 쌍을 찾으세요 4. 발견한 관계 중 인과관계라고 볼 수 있는 것이 있는지 팀원(또는 혼자)과 토론해 보세요

    제19장: 지혜로운 어부 생활 (1) — 문제 정의와 데이터 준비¶

    Part 4 | [2권] 데이터 과학 프로젝트 — 교과서 주제 실습

    🎯 이 장에서 배우는 것¶

    • 수산·환경 데이터 기반 어획량 분석 프로젝트의 문제를 정의할 수 있다
    • 수온, 염도, 어획량 등 환경 데이터를 수집하고 전처리할 수 있다
    • 시계열 데이터의 특성을 이해하고 시간에 따른 변화를 시각화할 수 있다
    • 계절별·연도별 패턴을 탐색적 데이터 분석(EDA) 으로 발견할 수 있다

    💡 왜 이걸 배우나요?¶

    🤔 생각해보기: 바다 수온이 올라가면 잡히는 물고기 종류가 달라질까?

    뉴스에서 "올해 오징어가 안 잡힌다", "동해에서 아열대 물고기가 출현했다" 같은 보도를 본 적 있나요? 이런 현상의 배경에는 해양 환경 변화가 있습니다.

    실제 어부들은 수십 년의 경험으로 바다를 읽습니다. 수온이 어떤지, 조류가 어떤지 감으로 판단하죠. 하지만 데이터 과학을 활용하면 경험에 숫자로 된 근거를 더할 수 있습니다.

    이 프로젝트에서 우리는 "지혜로운 어부" 가 되어봅니다.

    • 🌊 해양 환경 데이터(수온, 염도 등)를 수집하고
    • 🐟 어획량 데이터와 연결해서
    • 📊 "어떤 환경 조건에서 물고기가 많이 잡히는지" 분석합니다

    이번 장(19장)에서는 프로젝트의 첫 단계인 문제 정의와 데이터 준비를 다루고, 다음 장(20장)에서 본격적인 분석과 모델링을 진행합니다.

    📚 핵심 개념¶

    개념 1: 데이터 과학 프로젝트의 문제 정의¶

    1) 비유로 시작¶

    여행을 떠나기 전, 가장 먼저 할 일은 무엇일까요? 바로 "어디로 갈 것인가?" 를 정하는 것입니다. 목적지 없이 짐을 싸기 시작하면 필요 없는 것을 챙기거나, 정작 중요한 것을 빠뜨리게 됩니다.

    데이터 과학 프로젝트도 마찬가지입니다. 데이터를 모으고 코드를 작성하기 전에, 반드시 "무엇을 알고 싶은가?"를 명확히 해야 합니다. 이것이 문제 정의(Problem Definition) 입니다.

    2) 정확한 정의¶

    문제 정의란, 프로젝트에서 답하고자 하는 질문을 구체적이고 측정 가능하게 만드는 과정입니다.

    좋은 문제 정의의 조건은 다음과 같습니다.

    • 구체적(Specific): "물고기가 잘 잡히나?" ❌ → "제주 근해 월별 고등어 어획량은 수온과 관련이 있는가?" ✅
    • 측정 가능(Measurable): 숫자로 확인할 수 있어야 합니다
    • 데이터 확보 가능(Achievable): 실제로 데이터를 구할 수 있어야 합니다

    3) 예시로 확인¶

    우리 프로젝트의 문제 정의 과정을 따라가 봅시다.

    [막연한 궁금증]
"바다 환경이 변하면 물고기도 달라지나?"

    ↓ 구체화

[좁힌 질문]
"해수면 온도가 어획량에 영향을 미치는가?"

    ↓ 더 구체화

[최종 문제 정의]
"2010~2023년 한국 연근해 월별 어획량은
 해수면 온도 및 염도와 어떤 상관관계를 보이며,
 계절별 패턴은 어떻게 다른가?"

    📌 알아보기: 문제 정의에서 "기간", "지역", "어종", "환경 변수"를 명시하면 프로젝트 범위가 명확해집니다. 범위가 명확해야 필요한 데이터도 알 수 있습니다.

    flowchart LR A["🤔 막연한 호기심"] --> B["❓ 구체적 질문"] B --> C["📋 문제 정의"] C --> D["📊 필요 데이터 식별"] D --> E["🔍 분석 계획 수립"]

    개념 2: 수산·환경 공공데이터의 이해¶

    1) 비유로 시작¶

    요리를 하려면 먼저 재료를 준비해야 합니다. 파스타를 만들 때 면, 소스, 채소가 각각 다른 가게에서 올 수 있듯이, 데이터 과학 프로젝트의 재료인 데이터도 여러 출처에서 모아야 합니다.

    우리 프로젝트의 "재료"는 크게 두 가지입니다.

    • 🌡️ 해양 환경 데이터: 수온, 염도 등 (바다의 상태)
    • 🐟 어획량 데이터: 언제, 어디서, 얼마나 잡혔는지

    2) 정확한 정의¶

    공공데이터란 정부나 공공기관이 수집·관리하여 누구나 자유롭게 이용할 수 있도록 공개한 데이터입니다.

    우리 프로젝트에서 활용할 수 있는 주요 데이터 출처는 다음과 같습니다.

    • 국가해양환경정보통합시스템(MEIS): 해수면 온도, 염도, 용존산소 등
    • 국가통계포털(KOSIS): 어종별·월별 어획량 통계
    • 공공데이터포털(data.go.kr): 다양한 해양·수산 데이터 API
    • NOAA(미국해양대기청): 전 세계 해수면 온도 데이터

    📌 알아보기: 실습에서는 실제 공공데이터의 구조를 본떠 만든 시뮬레이션 데이터를 사용합니다. 실제 데이터와 동일한 형식이므로, 나중에 진짜 공공데이터를 다룰 때도 그대로 적용할 수 있습니다.

    3) 예시로 확인¶

    우리가 다룰 데이터의 구성을 살펴봅시다.

    해양 환경 데이터 (환경 테이블) - date — 측정 날짜 (예: 2015-03-01) - sea_temp — 해수면 온도 (°C) - salinity — 염도 (PSU, 실용염분단위) - wind_speed — 풍속 (m/s) - precipitation — 강수량 (mm)

    어획량 데이터 (어획 테이블) - date — 조사 날짜 - region — 해역 (동해, 서해, 남해, 제주) - species — 어종 (고등어, 오징어, 멸치 등) - catch_amount — 어획량 (톤)

    erDiagram ENVIRONMENT { date date float sea_temp float salinity float wind_speed float precipitation } FISHERY { date date string region string species float catch_amount } ENVIRONMENT ||--o{ FISHERY : "날짜로 연결"

    두 데이터는 날짜(date) 를 기준으로 연결(조인)할 수 있습니다.

    개념 3: 시계열 데이터의 특성¶

    1) 비유로 시작¶

    일기장을 생각해 보세요. 매일매일 날짜 순서대로 기록하죠? 3월 15일 일기를 읽으면 그날 무슨 일이 있었는지 알 수 있고, 일기장을 쭉 넘기면 시간에 따라 기분이나 생활이 어떻게 변했는지 흐름을 파악할 수 있습니다.

    시계열 데이터(Time Series Data) 는 바로 이런 "시간 순서대로 기록된 데이터"입니다.

    2) 정확한 정의¶

    시계열 데이터란, 일정한 시간 간격으로 순서대로 수집된 데이터를 말합니다.

    시계열 데이터의 세 가지 핵심 구성 요소는 다음과 같습니다.

    • 추세(Trend): 장기적으로 올라가거나 내려가는 경향. 예를 들어, "해수면 온도가 10년간 서서히 올라가고 있다."
    • 계절성(Seasonality): 일정 주기로 반복되는 패턴. 예를 들어, "여름엔 수온이 높고, 겨울엔 낮다."
    • 불규칙 변동(Noise/Residual): 추세나 계절성으로 설명되지 않는 랜덤한 변동
    flowchart TB A["📈 시계열 데이터"] --> B["↗️ 추세<br/>장기적 방향성"] A --> C["🔄 계절성<br/>반복 패턴"] A --> D["〰️ 불규칙 변동<br/>랜덤 노이즈"]

    3) 예시로 확인¶

    해수면 온도 데이터를 예로 들어봅시다.

    • 추세: 2010년 평균 15.2°C → 2023년 평균 16.1°C (서서히 상승)
    • 계절성: 매년 8월이 가장 높고(약 25°C), 2월이 가장 낮음(약 8°C)
    • 불규칙 변동: 2018년 8월은 태풍 영향으로 예년보다 2°C 낮았음

    💡 생각해보기: 우리가 매일 기록하는 체중 데이터도 시계열 데이터입니다. 다이어트 중이면 추세는 하락, 주말에 많이 먹으면 주간 계절성이 생기고, 갑자기 아파서 못 먹은 날은 불규칙 변동이 됩니다.

    개념 4: 데이터 전처리 — 시계열 데이터 다루기¶

    1) 비유로 시작¶

    마트에서 사온 채소를 바로 냄비에 넣지 않죠? 흙을 씻고, 시든 잎을 떼고, 적당한 크기로 썰어야 합니다. 데이터도 마찬가지로 분석 전에 씻고, 다듬고, 정리하는 과정이 필요합니다. 이것이 데이터 전처리(Data Preprocessing) 입니다.

    2) 정확한 정의¶

    시계열 데이터 전처리에서 특히 중요한 작업은 다음과 같습니다.

    • 날짜 형식 변환: 문자열 "2020-01-15"를 컴퓨터가 날짜로 인식하게 변환
    • 결측치 처리: 측정이 빠진 날의 데이터를 적절히 채우기 (보간법, 앞/뒤 값 채우기 등)
    • 이상치 확인: 비정상적으로 튀는 값이 오류인지 실제 현상인지 판단
    • 시간 인덱스 설정: 날짜를 데이터의 기준 축으로 설정
    • 리샘플링: 일별 데이터를 월별로 합치거나, 분기별로 묶기

    3) 예시로 확인¶

    결측치 처리의 대표적 방법을 비유로 이해해 봅시다.

    • 앞쪽 값으로 채우기(forward fill): "어제 수온이 20°C였으니, 측정 못 한 오늘도 20°C 정도겠지" → 변화가 느린 데이터에 적합
    • 보간법(interpolation): "월요일 20°C, 수요일 24°C였으니, 화요일은 22°C 정도겠지" → 중간값을 추정
    • 평균으로 채우기: "전체 평균을 넣자" → 간단하지만 시계열 특성을 무시할 수 있음

    ⚠️ 시계열 데이터에서는 시간 순서를 고려한 방법(forward fill, 보간법)이 단순 평균 대입보다 대체로 더 적합합니다.

    구글 코랩에서 새 노트북을 열고, 필요한 라이브러리를 불러옵니다. 실습을 위한 시뮬레이션 데이터도 함께 생성합니다.

    📌 알아보기: 실제 프로젝트에서는 공공데이터 포털에서 CSV 파일을 다운로드하거나 API로 데이터를 가져옵니다. 여기서는 실제 데이터의 구조와 패턴을 반영한 시뮬레이션 데이터를 사용합니다.

    # Step 1: 라이브러리 불러오기 & 시뮬레이션 데이터 생성

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import warnings
warnings.filterwarnings('ignore')

# 한글 폰트 설정 (코랩용)
plt.rcParams['font.family'] = 'DejaVu Sans'
plt.rcParams['axes.unicode_minus'] = False

# 재현 가능한 난수 설정
np.random.seed(42)

# --- 해양 환경 데이터 생성 ---
# 2015년 1월 ~ 2023년 12월 (월별 데이터)
dates = pd.date_range(start='2015-01-01', end='2023-12-01', freq='MS')
n = len(dates)  # 108개월

# 월 정보 추출
months = dates.month

# 해수면 온도: 계절성 + 상승 추세 + 노이즈
trend = np.linspace(0, 1.5, n)  # 9년간 1.5도 상승 추세
seasonal_temp = 8 * np.sin(2 * np.pi * (months - 3) / 12)  # 계절 변동
sea_temp = 15 + trend + seasonal_temp + np.random.normal(0, 0.8, n)

# 염도: 약한 계절성 + 노이즈
seasonal_sal = 0.5 * np.cos(2 * np.pi * (months - 1) / 12)
salinity = 33.5 + seasonal_sal + np.random.normal(0, 0.3, n)

# 풍속: 겨울에 강함
seasonal_wind = 2 * np.cos(2 * np.pi * (months - 1) / 12)
wind_speed = 5 + seasonal_wind + np.random.normal(0, 1, n)
wind_speed = np.clip(wind_speed, 0.5, 15)  # 음수 방지

# 강수량: 여름에 많음
seasonal_rain = 80 * np.sin(2 * np.pi * (months - 4) / 12)
precipitation = 100 + seasonal_rain + np.random.normal(0, 30, n)
precipitation = np.clip(precipitation, 0, 400)  # 음수 방지

# 환경 데이터프레임 생성
df_env = pd.DataFrame({
    'date': dates,
    'sea_temp': np.round(sea_temp, 1),
    'salinity': np.round(salinity, 2),
    'wind_speed': np.round(wind_speed, 1),
    'precipitation': np.round(precipitation, 1)
})

# --- 어획량 데이터 생성 ---
regions = ['동해', '서해', '남해', '제주']
species_list = ['고등어', '오징어', '멸치', '갈치']

fishery_rows = []
for date in dates:
    m = date.month
    year_idx = date.year - 2015
    for region in regions:
        for species in species_list:
            # 기본 어획량 (어종별 차이)
            base = {'고등어': 500, '오징어': 300, '멸치': 800, '갈치': 200}[species]
            # 해역별 차이
            region_factor = {'동해': 1.0, '서해': 0.8, '남해': 1.2, '제주': 0.7}[region]
            # 계절 효과
            if species == '고등어':
                season_effect = 200 * np.sin(2 * np.pi * (m - 5) / 12)
            elif species == '오징어':
                season_effect = 150 * np.sin(2 * np.pi * (m - 8) / 12)
            elif species == '멸치':
                season_effect = 300 * np.sin(2 * np.pi * (m - 4) / 12)
            else:
                season_effect = 100 * np.sin(2 * np.pi * (m - 9) / 12)
            # 수온 상승에 따른 감소 추세 (오징어 특히 민감)
            if species == '오징어':
                trend_effect = -year_idx * 15
            else:
                trend_effect = -year_idx * 5
            catch = base * region_factor + season_effect + trend_effect
            catch += np.random.normal(0, 50)
            catch = max(catch, 10)  # 최소 10톤
            fishery_rows.append({
                'date': date,
                'region': region,
                'species': species,
                'catch_amount': round(catch, 1)
            })

df_fish = pd.DataFrame(fishery_rows)

# 결과 확인
print("=== 해양 환경 데이터 ===")
print(f"크기: {df_env.shape}")
print(df_env.head())
print()
print("=== 어획량 데이터 ===")
print(f"크기: {df_fish.shape}")
print(df_fish.head(8))

    Step 3: 결측치 생성 및 전처리¶

    실제 상황을 시뮬레이션하기 위해 일부 데이터를 결측치로 만들고, 이를 처리하는 과정을 실습합니다.

    # Step 3: 결측치 처리 실습

# --- 실전처럼 결측치 만들기 ---
df_env_practice = df_env.copy()

# 무작위로 5%를 결측치로 변환
np.random.seed(123)
for col in ['sea_temp', 'salinity', 'wind_speed', 'precipitation']:
    missing_idx = np.random.choice(df_env_practice.index, size=5, replace=False)
    df_env_practice.loc[missing_idx, col] = np.nan

print("결측치 현황 (처리 전):")
print(df_env_practice.isnull().sum())
print()

# 결측치가 있는 행 확인
print("결측치가 포함된 행:")
missing_rows = df_env_practice[df_env_practice.isnull().any(axis=1)]
print(missing_rows)
print()

# --- 결측치 처리: 시간순 보간법 사용 ---
# 날짜를 인덱스로 설정
df_env_practice = df_env_practice.set_index('date')

# 보간법(interpolation)으로 결측치 채우기
# method='time': 시간 간격을 고려한 선형 보간
df_env_clean = df_env_practice.interpolate(method='time')

# 결과 확인
print("결측치 현황 (처리 후):")
print(df_env_clean.isnull().sum())
print()

# 인덱스를 다시 컬럼으로
df_env_clean = df_env_clean.reset_index()

# 처리 전후 비교 (수온 예시)
print("보간 처리 예시 (수온):")
for idx in missing_rows.index[:3]:
    original = df_env_practice.iloc[idx - df_env_practice.index[0].day]
    print(f"  {df_env.loc[idx, 'date'].strftime('%Y-%m')}: "
          f"원본={df_env.loc[idx, 'sea_temp']:.1f}°C, "
          f"결측 후 보간={df_env_clean.loc[idx, 'sea_temp']:.1f}°C")

    📌 정리하기: 시계열 데이터의 결측치는 보간법(interpolation) 을 사용하는 것이 좋습니다. 앞뒤 시점의 값을 참고하여 자연스러운 값을 추정할 수 있기 때문입니다. 단순 평균 대입은 시간적 맥락을 무시하므로 추천하지 않습니다.

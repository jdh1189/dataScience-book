    Chapter 05. 데이터 수집 및 특성 분석 (1) — 데이터 수집과 탐색¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 데이터 수집이 왜 필요한지 설명하고, 다양한 수집 경로를 구분할 수 있다
    • 공공데이터 포털이나 CSV 파일에서 데이터를 불러올 수 있다
    • describe(), value_counts(), info()로 데이터 특성을 요약할 수 있다
    • 히스토그램과 막대그래프로 데이터 분포를 시각적으로 탐색할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: "우리 반 학생들의 하루 스크린 타임은 어떻게 분포할까?"

    이 질문에 답하려면 어떻게 해야 할까요? "대충 3시간 정도 아닐까?"라고 감으로 추측할 수도 있지만, 실제로 데이터를 모아보면 예상과 전혀 다른 결과가 나올 수 있습니다.

    데이터 분석의 첫 단계는 좋은 데이터를 수집하는 것입니다. 아무리 뛰어난 분석 기술이 있어도, 데이터가 없으면 아무것도 할 수 없습니다. 그리고 데이터를 모았다면, 바로 분석에 뛰어들기 전에 "이 데이터는 어떤 모습인가?"를 먼저 살펴봐야 합니다.

    이번 장에서는 데이터를 어디서 구하고, 어떻게 첫인상을 파악하는지 배웁니다. 마치 새로운 도시에 도착했을 때 지도를 펼쳐보는 것처럼, 데이터의 전체적인 윤곽을 그려보는 과정입니다.

    📚 핵심 개념¶

    개념 1: 데이터 수집 경로 🗂️¶

    비유로 시작하기

    요리를 하려면 재료가 필요합니다. 재료는 마트에서 살 수도 있고, 텃밭에서 직접 기를 수도 있고, 이웃에게 나눠 받을 수도 있죠. 데이터도 마찬가지입니다. 목적에 맞는 데이터를 다양한 곳에서 구할 수 있습니다.

    주요 데이터 수집 경로

    • 직접 수집: 설문조사, 실험, 관찰 등으로 내가 직접 만드는 데이터 (예: 급식 만족도 설문)
    • 공공데이터 포털 (data.go.kr): 정부·공공기관이 무료로 제공하는 데이터 (예: 인구통계, 교통사고, 날씨)
    • 캐글 (kaggle.com): 전 세계 데이터 과학자들이 공유하는 데이터셋 모음
    • 웹 크롤링: 웹사이트에서 자동으로 정보를 추출하는 방법 (고급 과정에서 다룸)
    flowchart LR A["🎯 분석 목적"] --> B{"데이터가\n있는가?"} B -->|"직접 만들기"| C["📋 설문조사\n실험·관찰"] B -->|"가져오기"| D["🏛️ 공공데이터\n포털"] B -->|"가져오기"| E["📊 캐글\nKaggle"] B -->|"가져오기"| F["🌐 웹\n크롤링"]

    알아보기 📌: 가장 흔한 데이터 형식은 CSV(Comma-Separated Values) 파일입니다. 이름 그대로 값들이 쉼표(,)로 구분된 텍스트 파일이며, 엑셀로도 열 수 있고 pandas로 바로 읽을 수 있습니다.

    개념 2: 데이터 불러오기와 기본 확인 📥¶

    비유로 시작하기

    택배 상자를 받았을 때, 바로 사용하지 않고 먼저 뚜껑을 열어 내용물을 확인하죠? 데이터도 마찬가지입니다. 불러온 직후 "몇 줄짜리인지", "어떤 항목이 있는지", "빠진 값은 없는지"를 체크합니다.

    핵심 함수 3가지

    • df.head(): 데이터의 처음 5줄을 보여줍니다 → "첫인상 확인"
    • df.info(): 각 열의 이름, 데이터 타입, 비어있지 않은 값의 개수를 보여줍니다 → "건강검진표"
    • df.shape: (행 수, 열 수)를 알려줍니다 → "데이터의 크기"

    정리하기 📋: head()로 모양을 보고, info()로 건강 상태를 점검하고, shape로 크기를 파악하는 것이 데이터를 처음 만났을 때의 3단계 인사입니다.

    개념 3: 요약 통계량 📊¶

    비유로 시작하기

    시험을 보고 나면 선생님이 "평균 72점, 최고 98점, 최저 35점"이라고 알려주시죠? 이것만으로도 "아, 이번 시험은 대체로 이 정도 수준이었구나"라고 파악할 수 있습니다. 이렇게 데이터 전체를 몇 개의 숫자로 요약한 것이 요약 통계량입니다.

    정확한 정의

    • df.describe(): 숫자형 열에 대해 개수(count), 평균(mean), 표준편차(std), 최솟값(min), 사분위수(25%·50%·75%), 최댓값(max)을 한 번에 보여주는 함수
    • df['열이름'].value_counts(): 범주형(카테고리) 데이터에서 각 값이 몇 번 등장하는지 세어주는 함수
    flowchart TD A["데이터 요약"] --> B{"데이터 유형?"} B -->|"숫자형\n(키, 점수, 타율)"| C["describe()\n평균·최대·최소 등"] B -->|"범주형\n(포지션, 팀, 성별)"| D["value_counts()\n각 항목별 개수"]

    알아보기 📌: 표준편차(std)는 "데이터가 평균에서 얼마나 퍼져 있는가"를 나타냅니다. 값이 크면 데이터가 넓게 흩어져 있고, 작으면 평균 근처에 모여 있다는 뜻입니다.

    개념 4: 분포 시각화 — 히스토그램과 막대그래프 📈¶

    비유로 시작하기

    숫자 나열만으로는 전체 그림이 잘 안 그려집니다. 마치 지도 없이 길을 찾는 것과 같죠. 그래프는 데이터의 지도입니다. 한눈에 "어디에 많이 모여 있는지", "특이한 값은 없는지" 파악할 수 있습니다.

    두 가지 그래프의 차이

    • 히스토그램(Histogram): 숫자형 데이터의 분포를 보여줍니다. 값의 범위를 구간(bin)으로 나누고, 각 구간에 속하는 데이터 개수를 막대 높이로 표현합니다. (예: 타율 분포)
    • 막대그래프(Bar Chart): 범주형 데이터의 빈도를 보여줍니다. 각 카테고리별 개수를 막대로 표현합니다. (예: 포지션별 선수 수)
    flowchart LR A["📊 분포 시각화"] --> B["숫자형 데이터"] A --> C["범주형 데이터"] B --> D["히스토그램\n구간별 빈도"] C --> E["막대그래프\n항목별 개수"]

    생각해보기 🤔: 히스토그램에서 막대들이 서로 붙어 있는 이유는 뭘까요? 숫자형 데이터는 값이 연속적으로 이어지기 때문입니다. 반면 막대그래프는 카테고리가 서로 독립적이라 막대 사이에 간격이 있습니다.

    Step 3: 요약 통계량 확인하기 — describe()¶

    # 숫자형 열의 요약 통계
print("📊 요약 통계량")
print("=" * 50)
df.describe()

    결과를 살펴봅시다.

    • count: 데이터 개수 (20명)
    • mean: 평균값 (타율 평균이 약 0.253 — 투수 포함이라 낮게 나옵니다)
    • std: 표준편차 (값이 평균에서 얼마나 퍼져 있는지)
    • min / max: 최솟값 / 최댓값
    • 25%, 50%, 75%: 사분위수 (데이터를 크기순으로 나열했을 때 25%, 50%, 75% 지점의 값)

    생각해보기 🤔: 타율의 min이 0.000인 데이터가 보입니다. 이건 타율이 정말 0인 걸까요? 데이터를 다시 보면 투수들의 타율입니다. 분석 목적에 따라 투수를 제외해야 할 수도 있습니다. 이렇게 요약 통계를 보면서 "이상한 점"을 발견하는 것이 탐색의 핵심입니다!

    Step 4: 범주형 데이터 탐색하기 — value_counts()¶

    # 팀별 선수 수
print("⚾ 팀별 선수 수")
print("=" * 30)
print(df['팀'].value_counts())

    # 포지션별 선수 수
print("\n🧢 포지션별 선수 수")
print("=" * 30)
print(df['포지션'].value_counts())

    value_counts()는 해당 열에서 각 값이 몇 번 등장하는지 내림차순으로 보여줍니다. 이 데이터에서는 내야수가 가장 많고, 투수는 2명뿐이라는 것을 알 수 있습니다.

    Step 5: 히스토그램으로 분포 살펴보기¶

    타자들의 타율 분포를 히스토그램으로 그려봅시다.

    # 투수를 제외한 타자 데이터만 추출
batters = df[df['포지션'] != '투수']

# 타율 히스토그램
plt.figure(figsize=(8, 5))
plt.hist(batters['타율'], bins=8, color='steelblue', edgecolor='white')
plt.title('프로야구 타자 타율 분포', fontsize=14)
plt.xlabel('타율', fontsize=12)
plt.ylabel('선수 수', fontsize=12)
plt.grid(axis='y', alpha=0.3)
plt.show()

    알아보기 📌: bins=8은 타율 범위를 8개 구간으로 나눈다는 뜻입니다. bins 값을 바꾸면 그래프 모양이 달라집니다. 너무 적으면 뭉뚱그려지고, 너무 많으면 쪼개져서 패턴이 안 보입니다. 보통 데이터 수의 제곱근 정도가 적당합니다.

    Step 6: 막대그래프로 범주별 비교하기¶

    포지션별 평균 홈런 수를 막대그래프로 비교해봅시다.

    # 포지션별 평균 홈런 (투수 제외)
hr_by_pos = batters.groupby('포지션')['홈런'].mean()

# 막대그래프
plt.figure(figsize=(8, 5))
hr_by_pos.plot(kind='bar', color=['coral', 'mediumseagreen', 'gold'])
plt.title('포지션별 평균 홈런 수', fontsize=14)
plt.xlabel('포지션', fontsize=12)
plt.ylabel('평균 홈런', fontsize=12)
plt.xticks(rotation=0)
plt.grid(axis='y', alpha=0.3)
plt.show()

    그래프를 보면 어떤 포지션이 홈런을 많이 치는지 한눈에 비교할 수 있습니다. 숫자만 나열했을 때보다 훨씬 직관적이죠?

    기본 문제¶

    문제 1. 다음 중 describe() 함수의 결과에 포함되지 않는 것은?

    • ① 평균(mean)
    • ② 최빈값(mode)
    • ③ 표준편차(std)
    • ④ 중앙값(50%)
    정답 확인 **② 최빈값(mode)** `describe()`는 count, mean, std, min, 25%, 50%(중앙값), 75%, max를 보여줍니다. 최빈값은 포함되지 않으며, 따로 `df['열이름'].mode()`로 구할 수 있습니다.

    문제 2. "팀별 선수 수"처럼 범주형 데이터의 빈도를 확인할 때 사용하는 함수는?

    정답 확인 **`value_counts()`** 사용법: `df['팀'].value_counts()`

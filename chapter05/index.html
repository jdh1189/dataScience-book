    Chapter 5: 데이터 수집과 탐색적 분석¶

    🎯 이 장에서 배우는 것¶

    • 다양한 데이터 수집 방법(설문·크롤링·공공데이터·API)을 비교 설명할 수 있다
    • pandas를 활용하여 CSV 데이터를 불러오고 기본 구조를 파악할 수 있다
    • 평균·중앙값·표준편차 등 기본 통계량을 산출하고 해석할 수 있다
    • 히스토그램과 박스플롯으로 데이터 분포를 탐색적으로 분석(EDA)할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 여러분이 좋아하는 유튜버의 구독자 수 데이터는 어디서 구할 수 있을까요? 🤔

    "우리 학교 학생들은 평균 몇 시간 잠을 잘까?", "전국 고등학교 중 학생 수가 가장 많은 학교는?" — 이런 궁금증에 답하려면 데이터가 필요합니다.

    데이터 분석의 첫 단계는 "좋은 데이터를 모으는 것"이고, 두 번째 단계는 "데이터를 꼼꼼히 살펴보는 것"입니다. 요리에 비유하면, 좋은 재료를 시장에서 골라오는 것(수집)과 재료의 상태를 확인하고 손질하는 것(탐색)에 해당합니다. 아무리 뛰어난 요리사라도 상한 재료로는 맛있는 음식을 만들 수 없듯, 데이터 분석도 수집과 탐색이 탄탄해야 올바른 결론에 도달할 수 있습니다.

    이번 장에서는 데이터를 어디서, 어떻게 모으는지 알아보고, 모은 데이터를 pandas로 불러와 통계량을 계산하고 시각화하는 전 과정을 직접 경험합니다.

    📚 핵심 개념¶

    개념 1: 데이터 수집 방법 🎣¶

    1. 비유로 시작

    데이터 수집은 낚시와 비슷합니다. 어떤 물고기(데이터)를 잡고 싶은지에 따라 바다에 갈 수도, 강에 갈 수도, 양식장에서 구매할 수도 있죠. 마찬가지로 필요한 데이터에 따라 수집 방법이 달라집니다.

    2. 정확한 정의

    데이터 수집이란 분석 목적에 맞는 데이터를 확보하는 과정입니다. 크게 4가지 방법이 있습니다.

    • 설문조사: 구글 폼, 네이버 폼 등으로 사람들에게 직접 물어 데이터를 모으는 방법
    • 웹 크롤링(Web Crawling): 프로그램으로 웹사이트의 정보를 자동으로 수집하는 방법 (법적·윤리적 주의 필요!)
    • 공공데이터: 정부·공공기관이 누구나 쓸 수 있도록 공개한 데이터 (공공데이터포털, 통계청 등)
    • API(Application Programming Interface): 서비스 제공자가 정해진 규칙으로 데이터를 제공하는 통로 (날씨 API, 유튜브 API 등)

    3. 예시로 확인

    flowchart LR A["🎯 분석 목적 결정"] --> B{"어떤 데이터가\n필요한가?"} B -->|"사람들의 의견"| C["📋 설문조사\n구글 폼, 네이버 폼"] B -->|"웹사이트 정보"| D["🕷️ 웹 크롤링\n뉴스, 리뷰 등"] B -->|"공개된 통계"| E["🏛️ 공공데이터\ndata.go.kr, 캐글"] B -->|"서비스 연동"| F["🔌 API\n날씨, 유튜브 등"]

    알아보기: 각 수집 방법의 장단점

    • 설문조사 — 👍 원하는 질문을 직접 설계 / 👎 응답자 확보가 어려움
    • 웹 크롤링 — 👍 대량 데이터 수집 가능 / 👎 법적 문제 가능성, 사이트 구조 변경 시 코드 수정 필요
    • 공공데이터 — 👍 신뢰도 높고 무료 / 👎 원하는 형태가 아닐 수 있음
    • API — 👍 실시간·구조화된 데이터 / 👎 사용 제한(호출 횟수)이 있을 수 있음

    개념 2: pandas로 데이터 불러오기 🐼¶

    1. 비유로 시작

    엑셀을 떠올려 보세요. 행(row)과 열(column)로 정리된 표를 다루잖아요? pandas는 파이썬에서 이 엑셀 표를 다루는 도구입니다. 엑셀의 "시트" 하나가 pandas의 DataFrame(데이터프레임)에 해당합니다.

    2. 정확한 정의

    • pandas: 파이썬의 데이터 분석 라이브러리. 표 형태의 데이터를 쉽게 다룰 수 있게 해줍니다.
    • DataFrame: 행과 열로 이루어진 2차원 데이터 구조. 엑셀 시트와 유사합니다.
    • CSV(Comma-Separated Values): 쉼표로 값을 구분한 텍스트 파일. 데이터 교환에 가장 많이 쓰이는 형식입니다.

    3. 예시로 확인

    import pandas as pd

# CSV 파일 불러오기
df = pd.read_csv('school_data.csv')

# 데이터 구조를 파악하는 3가지 필수 명령어
df.head()       # 처음 5줄 미리보기
df.info()       # 열 이름, 데이터 타입, 결측값 확인
df.shape        # (행 수, 열 수) 확인
    flowchart TD A["📁 CSV 파일"] -->|"pd.read_csv()"| B["📊 DataFrame"] B --> C["df.head() → 처음 5줄 미리보기"] B --> D["df.info() → 데이터 타입·결측값 확인"] B --> E["df.shape → 행과 열의 개수"] B --> F["df.describe() → 기본 통계량"]

    알아보기: df.info()가 알려주는 것

    info()를 실행하면 열 이름, 비어있지 않은 값의 개수(Non-Null Count), 데이터 타입(Dtype)을 한눈에 볼 수 있습니다. 여기서 Non-Null Count가 전체 행 수보다 적다면 결측값(빈칸)이 있다는 뜻입니다.

    개념 3: 기본 통계량 📊¶

    1. 비유로 시작

    반 친구 30명의 키를 조사했다고 합시다. 30개의 숫자를 하나하나 보는 것보다, "평균 168cm, 가장 작은 사람 155cm, 가장 큰 사람 185cm"라고 요약하면 한눈에 파악할 수 있죠. 이렇게 데이터를 몇 개의 숫자로 요약한 것이 기본 통계량입니다.

    2. 정확한 정의

    • 평균(mean): 모든 값을 더한 뒤 개수로 나눈 값. 데이터의 "무게중심"
    • 중앙값(median): 값을 크기순으로 나열했을 때 정가운데 오는 값. 극단적인 값(이상치)에 영향을 덜 받음
    • 표준편차(std, standard deviation): 값들이 평균에서 얼마나 퍼져 있는지를 나타내는 수치. 클수록 데이터가 넓게 흩어져 있음
    • 사분위수(quartile): 데이터를 4등분하는 값들 (25%, 50%, 75% 지점)

    3. 예시로 확인

    생각해보기: 다음 두 반의 수학 점수를 비교해 봅시다.

    • A반: 70, 72, 74, 76, 78 → 평균 74, 중앙값 74
    • B반: 50, 60, 74, 85, 101 → 평균 74, 중앙값 74

    평균과 중앙값이 같은데, 두 반의 성적 분포는 같을까요? 🤔 아닙니다! B반의 표준편차가 훨씬 큽니다. 이것이 표준편차를 함께 봐야 하는 이유입니다.

    # pandas의 describe()는 이 통계량들을 한 번에 보여줍니다
df['학생수'].describe()

    실행 결과(예시): 

    count    2000.000000    ← 데이터 개수
mean      750.500000    ← 평균
std       420.300000    ← 표준편차
min        45.000000    ← 최솟값
25%       410.000000    ← 1사분위수 (하위 25%)
50%       680.000000    ← 중앙값 (2사분위수)
75%      1050.000000    ← 3사분위수 (상위 25%)
max      3200.000000    ← 최댓값

    개념 4: 탐색적 데이터 분석(EDA) 🔍¶

    1. 비유로 시작

    새 학교에 전학을 갔다고 상상해 보세요. 첫날에 무엇을 할까요? 교실을 둘러보고, 친구들이 몇 명인지 세어보고, 분위기를 파악하죠. EDA는 이처럼 데이터를 처음 만났을 때 이리저리 살펴보는 과정입니다.

    2. 정확한 정의

    EDA(Exploratory Data Analysis, 탐색적 데이터 분석)란 데이터를 다양한 각도에서 살펴보며 패턴, 이상치(극단적 값), 분포 특성을 발견하는 분석 과정입니다. 주로 통계량 계산과 시각화를 함께 사용합니다.

    3. 예시로 확인 — EDA의 단계

    flowchart LR A["1️⃣ 데이터 불러오기\nread_csv()"] --> B["2️⃣ 구조 파악\ninfo(), shape"] B --> C["3️⃣ 통계량 확인\ndescribe()"] C --> D["4️⃣ 분포 시각화\n히스토그램, 박스플롯"] D --> E["5️⃣ 패턴·이상치 발견\n해석과 기록"]

    EDA에서 자주 사용하는 시각화 두 가지:

    • 히스토그램(Histogram): 데이터가 어떤 구간에 많이 몰려있는지 보여주는 막대 그래프. "분포의 전체 모양"을 파악
    • 박스플롯(Box Plot): 중앙값, 사분위수, 이상치를 한눈에 보여주는 그래프. "요약과 이상치"를 파악
    flowchart TD subgraph 히스토그램 H1["📊 X축: 값의 구간"] H2["📊 Y축: 빈도(개수)"] H3["→ 데이터가 어디에 몰려있나?"] end subgraph 박스플롯 B1["📦 상자: 25%~75% 구간"] B2["📦 가운데 선: 중앙값"] B3["📦 점/원: 이상치"] end

    🔨 따라하기¶

    이번 실습에서는 전국 고등학교 정보 데이터를 코랩(Google Colab)에서 불러와 EDA를 수행합니다. 실습에 사용할 데이터는 실제 공공데이터를 기반으로 한 예시 CSV입니다.

    Step 1: 코랩 열기와 데이터 준비 🚀¶

    구글 코랩(colab.research.google.com)에 접속하여 새 노트북을 만듭니다.

    먼저 실습용 데이터를 직접 만들어 보겠습니다. 실제 프로젝트에서는 CSV 파일을 다운로드하겠지만, 지금은 코드로 샘플 데이터를 생성합니다.

    import pandas as pd
import numpy as np

# 재현 가능하도록 시드 설정
np.random.seed(42)

# 전국 고등학교 샘플 데이터 생성 (200개 학교)
n = 200

    문제 5. 히스토그램에서 막대가 오른쪽에 넓게 꼬리를 끌고 있고, 평균이 중앙값보다 크다면 데이터의 분포에 대해 어떤 해석을 내릴 수 있나요?

    정답: 양의 왜도(오른쪽 꼬리 분포)를 가지고 있습니다. 대부분의 값은 작은 쪽에 몰려있고, 소수의 매우 큰 값(이상치)이 평균을 끌어올리고 있습니다. 이 경우 중앙값이 "전형적인 값"을 더 잘 대표합니다.

    심화 문제 ⭐⭐⭐¶

    문제 6. 박스플롯에서 "이상치"는 어떤 기준으로 판별되나요? Q1, Q3, IQR을 사용하여 설명하세요.

    정답: IQR(사분위 범위) = Q3 - Q1입니다. Q1 - 1.5 × IQR 미만이거나 Q3 + 1.5 × IQR 초과인 값을 이상치로 판별합니다. 예를 들어 Q1=400, Q3=1000이면 IQR=600이고, 400 - 900 = -500 미만 또는 1000 + 900 = 1900 초과인 값이 이상치입니다.

    도전 과제: 나만의 EDA 보고서 작성하기 📋¶

    다음 중 하나의 데이터셋을 선택하여 EDA 보고서를 작성해 보세요.

    데이터셋 선택지: - 캐글(kaggle.com) — "student performance", "world happiness" 등 검색 - 공공데이터포털(data.go.kr) — 관심 있는 공공데이터 다운로드 - 직접 설문 — 구글 폼으로 반 친구들에게 설문 후 CSV 다운로드

    보고서에 포함할 내용:

    1. 데이터 소개: 어디서 구했는지, 행/열이 몇 개인지, 각 열의 의미는 무엇인지
    2. 데이터 구조: info(), shape, head() 결과
    3. 기본 통계량: describe() 결과와 그 해석 (평균 vs 중앙값 비교!)
    4. 시각화: 히스토그램 1개 이상, 박스플롯 1개 이상
    5. 발견한 점: "이 데이터에서 내가 발견한 흥미로운 사실 3가지"

    💡 팁: 완벽한 분석을 할 필요 없습니다. "데이터를 꼼꼼히 살펴보고, 발견한 것을 기록하는 연습"이 목적입니다.

    🔑 핵심 개념 요약¶

    • 데이터 수집 4가지 방법: 설문조사, 웹 크롤링, 공공데이터, API — 목적에 따라 적합한 방법을 선택
    • pandas 필수 명령어: read_csv() → head() → info() → describe() → value_counts() 순서로 데이터를 파악
    • 기본 통계량: 평균(전체 경향), 중앙값(이상치에 강함), 표준편차(퍼진 정도)를 함께 봐야 데이터를 올바르게 이해
    • EDA: 통계량 + 시각화(히스토그램, 박스플롯)로 데이터의 분포, 패턴, 이상치를 탐색하는 과정

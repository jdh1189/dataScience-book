    Chapter 5: 데이터 수집 및 특성 분석¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 다양한 형식(CSV, 웹, API)의 데이터를 Python으로 수집할 수 있다
    • 수집한 데이터의 기본 구조와 통계량을 파악할 수 있다
    • 데이터의 자료형(수치형, 범주형)을 구분하고 적절히 처리할 수 있다
    • 시각화를 활용하여 데이터의 분포와 특성을 분석할 수 있다

    💡 왜 이걸 배우나요?¶

    요리를 시작하기 전에 재료를 확인하는 것처럼, 데이터 분석도 "내가 가진 데이터가 어떤 녀석인지" 파악하는 것에서 시작합니다.

    아무리 뛰어난 머신러닝 모델도, 데이터를 제대로 이해하지 못한 채 투입하면 엉뚱한 결과를 냅니다. 실제 데이터 과학자들은 전체 프로젝트 시간의 60~80%를 데이터 수집과 이해에 사용합니다.

    이 장에서는 데이터를 모으고, 처음 만난 데이터에게 "너 누구야?"라고 물어보는 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 데이터 수집 — 재료 장보기 🛒¶

    비유: 요리사가 시장에서 재료를 사 오듯, 데이터 분석가는 여러 곳에서 데이터를 수집합니다. 시장마다 파는 물건이 다르듯, 데이터 출처마다 형식도 다릅니다.

    정의: 데이터 수집(Data Collection)이란 분석 목적에 맞는 데이터를 다양한 출처에서 가져와 하나의 구조화된 형태로 정리하는 과정입니다.

    주요 데이터 출처와 형식

    • CSV 파일: 쉼표로 구분된 텍스트 파일. 가장 보편적인 데이터 교환 형식
    • 엑셀 파일(.xlsx): 스프레드시트 형태. 기업 현장에서 많이 사용
    • 웹 데이터: 웹사이트에서 직접 가져오는 데이터 (웹 스크래핑)
    • API: 서비스가 제공하는 공식 데이터 통로 (예: 공공데이터포털, 날씨 API)
    flowchart LR A["📁 CSV/Excel\n파일"] --> D["🐼 pandas\nDataFrame"] B["🌐 웹사이트\n스크래핑"] --> D C["🔌 API\n공공데이터"] --> D D --> E["📊 분석 시작!"]

    알아보기: pandas의 read_csv(), read_excel(), read_html() 함수는 각각 다른 형식의 데이터를 동일한 DataFrame 구조로 변환해줍니다. 입구는 달라도 도착지는 같은 셈이죠!

    개념 2: 데이터 구조 파악 — 첫인상 확인하기 👀¶

    비유: 새 학기에 반 친구들을 처음 만나면, 먼저 "몇 명이지?", "이름이 뭐지?"를 확인하죠. 데이터도 마찬가지입니다. 처음 만나면 크기, 구성, 형태부터 확인합니다.

    정의: 데이터 구조 파악이란 데이터의 행(관측값) 수, 열(변수) 수, 각 열의 자료형, 결측값 유무 등 기본적인 뼈대를 확인하는 과정입니다.

    핵심 확인 항목

    • shape: 행 × 열 크기 (예: 150행 × 4열)
    • dtypes: 각 열의 자료형 (숫자인지, 문자인지)
    • info(): 전체 구조 요약 (결측값 포함)
    • head(): 처음 5행 미리보기
    • describe(): 수치형 데이터의 기본 통계량

    생각해보기: describe()가 보여주는 mean(평균), std(표준편차), min, max 값만으로도 데이터에 이상한 점이 있는지 감을 잡을 수 있습니다. 예를 들어 "나이" 열의 max가 999라면? 🤔

    개념 3: 자료형 구분 — 숫자와 카테고리 🏷️¶

    비유: 학교에서 학생 정보를 정리한다고 생각해보세요. 키(168.5cm) 는 숫자로 계산할 수 있지만, 혈액형(A, B, O, AB) 은 숫자가 아닌 카테고리입니다. 이 둘을 같은 방식으로 다루면 안 됩니다.

    정의: 자료형(Data Type)은 데이터가 가진 값의 성질에 따른 분류입니다.

    flowchart TD A["데이터 자료형"] --> B["수치형\nNumerical"] A --> C["범주형\nCategorical"] B --> B1["연속형\n키, 몸무게, 온도"] B --> B2["이산형\n학생 수, 횟수"] C --> C1["명목형\n혈액형, 성별"] C --> C2["순서형\n학점(A>B>C), 만족도"]

    왜 구분이 중요한가요?

    • 수치형 → 평균, 표준편차 계산 가능 → 히스토그램으로 시각화
    • 범주형 → 빈도(개수) 계산 → 막대그래프로 시각화
    • 자료형을 잘못 인식하면 분석 결과 자체가 틀어집니다!

    알아보기: pandas에서 숫자처럼 보이는 "1, 2, 3"이 사실은 문자(object)로 저장되어 있는 경우가 많습니다. dtypes로 반드시 확인하세요!

    개념 4: 특성 분석 — 데이터의 성격 읽기 📊¶

    비유: 사람의 성격을 파악하려면 대화도 하고 행동도 관찰하듯, 데이터의 성격을 파악하려면 통계량도 보고 그래프도 그려봐야 합니다.

    정의: 특성 분석(Feature Analysis)이란 각 변수의 분포, 중심 경향, 퍼짐 정도, 변수 간 관계를 통계와 시각화로 파악하는 과정입니다.

    핵심 분석 도구

    • 히스토그램(histogram): 수치형 데이터가 어떻게 퍼져 있는지 확인
    • 박스플롯(boxplot): 이상치(outlier, 극단적으로 튀는 값)를 한눈에 포착
    • 상관계수(correlation): 두 수치형 변수가 얼마나 함께 움직이는지 (-1 ~ +1)
    • 값 빈도(value_counts): 범주형 데이터에서 각 카테고리의 개수
    flowchart LR A["특성 분석"] --> B["단변량 분석\n변수 하나씩"] A --> C["이변량 분석\n변수 둘 사이 관계"] B --> B1["히스토그램\n박스플롯\n빈도표"] C --> C1["산점도\n상관계수\n그룹별 비교"]

    🔨 따라하기¶

    유명한 붓꽃(Iris) 데이터셋을 활용하여, 데이터 수집부터 특성 분석까지 전체 흐름을 체험합니다.

    Step 1: 데이터 수집 (CSV 불러오기)¶

    import pandas as pd

# Iris 데이터셋 불러오기 (인터넷에서 직접 CSV 다운로드)
url = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv"
df = pd.read_csv(url)

print("✅ 데이터 수집 완료!")
print(f"데이터 크기: {df.shape[0]}행, {df.shape[1]}열")

    Step 4: 시각화로 분포 확인¶

    import matplotlib.pyplot as plt

# 한글 깨짐 방지 (환경에 따라 조정)
plt.rcParams['font.size'] = 12

# 히스토그램: 수치형 4개 변수의 분포
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
columns = ['sepal_length', 'sepal_width', 'petal_length', 'petal_width']

for ax, col in zip(axes.flatten(), columns):
    ax.hist(df[col], bins=20, color='steelblue', edgecolor='white')
    ax.set_title(col)
    ax.set_xlabel('Value')
    ax.set_ylabel('Count')

plt.tight_layout()
plt.savefig('iris_histograms.png', dpi=100)
plt.show()
print("✅ 히스토그램 저장 완료!")

    이 그래프에서 읽어야 할 것: - petal_length, petal_width는 두 개의 봉우리가 보임 → 품종에 따라 값이 확연히 다름 - sepal_width는 종 모양에 가까움 → 정규분포에 가까운 형태

    Step 5: 박스플롯으로 이상치 탐색¶

    # 품종별 꽃잎 길이 박스플롯
fig, ax = plt.subplots(figsize=(8, 5))

species_list = df['species'].unique()
data_by_species = [df[df['species'] == s]['petal_length'] for s in species_list]

ax.boxplot(data_by_species, labels=species_list)
ax.set_title('Petal Length by Species')
ax.set_ylabel('Petal Length (cm)')

plt.tight_layout()
plt.savefig('iris_boxplot.png', dpi=100)
plt.show()
print("✅ 박스플롯 저장 완료!")

    박스플롯 읽는 법: - 상자: 데이터의 중간 50%가 모여 있는 범위 (Q1~Q3) - 가운데 선: 중앙값(median) - 수염(whisker): 정상 범위 - 점(●): 수염 바깥의 값 = 이상치(outlier) 후보

    Step 6: 상관관계 분석¶

    # 상관계수 계산
corr = df.select_dtypes(include='number').corr()
print("🔗 상관계수 행렬:")
print(corr.round(2))
print()

# 히트맵 시각화
fig, ax = plt.subplots(figsize=(7, 6))
im = ax.imshow(corr, cmap='coolwarm', vmin=-1, vmax=1)

# 축 라벨 설정
ax.set_xticks(range(len(corr.columns)))
ax.set_yticks(range(len(corr.columns)))
ax.set_xticklabels(corr.columns, rotation=45, ha='right')
ax.set_yticklabels(corr.columns)

# 수치 표시
for i in range(len(corr)):
    for j in range(len(corr)):
        ax.text(j, i, f'{corr.iloc[i, j]:.2f}', ha='center', va='center')

plt.colorbar(im)
plt.title('Correlation Heatmap')
plt.tight_layout()
plt.savefig('iris_correlation.png', dpi=100)
plt.show()

    결과 해석: - petal_length와 petal_width의 상관계수 ≈ 0.96 → 매우 강한 양의 상관관계 (꽃잎이 길면 넓기도 하다) - sepal_width와 다른 변수들은 상관관계가 약함

    정리하기: 상관계수는 -1 ~ +1 사이의 값입니다. +1에 가까우면 "같이 증가", -1에 가까우면 "하나가 증가하면 다른 하나는 감소", 0에 가까우면 "별 관련 없음"을 의미합니다.

    실수 3: describe()만 보고 범주형 변수를 놓침¶

    # ❌ describe()는 기본적으로 수치형만 보여줌

# ✅ 범주형까지 보려면 include 파라미터 사용
df.describe(include='all')  # 모든 자료형 요약

# 또는 범주형은 따로 확인
df.select_dtypes(include='object').describe()

    실수 4: 상관계수를 인과관계로 오해¶

    상관계수가 높다고 해서 "A가 B를 일으킨다"는 아닙니다! 아이스크림 판매량과 익사 사고 건수는 상관관계가 높지만, 아이스크림이 익사를 일으키는 것은 아닙니다 (둘 다 여름에 증가할 뿐).

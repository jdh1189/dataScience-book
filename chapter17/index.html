    17장. 슬기로운 의사 생활 (1) — 문제 정의와 데이터 준비¶

    Part 4 | [2권] 데이터 과학 프로젝트 — 교과서 주제 실습

    🎯 이 장에서 배우는 것¶

    • 건강 데이터 기반 질병 예측 프로젝트의 문제를 명확하게 정의할 수 있다
    • 건강 검진 데이터를 로드하고 결측치·이상치·변환 전처리를 종합 수행할 수 있다
    • 탐색적 데이터 분석(EDA)을 통해 주요 변수 간 관계를 파악할 수 있다
    • EDA 결과를 바탕으로 예측에 유용한 변수를 선별할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    매년 건강 검진을 받으면 숫자가 빼곡한 결과표를 받습니다. 혈압 130/85, 공복혈당 112, 콜레스테롤 240… 이 숫자들만 보고 "앞으로 심장 질환에 걸릴 가능성이 높다"고 미리 알 수 있다면 어떨까요?

    실제로 병원과 보험회사는 수십만 명의 검진 데이터를 분석해서 질병 위험도를 예측합니다. 우리도 이번 프로젝트에서 진짜 건강 검진 데이터를 다루며 이 과정을 직접 체험합니다.

    하지만 데이터를 받자마자 바로 모델을 만들 수는 없습니다. 현실 데이터에는 빠진 값, 말도 안 되는 수치, 들쭉날쭉한 형식이 가득하기 때문입니다. 요리로 비유하면, 좋은 요리(모델)를 만들려면 재료 손질(전처리)이 먼저입니다.

    이번 장은 그 "재료 손질"에 해당합니다. 1~2권에서 배운 판다스, 시각화, 전처리 기술을 하나의 프로젝트에 종합 적용하는 첫걸음입니다.

    flowchart LR A["🏥 건강 검진 데이터"] --> B["🔧 전처리"] B --> C["📊 EDA"] C --> D["🎯 모델링 준비 완료"] style A fill:#e3f2fd,stroke:#1565c0 style B fill:#fff3e0,stroke:#e65100 style C fill:#e8f5e9,stroke:#2e7d32 style D fill:#fce4ec,stroke:#c62828

    이번 장(17장)에서는 A → B → C까지, 다음 장(18장)에서 D(모델링)를 다룹니다.

    📚 핵심 개념¶

    개념 1: 문제 정의 — 프로젝트의 나침반 🧭¶

    1) 비유로 시작¶

    여행을 떠날 때 "어디로 갈지"를 정하지 않으면 짐을 쌀 수도, 경로를 찾을 수도 없습니다. 데이터 과학 프로젝트도 마찬가지입니다. "무엇을 예측할 것인가?"를 먼저 명확하게 정해야 어떤 데이터를 모으고, 어떤 방법을 쓸지 결정할 수 있습니다. 이것이 문제 정의입니다.

    2) 정확한 정의¶

    문제 정의(Problem Definition)란, 데이터 과학 프로젝트에서 해결하려는 질문을 구체적이고 측정 가능한 형태로 바꾸는 과정입니다. 좋은 문제 정의에는 다음 요소가 포함됩니다.

    • 예측 대상(타겟 변수): 무엇을 맞히고 싶은가?
    • 입력 정보(특성 변수): 어떤 데이터를 활용하는가?
    • 문제 유형: 분류인가, 회귀인가?
    • 성공 기준: 어느 정도 정확하면 의미가 있는가?

    3) 예시로 확인 — 우리 프로젝트의 문제 정의¶

    flowchart TD Q["❓ 막연한 질문<br>'건강 검진으로 병을 예측할 수 있을까?'"] --> R["🎯 구체적 문제 정의"] R --> T["타겟: 심혈관 질환 여부<br>(있다=1, 없다=0)"] R --> F["특성: 나이, 혈압, 콜레스테롤,<br>혈당, BMI, 흡연, 음주 등"] R --> P["유형: 이진 분류<br>(Binary Classification)"] R --> S["성공 기준: 정확도 70% 이상"]

    알아보기 📖

    이진 분류(Binary Classification)란 결과가 딱 두 가지(예/아니오, 0/1)인 문제입니다. "이 사람이 심혈관 질환이 있는가, 없는가?"처럼요. 스팸 메일 분류(스팸/정상)도 같은 유형입니다.

    개념 2: 건강 검진 데이터의 구조 이해 📋¶

    1) 비유로 시작¶

    병원에서 받는 검진 결과표를 떠올려 보세요. 한 줄에 한 사람의 정보가 있고, 각 열에는 "혈압", "혈당", "콜레스테롤" 같은 항목이 나열됩니다. 데이터프레임도 정확히 그 구조입니다. 한 행(row) = 한 환자, 한 열(column) = 하나의 검사 항목입니다.

    2) 정확한 정의¶

    이번 프로젝트에서 사용하는 데이터셋은 Cardiovascular Disease Dataset으로, 약 70,000명의 건강 검진 기록이 담겨 있습니다.

    주요 변수(컬럼) 설명:

    • id — 환자 고유 번호
    • age — 나이 (일 단위로 기록됨, 예: 18,393일 ≈ 50세)
    • gender — 성별 (1: 여성, 2: 남성)
    • height — 키 (cm)
    • weight — 몸무게 (kg)
    • ap_hi — 수축기 혈압 (최고 혈압)
    • ap_lo — 이완기 혈압 (최저 혈압)
    • cholesterol — 콜레스테롤 수치 (1: 정상, 2: 높음, 3: 매우 높음)
    • gluc — 혈당 수치 (1: 정상, 2: 높음, 3: 매우 높음)
    • smoke — 흡연 여부 (0: 비흡연, 1: 흡연)
    • alco — 음주 여부 (0: 비음주, 1: 음주)
    • active — 운동 여부 (0: 비활동, 1: 활동)
    • cardio — 🎯 심혈관 질환 여부 (0: 없음, 1: 있음) ← 타겟 변수

    3) 예시로 확인¶

    flowchart LR subgraph "한 행 = 한 환자" A["나이: 50세"] --- B["혈압: 130/85"] B --- C["콜레스테롤: 높음"] C --- D["흡연: X"] D --- E["🎯 심혈관질환: 있음"] end

    이 환자의 나이, 혈압, 콜레스테롤, 흡연 정보(특성)를 보고 심혈관 질환 여부(타겟)를 예측하는 것이 우리의 목표입니다.

    개념 3: 전처리 파이프라인 — 데이터 청소의 정석 🧹¶

    1) 비유로 시작¶

    요리 전에 채소를 씻고(결측치 처리), 상한 부분을 잘라내고(이상치 제거), 먹기 좋게 썰어놓는(변환) 과정이 있듯이, 데이터도 정해진 순서로 깨끗하게 만들어야 합니다.

    2) 정확한 정의¶

    전처리 파이프라인(Preprocessing Pipeline)이란, 원시 데이터를 분석·모델링에 적합한 형태로 바꾸는 일련의 단계적 작업을 말합니다.

    flowchart TD A["1️⃣ 데이터 로드<br>CSV 파일 읽기"] --> B["2️⃣ 기본 탐색<br>shape, info, describe"] B --> C["3️⃣ 결측치 처리<br>확인 → 삭제 또는 대체"] C --> D["4️⃣ 이상치 처리<br>비현실적 값 제거"] D --> E["5️⃣ 변수 변환<br>단위 변경, 새 변수 생성"] E --> F["6️⃣ EDA<br>시각화로 패턴 발견"]

    3) 예시로 확인¶

    • 결측치: 혈압 칸이 비어 있는 환자 → 평균값으로 대체하거나 해당 행 삭제
    • 이상치: 수축기 혈압이 -100이거나 16,020인 경우 → 현실적으로 불가능하므로 제거
    • 변수 변환: 나이가 "일(day)" 단위 → "년(year)" 단위로 변환 (÷ 365.25)

    개념 4: 탐색적 데이터 분석(EDA) — 데이터에게 질문하기 🔍¶

    1) 비유로 시작¶

    형사가 사건을 수사할 때, 증거를 하나하나 살펴보고 연결고리를 찾습니다. EDA는 데이터라는 "증거"를 시각화와 통계로 살펴보며 "어떤 변수가 범인(질병)과 관련이 있는가?"를 추리하는 과정입니다.

    2) 정확한 정의¶

    탐색적 데이터 분석(EDA, Exploratory Data Analysis)이란, 모델링 전에 데이터의 분포, 패턴, 이상점, 변수 간 관계를 시각화와 기초 통계량으로 파악하는 분석 과정입니다.

    주요 EDA 기법:

    • 히스토그램(Histogram): 하나의 변수가 어떤 분포를 가지는지 확인
    • 상관 행렬 히트맵(Correlation Heatmap): 변수들 사이의 상관관계를 색상으로 한눈에 파악
    • 그룹별 비교 차트: 타겟(심혈관 질환 유/무)에 따라 변수 분포가 어떻게 다른지 비교

    3) 예시로 확인¶

    flowchart LR subgraph "EDA 도구 상자" H["📊 히스토그램<br>나이 분포 확인"] B["🔥 히트맵<br>변수 간 상관관계"] C["📈 그룹 비교<br>질환 유/무별 혈압 차이"] end

    정리하기 📌

    이번 장의 핵심 개념 4가지를 정리하면: 1. 문제 정의 — "무엇을 예측할 것인가?"를 구체적으로 정한다 2. 데이터 구조 이해 — 행(환자)과 열(검사 항목)의 의미를 파악한다 3. 전처리 파이프라인 — 결측치 → 이상치 → 변환 순서로 데이터를 정리한다 4. EDA — 시각화로 변수 간 관계를 탐색하여 중요한 변수를 찾는다

    Step 1: 데이터 다운로드 및 로드 📥¶

    이번 프로젝트에서는 Kaggle의 Cardiovascular Disease Dataset을 사용합니다. 코랩에서 직접 다운로드하겠습니다.

    # === Step 1: 데이터 다운로드 및 로드 ===

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import warnings
warnings.filterwarnings('ignore')

# 이 데이터는 세미콜론(;)으로 구분되어 있습니다!

# 기본 정보 확인
print("=" * 50)

print("=" * 50)

print(f"📊 변수 수: {df.shape[1]}개")

    # 3-3) 의학적으로 합리적인 범위 설정 후 이상치 제거
print("🧹 이상치 제거 전 데이터 수:", len(df))

# 의학적으로 합리적인 혈압 범위
# 수축기: 60 ~ 250 mmHg
# 이완기: 40 ~ 150 mmHg
df_clean = df[
    (df['ap_hi'] >= 60) & (df['ap_hi'] <= 250) &
    (df['ap_lo'] >= 40) & (df['ap_lo'] <= 150)
].copy()

print("🧹 혈압 이상치 제거 후:", len(df_clean))
print(f"   제거된 데이터: {len(df) - len(df_clean):,}건 ({(len(df) - len(df_clean))/len(df)*100:.1f}%)")

    🧹 이상치 제거 전 데이터 수: 70000

   제거된 데이터: 5,411건 (7.7%)

    # 3-4) 추가 이상치 확인: 수축기 < 이완기인 경우
# 수축기 혈압은 항상 이완기 혈압보다 높아야 합니다!
abnormal_bp = df_clean[df_clean['ap_hi'] < df_clean['ap_lo']]
print(f"\n⚠️ 수축기 < 이완기인 경우: {len(abnormal_bp)}건")

# 제거
df_clean = df_clean[df_clean['ap_hi'] >= df_clean['ap_lo']].copy()
print(f"✅ 최종 정리 후 데이터 수: {len(df_clean):,}건")

    # 3-5) 키와 몸무게 이상치도 확인
print("🔍 키/몸무게 이상치 확인:")
print(f"   키 — 최소: {df_clean['height'].min()}cm, 최대: {df_clean['height'].max()}cm")
print(f"   몸무게 — 최소: {df_clean['weight'].min()}kg, 최대: {df_clean['weight'].max()}kg")

# 극단적인 키/몸무게 제거 (키: 100~220cm, 몸무게: 30~200kg)
before = len(df_clean)
df_clean = df_clean[
    (df_clean['height'] >= 100) & (df_clean['height'] <= 220) &
    (df_clean['weight'] >= 30) & (df_clean['weight'] <= 200)
].copy()

print(f"   키/몸무게 이상치 제거: {before - len(df_clean)}건")
print(f"✅ 최종 데이터 수: {len(df_clean):,}건")

    정리하기 📌

    이상치 처리에서 중요한 것은 도메인 지식(해당 분야의 전문 지식)입니다. - 혈압의 정상 범위를 알아야 비정상 값을 걸러낼 수 있습니다 - 수축기가 이완기보다 항상 높다는 의학 상식도 활용했습니다 - 무작정 통계적 방법(예: IQR)만 쓰는 것보다, 분야 지식 + 통계적 방법을 함께 쓰는 것이 좋습니다

    # === Step 4: 변수 변환 및 새 변수 생성 ===

# 4-1) BMI(체질량지수) 계산
# BMI = 몸무게(kg) / 키(m)²
df_clean['bmi'] = df_clean['weight'] / ((df_clean['height'] / 100) ** 2)

print("📊 BMI 통계:")
print(f"   평균: {df_clean['bmi'].mean():.1f}")
print(f"   최소: {df_clean['bmi'].min():.1f}")
print(f"   최대: {df_clean['bmi'].max():.1f}")

    📊 BMI 통계:
   평균: 26.8
   최소: 11.2
   최대: 56.2

    알아보기 📖

    BMI(Body Mass Index, 체질량지수)는 비만도를 나타내는 지표입니다. - 18.5 미만: 저체중 - 18.5 ~ 24.9: 정상 - 25.0 ~ 29.9: 과체중 - 30.0 이상: 비만

    키와 몸무게를 따로 사용하는 것보다, BMI라는 하나의 종합 지표로 만들면 모델 성능이 좋아질 수 있습니다.

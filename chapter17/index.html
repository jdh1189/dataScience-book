    Chapter 17. 자유 주제 최종 프로젝트 설계 및 데이터 수집¶

    Part 4 | [2권] 데이터 과학 프로젝트 · 17차시

    🎯 이 장에서 배우는 것¶

    • 스스로 데이터 과학 프로젝트 주제를 선정하고 문제를 정의할 수 있다
    • 주제 선정 기준(관심도·데이터 확보 가능성·분석 가능성)으로 아이디어를 검증할 수 있다
    • 주제에 적합한 데이터를 탐색·수집·전처리하는 계획을 수립할 수 있다
    • 프로젝트 계획서를 작성하고 동료 피드백을 반영하여 개선할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 주어진 데이터를 분석하는 연습을 해왔습니다. 날씨, 영화, 주가 등 이미 누군가가 준비해 둔 데이터셋으로 기술을 익혔죠.

    하지만 진짜 데이터 과학자는 "스스로 질문을 만들고, 데이터를 찾고, 답을 구합니다."

    이것은 마치 요리를 배우는 과정과 비슷합니다. 📖

    • 지금까지: 레시피북 그대로 따라 요리하기 (따라하기 실습)
    • 이번 장: 냉장고를 열어 "오늘 뭘 만들까?" 스스로 결정하기 (자유 프로젝트)

    이번 장에서는 여러분만의 궁금증을 데이터 과학 프로젝트로 바꾸는 전 과정을 경험합니다. 이 경험이야말로 포트폴리오의 핵심이 되고, 다음 장(18차시)의 발표와 회고로 이어지는 출발점입니다.

    생각해보기 🤔

    "내가 데이터로 해결하고 싶은 궁금증은 무엇인가?"

    10초만 멈추고 떠올려 보세요. 게임 승률? 우리 동네 미세먼지? 유튜브 조회수의 비밀? 급식 메뉴와 잔반량의 관계? 무엇이든 좋습니다.

    📚 핵심 개념¶

    개념 1: 문제 정의 — "좋은 질문이 좋은 분석을 만든다"¶

    1. 비유로 시작

    의사가 환자를 치료할 때, 가장 먼저 하는 일은 "어디가 아프세요?"라고 질문을 명확히 하는 것입니다. "그냥 어딘가 안 좋아요"로는 치료를 시작할 수 없죠. 데이터 과학도 마찬가지입니다.

    2. 정확한 정의

    문제 정의(Problem Definition) 란, 데이터로 답하고 싶은 질문을 구체적이고 측정 가능한 형태로 서술하는 것입니다.

    3. 예시로 확인

    • ❌ 나쁜 질문: "유튜브는 왜 인기 있을까?"
    • ✅ 좋은 질문: "유튜브 인기 동영상의 제목 글자 수와 조회수 사이에 상관관계가 있는가?"

    알아보기 📌

    좋은 문제 정의의 3요소 - 구체적: 분석 대상과 범위가 명확하다 - 측정 가능: 숫자나 범주로 비교할 수 있다 - 답변 가능: 확보할 수 있는 데이터로 실제로 검증할 수 있다

    개념 2: 주제 선정 기준 — "삼각 체크리스트"¶

    1. 비유로 시작

    여행지를 고를 때 "가고 싶은 곳", "예산 범위", "일정에 맞는 곳" 세 가지를 동시에 따지죠? 프로젝트 주제도 세 가지 축으로 검증해야 합니다.

    2. 정확한 정의

    graph TD A["🔺 주제 선정 삼각 체크리스트"] B["❤️ 관심도<br/>내가 정말 궁금한가?"] C["📦 데이터 확보 가능성<br/>데이터를 구할 수 있는가?"] D["🔍 분석 가능성<br/>배운 기술로 분석할 수 있는가?"] A --> B A --> C A --> D
    • 관심도: 흥미가 없으면 프로젝트 중간에 지칩니다
    • 데이터 확보 가능성: 공개 데이터가 존재하거나, 직접 수집할 수 있어야 합니다
    • 분석 가능성: 지금까지 배운 도구(pandas, matplotlib, 기초 통계 등)로 다룰 수 있어야 합니다

    3. 예시로 확인

    아이디어: "우리 학교 학생들의 수면 시간과 성적의 관계"

    • ❤️ 관심도: 매우 높음 (나도 궁금하다!)
    • 📦 데이터 확보: 설문조사로 수집 가능, 단 개인정보 주의 필요
    • 🔍 분석 가능성: 산점도 + 상관분석으로 충분

    → 삼각 체크 통과! ✅

    개념 3: 프로젝트 계획서 — "지도 없이 여행하지 않는다"¶

    1. 비유로 시작

    건축가가 건물을 짓기 전에 설계도(blueprint) 를 그리듯, 데이터 과학 프로젝트도 시작 전에 계획서를 작성합니다. 계획서는 프로젝트의 설계도입니다.

    2. 정확한 정의

    프로젝트 계획서는 다음 항목을 포함하는 문서입니다:

    • 프로젝트 제목: 한 문장으로 핵심을 담은 제목
    • 문제 정의: 구체적인 연구 질문
    • 가설: 예상하는 답(결과)
    • 데이터 출처: 어디서, 어떻게 구할 것인가
    • 분석 방법: 어떤 도구와 기법을 사용할 것인가
    • 일정: 마감까지의 단계별 타임라인

    3. 예시로 확인

    제목: 서울시 구별 공원 면적과 미세먼지 농도의 관계 분석
문제 정의: 공원 면적이 넓은 구는 미세먼지 농도가 낮은가?
가설: 공원 면적이 넓을수록 연평균 미세먼지 농도가 낮을 것이다
데이터 출처: 서울 열린데이터광장 (공원 현황, 대기질 측정)
분석 방법: pandas 전처리, 산점도, 상관계수 계산
일정: 1일차 데이터 수집 → 2일차 전처리 → 3일차 분석·시각화 → 4일차 정리·발표 준비

    개념 4: 데이터 수집과 1차 전처리 — "원석을 다듬는 첫 단계"¶

    1. 비유로 시작

    광산에서 캔 원석은 바로 보석이 되지 않습니다. 흙을 털어내고, 모양을 다듬어야 빛나는 보석이 되죠. 수집한 원본(raw) 데이터도 바로 분석에 쓸 수 없습니다. 1차 전처리가 필요합니다.

    2. 정확한 정의

    데이터 수집은 프로젝트 질문에 답하기 위해 필요한 데이터를 확보하는 과정이고, 1차 전처리는 수집한 데이터에서 분석에 불필요한 부분을 제거하고 기본 형태를 갖추는 작업입니다.

    3. 예시로 확인

    1차 전처리에서 흔히 하는 작업:

    • 필요 없는 열(column) 삭제
    • 결측치(비어있는 값) 확인
    • 데이터 타입 변환 (문자열 → 숫자)
    • 인코딩 문제 해결 (한글 깨짐)

    🔨 따라하기¶

    이 실습에서는 "서울시 구별 공원 면적과 미세먼지 농도의 관계" 를 예시 프로젝트로 삼아, 주제 선정부터 데이터 수집·1차 전처리까지 전 과정을 진행합니다. 여러분은 이 흐름을 참고해 자신의 주제로 동일한 과정을 수행하세요.

    Step 1: 브레인스토밍 — 아이디어 쏟아내기 🧠¶

    종이(또는 코드 셀)에 최소 5개 아이디어를 자유롭게 적어봅니다. 형식이나 완성도는 신경 쓰지 마세요.

    # 브레인스토밍 아이디어 목록
ideas = [
    "서울시 구별 공원 면적과 미세먼지 관계",
    "유튜브 썸네일 밝기와 조회수 관계",
    "프로야구 팀별 연봉 총액과 승률 관계",
    "카페 리뷰 키워드와 별점 관계",
    "수면 시간과 시험 성적 관계",
]

print("=== 나의 아이디어 목록 ===")
for i, idea in enumerate(ideas, 1):
    print(f"  {i}. {idea}")

    생각해보기 🤔

    아이디어가 떠오르지 않나요? 이런 질문을 던져보세요: - 내가 매일 접하는 것 중 숫자로 바꿀 수 있는 것은? - 최근 뉴스에서 "정말?" 하고 의심한 주장은? - 친구와 논쟁한 적 있는 주제는?

    Step 2: 삼각 체크리스트로 주제 검증 ✅¶

    각 아이디어를 점수로 평가합니다 (1~5점).

    import pandas as pd

# 아이디어 평가
evaluation = {
    "아이디어": ideas,
    "관심도": [5, 4, 5, 3, 4],
    "데이터확보": [5, 3, 4, 2, 3],
    "분석가능성": [5, 3, 4, 3, 4],
}

df_eval = pd.DataFrame(evaluation)
df_eval["총점"] = df_eval["관심도"] + df_eval["데이터확보"] + df_eval["분석가능성"]
df_eval = df_eval.sort_values("총점", ascending=False)

print("=== 주제 평가 결과 (총점 순) ===")
for _, row in df_eval.iterrows():
    print(f"  [{row['총점']}점] {row['아이디어']}")
    print(f"         관심도:{row['관심도']} | 데이터확보:{row['데이터확보']} | 분석가능성:{row['분석가능성']}")

    === 주제 평가 결과 (총점 순) ===
  [15점] 서울시 구별 공원 면적과 미세먼지 관계
         관심도:5 | 데이터확보:5 | 분석가능성:5
  [13점] 프로야구 팀별 연봉 총액과 승률 관계
         관심도:5 | 데이터확보:4 | 분석가능성:4
  [11점] 수면 시간과 시험 성적 관계
         관심도:4 | 데이터확보:3 | 분석가능성:4
  [10점] 유튜브 썸네일 밝기와 조회수 관계
         관심도:4 | 데이터확보:3 | 분석가능성:3
  [8점] 카페 리뷰 키워드와 별점 관계
         관심도:3 | 데이터확보:2 | 분석가능성:3

    → 총점이 가장 높은 주제를 선택합니다.

    Step 3: 프로젝트 계획서 작성 📋¶

    Chapter 8: 동일한 데이터의 다양한 분석 및 비교¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 하나의 데이터셋을 막대·원·선·산점도 등 다양한 차트로 표현할 수 있다
    • 분석 목적에 따라 적절한 시각화 방법을 선택하고 그 이유를 설명할 수 있다
    • 동일 데이터에 대해 서로 다른 관점의 분석 결과를 비교·해석할 수 있다
    • 그래프가 전달하는 메시지의 차이를 읽어내는 미디어 리터러시를 갖출 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    여러분의 중간고사 평균 점수가 75점이라고 합시다. - 막대그래프로 과목별 점수를 보면 → "수학이 좀 낮네, 영어는 잘했어!" - 원그래프로 과목별 비중을 보면 → "전체에서 수학이 차지하는 비율은 생각보다 작네?" - 선그래프로 시험별 추이를 보면 → "점점 오르고 있어!"

    같은 데이터인데, 어떤 그래프로 보느냐에 따라 받는 인상이 완전히 다릅니다.

    뉴스에서 "올해 경제 성장률"을 보도할 때, 어떤 방송은 막대그래프로 "급격히 떨어졌다"고 보여주고, 다른 방송은 선그래프로 "완만하게 회복 중"이라고 보여줍니다. 둘 다 같은 숫자를 사용했는데 말입니다.

    데이터를 읽는 힘은 단순히 숫자를 아는 것이 아니라, 같은 데이터를 여러 각도로 바라보고, 어떤 시각화가 어떤 이야기를 하는지 구별하는 것입니다. 이번 장에서는 하나의 데이터셋을 가지고 다양한 차트를 직접 그려보면서 이 능력을 키워보겠습니다.

    📚 핵심 개념¶

    개념 1: 시각화의 목적 — "질문이 다르면 그래프도 달라진다"¶

    🎭 비유로 시작

    같은 사과를 카메라로 찍는다고 상상해봅시다. - 위에서 찍으면 → 동그란 원 모양 - 옆에서 찍으면 → 꼭지가 보이는 모양 - 잘라서 찍으면 → 씨앗이 보이는 단면

    사과는 하나인데, 찍는 각도에 따라 보이는 정보가 다릅니다. 데이터 시각화도 마찬가지입니다.

    📖 정확한 정의

    시각화의 목적이란, "이 데이터로 어떤 질문에 답하고 싶은가?"를 뜻합니다. 질문이 달라지면, 그에 맞는 차트 유형도 달라집니다.

    ✅ 예시로 확인

    서울의 월별 평균 기온 데이터가 있다고 합시다.

    • "월별 기온이 어떻게 변하나요?" → 선 그래프 (시간에 따른 변화)
    • "어떤 달이 가장 더운가요?" → 막대 그래프 (크기 비교)
    • "기온의 전체 분포는?" → 히스토그램 (분포 확인)
    • "여름과 겨울의 기온 차이는?" → 박스플롯 (범위·중앙값 비교)

    📌 알아보기

    시각화를 시작하기 전에 항상 "나는 무엇을 알고 싶은가?"를 먼저 적어보세요. 이 질문이 차트 선택의 나침반이 됩니다.

    개념 2: 차트 유형별 특성 — "각 그래프의 전문 분야"¶

    🎭 비유로 시작

    운동 선수마다 잘하는 종목이 다르듯, 그래프에도 각자 잘 표현하는 영역이 있습니다.

    📖 정확한 정의와 특성

    graph LR A[데이터 시각화] --> B[📊 막대 그래프] A --> C[📈 선 그래프] A --> D[🥧 원 그래프] A --> E[📉 히스토그램] A --> F[📦 박스플롯] A --> G[🔵 산점도] B --> B1["카테고리별 크기 비교"] C --> C1["시간에 따른 변화 추이"] D --> D1["전체 대비 비율/구성"] E --> E1["데이터의 분포 형태"] F --> F1["중앙값·사분위수·이상치"] G --> G1["두 변수 간 관계"]

    각 차트가 잘하는 것과 못하는 것을 정리하면 이렇습니다.

    • 📊 막대 그래프: 카테고리 간 크기 비교에 최적. 하지만 시간 흐름을 보여주기엔 부적합
    • 📈 선 그래프: 시간에 따른 변화(추이)를 보여주는 데 최적. 카테고리 비교엔 어색함
    • 🥧 원 그래프: 전체 대비 각 부분의 비율을 직관적으로 표현. 항목이 6개 이상이면 읽기 어려움
    • 📉 히스토그램: 연속형 데이터의 분포(어디에 많이 몰려 있는지)를 파악. 구간 설정에 따라 모양이 달라짐
    • 📦 박스플롯: 중앙값, 범위, 이상치를 한눈에. 세부 분포 형태는 알기 어려움
    • 🔵 산점도: 두 변수 사이의 관계(상관관계)를 발견. 시간 흐름 표현엔 부적합

    ✅ 예시로 확인

    "우리 반 30명의 키 데이터"를 생각해봅시다.

    • "남녀 평균 키 비교" → 막대 그래프
    • "전체 키의 분포" → 히스토그램
    • "키와 몸무게의 관계" → 산점도
    • "반 전체에서 170cm 이상의 비율" → 원 그래프

    개념 3: 같은 데이터, 다른 메시지 — "프레이밍 효과"¶

    🎭 비유로 시작

    액자(frame)를 바꾸면 같은 그림도 다른 느낌을 줍니다. 고급 금색 액자에 넣으면 격조 있어 보이고, 알록달록한 액자에 넣으면 활기차 보이죠. 데이터도 어떤 "틀(frame)"로 보여주느냐에 따라 메시지가 달라집니다. 이것을 프레이밍 효과라고 합니다.

    📖 정확한 정의

    프레이밍 효과(Framing Effect): 동일한 정보라도 표현 방식이나 강조점에 따라 수용자의 판단이나 해석이 달라지는 현상

    ✅ 예시로 확인

    어떤 도시의 연간 범죄 건수가 다음과 같다고 합시다.

    • 2020년: 1,000건
    • 2021년: 1,050건
    • 2022년: 1,080건
    • 2023년: 1,100건

    해석 A (Y축을 0부터 시작하는 막대그래프): "범죄가 거의 비슷한 수준을 유지하고 있다"

    해석 B (Y축을 990부터 시작하는 선그래프): "범죄가 급격히 증가하고 있다!"

    둘 다 거짓말은 아닙니다. 하지만 전달하는 느낌은 극적으로 다릅니다.

    🧠 생각해보기

    뉴스나 광고에서 그래프를 볼 때, Y축이 0부터 시작하는지 꼭 확인하세요. Y축의 시작점을 바꾸는 것은 그래프를 왜곡하는 가장 흔한 방법 중 하나입니다.

    개념 4: 분석 관점의 비교 — "데이터에게 다른 질문하기"¶

    🎭 비유로 시작

    의사, 영양사, 운동 코치가 같은 건강검진 결과를 보더라도 주목하는 포인트가 다릅니다. - 의사: "혈압이 높네요" - 영양사: "나트륨 섭취를 줄여야겠어요" - 운동 코치: "유산소 운동을 시작하세요"

    데이터 분석도 마찬가지입니다. 어떤 관점에서 보느냐에 따라 같은 데이터에서 다른 인사이트가 나옵니다.

    📖 정확한 정의

    분석 관점(Analytical Perspective): 데이터를 바라보는 목적이나 초점. 같은 데이터라도 비교, 추이, 분포, 관계 등 다른 관점으로 분석하면 서로 다른 결론을 도출할 수 있습니다.

    graph TD D["🗂️ 하나의 데이터셋<br>(서울시 월별 날씨)"] --> P1["👀 관점 1: 비교<br>'어느 달이 가장 더운가?'<br>→ 막대 그래프"] D --> P2["👀 관점 2: 추이<br>'기온은 어떻게 변하는가?'<br>→ 선 그래프"] D --> P3["👀 관점 3: 분포<br>'기온이 어디에 몰려있는가?'<br>→ 히스토그램"] D --> P4["👀 관점 4: 관계<br>'기온과 습도는 관련있는가?'<br>→ 산점도"]

    ✅ 예시로 확인

    이번 장에서는 서울시 월별 날씨 데이터를 사용하여, 위 네 가지 관점을 모두 실습해 볼 것입니다.

    🔨 따라하기¶

    준비: 데이터와 라이브러리 세팅¶

    먼저 실습에 사용할 데이터를 만들고 필요한 라이브러리를 불러옵니다. 실제 서울시 기상 데이터를 기반으로 한 예시 데이터입니다.

    # 필요한 라이브러리 불러오기
import matplotlib.pyplot as plt
import matplotlib
import numpy as np

# 한글 폰트 설정 (운영체제에 따라 선택)
# Windows: 'Malgun Gothic', Mac: 'AppleGothic', Linux: 'NanumGothic'
matplotlib.rcParams['font.family'] = 'Malgun Gothic'
matplotlib.rcParams['axes.unicode_minus'] = False  # 마이너스 기호 깨짐 방지

# 서울시 월별 날씨 데이터 (2023년 기준 예시)
months = ['1월', '2월', '3월', '4월', '5월', '6월',
          '7월', '8월', '9월', '10월', '11월', '12월']

avg_temp = [-2.5, 0.3, 6.8, 13.2, 18.5, 23.1,
            25.8, 26.1, 21.4, 14.7, 7.2, -0.5]      # 평균 기온(°C)

humidity = [52, 50, 48, 49, 58, 68,
            78, 76, 65, 55, 54, 51]                     # 평균 습도(%)

rainfall = [18, 25, 47, 65, 105, 133,
            395, 348, 138, 49, 53, 22]                  # 강수량(mm)

print("✅ 데이터 준비 완료!")
print(f"월 수: {len(months)}개")
print(f"기온 범위: {min(avg_temp)}°C ~ {max(avg_temp)}°C")
print(f"강수량 범위: {min(rainfall)}mm ~ {max(rainfall)}mm")

    📌 알아보기: 왜 직접 데이터를 만드나요?

    실습에서는 데이터를 직접 리스트로 만들어 사용합니다. 이렇게 하면 파일 경로 문제 없이 누구나 바로 실행할 수 있고, 데이터 구조를 명확히 이해할 수 있습니다. 나중에 실제 CSV 파일을 불러와 같은 분석을 적용해볼 수 있습니다.

    Step 1: 막대 그래프 — "어느 달이 비가 가장 많이 왔을까?"¶

    막대 그래프는 카테고리별 크기를 한눈에 비교할 때 사용합니다. 각 월의 강수량을 비교해봅시다.

    # 막대 그래프: 월별 강수량 비교
plt.figure(figsize=(10, 5))

# 색상: 100mm 이상은 파란색 강조, 미만은 하늘색
colors = ['#3498db' if r >= 100 else '#85c1e9' for r in rainfall]

plt.bar(months, rainfall, color=colors, edgecolor='white', linewidth=0.5)

plt.title('서울시 월별 강수량 (2023년)', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('강수량 (mm)', fontsize=12)

# 막대 위에 수치 표시
for i, val in enumerate(rainfall):
    plt.text(i, val + 10, f'{val}', ha='center', fontsize=9)

plt.tight_layout()
plt.show()

    이 그래프가 말해주는 것: - 7월과 8월의 강수량이 압도적으로 많다 → 장마·태풍 시즌 - 1~2월, 12월은 강수량이 매우 적다 → 건조한 겨울 - 각 달을 "개별적으로" 비교하기에 좋다

    Step 2: 선 그래프 — "기온은 어떤 패턴으로 변할까?"¶

    선 그래프는 시간의 흐름에 따른 변화(추이, trend)를 보여줄 때 최적입니다.

    # 선 그래프: 월별 평균 기온 변화
plt.figure(figsize=(10, 5))

plt.plot(months, avg_temp, 
         marker='o',           # 각 데이터 포인트에 동그라미
         color='#e74c3c',      # 빨간색 선
         linewidth=2,          # 선 두께
         markersize=8,         # 점 크기
         markerfacecolor='white',  # 점 안쪽 흰색
         markeredgewidth=2)        # 점 테두리 두께

# 0도 기준선 추가
plt.axhline(y=0, color='gray', linestyle='--', linewidth=0.8, alpha=0.7)

plt.title('서울시 월별 평균 기온 변화 (2023년)', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('평균 기온 (°C)', fontsize=12)
plt.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()

    이 그래프가 말해주는 것: - 기온이 매끄러운 곡선을 그리며 올라갔다 내려온다 → 계절의 순환 - 7~8월이 정점, 1월·12월이 최저 → 뚜렷한 사계절 - 막대 그래프에서는 보기 어려웠던 연속적인 변화 패턴이 선명하게 보인다

    🧠 생각해보기

    같은 기온 데이터를 막대 그래프로 그리면 어떤 느낌일까요? "비교"의 느낌이 강해지고, "변화"의 느낌은 약해집니다. 직접 plt.bar(months, avg_temp)로 그려서 비교해보세요!

    Step 3: 원 그래프 — "연간 강수량에서 각 계절의 비중은?"¶

    원 그래프는 전체에서 각 부분이 차지하는 비율을 보여줍니다. 여기서는 계절별 강수량 비중을 표현합니다.

    # 계절별로 데이터 묶기
spring = sum(rainfall[2:5])    # 3~5월
summer = sum(rainfall[5:8])    # 6~8월
autumn = sum(rainfall[8:11])   # 9~11월
winter = sum(rainfall[0:2]) + rainfall[11]  # 12~2월

seasons = ['봄 (3~5월)', '여름 (6~8월)', '가을 (9~11월)', '겨울 (12~2월)']
season_rain = [spring, summer, autumn, winter]
season_colors = ['#2ecc71', '#e74c3c', '#f39c12', '#3498db']

# 원 그래프
plt.figure(figsize=(8, 8))

wedges, texts, autotexts = plt.pie(
    season_rain,
    labels=seasons,
    colors=season_colors,
    autopct='%1.1f%%',          # 퍼센트 표시
    startangle=90,               # 12시 방향부터 시작
    explode=(0, 0.08, 0, 0),    # 여름을 살짝 분리
    textprops={'fontsize': 12}
)

# 퍼센트 글씨 굵게
for autotext in autotexts:
    autotext.set_fontweight('bold')

plt.title('계절별 강수량 비중', fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

# 구체적 수치도 출력
total = sum(season_rain)
print(f"\n📊 계절별 강수량:")
for s, r in zip(seasons, season_rain):
    print(f"  {s}: {r}mm ({r/total*100:.1f}%)")

    이 그래프가 말해주는 것: - 여름이 연간 강수량의 대부분(약 60% 이상)을 차지한다 - 겨울은 강수량 비중이 매우 작다 - 전체 대비 비율이 직관적으로 보인다

    ⚠️ 주의!

    원 그래프는 항목이 4~5개 이하일 때 효과적입니다. 12개 월을 모두 원 그래프로 표현하면 조각이 너무 많아 읽기 어려워집니다. 그래서 위 예시에서는 4계절로 묶어서 표현했습니다.

    Step 4: 히스토그램과 박스플롯 — "기온의 분포는 어떤 형태일까?"¶

    히스토그램과 박스플롯은 데이터가 어떻게 퍼져 있는지(분포)를 보여줍니다.

    # 히스토그램과 박스플롯을 나란히 그리기
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))

# --- 왼쪽: 히스토그램 ---
ax1.hist(avg_temp, bins=6, color='#9b59b6', edgecolor='white', linewidth=1.5, alpha=0.8)
ax1.set_title('월별 평균 기온의 분포', fontsize=14, fontweight='bold')
ax1.set_xlabel('기온 (°C)', fontsize=11)
ax1.set_ylabel('해당 구간의 월 수', fontsize=11)
ax1.axvline(x=np.mean(avg_temp), color='red', linestyle='--', linewidth=1.5, label=f'평균: {np.mean(avg_temp):.1f}°C')
ax1.legend(fontsize=10)

# --- 오른쪽: 박스플롯 ---
bp = ax2.boxplot(avg_temp, vert=True, patch_artist=True,
                  boxprops=dict(facecolor='#85c1e9', color='#2c3e50'),
                  medianprops=dict(color='#e74c3c', linewidth=2),
                  whiskerprops=dict(color='#2c3e50'),
                  capprops=dict(color='#2c3e50'))

ax2.set_title('월별 평균 기온의 박스플롯', fontsize=14, fontweight='bold')
ax2.set_ylabel('기온 (°C)', fontsize=11)
ax2.set_xticklabels(['서울 2023'])

# 주요 통계량 텍스트로 표시
median_val = np.median(avg_temp)
q1 = np.percentile(avg_temp, 25)
q3 = np.percentile(avg_temp, 75)
ax2.text(1.3, median_val, f'중앙값: {median_val}°C', fontsize=10, color='#e74c3c')
ax2.text(1.3, q1, f'Q1: {q1}°C', fontsize=9, color='gray')
ax2.text(1.3, q3, f'Q3: {q3}°C', fontsize=9, color='gray')

plt.tight_layout()
plt.show()

    히스토그램이 말해주는 것: - 기온 데이터가 어느 구간에 몰려 있는지 보여준다 - 낮은 기온(겨울)과 높은 기온(여름)에 데이터가 나뉘어 있는 두 봉우리 형태가 보일 수 있다

    박스플롯이 말해주는 것: - 중앙값(빨간 선): 서울 기온의 "대표값" - 상자 범위(Q1~Q3): 전체 데이터의 가운데 50%가 이 범위 안에 있다 - 수염(위아래 선): 데이터의 전체 범위

    Step 5: 산점도 — "기온과 습도는 관계가 있을까?"¶

    산점도는 두 변수 사이에 관계(상관관계)가 있는지 탐색할 때 사용합니다.

    # 산점도: 기온 vs 습도
plt.figure(figsize=(8, 6))

# 점의 크기를 강수량에 비례하도록 설정 (시각적 정보 추가)
sizes = [r / 3 for r in rainfall]  # 강수량을 적절한 크기로 변환

scatter = plt.scatter(avg_temp, humidity, 
                       s=sizes,              # 점 크기 = 강수량 비례
                       c=avg_temp,           # 점 색상 = 기온 비례
                       cmap='RdYlBu_r',     # 파랑(차가움)~빨강(더움)
                       edgecolors='black', 
                       linewidth=0.5,
                       alpha=0.8)

# 각 점에 월 이름 표시
for i, month in enumerate(months):
    plt.annotate(month, (avg_temp[i], humidity[i]), 
                 textcoords="offset points", xytext=(8, 5), fontsize=9)

plt.colorbar(scatter, label='기온 (°C)')
plt.title('기온과 습도의 관계', fontsize=16, fontweight='bold')
plt.xlabel('평균 기온 (°C)', fontsize=12)
plt.ylabel('평균 습도 (%)', fontsize=12)
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

    이 그래프가 말해주는 것: - 기온이 높은 달(여름)일수록 습도도 높은 양의 상관관계가 보인다 - 점의 크기(강수량)도 여름에 크다 → 기온·습도·강수량이 함께 높아진다 - 두 변수의 관계를 한눈에 파악할 수 있다 — 이것은 막대 그래프나 선 그래프로는 보기 어렵다

    Step 6: 한 화면에 모아보기 — "다양한 관점, 하나의 데이터"¶

    지금까지 만든 5가지 차트를 한 화면에 배치하면, 같은 데이터가 얼마나 다양한 이야기를 할 수 있는지 한눈에 볼 수 있습니다.

    # 2x3 격자로 다양한 차트를 한 화면에 배치
fig, axes = plt.subplots(2, 3, figsize=(16, 10))
fig.suptitle('🔍 같은 서울 날씨 데이터, 6가지 시각화', fontsize=18, fontweight='bold', y=1.02)

# 1) 막대 그래프 - 강수량 비교
colors_bar = ['#3498db' if r >= 100 else '#85c1e9' for r in rainfall]
axes[0, 0].bar(months, rainfall, color=colors_bar, edgecolor='white')
axes[0, 0].set_title('① 막대: 월별 강수량', fontsize=12, fontweight='bold')
axes[0, 0].set_ylabel('강수량(mm)')
axes[0, 0].tick_params(axis='x', rotation=45)

# 2) 선 그래프 - 기온 추이
axes[0, 1].plot(months, avg_temp, 'o-', color='#e74c3c', linewidth=2, markersize=6)
axes[0, 1].axhline(y=0, color='gray', linestyle='--', linewidth=0.8)
axes[0, 1].set_title('② 선: 기온 변화 추이', fontsize=12, fontweight='bold')
axes[0, 1].set_ylabel('기온(°C)')
axes[0, 1].tick_params(axis='x', rotation=45)

# 3) 원 그래프 - 계절별 강수량 비중
spring = sum(rainfall[2:5])
summer = sum(rainfall[5:8])
autumn = sum(rainfall[8:11])
winter = sum(rainfall[0:2]) + rainfall[11]
axes[0, 2].pie([spring, summer, autumn, winter],
               labels=['봄', '여름', '가을', '겨울'],
               colors=['#2ecc71', '#e74c3c', '#f39c12', '#3498db'],
               autopct='%1.0f%%', startangle=90)
axes[0, 2].set_title('③ 원: 계절별 강수량 비중', fontsize=12, fontweight='bold')

# 4) 히스토그램 - 기온 분포
axes[1, 0].hist(avg_temp, bins=6, color='#9b59b6', edgecolor='white', alpha=0.8)
axes[1, 0].set_title('④ 히스토그램: 기온 분포', fontsize=12, fontweight='bold')
axes[1, 0].set_xlabel('기온(°C)')
axes[1, 0].set_ylabel('월 수')

# 5) 박스플롯 - 기온 요약
bp = axes[1, 1].boxplot(avg_temp, vert=True, patch_artist=True,
                         boxprops=dict(facecolor='#85c1e9'))
axes[1, 1].set_title('⑤ 박스플롯: 기온 요약', fontsize=12, fontweight='bold')
axes[1, 1].set_ylabel('기온(°C)')

# 6) 산점도 - 기온 vs 습도
axes[1, 2].scatter(avg_temp, humidity, c=avg_temp, cmap='RdYlBu_r',
                    s=80, edgecolors='black', linewidth=0.5)
axes[1, 2].set_title('⑥ 산점도: 기온 vs 습도', fontsize=12, fontweight='bold')
axes[1, 2].set_xlabel('기온(°C)')
axes[1, 2].set_ylabel('습도(%)')

plt.tight_layout()
plt.show()

    정리하기 📋

    하나의 서울 날씨 데이터로 6개의 차트를 만들었습니다. 각 차트가 전달하는 핵심 메시지를 정리합니다.

    • ① 막대: "7~8월 강수량이 압도적" (크기 비교)
    • ② 선: "기온이 여름에 정점을 찍고 내려온다" (시간 변화)
    • ③ 원: "여름이 연간 강수량의 60% 이상" (비율)
    • ④ 히스토그램: "기온이 0~5도, 20~25도 구간에 몰려있다" (분포)
    • ⑤ 박스플롯: "기온 중앙값은 약 10도, 범위는 -2.5~26도" (요약)
    • ⑥ 산점도: "기온이 높을수록 습도도 높다" (관계)

    📝 전체 코드¶

    아래는 이번 장의 모든 시각화를 하나의 파일에서 실행할 수 있는 전체 코드입니다.

    """
Chapter 8: 동일한 데이터의 다양한 분석 및 비교
서울시 월별 날씨 데이터를 6가지 차트로 시각화합니다.
"""

import matplotlib.pyplot as plt
import matplotlib
import numpy as np

# 한글 폰트 설정
matplotlib.rcParams['font.family'] = 'Malgun Gothic'  # Mac: 'AppleGothic'
matplotlib.rcParams['axes.unicode_minus'] = False

# ===== 데이터 준비 =====
months = ['1월', '2월', '3월', '4월', '5월', '6월',
          '7월', '8월', '9월', '10월', '11월', '12월']
avg_temp = [-2.5, 0.3, 6.8, 13.2, 18.5, 23.1, 25.8, 26.1, 21.4, 14.7, 7.2, -0.5]
humidity = [52, 50, 48, 49, 58, 68, 78, 76, 65, 55, 54, 51]
rainfall = [18, 25, 47, 65, 105, 133, 395, 348, 138, 49, 53, 22]

# ===== 6가지 차트를 한 화면에 =====
fig, axes = plt.subplots(2, 3, figsize=(16, 10))
fig.suptitle('같은 서울 날씨 데이터, 6가지 시각화', fontsize=18, fontweight='bold')

# ① 막대 그래프
colors_bar = ['#3498db' if r >= 100 else '#85c1e9' for r in rainfall]
axes[0, 0].bar(months, rainfall, color=colors_bar, edgecolor='white')
axes[0, 0].set_title('① 막대: 월별 강수량', fontweight='bold')
axes[0, 0].set_ylabel('강수량(mm)')
axes[0, 0].tick_params(axis='x', rotation=45)

# ② 선 그래프
axes[0, 1].plot(months, avg_temp, 'o-', color='#e74c3c', linewidth=2, markersize=6)
axes[0, 1].axhline(y=0, color='gray', linestyle='--', linewidth=0.8)
axes[0, 1].set_title('② 선: 기온 변화 추이', fontweight='bold')
axes[0, 1].set_ylabel('기온(°C)')
axes[0, 1].tick_params(axis='x', rotation=45)

# ③ 원 그래프
spring = sum(rainfall[2:5])
summer = sum(rainfall[5:8])
autumn = sum(rainfall[8:11])
winter = sum(rainfall[0:2]) + rainfall[11]
axes[0, 2].pie([spring, summer, autumn, winter],
               labels=['봄', '여름', '가을', '겨울'],
               colors=['#2ecc71', '#e74c3c', '#f39c12', '#3498db'],
               autopct='%1.0f%%', startangle=90)
axes[0, 2].set_title('③ 원: 계절별 강수량 비중', fontweight='bold')

# ④ 히스토그램
axes[1, 0].hist(avg_temp, bins=6, color='#9b59b6', edgecolor='white', alpha=0.8)
axes[1, 0].set_title('④ 히스토그램: 기온 분포', fontweight='bold')
axes[1, 0].set_xlabel('기온(°C)')
axes[1, 0].set_ylabel('월 수')

# ⑤ 박스플롯
axes[1, 1].boxplot(avg_temp, vert=True, patch_artist=True,
                    boxprops=dict(facecolor='#85c1e9'))
axes[1, 1].set_title('⑤ 박스플롯: 기온 요약', fontweight='bold')
axes[1, 1].set_ylabel('기온(°C)')

# ⑥ 산점도
axes[1, 2].scatter(avg_temp, humidity, c=avg_temp, cmap='RdYlBu_r',
                    s=80, edgecolors='black', linewidth=0.5)
axes[1, 2].set_title('⑥ 산점도: 기온 vs 습도', fontweight='bold')
axes[1, 2].set_xlabel('기온(°C)')
axes[1, 2].set_ylabel('습도(%)')

plt.tight_layout()
plt.show()

print("\n✅ 6가지 시각화 완료!")
print("같은 데이터인데, 각 차트가 전달하는 메시지가 어떻게 다른지 비교해보세요.")

    ⚠️ 자주 하는 실수¶

    실수 1: "모든 데이터에 원 그래프를 쓰려고 한다"¶

    # ❌ 잘못된 사용: 12개 월의 기온을 원 그래프로
plt.pie(avg_temp, labels=months)  # 조각이 너무 많고, 음수 값 포함!

    원 그래프는 비율(합계가 100%)을 표현합니다. 기온처럼 음수가 포함된 데이터나, 합계가 의미 없는 데이터에는 사용할 수 없습니다. 또한 항목이 6개 이상이면 읽기 어려워집니다.

    # ✅ 올바른 사용: 4개 계절로 묶어서, 강수량(합계가 의미있는 데이터)으로
plt.pie([spring, summer, autumn, winter], labels=['봄', '여름', '가을', '겨울'])

    실수 2: "Y축 범위를 무심코 설정해서 왜곡된 그래프를 만든다"¶

    # ❌ 오해를 부르는 그래프: Y축이 95부터 시작
scores = [96, 97, 98, 99, 100]
subjects = ['국어', '영어', '수학', '과학', '사회']

plt.bar(subjects, scores)
plt.ylim(95, 101)  # 작은 차이가 엄청나게 커 보임!
plt.title('과목별 점수')
plt.show()

    4점 차이(96→100)가 마치 몇 배 차이인 것처럼 보입니다.

    # ✅ 정직한 그래프: Y축을 0부터 시작
plt.bar(subjects, scores)
plt.ylim(0, 105)  # 0부터 시작하면 실제 비율대로 보임
plt.title('과목별 점수')
plt.show()

    📌 알아보기

    Y축을 0부터 시작하지 않는 것이 항상 나쁜 건 아닙니다. 미세한 변화를 강조해야 할 때는 의도적으로 범위를 조절하기도 합니다. 중요한 건 "왜 이 범위를 선택했는지"를 인식하는 것입니다.

    실수 3: "차트 제목과 축 레이블을 빠뜨린다"¶

    # ❌ 제목도 없고 축 레이블도 없는 그래프
plt.plot(avg_temp)
plt.show()  # 이게 뭔지 아무도 모른다!

    # ✅ 정보가 명확한 그래프
plt.plot(months, avg_temp, 'o-', color='#e74c3c')
plt.title('서울시 월별 평균 기온 (2023년)')  # 무엇의 데이터인지
plt.xlabel('월')                              # X축이 뭔지
plt.ylabel('평균 기온 (°C)')                   # Y축이 뭔지, 단위까지!
plt.show()

    그래프는 제목, X축 레이블, Y축 레이블, 단위가 반드시 있어야 합니다. 이것이 없으면 그래프는 "의미 없는 그림"이 됩니다.

    실수 4: "목적을 생각하지 않고 예쁜 차트만 선택한다"¶

    시간에 따른 변화를 보여줘야 하는데 "원 그래프가 예뻐서" 원 그래프를 쓰면, 데이터가 말하려는 이야기를 왜곡합니다.

    graph LR Q["내가 보여주고 싶은 것은?"] --> A["크기 비교 → 막대"] Q --> B["변화 추이 → 선"] Q --> C["비율 구성 → 원"] Q --> D["분포 형태 → 히스토그램"] Q --> E["두 변수 관계 → 산점도"]

    항상 "이 차트로 무엇을 전달하고 싶은가?"를 먼저 생각하세요.

    • (a) "우리 학교 학년별 학생 수를 비교하고 싶다" → ( )
    • (b) "한 학생의 1학년부터 3학년까지 성적 변화를 보고 싶다" → ( )
    • (c) "반 전체 수학 점수가 어디에 몰려 있는지 보고 싶다" → ( )
    • (d) "학교 예산에서 각 항목이 차지하는 비율을 보고 싶다" → ( )
    정답 확인 - (a) **막대 그래프** — 카테고리별 크기 비교 - (b) **선 그래프** — 시간에 따른 변화 추이 - (c) **히스토그램** — 연속형 데이터의 분포 - (d) **원 그래프** — 전체 대비 비율/구성

    응용 문제¶

    문제 2. 아래 코드의 문제점을 찾고 수정하세요.

    temps = [-3, 1, 7, 14, 19, 24, 27, 27, 22, 15, 8, 0]
plt.pie(temps, labels=['1월','2월','3월','4월','5월','6월',
                        '7월','8월','9월','10월','11월','12월'])

    정답 확인 **문제점:** - 기온 데이터에 **음수(-3)**가 포함되어 있어 원 그래프를 사용할 수 없습니다 - 기온은 **합계가 의미 없는 데이터**이므로 비율로 표현하는 것이 부적절합니다 - 12개 항목이라 조각이 너무 많습니다 **수정:** 선 그래프나 막대 그래프로 변경 
    months = ['1월','2월','3월','4월','5월','6월',
          '7월','8월','9월','10월','11월','12월']
plt.plot(months, temps, 'o-')
plt.title('월별 기온 변화')

    🏠 모둠 활동: "같은 데이터, 다른 이야기"¶

    활동 방법: 1. 4~5명이 한 모둠을 이룹니다 2. 모둠원 각자 같은 데이터를 서로 다른 차트 유형으로 시각화합니다 3. 각자 만든 그래프를 보여주며 "이 그래프가 전달하는 핵심 메시지"를 발표합니다 4. 모둠 토론: "어떤 질문에는 어떤 차트가 가장 효과적이었는가?"

    활동 데이터 (원하는 것 선택): - 우리 반 학생들의 취미별 인원수 - 일주일 간 급식 만족도 변화 - 교내 동아리별 회원 수

    🎯 도전 과제: "가장 오해를 부르는 그래프 vs 가장 정직한 그래프"¶

    아래 데이터를 사용해 의도적으로 오해를 부르는 그래프와 가장 정확하고 정직한 그래프를 각각 만들어보세요.

    # A 제품과 B 제품의 고객 만족도 (5점 만점)
products = ['A 제품', 'B 제품']
satisfaction = [4.2, 4.5]

    오해를 부르는 방법 힌트: Y축 범위 조절, 3D 효과, 색상 대비 강조 등

    이 활동의 목적은 "이런 방법으로 속일 수 있구나"를 알아야, 속지 않을 수 있다는 미디어 리터러시를 기르는 것입니다.

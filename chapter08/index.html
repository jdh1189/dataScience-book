    Chapter 08. 데이터 전처리 (2) — 데이터 변환과 정리¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 문자열을 숫자로, 날짜 형식으로 등 데이터 타입을 변환할 수 있다
    • 컬럼명 변경, 문자열 정리 등 데이터를 깔끔하게 정리할 수 있다
    • query, sort_values, groupby로 필터링·정렬·그룹화를 수행할 수 있다
    • 전처리 과정을 하나의 재현 가능한 파이프라인으로 구성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    스트리밍 차트 데이터에서 재생 수가 "1,234,567"처럼 콤마가 포함된 문자열이라면, 바로 평균을 구할 수 있을까요?

    정답은 "불가능" 입니다. 파이썬은 "1,234,567"을 숫자가 아닌 글자로 인식합니다. 마치 계산기에 숫자 대신 한글을 입력하는 것과 같습니다.

    현실의 데이터는 항상 지저분합니다.

    • 숫자인데 문자열로 저장된 경우
    • 날짜가 "2024-03-15", "03/15/2024", "2024년 3월 15일" 등 제각각인 경우
    • 컬럼명이 "아티스트 이름 " 처럼 공백이 포함된 경우

    7장에서 결측치와 이상치를 처리했다면, 이번 장에서는 데이터의 형태 자체를 바꾸고 정리하는 기술을 배웁니다. 요리에 비유하면, 7장이 상한 재료를 골라내는 작업이었다면, 8장은 재료를 씻고, 껍질을 벗기고, 먹기 좋게 썰어놓는 작업입니다.

    📚 핵심 개념¶

    개념 1: 데이터 타입 변환 🔄¶

    1. 비유로 시작

    외국 여행을 갔을 때 원화를 달러로 환전해야 쓸 수 있듯이, 데이터도 분석에 맞는 타입으로 변환(환전) 해야 제대로 활용할 수 있습니다.

    2. 정확한 정의

    데이터 타입 변환이란, 값의 자료형(문자열, 정수, 실수, 날짜 등)을 분석 목적에 맞게 바꾸는 작업입니다. pandas에서 자주 쓰는 변환 메서드는 다음과 같습니다.

    • astype() — 직접 타입을 지정하여 변환 (문자열→정수, 정수→실수 등)
    • pd.to_numeric() — 문자열을 숫자로 변환 (변환 불가능한 값 처리 옵션 포함)
    • pd.to_datetime() — 문자열을 날짜(datetime) 타입으로 변환

    3. 예시로 확인

    import pandas as pd

# 콤마가 포함된 재생 수 데이터
data = {"곡명": ["곡A", "곡B", "곡C"],
        "재생수": ["1,234,567", "987,654", "2,345,678"]}
df = pd.DataFrame(data)

print(df["재생수"].dtype)  # object (= 문자열)

# 콤마를 제거한 뒤 숫자로 변환
df["재생수"] = df["재생수"].str.replace(",", "").astype(int)

print(df["재생수"].dtype)  # int64
print(df["재생수"].mean())  # 1522633.0 ← 이제 계산 가능!

    알아보기 📌

    dtype이 object라면 대부분 문자열입니다. 숫자 계산을 하려면 반드시 int64나 float64로 변환해야 합니다.

    개념 2: 문자열 정리와 컬럼명 변경 🧹¶

    1. 비유로 시작

    도서관에서 책을 찾으려면 책 제목이 정확해야 합니다. " 해리포터 " 처럼 앞뒤에 공백이 있거나, "해리포터" 와 "해리 포터"가 섞여 있으면 같은 책인데도 다르게 인식됩니다. 데이터의 문자열도 마찬가지입니다.

    2. 정확한 정의

    문자열 정리란 불필요한 공백 제거, 대소문자 통일, 특정 문자 치환 등을 통해 일관된 형태로 만드는 작업입니다. pandas의 .str 접근자(accessor)를 통해 문자열 전용 메서드를 사용합니다.

    • .str.strip() — 앞뒤 공백 제거
    • .str.lower() / .str.upper() — 소문자/대문자 통일
    • .str.replace() — 특정 문자를 다른 문자로 치환
    • df.rename(columns={...}) — 컬럼명 변경
    • df.columns = [...] — 컬럼명 일괄 변경

    3. 예시로 확인

    data = {"아티스트 이름 ": ["  BTS ", "bts", " Bts"],
        "장르 ": ["팝", "팝 ", " 팝"]}
df = pd.DataFrame(data)

# 컬럼명 공백 제거 & 영문 변환
df.columns = df.columns.str.strip()
df = df.rename(columns={"아티스트 이름": "artist", "장르": "genre"})

# 값 정리: 공백 제거 + 소문자 통일
df["artist"] = df["artist"].str.strip().str.lower()
df["genre"] = df["genre"].str.strip()

print(df)

      artist genre
0    bts     팝
1    bts     팝
2    bts     팝

    세 행 모두 bts, 팝으로 통일되었습니다!

    개념 3: 필터링과 정렬 🔍¶

    1. 비유로 시작

    음악 앱에서 "2024년 발매, 재생 수 100만 이상" 조건으로 곡을 검색하고, 재생 수 높은 순으로 정렬하는 것과 같습니다.

    2. 정확한 정의

    • 필터링: 조건에 맞는 행만 골라내는 작업
    • 정렬: 특정 컬럼 기준으로 행의 순서를 바꾸는 작업
    flowchart LR A["전체 데이터\n(100행)"] -->|"조건 필터링\n재생수 > 100만"| B["필터링 결과\n(35행)"] B -->|"정렬\n재생수 내림차순"| C["최종 결과\n(35행, 정렬됨)"]

    3. 예시로 확인

    data = {"곡명": ["곡A", "곡B", "곡C", "곡D", "곡E"],
        "재생수": [1500000, 800000, 2300000, 500000, 1200000],
        "장르": ["팝", "힙합", "팝", "발라드", "힙합"]}
df = pd.DataFrame(data)

# 방법 1: 불리언 인덱싱
result1 = df[df["재생수"] >= 1000000]

# 방법 2: query() — 더 읽기 쉬운 방식
result2 = df.query("재생수 >= 1000000")

# 정렬: 재생수 기준 내림차순
result_sorted = result2.sort_values("재생수", ascending=False)
print(result_sorted)

      곡명      재생수  장르
2  곡C  2300000   팝
0  곡A  1500000   팝
4  곡E  1200000  힙합

    알아보기 📌

    query()는 조건을 문자열로 작성하므로 복잡한 조건에서도 가독성이 좋습니다. ascending=False는 내림차순(큰 수부터), True는 오름차순(작은 수부터)입니다.

    개념 4: 그룹화(groupby) 📊¶

    1. 비유로 시작

    학교 체육대회에서 반별로 점수를 합산하는 것과 같습니다. 전체 학생의 점수를 하나하나 보는 대신, "1반 합계", "2반 합계" 처럼 그룹으로 묶어서 요약하는 것이죠.

    2. 정확한 정의

    groupby()는 특정 컬럼의 값을 기준으로 데이터를 그룹으로 나누고, 각 그룹에 집계 함수(합계, 평균, 개수 등) 를 적용하는 메서드입니다.

    flowchart TD A["전체 데이터"] --> B["groupby('장르')"] B --> C["팝 그룹"] B --> D["힙합 그룹"] B --> E["발라드 그룹"] C --> F["평균: 1,900,000"] D --> G["평균: 1,000,000"] E --> H["평균: 500,000"]

    3. 예시로 확인

    # 장르별 평균 재생 수
genre_avg = df.groupby("장르")["재생수"].mean()
print(genre_avg)

    장르
발라드     500000.0
팝       1900000.0
힙합     1000000.0
Name: 재생수, dtype: float64

    여러 집계를 한 번에 보려면 agg()를 사용합니다.

    genre_stats = df.groupby("장르")["재생수"].agg(["mean", "sum", "count"])
print(genre_stats)

    🔨 따라하기: 음원 차트 데이터 전처리 파이프라인¶

    실제 분석과 유사한 음원 차트 데이터를 처음부터 끝까지 정리해봅시다.

    Step 1: 지저분한 원본 데이터 만들기¶

    import pandas as pd

# 현실적인 '지저분한' 데이터
raw_data = {
    " 곡명 ": ["Dynamite", "Butter ", " Super Shy", "Seven", "Hype Boy", "Ditto"],
    "아티스트": ["  BTS", "BTS ", "NewJeans", " 정국 ", " NewJeans", "NewJeans "],
    "재생수": ["1,500,000", "2,100,000", "980,000", "1,800,000", "1,200,000", "1,600,000"],
    "발매일": ["2020-08-21", "2021-05-21", "2023-07-07", "2023-07-14", "2022-08-01", "2022-12-19"],
    "장르 ": ["팝", "팝 ", " 팝", "팝", " 팝", " 팝"]
}
df = pd.DataFrame(raw_data)
print("=== 원본 데이터 ===")
print(df)
print("\n=== 데이터 타입 ===")
print(df.dtypes)

    생각해보기 🤔

    이 데이터에는 어떤 문제가 있을까요? 직접 찾아보세요! (힌트: 공백, 타입, 컬럼명)

    Step 2: 컬럼명 정리¶

    # 컬럼명 앞뒤 공백 제거
df.columns = df.columns.str.strip()

# 영문으로 통일 (분석 편의를 위해)
df = df.rename(columns={
    "곡명": "title",
    "아티스트": "artist",
    "재생수": "plays",
    "발매일": "release_date",
    "장르": "genre"
})

print(df.columns.tolist())
# ['title', 'artist', 'plays', 'release_date', 'genre']

    Step 3: 문자열 값 정리¶

    # 모든 문자열 컬럼의 앞뒤 공백 제거
for col in ["title", "artist", "genre"]:
    df[col] = df[col].str.strip()

print(df[["artist", "genre"]])

    이제 " BTS"와 "BTS "가 모두 "BTS"로 통일됩니다.

    Step 4: 데이터 타입 변환¶

    # 재생수: 콤마 제거 → 정수 변환
df["plays"] = df["plays"].str.replace(",", "").astype(int)

# 발매일: 날짜 타입 변환
df["release_date"] = pd.to_datetime(df["release_date"])

print(df.dtypes)

    title                    object
artist                   object
plays                     int64
release_date     datetime64[ns]
genre                    object
dtype: object

    plays가 int64, release_date가 datetime64로 바뀌었습니다!

    Step 5: 필터링과 정렬¶

    # 재생수 100만 이상인 곡만 필터링
popular = df.query("plays >= 1000000")

# 재생수 높은 순으로 정렬
popular_sorted = popular.sort_values("plays", ascending=False)
print(popular_sorted[["title", "artist", "plays"]])

          title  artist    plays
1    Butter     BTS  2100000
3     Seven      정국  1800000
5     Ditto  NewJeans  1600000
0  Dynamite     BTS  1500000
4  Hype Boy  NewJeans  1200000

    Step 6: 그룹화로 인사이트 도출¶

    # 아티스트별 평균 재생 수
artist_avg = df.groupby("artist")["plays"].mean()
print("=== 아티스트별 평균 재생수 ===")
print(artist_avg.sort_values(ascending=False))

# 연도별 발매 곡 수 (날짜 타입이라 .dt 접근자 사용 가능!)
df["year"] = df["release_date"].dt.year
year_count = df.groupby("year")["title"].count()
print("\n=== 연도별 발매 곡 수 ===")
print(year_count)

    알아보기 📌

    .dt는 datetime 타입 전용 접근자입니다. .dt.year(연도), .dt.month(월), .dt.day(일) 등을 추출할 수 있습니다. 이것이 날짜 타입으로 변환해야 하는 이유입니다!

    📝 전체 코드¶

    아래는 Step 1~6을 하나의 파이프라인으로 정리한 코드입니다. 복사해서 바로 실행할 수 있습니다.

    import pandas as pd

# ===== 1. 원본 데이터 =====
raw_data = {
    " 곡명 ": ["Dynamite", "Butter ", " Super Shy", "Seven", "Hype Boy", "Ditto"],
    "아티스트": ["  BTS", "BTS ", "NewJeans", " 정국 ", " NewJeans", "NewJeans "],
    "재생수": ["1,500,000", "2,100,000", "980,000", "1,800,000", "1,200,000", "1,600,000"],
    "발매일": ["2020-08-21", "2021-05-21", "2023-07-07", "2023-07-14", "2022-08-01", "2022-12-19"],
    "장르 ": ["팝", "팝 ", " 팝", "팝", " 팝", " 팝"]
}
df = pd.DataFrame(raw_data)

# ===== 2. 컬럼명 정리 =====
df.columns = df.columns.str.strip()
df = df.rename(columns={"곡명": "title", "아티스트": "artist",
                         "재생수": "plays", "발매일": "release_date", "장르": "genre"})

# ===== 3. 문자열 정리 =====
for col in ["title", "artist", "genre"]:
    df[col] = df[col].str.strip()

# ===== 4. 타입 변환 =====
df["plays"] = df["plays"].str.replace(",", "").astype(int)
df["release_date"] = pd.to_datetime(df["release_date"])

# ===== 5. 필터링 & 정렬 =====
popular = df.query("plays >= 1000000").sort_values("plays", ascending=False)
print("=== 인기곡 (재생수 100만 이상) ===")
print(popular[["title", "artist", "plays"]])

# ===== 6. 그룹화 =====
print("\n=== 아티스트별 평균 재생수 ===")
print(df.groupby("artist")["plays"].mean().sort_values(ascending=False))

    정리하기 📋

    전처리 파이프라인의 순서를 기억하세요!

    컬럼명 정리 → 문자열 정리 → 타입 변환 → 필터링/정렬 → 그룹화/분석

    이 순서를 코드로 기록해두면, 새로운 데이터가 들어와도 동일한 전처리를 재현할 수 있습니다. 이것이 바로 재현 가능한 분석 파이프라인입니다.

    ⚠️ 자주 하는 실수¶

    실수 1: 콤마를 제거하지 않고 바로 숫자로 변환하기 🚫

    # ❌ 이렇게 하면 에러 발생!
df["plays"] = df["plays"].astype(int)
# ValueError: invalid literal for int() with base 10: '1,500,000'

# ✅ 콤마를 먼저 제거!
df["plays"] = df["plays"].str.replace(",", "").astype(int)

    실수 2: 원본 데이터를 덮어쓰기 🚫

    # ❌ 원본이 사라져서 되돌릴 수 없음
df = df.query("plays >= 1000000")

# ✅ 필터링 결과는 새 변수에 저장
popular = df.query("plays >= 1000000")

    실수 3: 문자열 공백을 무시하기 🚫

    # "BTS"와 "BTS "는 서로 다른 값으로 인식됨!
print("BTS" == "BTS ")  # False

# groupby 시 같은 아티스트가 따로 집계됨
# 반드시 .str.strip()으로 정리 후 그룹화하세요

    실수 4: query() 안에서 변수를 잘못 사용하기 🚫

    threshold = 1000000

# ❌ 변수를 그냥 쓰면 컬럼명으로 인식
# df.query("plays >= threshold")  # 에러 가능

# ✅ @ 기호로 외부 변수임을 표시
df.query("plays >= @threshold")

    "  품목 ": ["사과", "바나나 ", " 사과", " 바나나", "딸기"],
    "카테고리": ["과일 ", " 과일", "과일", " 과일 ", "과일"],

    힌트 1. 컬럼명 정리 → 2. 문자열 정리 → 3. 가격 변환 → 4. `groupby("품목")["가격"].mean()`
    정답 확인 
    import pandas as pd

raw = {
    "  품목 ": ["사과", "바나나 ", " 사과", " 바나나", "딸기"],
    "카테고리": ["과일 ", " 과일", "과일", " 과일 ", "과일"],
    "가격(원)": ["3,000", "1,500", "3,500", "1,200", "5,000"]
}
df = pd.DataFrame(raw)

# 컬럼명 정리
df.columns = df.columns.str.strip()
df = df.rename(columns={"가격(원)": "가격"})

# 문자열 정리
for col in ["품목", "카테고리"]:
    df[col] = df[col].str.strip()

# 타입 변환
df["가격"] = df["가격"].str.replace(",", "").astype(int)

# 그룹화
print(df.groupby("품목")["가격"].mean())

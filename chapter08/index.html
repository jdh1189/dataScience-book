    Chapter 08: 동일한 데이터, 다양한 분석과 시각화¶

    🎯 이 장에서 배우는 것¶

    • 하나의 데이터셋을 막대·원·선·산점도 등 다양한 차트로 표현할 수 있다
    • 분석 목적에 따라 적절한 시각화 방법을 선택하고 그 이유를 설명할 수 있다
    • 동일 데이터에 대해 서로 다른 관점의 분석 결과를 비교·해석할 수 있다
    • 그래프가 전달하는 메시지가 어떻게 달라질 수 있는지 비판적으로 판단할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    반 친구 30명의 시험 성적이 있습니다. 이걸 막대그래프로 그리면 "누가 잘했는지"가 눈에 들어오고, 원그래프로 그리면 "A등급이 몇 %인지"가 먼저 보입니다. 같은 숫자인데 그래프만 바꿔도 사람들이 받는 인상이 완전히 달라집니다.

    뉴스에서 "청소년 스마트폰 사용 시간이 급증했다"는 기사를 볼 때, 어떤 그래프를 사용했느냐에 따라 "심각한 문제"로도, "완만한 변화"로도 보일 수 있습니다. 데이터를 다양한 방식으로 시각화하는 능력은 정보를 정확히 읽고, 올바르게 전달하는 힘입니다.

    이번 장에서는 하나의 데이터를 여러 그래프로 그려보면서, 각 시각화가 어떤 이야기를 강조하는지 직접 체험합니다.

    📚 핵심 개념¶

    개념 1: 시각화의 목적 — "같은 재료, 다른 요리"¶

    비유로 시작 🍳

    같은 감자라도 구우면 구운 감자, 튀기면 감자튀김, 삶으면 감자 샐러드가 됩니다. 데이터도 마찬가지입니다. 같은 숫자라도 어떤 차트를 선택하느냐에 따라 전혀 다른 이야기가 만들어집니다.

    정확한 정의 📖

    데이터 시각화(Data Visualization)란 숫자나 문자로 된 데이터를 그래프, 차트, 도표 등 시각적 형태로 변환하여 패턴과 의미를 쉽게 파악할 수 있게 만드는 과정입니다. 중요한 것은 분석 목적에 따라 시각화 방법이 달라져야 한다는 점입니다.

    예시로 확인 ✅

    "서울의 월별 평균 기온" 데이터가 있을 때: - 선 그래프 → 기온이 어떻게 변해가는지 추세(흐름)가 보인다 - 막대그래프 → 각 월의 기온을 비교하기 쉽다 - 히스토그램 → 기온이 어느 범위에 몰려 있는지 분포가 보인다

    개념 2: 차트 유형별 특징 — "각자의 강점이 있다"¶

    비유로 시작 🔧

    도구 상자에 망치, 드라이버, 펜치가 있듯이, 차트에도 각각 잘하는 일이 있습니다. 못을 박을 때 드라이버를 쓰면 안 되겠죠?

    정확한 정의와 예시

    graph LR A[차트 유형] --> B["📊 막대그래프<br/>항목 간 크기 비교"] A --> C["📈 선 그래프<br/>시간에 따른 변화"] A --> D["🥧 원 그래프<br/>전체 대비 비율"] A --> E["📉 산점도<br/>두 변수의 관계"] A --> F["📦 박스플롯<br/>분포와 이상치"]

    각 차트의 "언제 쓰면 좋은가"를 정리하면:

    • 막대그래프(Bar Chart): "어떤 항목이 가장 큰가?" → 카테고리별 비교
    • 선 그래프(Line Chart): "시간이 흐르면서 어떻게 변했나?" → 추세 파악
    • 원 그래프(Pie Chart): "전체에서 각각 몇 %인가?" → 비율/구성
    • 산점도(Scatter Plot): "두 값 사이에 관계가 있나?" → 상관관계
    • 박스플롯(Box Plot): "데이터가 어떻게 퍼져 있나?" → 분포·이상치

    개념 3: 같은 데이터, 다른 메시지¶

    비유로 시작 📸

    같은 풍경을 넓게 찍으면 광활한 느낌이고, 꽃 한 송이를 클로즈업하면 섬세한 느낌입니다. 카메라 앵글이 곧 차트 유형입니다.

    정확한 정의 📖

    동일한 데이터라도 시각화 방법에 따라 강조되는 정보가 다릅니다. 이것을 "프레이밍 효과(Framing Effect)"라고 합니다. 데이터 자체는 거짓말을 하지 않지만, 표현 방식이 해석을 유도할 수 있습니다.

    예시로 확인 ✅

    월별 아이스크림 판매량 데이터에서: - 선 그래프로 그리면 → "여름에 급증한다"는 추세가 강조 - 원 그래프로 그리면 → "여름 3개월이 연간 판매의 60%"라는 비율이 강조 - 막대그래프로 그리면 → "7월이 1월보다 5배 많다"는 비교가 강조

    알아보기 💡

    뉴스나 광고에서 그래프를 볼 때, "왜 이 차트를 선택했을까?"를 생각해보세요. 의도적으로 특정 메시지를 강조하기 위해 차트 유형을 고른 경우가 많습니다.

    개념 4: matplotlib과 seaborn — "파이썬의 그래프 도구"¶

    비유로 시작 🎨

    matplotlib은 기본 물감 세트이고, seaborn은 미리 예쁜 색 조합이 준비된 프리미엄 물감 세트입니다. matplotlib으로 뭐든 그릴 수 있고, seaborn은 그 위에서 더 세련된 그래프를 쉽게 만들어줍니다.

    정확한 정의 📖

    • matplotlib: 파이썬의 가장 기본적인 시각화 라이브러리. 거의 모든 종류의 그래프를 그릴 수 있다
    • seaborn: matplotlib 기반으로, 통계적 시각화에 특화된 라이브러리. 기본 스타일이 깔끔하고 코드가 간결하다
    graph TB A["seaborn (고수준)"] -->|기반| B["matplotlib (저수준)"] B -->|기반| C["파이썬"] style A fill:#4ECDC4,color:#fff style B fill:#556270,color:#fff

    🔨 따라하기¶

    서울의 월별 평균 기온 데이터를 가지고, 같은 데이터를 5가지 차트로 그려봅니다.

    Step 1: 데이터 준비하기¶

    import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = 'Malgun Gothic'  # Windows
# Mac: matplotlib.rcParams['font.family'] = 'AppleGothic'
matplotlib.rcParams['axes.unicode_minus'] = False

# 서울 월별 평균 기온 데이터 (단위: °C)
months = ['1월','2월','3월','4월','5월','6월',
          '7월','8월','9월','10월','11월','12월']
temp = [-2.4, 0.4, 5.7, 12.5, 17.8, 22.2,
        24.9, 25.7, 21.2, 14.8, 7.2, 0.4]

print("✅ 데이터 준비 완료!")
print(f"가장 더운 달: {months[temp.index(max(temp))]} ({max(temp)}°C)")
print(f"가장 추운 달: {months[temp.index(min(temp))]} ({min(temp)}°C)")

    이 12개의 숫자를 이제 5가지 다른 시각으로 바라봅니다.

    Step 2: 막대그래프 — "어느 달이 가장 더울까?"¶

    막대그래프는 항목 간 크기를 한눈에 비교할 때 최적입니다.

    plt.figure(figsize=(10, 5))
colors = ['#3498db' if t < 10 else '#e74c3c' if t > 20 else '#f39c12' for t in temp]
plt.bar(months, temp, color=colors)
plt.title('서울 월별 평균 기온 (막대그래프)', fontsize=14)
plt.ylabel('평균 기온 (°C)')
plt.axhline(y=0, color='gray', linestyle='--', linewidth=0.8)
plt.tight_layout()
plt.show()

    관찰 포인트 👀: 파란색(추운 달), 주황색(적당한 달), 빨간색(더운 달)로 색을 다르게 했습니다. 색상만으로도 계절감이 느껴지나요? 막대그래프에서는 "8월이 가장 높다"는 비교 정보가 가장 강하게 전달됩니다.

    Step 3: 선 그래프 — "기온이 어떻게 변해갈까?"¶

    선 그래프는 시간에 따른 변화(추세)를 보여줄 때 가장 효과적입니다.

    plt.figure(figsize=(10, 5))
plt.plot(months, temp, marker='o', color='#e74c3c', linewidth=2, markersize=8)
plt.fill_between(range(12), temp, alpha=0.15, color='#e74c3c')
plt.title('서울 월별 평균 기온 (선 그래프)', fontsize=14)
plt.ylabel('평균 기온 (°C)')
plt.axhline(y=0, color='gray', linestyle='--', linewidth=0.8)
plt.tight_layout()
plt.show()

    관찰 포인트 👀: 선 그래프에서는 "겨울에서 여름까지 올라갔다가 다시 내려오는 흐름"이 강하게 느껴집니다. 막대그래프에서는 개별 막대를 비교했다면, 선 그래프에서는 전체 흐름에 눈이 갑니다.

    Step 4: 원 그래프 — "여름 기온이 차지하는 비율은?"¶

    원 그래프는 전체에서 각 부분이 차지하는 비율을 보여줍니다. 기온 데이터에 바로 적용하기보다, 계절별로 묶어서 활용합니다.

    # 계절별 평균 기온 합산
seasons = ['봄(3~5월)', '여름(6~8월)', '가을(9~11월)', '겨울(12~2월)']
season_temp = [
    sum(temp[2:5]),    # 봄
    sum(temp[5:8]),    # 여름
    sum(temp[8:11]),   # 가을
    sum([temp[11], temp[0], temp[1]])  # 겨울
]
# 양수로 변환 (비율 시각화를 위해)
season_abs = [abs(t) for t in season_temp]

plt.figure(figsize=(7, 7))
colors_pie = ['#2ecc71', '#e74c3c', '#f39c12', '#3498db']
plt.pie(season_abs, labels=seasons, autopct='%1.1f%%',
        colors=colors_pie, startangle=90, textprops={'fontsize': 12})
plt.title('계절별 기온 비중 (원 그래프)', fontsize=14)
plt.tight_layout()
plt.show()

    관찰 포인트 👀: 원 그래프를 보면 "여름이 전체 기온에서 가장 큰 비중"이라는 메시지가 전달됩니다. 하지만 이 경우 원 그래프가 최선일까요? 기온 데이터에 "비율"이라는 개념이 자연스러운지 한번 생각해보세요.

    알아보기 💡

    원 그래프는 "합이 100%가 되는 데이터"에 가장 적합합니다. 예: 설문조사 응답 비율, 예산 배분 등. 기온 데이터처럼 합계에 큰 의미가 없는 경우에는 막대그래프가 더 나을 수 있습니다. 차트 선택이 적절한지 판단하는 것도 중요한 능력입니다!

    Step 5: 히스토그램과 박스플롯 — "기온은 어떻게 분포할까?"¶

    이번에는 관점을 바꿔, 12개 기온 값의 분포를 살펴봅니다.

    import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 히스토그램
axes[0].hist(temp, bins=6, color='#3498db', edgecolor='white', alpha=0.8)
axes[0].set_title('기온 분포 (히스토그램)', fontsize=13)
axes[0].set_xlabel('평균 기온 (°C)')
axes[0].set_ylabel('월 수')

# 박스플롯
sns.boxplot(y=temp, ax=axes[1], color='#2ecc71', width=0.4)
axes[1].set_title('기온 분포 (박스플롯)', fontsize=13)
axes[1].set_ylabel('평균 기온 (°C)')

plt.tight_layout()
plt.show()

    관찰 포인트 👀: - 히스토그램: 기온이 어느 구간에 몇 개 몰려 있는지 보여줍니다. "0~10°C인 달이 가장 많구나!" - 박스플롯: 중앙값(가운데 선), 데이터가 퍼진 범위(상자), 극단값을 한눈에 보여줍니다.

    Step 6: 한 화면에 모아서 비교하기¶

    5가지 차트를 나란히 놓으면 같은 데이터가 얼마나 다르게 보이는지 확실히 느낄 수 있습니다.

    fig, axes = plt.subplots(2, 3, figsize=(16, 10))

# 1) 막대그래프
axes[0,0].bar(range(12), temp, color='#3498db')
axes[0,0].set_title('① 막대그래프: 비교')
axes[0,0].set_xticks(range(12))
axes[0,0].set_xticklabels([m[:-1] for m in months], fontsize=8)

# 2) 선 그래프
axes[0,1].plot(range(12), temp, 'o-', color='#e74c3c', linewidth=2)
axes[0,1].set_title('② 선 그래프: 추세')
axes[0,1].set_xticks(range(12))
axes[0,1].set_xticklabels([m[:-1] for m in months], fontsize=8)

# 3) 원 그래프
axes[0,2].pie(season_abs, labels=seasons, autopct='%1.0f%%',
              colors=['#2ecc71','#e74c3c','#f39c12','#3498db'])
axes[0,2].set_title('③ 원 그래프: 비율')

# 4) 히스토그램
axes[1,0].hist(temp, bins=6, color='#9b59b6', edgecolor='white')
axes[1,0].set_title('④ 히스토그램: 분포')

# 5) 박스플롯
sns.boxplot(y=temp, ax=axes[1,1], color='#1abc9c', width=0.4)
axes[1,1].set_title('⑤ 박스플롯: 분포 요약')

# 6) 빈 자리에 요약 텍스트
axes[1,2].axis('off')
summary = (
    "📊 같은 데이터, 다른 이야기\n\n"
    "① 막대: 8월이 가장 덥다\n"
    "② 선: 여름까지 오르고 내린다\n"
    "③ 원: 여름이 기온의 50%+\n"
    "④ 히스토그램: 0~10°C가 많다\n"
    "⑤ 박스: 중앙값 약 13°C"
)
axes[1,2].text(0.1, 0.5, summary, fontsize=13, verticalalignment='center',
               fontfamily='Malgun Gothic')

plt.suptitle('🔍 동일한 데이터, 5가지 시각화', fontsize=16, fontweight='bold')

    생각해보기 🤔

    만약 여러분이 "서울은 사계절이 뚜렷하다"는 것을 보여주고 싶다면 어떤 차트를 선택하겠습니까? "겨울이 너무 춥다"를 강조하고 싶다면요? 목적이 달라지면 최적의 차트도 달라집니다.

    📝 전체 코드¶

    """
Chapter 08: 동일한 데이터, 다양한 분석과 시각화
- 서울 월별 평균 기온 데이터를 5가지 차트로 표현하기
"""
import matplotlib.pyplot as plt
import matplotlib
import seaborn as sns

# 한글 폰트 설정
matplotlib.rcParams['font.family'] = 'Malgun Gothic'  # Mac: 'AppleGothic'
matplotlib.rcParams['axes.unicode_minus'] = False

# ── 1. 데이터 준비 ──
months = ['1월','2월','3월','4월','5월','6월',
          '7월','8월','9월','10월','11월','12월']
temp = [-2.4, 0.4, 5.7, 12.5, 17.8, 22.2,
        24.9, 25.7, 21.2, 14.8, 7.2, 0.4]

seasons = ['봄(3~5월)', '여름(6~8월)', '가을(9~11월)', '겨울(12~2월)']
season_temp = [sum(temp[2:5]), sum(temp[5:8]),
               sum(temp[8:11]), sum([temp[11], temp[0], temp[1]])]
season_abs = [abs(t) for t in season_temp]

# ── 2. 5가지 시각화 한 화면에 ──
fig, axes = plt.subplots(2, 3, figsize=(16, 10))

# 막대그래프
colors = ['#3498db' if t < 10 else '#e74c3c' if t > 20 else '#f39c12' for t in temp]
axes[0,0].bar(range(12), temp, color=colors)
axes[0,0].set_title('① 막대그래프: 월별 비교')
axes[0,0].set_xticks(range(12))
axes[0,0].set_xticklabels([m[:-1] for m in months], fontsize=8)
axes[0,0].axhline(y=0, color='gray', linestyle='--', linewidth=0.8)

# 선 그래프
axes[0,1].plot(range(12), temp, 'o-', color='#e74c3c', linewidth=2)
axes[0,1].fill_between(range(12), temp, alpha=0.15, color='#e74c3c')
axes[0,1].set_title('② 선 그래프: 연간 추세')
axes[0,1].set_xticks(range(12))
axes[0,1].set_xticklabels([m[:-1] for m in months], fontsize=8)

# 원 그래프
axes[0,2].pie(season_abs, labels=seasons, autopct='%1.0f%%',
              colors=['#2ecc71','#e74c3c','#f39c12','#3498db'], startangle=90)
axes[0,2].set_title('③ 원 그래프: 계절별 비율')

# 히스토그램
axes[1,0].hist(temp, bins=6, color='#9b59b6', edgecolor='white')
axes[1,0].set_title('④ 히스토그램: 기온 분포')
axes[1,0].set_xlabel('평균 기온 (°C)')

# 박스플롯
sns.boxplot(y=temp, ax=axes[1,1], color='#1abc9c', width=0.4)
axes[1,1].set_title('⑤ 박스플롯: 분포 요약')

# 요약
axes[1,2].axis('off')
summary = ("📊 같은 데이터, 다른 이야기\n\n"
           "① 막대 → 어느 달이 덥고 추운지 비교\n"
           "② 선 → 기온 변화의 흐름\n"
           "③ 원 → 계절별 비중\n"
           "④ 히스토그램 → 어느 기온대가 많은지\n"
           "⑤ 박스 → 중앙값·범위·이상치")
axes[1,2].text(0.1, 0.5, summary, fontsize=12, verticalalignment='center',
               fontfamily='Malgun Gothic')

plt.suptitle('🔍 동일한 데이터, 5가지 시각화', fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: 원 그래프에 항목이 너무 많다 🥧

    원 그래프에 12개월을 모두 넣으면 조각이 너무 많아 오히려 아무것도 읽히지 않습니다. 원 그래프는 5개 이하의 항목일 때 효과적입니다. 그래서 위 예제에서도 4계절로 묶었습니다.

    실수 2: 선 그래프를 범주형 데이터에 사용 📈

    "좋아하는 과일별 학생 수"처럼 순서가 없는 데이터에 선 그래프를 쓰면 "사과에서 바나나로 증가했다"는 잘못된 인상을 줍니다. 선 그래프는 시간처럼 순서가 있는 데이터에만 쓰세요.

    실수 3: Y축을 0에서 시작하지 않는 막대그래프 📊

    Y축을 20부터 시작하면 25와 22 사이의 차이가 실제보다 엄청나게 커 보입니다. 막대그래프의 Y축은 반드시 0부터 시작하는 것이 원칙입니다. (이것이 바로 "오해를 불러일으키는 그래프"를 만드는 대표적 수법입니다!)

    실수 4: 한글 폰트 설정을 빠뜨림 🔤

    matplotlib.rcParams['font.family'] 설정 없이 한글을 쓰면 글자가 깨져서 □□□로 표시됩니다. 코드 맨 위에 반드시 폰트 설정을 넣으세요.

    이번 장의 핵심을 한 문장으로 요약하면: "데이터는 하나지만, 시각화는 선택이다. 그리고 그 선택이 메시지를 결정한다."

    • 막대그래프 → 비교, 선 그래프 → 추세, 원 그래프 → 비율, 히스토그램 → 분포, 박스플롯 → 분포 요약
    • 차트를 선택할 때는 항상 "무엇을 보여주고 싶은가?"를 먼저 생각하세요
    • 그래프는 설득의 도구이므로, 읽는 사람도 만드는 사람도 비판적 시각이 필요합니다

    Chapter 10. 회귀 분석 - 숫자를 예측하자¶

    🎯 이 장에서 배우는 것¶

    • 회귀 분석이 무엇인지 설명하고, 산점도 위에 '가장 잘 맞는 직선'의 의미를 이해할 수 있다
    • 최소제곱법의 원리를 '오차를 최소로 만드는 게임'으로 직관적으로 설명할 수 있다
    • scikit-learn의 LinearRegression으로 회귀 모델을 학습시키고 예측값을 산출할 수 있다
    • 결정계수(R²)와 평균제곱오차(MSE)로 모델 성능을 평가하고 해석할 수 있다

    💡 왜 이걸 배우나요?¶

    "공부를 하루에 1시간 더 하면 시험 점수가 몇 점 오를까?"

    이 질문에 "글쎄요, 한 5점쯤?"이라고 감으로 대답하는 것과, 데이터를 분석해서 "평균적으로 4.8점 상승합니다"라고 근거 있게 대답하는 것은 완전히 다릅니다.

    회귀 분석은 이처럼 숫자를 예측하는 기술입니다. 우리 주변에는 회귀 분석이 쓰이는 곳이 아주 많습니다.

    • 🏠 부동산: 면적이 10평 넓어지면 가격이 얼마나 오를까?
    • 🌡️ 날씨: 내일 기온이 몇 도일까?
    • 📈 비즈니스: 광고비를 100만 원 더 쓰면 매출이 얼마나 늘까?

    이전 장까지는 "이것은 A인가 B인가?"를 구분하는 분류 문제를 다뤘습니다. 이번 장에서는 구체적인 숫자를 예측하는 방법을 배웁니다. 머신러닝의 양대 산맥 중 하나인 회귀(Regression)를 이제 시작해봅시다! 🚀

    📚 핵심 개념¶

    개념 1: 회귀 분석이란?¶

    1. 비유로 시작¶

    학교 앞 분식집 사장님을 떠올려 보세요. 사장님은 오랜 경험으로 알고 있습니다.

    "비가 오는 날에는 손님이 적고, 맑은 날에는 많아. 기온이 높으면 냉면이 잘 팔리고, 낮으면 라면이 잘 팔려."

    사장님은 머릿속으로 날씨(원인)와 매출(결과) 사이의 관계를 파악하고 있는 겁니다. 회귀 분석은 이런 관계를 수학적으로 정확하게 찾아내는 방법입니다.

    2. 정확한 정의¶

    회귀 분석(Regression Analysis): 하나 이상의 입력 변수(독립변수)와 연속적인 숫자 출력(종속변수) 사이의 관계를 수학적 함수로 모델링하는 통계 기법

    쉽게 말하면, "X가 변하면 Y가 어떻게 변하는지"를 수식으로 표현하는 것입니다.

    3. 예시로 확인¶

    분류 vs 회귀의 차이를 확실히 구분해봅시다.

    graph LR A[머신러닝 문제] --> B[분류 Classification] A --> C[회귀 Regression] B --> D["결과: 카테고리<br/>예: 합격/불합격"] C --> E["결과: 숫자<br/>예: 85.3점"] style B fill:#FFB3BA,stroke:#333 style C fill:#BAE1FF,stroke:#333 style D fill:#FFB3BA,stroke:#333 style E fill:#BAE1FF,stroke:#333
    • 분류: "이 학생은 합격일까, 불합격일까?" → 답이 범주(카테고리)
    • 회귀: "이 학생의 시험 점수는 몇 점일까?" → 답이 숫자(연속값)

    📌 알아보기: "회귀(回歸)"라는 이름은 19세기 통계학자 프랜시스 골턴이 부모와 자녀의 키를 연구하면서 붙인 이름입니다. 키가 아주 큰 부모의 자녀는 부모보다 약간 작고, 키가 아주 작은 부모의 자녀는 부모보다 약간 큰 경향, 즉 평균으로 되돌아가는(회귀하는) 현상을 발견한 데서 유래했습니다.

    개념 2: 단순 선형 회귀와 최소제곱법¶

    1. 비유로 시작¶

    여러분 앞에 산점도(점들이 흩어진 그래프)가 있다고 상상해보세요. 이 점들 사이로 자(ruler)를 하나 놓아서 가장 잘 맞는 직선을 긋는 게임을 한다고 생각해봅시다.

    "잘 맞는다"는 건 뭘까요? 각 점에서 직선까지의 거리(오차)가 전체적으로 가장 작은 직선을 의미합니다. 이것이 바로 최소제곱법의 핵심 아이디어입니다!

    2. 정확한 정의¶

    단순 선형 회귀(Simple Linear Regression)는 입력 변수 1개와 출력 변수 1개의 관계를 직선으로 표현합니다.

    $$y = wx + b$$

    • y: 예측하고 싶은 값 (종속변수, 예: 시험 점수)
    • x: 예측에 사용하는 값 (독립변수, 예: 공부 시간)
    • w: 기울기(가중치) — x가 1 증가할 때 y가 얼마나 변하는지
    • b: 절편(y-intercept) — x가 0일 때 y의 값

    최소제곱법(Least Squares Method)은 이 직선의 w와 b를 찾는 방법입니다.

    graph TD A["모든 데이터 점에 대해"] --> B["실제값 - 예측값 = 오차"] B --> C["각 오차를 제곱"] C --> D["제곱한 오차를 모두 합산"] D --> E["이 합이 최소가 되는<br/>기울기 w와 절편 b를 찾기"] style E fill:#BAFFC9,stroke:#333,stroke-width:2px

    📌 생각해보기: 오차를 왜 그냥 더하지 않고 제곱해서 더할까요? 양수 오차(+3)와 음수 오차(-3)를 그냥 더하면 서로 상쇄되어 0이 됩니다. 실제로는 둘 다 3만큼 틀린 건데 말이죠! 제곱하면 모두 양수가 되어 이 문제가 해결됩니다. 또한 큰 오차에 더 큰 벌점(페널티)을 주는 효과도 있습니다.

    3. 예시로 확인¶

    5명의 학생 데이터를 살펴봅시다.

    • 학생 A: 공부 1시간 → 20점
    • 학생 B: 공부 2시간 → 35점
    • 학생 C: 공부 3시간 → 50점
    • 학생 D: 공부 4시간 → 55점
    • 학생 E: 공부 5시간 → 70점

    이 5개의 점을 가장 잘 통과하는 직선을 찾는 것이 회귀 분석입니다. 만약 그 직선이 y = 12x + 10이라면:

    • 공부 6시간을 하는 학생의 예상 점수: 12 × 6 + 10 = 82점

    이렇게 아직 보지 못한 데이터에 대해서도 예측할 수 있게 됩니다!

    개념 3: 모델 평가 지표 — MSE와 R²¶

    모델을 만들었으면 "이 모델이 얼마나 잘 예측하는지"를 숫자로 평가할 수 있어야 합니다. 회귀에서 가장 많이 쓰는 두 가지 지표를 배워봅시다.

    1. 비유로 시작¶

    양궁 선수 두 명이 과녁에 화살을 쏜다고 생각해보세요.

    • MSE(평균제곱오차): 화살들이 과녁 중심에서 평균적으로 얼마나 빗나갔는지 (작을수록 좋음 🎯)
    • R²(결정계수): 선수의 실력이 아무렇게나 쏘는 것 대비 얼마나 나은지 (1에 가까울수록 좋음 ⭐)

    2. 정확한 정의¶

    MSE (Mean Squared Error, 평균제곱오차)

    각 데이터 점에서 (실제값 - 예측값)²을 구한 뒤, 그 평균을 낸 것

    • 값의 범위: 0 이상 (0이면 완벽한 예측)
    • 단위: 원래 값의 단위의 제곱 (점수를 예측했다면 "점²")
    • 작을수록 좋은 모델

    R² (R-squared, 결정계수)

    모델이 데이터의 변동을 얼마나 잘 설명하는지를 비율로 나타낸 것

    • 값의 범위: 보통 0~1 (음수가 될 수도 있지만, 그러면 매우 나쁜 모델)
    • R² = 1이면 완벽한 예측, R² = 0이면 평균값으로 찍는 것과 같은 수준
    • 1에 가까울수록 좋은 모델

    3. 예시로 확인¶

    graph LR subgraph 좋은모델["✅ 좋은 모델"] A["MSE = 4.2<br/>R² = 0.95"] end subgraph 보통모델["⚠️ 보통 모델"] B["MSE = 25.1<br/>R² = 0.62"] end subgraph 나쁜모델["❌ 나쁜 모델"] C["MSE = 102.7<br/>R² = 0.15"] end style 좋은모델 fill:#BAFFC9,stroke:#333 style 보통모델 fill:#FFFFBA,stroke:#333 style 나쁜모델 fill:#FFB3BA,stroke:#333

    R² = 0.95라면 "이 모델이 데이터 변동의 95%를 설명한다"는 뜻입니다. 남은 5%는 모델이 포착하지 못한 부분(노이즈, 다른 변수의 영향 등)입니다.

    📌 정리하기: MSE는 "오차의 크기"를, R²는 "설명력의 비율"을 알려줍니다. 보통 두 지표를 함께 확인하여 모델을 종합적으로 평가합니다.

    개념 4: scikit-learn의 LinearRegression¶

    1. 비유로 시작¶

    직접 수학 공식으로 기울기(w)와 절편(b)을 계산할 수도 있지만, 그건 마치 빨래를 손으로 하는 것과 같습니다. scikit-learn의 LinearRegression은 전자동 세탁기입니다. 데이터를 넣고 버튼만 누르면 최적의 직선을 자동으로 찾아줍니다!

    2. 사용법 정리¶

    • LinearRegression() — 모델 객체 생성
    • .fit(X, y) — 데이터로 학습 (최적의 w, b를 찾음)
    • .predict(X_new) — 새 데이터에 대해 예측
    • .coef_ — 학습된 기울기(w) 확인
    • .intercept_ — 학습된 절편(b) 확인

    3. 전체 흐름¶

    graph LR A["1. 데이터 준비"] --> B["2. 모델 생성<br/>LinearRegression()"] B --> C["3. 모델 학습<br/>.fit(X, y)"] C --> D["4. 예측<br/>.predict(X_new)"] D --> E["5. 평가<br/>R², MSE 계산"] style A fill:#E8E8E8,stroke:#333 style C fill:#BAE1FF,stroke:#333 style E fill:#BAFFC9,stroke:#333

    🔨 따라하기¶

    이제 Google Colab에서 직접 회귀 모델을 만들어봅시다! 공부 시간으로 시험 점수를 예측하는 모델을 단계별로 구현합니다.

    Step 1: 데이터 준비하기¶

    import numpy as np
import matplotlib.pyplot as plt

# 학생 15명의 공부 시간(시간)과 시험 점수(점) 데이터
study_hours = np.array([1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, 5, 5.5, 6, 6.5, 7, 8, 9])
scores = np.array([20, 25, 30, 38, 45, 48, 55, 58, 62, 68, 72, 78, 82, 90, 95])

# 산점도로 데이터 확인
plt.figure(figsize=(8, 5))
plt.scatter(study_hours, scores, color='dodgerblue', s=80, edgecolors='navy', zorder=5)
plt.xlabel('Study Hours', fontsize=12)
plt.ylabel('Test Score', fontsize=12)
plt.title('Study Hours vs Test Score', fontsize=14)
plt.grid(True, alpha=0.3)
plt.show()

    실행하면 점들이 왼쪽 아래에서 오른쪽 위로 흩어져 있는 산점도가 나타납니다. 공부 시간이 늘수록 점수가 높아지는 경향이 눈에 보이시죠? 이 점들 사이로 직선을 그어보겠습니다.

    📌 알아보기: 산점도(scatter plot)는 두 변수의 관계를 한눈에 파악할 수 있는 가장 기본적인 시각화입니다. 회귀 분석 전에 반드시 산점도를 먼저 그려서 "직선으로 설명 가능한 관계인지" 확인하는 습관을 들이세요.

    Step 2: 모델 학습시키기¶

    from sklearn.linear_model import LinearRegression

# ⚠️ scikit-learn은 X가 2차원 배열이어야 합니다!
X = study_hours.reshape(-1, 1)  # (15,) → (15, 1)로 변환
y = scores

# 모델 생성 및 학습
model = LinearRegression()
model.fit(X, y)

# 학습된 기울기와 절편 확인
print(f"기울기 (w): {model.coef_[0]:.2f}")
print(f"절편 (b): {model.intercept_:.2f}")
print(f"\n예측 공식: 점수 = {model.coef_[0]:.2f} × 공부시간 + {model.intercept_:.2f}")

    예상 출력: 

    기울기 (w): 9.37
절편 (b): 10.63

예측 공식: 점수 = 9.37 × 공부시간 + 10.63

    이 결과가 의미하는 바를 해석해봅시다.

    • 기울기 9.37: 공부 시간이 1시간 늘 때마다 시험 점수가 약 9.37점 상승
    • 절편 10.63: 공부를 전혀 하지 않아도 받을 수 있는 기본 점수 (수업 출석 등의 효과)

    📌 생각해보기: .reshape(-1, 1)은 왜 필요할까요? scikit-learn의 .fit() 메서드는 X 데이터를 "행 = 샘플, 열 = 특성(feature)"의 2차원 배열로 받습니다. 우리 데이터는 특성이 1개(공부 시간)뿐이지만, 형식은 맞춰야 하기에 1열짜리 2차원 배열로 변환하는 것입니다.

    Step 3: 예측하고 시각화하기¶

    # 예측선 그리기
X_line = np.linspace(0, 10, 100).reshape(-1, 1)  # 0~10시간 범위
y_line = model.predict(X_line)

plt.figure(figsize=(8, 5))
plt.scatter(study_hours, scores, color='dodgerblue', s=80, 
            edgecolors='navy', zorder=5, label='Actual Data')
plt.plot(X_line, y_line, color='red', linewidth=2, label='Regression Line')
plt.xlabel('Study Hours', fontsize=12)
plt.ylabel('Test Score', fontsize=12)
plt.title('Linear Regression: Study Hours → Test Score', fontsize=14)
plt.legend(fontsize=11)
plt.grid(True, alpha=0.3)
plt.show()

# 새로운 데이터로 예측
new_hours = np.array([[3], [6.5], [10]])
predictions = model.predict(new_hours)
for h, p in zip(new_hours.flatten(), predictions):
    print(f"공부 {h}시간 → 예상 점수: {p:.1f}점")

    예상 출력: 

    공부 3.0시간 → 예상 점수: 38.7점
공부 6.5시간 → 예상 점수: 71.5점
공부 10.0시간 → 예상 점수: 104.3점

    빨간 직선이 파란 점들 사이를 관통하는 그래프가 그려집니다. 이 직선이 바로 최소제곱법으로 찾은 최적의 직선입니다!

    ⚠️ 10시간 공부하면 104.3점? 시험 만점이 100점이라면 말이 안 됩니다! 이처럼 학습 데이터 범위 밖으로 예측(외삽, extrapolation)하면 비현실적인 결과가 나올 수 있습니다. 모델의 예측을 맹신하지 말고, 항상 상식적으로 검증하세요.

    Step 4: 모델 성능 평가하기¶

    from sklearn.metrics import mean_squared_error, r2_score

# 학습 데이터에 대한 예측
y_pred = model.predict(X)

# MSE와 R² 계산
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print(f"평균제곱오차 (MSE): {mse:.2f}")
print(f"평균제곱근오차 (RMSE): {np.sqrt(mse):.2f}")
print(f"결정계수 (R²): {r2:.4f}")

    예상 출력: 

    평균제곱오차 (MSE): 7.35
평균제곱근오차 (RMSE): 2.71
결정계수 (R²): 0.9904

    이 결과를 해석해봅시다.

    • RMSE ≈ 2.71: 예측값이 실제값과 평균적으로 약 2.71점 차이남
    • R² ≈ 0.99: 공부 시간 하나만으로 시험 점수 변동의 99%를 설명 → 매우 우수!

    📌 알아보기: RMSE(Root MSE)는 MSE에 루트(√)를 씌운 것입니다. MSE의 단위가 "점²"이라 직관적이지 않은데, RMSE는 원래 단위인 "점"으로 돌아오므로 해석하기 훨씬 편합니다. 실무에서는 RMSE를 더 자주 사용합니다.

    Step 5: 잔차(오차) 시각화하기¶

    모델이 어디서 잘 맞고 어디서 틀리는지 확인하는 잔차 플롯을 그려봅시다.

    residuals = y - y_pred  # 잔차 = 실제값 - 예측값

plt.figure(figsize=(8, 4))
plt.bar(range(len(residuals)), residuals, color=['green' if r >= 0 else 'red' for r in residuals],
        alpha=0.7, edgecolor='black')
plt.axhline(y=0, color='black', linewidth=1)
plt.xlabel('Student Index', fontsize=12)
plt.ylabel('Residual (Actual - Predicted)', fontsize=12)
plt.title('Residual Plot', fontsize=14)
plt.grid(True, alpha=0.3, axis='y')
plt.show()

    잔차(residual)는 실제값에서 예측값을 뺀 것입니다.

    • 🟢 양수 잔차: 모델이 실제보다 낮게 예측함 (과소예측)
    • 🔴 음수 잔차: 모델이 실제보다 높게 예측함 (과대예측)

    좋은 모델이라면 잔차가 0 근처에 고르게 분포되어야 합니다.

    Step 6: 🚀 도전! 부동산 가격 예측¶

    이제 배운 내용을 응용해서 아파트 면적으로 가격을 예측하는 모델을 만들어봅시다!

    from sklearn.model_selection import train_test_split

# 아파트 데이터 (면적: 평, 가격: 만원)
area = np.array([15, 18, 20, 23, 25, 28, 30, 33, 35, 38, 
                 40, 42, 45, 48, 50, 55, 58, 60, 65, 70])
price = np.array([15000, 18000, 19500, 22000, 25000, 27000, 30000, 32000, 35000, 37500,
                  39000, 41000, 44000, 46500, 49000, 54000, 57000, 59000, 63000, 69000])

# 데이터 분할 (학습용 80%, 테스트용 20%)
X_area = area.reshape(-1, 1)
X_train, X_test, y_train, y_test = train_test_split(
    X_area, price, test_size=0.2, random_state=42
)

# 모델 학습
model_house = LinearRegression()
model_house.fit(X_train, y_train)

# 테스트 데이터로 평가
y_test_pred = model_house.predict(X_test)
test_r2 = r2_score(y_test, y_test_pred)
test_rmse = np.sqrt(mean_squared_error(y_test, y_test_pred))

print(f"기울기: 평당 {model_house.coef_[0]:.0f}만원")
print(f"절편: {model_house.intercept_:.0f}만원")
print(f"테스트 R²: {test_r2:.4f}")
print(f"테스트 RMSE: {test_rmse:.0f}만원")

# 특정 면적의 예상 가격
target_areas = np.array([[32], [45], [55]])
predicted_prices = model_house.predict(target_areas)
print("\n--- 예상 가격 ---")
for a, p in zip(target_areas.flatten(), predicted_prices):
    print(f"면적 {a}평 → 예상 가격: {p:,.0f}만원 ({p/10000:.1f}억원)")

# 시각화
plt.figure(figsize=(8, 5))
plt.scatter(X_train, y_train, color='dodgerblue', s=80, edgecolors='navy', 
            label='Train Data', zorder=5)
plt.scatter(X_test, y_test, color='orange', s=80, edgecolors='darkorange', 
            marker='D', label='Test Data', zorder=5)
X_plot = np.linspace(10, 75, 100).reshape(-1, 1)
plt.plot(X_plot, model_house.predict(X_plot), color='red', linewidth=2, 
         label='Regression Line')
plt.xlabel('Area (pyeong)', fontsize=12)
plt.ylabel('Price (man-won)', fontsize=12)
plt.title('Apartment Price Prediction', fontsize=14)
plt.legend(fontsize=11)

    이번에는 train_test_split을 사용하여 데이터를 학습용과 테스트용으로 나눴습니다. 학습에 사용하지 않은 테스트 데이터로 평가해야 모델의 진짜 실력을 알 수 있습니다!

    ⚠️ 자주 하는 실수¶

    실수 1: X 데이터를 2차원으로 변환하지 않음 🔴¶

    # ❌ 잘못된 코드
model.fit(study_hours, scores)
# ValueError: Expected 2D array, got 1D array instead.

# ✅ 올바른 코드
X = study_hours.reshape(-1, 1)  # 반드시 2차원으로!
model.fit(X, scores)

    scikit-learn의 .fit()은 X를 항상 2차원 배열(행=샘플, 열=특성)로 요구합니다. 특성이 1개뿐이더라도 .reshape(-1, 1)로 변환하세요.

    실수 2: 학습 데이터로만 성능 평가 🔴¶

    # ⚠️ 위험한 평가 방식
model.fit(X, y)
y_pred = model.predict(X)       # 학습에 쓴 바로 그 데이터로 예측
r2 = r2_score(y, y_pred)        # 이 점수는 '시험지를 미리 본 것'과 같음!

# ✅ 올바른 평가 방식
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)  # 처음 보는 데이터로 평가해야 진짜 실력!
r2 = r2_score(y_test, y_pred)

    시험 문제를 미리 알고 공부하면 100점 맞는 건 당연하겠죠? 반드시 학습에 사용하지 않은 데이터로 평가해야 합니다.

    실수 3: 비선형 관계에 직선을 억지로 적용 🔴¶

    데이터가 곡선 형태인데 직선으로 모델링하면 R²가 낮게 나옵니다. 항상 산점도를 먼저 확인하세요!

    # 산점도를 먼저 그려서 확인하는 습관을 들이세요
plt.scatter(X, y)
plt.show()
# → 점들이 직선 형태? ✅ 선형 회귀 OK
# → 점들이 곡선 형태? ⚠️ 다른 방법 고려 (다항 회귀 등)

    실수 4: 예측 시 입력 데이터 형식 오류 🔴¶

    # ❌ 잘못된 예측
model.predict(5)        # 숫자 하나를 그냥 넣으면 에러

# ✅ 올바른 예측

    • 모델 B: MSE = 8.3, R² = 0.93

    • 💬 답: 모델 B (MSE가 더 작고, R²가 더 높으므로)

    • Q5. model.coef_ = [3.5], model.intercept_ = 12.0일 때, 이 모델의 예측 공식을 쓸 수 있나요?

    • 💬 답: y = 3.5x + 12.0

    심화 문제

    • Q6. 학습 데이터에서 R² = 0.99인데 테스트 데이터에서 R² = 0.45라면, 어떤 문제가 의심되나요?
    • 💬 힌트: 9장에서 배운 개념 — 과대적합(overfitting)

    🌟 도전 1: 나만의 데이터로 회귀 분석

    자신만의 데이터를 만들어서 회귀 모델을 학습시켜보세요. 예시 아이디어:

    • 운동 시간 → 체중 변화
    • 수면 시간 → 집중력 점수
    • 기온 → 아이스크림 판매량

    🌟 도전 2: 다중 선형 회귀 맛보기

    입력 변수가 2개 이상인 경우도 scikit-learn에서 쉽게 처리할 수 있습니다!

    # 공부 시간 + 수면 시간 → 시험 점수
X_multi = np.array([
    [1, 5], [2, 6], [3, 7], [4, 8], [5, 7],
    [6, 6], [7, 8], [8, 7], [3, 5], [5, 9]
])
y_multi = np.array([25, 35, 50, 60, 65, 70, 85, 88, 40, 72])

model_multi = LinearRegression()
model_multi.fit(X_multi, y_multi)

print(f"공부시간 기울기: {model_multi.coef_[0]:.2f}")
print(f"수면시간 기울기: {model_multi.coef_[1]:.2f}")
print(f"절편: {model_multi.intercept_:.2f}")

# 공부 4시간, 수면 7시간인 학생의 예상 점수는?
print(f"예상 점수: {model_multi.predict([[4, 7]])[0]:.1f}점")

    🔗 다음 장으로¶

    📌 정리하기: 이번 장에서 우리는 회귀 분석의 핵심을 배웠습니다.

    • 회귀: 연속적인 숫자를 예측하는 머신러닝 기법
    • 단순 선형 회귀: y = wx + b 형태의 직선으로 관계를 표현
    • 최소제곱법: 오차의 제곱합을 최소로 만드는 w, b를 찾는 방법
    • MSE와 R²: 모델의 예측 정확도를 정량적으로 평가하는 지표

    이번 장에서는 하나의 직선으로 데이터를 설명했습니다. 하지만 현실 세계의 데이터는 단순한 직선으로는 설명하기 어려운 경우가 많습니다.

    다음 장 "모델 평가와 개선"에서는 학습 데이터와 테스트 데이터를 체계적으로 나누는 교차 검증(Cross-Validation) 기법과, 모델의 과대적합/과소적합 문제를 진단하고 개선하는 방법을 배웁니다. 회귀든 분류든, 모델을 만든 후 제대로 평가하고 개선하는 것이 진짜 실력입니다! 💪

    Chapter 10: 동일한 데이터의 다양한 분석 및 비교¶

    Part 2 | [1권] 데이터 준비와 분석 — 10차시

    🎯 이 장에서 배우는 것¶

    • 같은 데이터를 막대그래프, 원그래프, 선그래프, 트리맵 등 다양한 시각화로 표현할 수 있다
    • 시각화 방법에 따라 전달되는 메시지가 달라질 수 있음을 이해할 수 있다
    • 분석 목적에 적합한 시각화 방법을 선택하고 그 이유를 설명할 수 있다
    • 오해를 유발하는 그래프의 문제점을 파악하고 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔 어떤 회사의 매출이 100억 → 102억 → 104억으로 변했습니다. 선그래프로 그리면 "꾸준히 성장 중!"이라고 느껴지는데, Y축을 0부터 시작하는 막대그래프로 그리면 "거의 변화 없네…"로 보입니다. 같은 숫자인데 왜 느낌이 다를까요?

    데이터 자체는 객관적이지만, 어떻게 보여주느냐에 따라 사람들이 받는 인상은 완전히 달라집니다. 뉴스, 보고서, 광고에서 우리는 매일 그래프를 접합니다. 시각화 방법을 잘 선택하면 핵심 메시지를 정확히 전달할 수 있고, 잘못 선택하면 오해를 만들 수 있습니다.

    이번 장에서는 하나의 데이터셋을 여러 방식으로 시각화해보면서, 각 그래프의 강점과 약점을 직접 체감해 보겠습니다.

    📚 핵심 개념¶

    개념 1: 시각화 유형별 특성 🎨¶

    비유로 시작

    같은 풍경이라도 사진, 수채화, 흑백 스케치로 그리면 전혀 다른 느낌을 줍니다. 사진은 사실적이고, 수채화는 분위기를, 스케치는 구조를 잘 보여주죠. 그래프도 마찬가지입니다. 같은 데이터라도 그래프 유형에 따라 강조되는 정보가 다릅니다.

    정확한 정의

    시각화 유형이란 데이터를 시각적으로 표현하는 형태를 말합니다. 대표적인 유형은 다음과 같습니다.

    • 막대그래프(Bar Chart): 범주(카테고리)별 값의 크기 비교에 최적
    • 선그래프(Line Chart): 시간에 따른 변화 추세를 보여줄 때 최적
    • 원그래프(Pie Chart): 전체에서 각 부분이 차지하는 비율(구성)을 보여줄 때 사용
    • 트리맵(Treemap): 계층 구조를 가진 데이터의 비율과 규모를 면적으로 표현
    • 히트맵(Heatmap): 두 변수 간의 관계 강도를 색상으로 표현

    예시로 확인

    "우리 반 학생 30명의 좋아하는 과일" 데이터가 있다면: - 막대그래프 → 사과가 몇 명, 바나나가 몇 명인지 수를 비교 - 원그래프 → 사과가 전체의 몇 %인지 비율을 파악 - 트리맵 → 면적 크기로 한눈에 인기 순위를 직감

    개념 2: 같은 데이터, 다른 메시지 📊¶

    비유로 시작

    코끼리를 만지는 장님 이야기를 아시나요? 다리를 만진 사람은 "기둥 같다", 코를 만진 사람은 "뱀 같다"고 했습니다. 같은 코끼리인데 어디를 보느냐에 따라 해석이 달라진 것이죠. 시각화도 동일합니다.

    정확한 정의

    시각적 프레이밍(Visual Framing) 이란 동일한 데이터를 특정 시각화 방식으로 표현함으로써 보는 사람의 해석과 판단에 영향을 주는 현상입니다.

    예시로 확인

    연도별 매출 데이터 [100, 102, 104, 107, 110]을 생각해 봅시다.

    • 선그래프 (Y축 95~115): 급격한 상승처럼 보임 → "놀라운 성장!"
    • 막대그래프 (Y축 0~200): 거의 변화 없어 보임 → "정체 상태?"
    • 원그래프 (각 연도 비율): 모두 약 20%씩 → "고르게 분포" (추세 정보 소실)

    💡 알아보기: 같은 숫자라도 Y축의 범위, 그래프 유형, 색상 강조 등에 따라 전혀 다른 이야기를 할 수 있습니다. 이것이 바로 "데이터 리터러시"가 중요한 이유입니다.

    개념 3: 목적에 따른 시각화 선택 기준 🎯¶

    비유로 시작

    못을 박을 때는 망치를, 나사를 돌릴 때는 드라이버를 씁니다. 도구에는 각각 최적의 용도가 있듯이, 그래프에도 "이 질문에는 이 그래프" 라는 적합한 짝이 있습니다.

    정확한 정의

    시각화 선택 기준이란 분석 목적(질문) 에 따라 가장 효과적으로 정보를 전달하는 그래프 유형을 결정하는 원칙입니다.

    flowchart TD Q["내가 보여주고 싶은 것은?"] Q --> A["크기 비교"] Q --> B["시간 변화"] Q --> C["부분의 비율"] Q --> D["관계/상관"] A --> A1["막대그래프"] B --> B1["선그래프"] C --> C1["원그래프 / 트리맵"] D --> D1["산점도 / 히트맵"]

    예시로 확인

    • "지역별 인구가 얼마나 차이 나지?" → 막대그래프
    • "최근 10년간 인구가 어떻게 변했지?" → 선그래프
    • "수도권 인구가 전체의 몇 %지?" → 원그래프
    • "인구와 면적 사이에 관계가 있을까?" → 산점도

    개념 4: 오해를 유발하는 시각화 ⚠️¶

    비유로 시작

    사진을 찍을 때 앵글을 낮추면 사람이 커 보이고, 높이면 작아 보입니다. 사진 속 사람의 실제 키는 같은데, 촬영 방법이 왜곡을 만든 거죠. 그래프도 의도적으로든 무심코든 이런 왜곡이 발생할 수 있습니다.

    정확한 정의

    오해 유발 시각화(Misleading Visualization) 란 축 범위 조작, 3D 효과, 면적 왜곡 등의 기법으로 데이터의 실제 의미와 다른 인상을 주는 그래프를 말합니다.

    대표적인 사례 3가지

    • Y축 잘라내기: 0부터 시작하지 않아 작은 차이가 크게 보임
    • 3D 원그래프: 앞쪽 조각이 실제보다 크게 보이는 원근 왜곡
    • 이중 Y축 남용: 서로 관계없는 두 변수가 마치 인과관계가 있는 것처럼 보임

    ⚠️ 정리하기: 그래프를 만들 때는 항상 "이 그래프가 데이터를 정직하게 보여주고 있는가?"를 점검해야 합니다.

    🔨 따라하기: 대한민국 지역별 인구 데이터로 5가지 시각화 만들기¶

    이제 하나의 데이터를 5가지 다른 그래프로 시각화해 보겠습니다.

    Step 1: 데이터 준비하기¶

    import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
import numpy as np

# 한글 폰트 설정 (Google Colab 기준)
plt.rcParams['font.family'] = 'NanumGothic'
plt.rcParams['axes.unicode_minus'] = False

# 대한민국 주요 지역별 인구 데이터 (2023년 기준, 단위: 만 명)
regions = ['서울', '경기', '부산', '대구', '인천', '광주', '대전', '울산']
population = [950, 1340, 330, 240, 295, 145, 145, 112]

print("✅ 데이터 준비 완료!")
print(f"지역 수: {len(regions)}개")
print(f"총 인구: {sum(population)}만 명")

    💡 알아보기: Colab에서 한글이 깨진다면 !apt-get install fonts-nanum을 먼저 실행하고 런타임을 재시작하세요.

    Step 2: 막대그래프 — 크기 비교에 최적¶

    plt.figure(figsize=(10, 5))
colors = plt.cm.Set2(range(len(regions)))
bars = plt.bar(regions, population, color=colors, edgecolor='gray')

# 막대 위에 수치 표시
for bar, pop in zip(bars, population):
    plt.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 15,
             f'{pop}', ha='center', fontsize=11, fontweight='bold')

plt.title('지역별 인구 비교 (막대그래프)', fontsize=16, fontweight='bold')
plt.ylabel('인구 (만 명)')
plt.ylim(0, 1500)
plt.tight_layout()
plt.show()

    생각해보기 🤔 이 그래프에서 가장 먼저 눈에 들어오는 정보는 무엇인가요? → "경기도가 가장 많고, 울산이 가장 적다"는 크기 순서가 바로 보입니다.

    Step 3: 원그래프 — 비율 파악에 최적¶

    plt.figure(figsize=(8, 8))
explode = [0.05 if p > 500 else 0 for p in population]  # 큰 지역 강조

plt.pie(population, labels=regions, autopct='%1.1f%%',
        startangle=90, explode=explode,
        colors=plt.cm.Pastel1(range(len(regions))),
        textprops={'fontsize': 12})

plt.title('지역별 인구 비율 (원그래프)', fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

    생각해보기 🤔 원그래프에서는 "서울+경기가 전체의 약 64%를 차지한다"는 비율 정보가 핵심으로 전달됩니다. 반면 울산과 대전의 차이(약 33만)는 거의 구분이 안 되죠.

    Step 4: 선그래프 — 이 데이터에 적합할까?¶

    plt.figure(figsize=(10, 5))
plt.plot(regions, population, marker='o', linewidth=2,
         markersize=8, color='coral')
plt.fill_between(range(len(regions)), population, alpha=0.2, color='coral')

plt.title('지역별 인구 (선그래프)', fontsize=16, fontweight='bold')
plt.ylabel('인구 (만 명)')
plt.tight_layout()
plt.show()

    ⚠️ 주의! 이 그래프는 기술적으로 틀리진 않지만 적절하지 않습니다. 선그래프는 X축이 연속적인 시간이나 순서일 때 의미가 있습니다. "서울 → 경기 → 부산"은 연속적 관계가 아니므로, 선으로 연결하면 마치 변화가 있는 것 같은 잘못된 인상을 줍니다.

    Step 5: 수평 막대그래프 — 긴 이름에 효과적¶

    plt.figure(figsize=(8, 6))

# 인구 순으로 정렬
sorted_data = sorted(zip(population, regions))
sorted_pop, sorted_reg = zip(*sorted_data)

colors = plt.cm.YlOrRd(np.linspace(0.2, 0.8, len(regions)))
plt.barh(sorted_reg, sorted_pop, color=colors, edgecolor='gray')

for i, pop in enumerate(sorted_pop):
    plt.text(pop + 10, i, f'{pop}만', va='center', fontsize=11)

plt.title('지역별 인구 순위 (수평 막대그래프)', fontsize=16, fontweight='bold')
plt.xlabel('인구 (만 명)')
plt.tight_layout()
plt.show()

    💡 알아보기: 수평 막대그래프는 순위(랭킹) 를 보여줄 때 특히 효과적입니다. 위에서 아래로 크기 순으로 정렬하면 순위가 직관적으로 전달됩니다.

    Step 6: 트리맵 — 면적으로 규모 직감¶

    # squarify 라이브러리 설치 (Colab에서는 아래 주석 해제)

              alpha=0.85, text_kwargs={'fontsize': 13, 'fontweight': 'bold'},
              edgecolor='white', linewidth=3)

    ⚠️ 자주 하는 실수¶

    실수 1: 범주형 데이터에 선그래프 사용

    선그래프의 선은 "점과 점 사이에 연속적인 변화가 있다"는 의미입니다. 지역명처럼 순서가 없는 범주형 데이터에 선그래프를 쓰면, 마치 서울에서 경기로 "변화"가 일어난 것 같은 잘못된 인상을 줍니다.

    ✅ 해결법: X축이 시간이나 연속적 순서인지 먼저 확인하세요. 아니라면 막대그래프를 사용하세요.

    실수 2: 원그래프에 너무 많은 조각 넣기

    원그래프에 10개 이상의 조각이 들어가면, 비슷한 크기의 조각들이 구분되지 않아 오히려 정보 전달력이 떨어집니다.

    ✅ 해결법: 원그래프는 5~6개 이하의 범주일 때 사용하세요. 범주가 많으면 막대그래프나 트리맵이 더 좋습니다.

    실수 3: Y축을 0부터 시작하지 않기 (의도 없이)

    Y축을 잘라내면 작은 차이가 과장되어 보입니다. 의도적으로 특정 범위를 확대하는 경우가 아니라면, 항상 0부터 시작하는 것이 데이터를 정직하게 보여주는 방법입니다.

    ✅ 해결법: plt.ylim(0, ...) 으로 Y축 시작점을 명시적으로 지정하세요.

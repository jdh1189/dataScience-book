    18장. 슬기로운 의사 생활 (2) — 모델링과 결과 해석¶

    Part 4 | [2권] 데이터 과학 프로젝트 — 교과서 주제 실습

    🎯 이 장에서 배우는 것¶

    • 건강 데이터에 로지스틱 회귀 모델을 적용하여 질병 위험도를 예측할 수 있다
    • 정확도, 정밀도, 재현율 등 분류 모델의 성능 평가 지표를 계산하고 해석할 수 있다
    • Feature Importance를 통해 예측에 가장 크게 기여한 변수를 찾아낼 수 있다
    • 분석 결과를 시각화하고, 건강 관련 인사이트를 담은 보고서를 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 건강 검진을 받으면 의사 선생님은 혈압, 혈당, 콜레스테롤 같은 여러 수치를 종합해서 "건강 위험군"인지 판단합니다. 그런데 이 판단은 어떻게 이루어질까요?

    현대 의학에서는 데이터 기반 예측 모델이 의사의 판단을 돕고 있습니다. 수천, 수만 명의 과거 건강 데이터를 학습한 모델이 "이 환자는 당뇨 위험이 높습니다"라고 알려주는 것이죠.

    이전 챕터(17장)에서 우리는 건강 데이터를 수집하고, 결측치를 처리하고, 탐색적 분석을 했습니다. 이제 그 데이터로 실제 예측 모델을 만들고, 그 결과를 해석하는 단계로 나아갑니다.

    🏥 실제 사례: 구글의 DeepMind는 환자의 안구 사진만으로 50가지 이상의 눈 질환을 예측하는 AI를 만들었습니다. 이 장에서 배우는 원리가 바로 그 출발점입니다!

    📚 핵심 개념¶

    개념 1: 분류 모델 — "이 환자는 위험군인가?"¶

    🎭 비유로 시작

    학교 급식실에서 알레르기가 있는 학생을 구분한다고 상상해 봅시다. 급식 선생님은 학생의 알레르기 카드(우유, 계란, 밀가루 등)를 보고 "이 학생은 오늘 메뉴를 먹으면 안 된다" 또는 "괜찮다"로 분류합니다. 분류 모델도 마찬가지입니다. 여러 건강 수치(입력)를 보고 "위험군이다(1)" 또는 "정상이다(0)"로 나누는 것이죠.

    📖 정확한 정의

    분류(Classification) 모델은 입력 데이터를 미리 정해진 카테고리(클래스)로 나누는 머신러닝 기법입니다. 건강 데이터에서는 주로 이진 분류(위험/정상)를 사용합니다.

    대표적인 분류 모델은 다음과 같습니다.

    • 로지스틱 회귀(Logistic Regression): 이름에 "회귀"가 들어가지만 분류 모델입니다. 결과를 0~1 사이의 확률로 출력하며, 보통 0.5를 기준으로 분류합니다
    • 결정 트리(Decision Tree): "혈당이 140 이상인가?" → "BMI가 30 이상인가?"처럼 질문을 이어가며 분류합니다
    • 랜덤 포레스트(Random Forest): 결정 트리 여러 개를 모아서 다수결로 판단합니다
    flowchart LR A["🏥 환자 데이터<br/>혈압, 혈당, BMI..."] --> B["🤖 분류 모델"] B --> C{"예측 확률"} C -->|"0.5 이상"| D["⚠️ 위험군"] C -->|"0.5 미만"| E["✅ 정상군"]

    ✏️ 예시로 확인

    환자 A의 데이터가 다음과 같다고 합시다.

    • 혈당: 180 mg/dL (높음)
    • BMI: 32 (비만)
    • 혈압: 150/95 mmHg (고혈압)

    로지스틱 회귀 모델이 이 데이터를 받으면, 내부적으로 각 수치에 가중치를 곱하고 합산한 뒤, 시그모이드 함수를 통과시켜 0.82 같은 확률을 출력합니다. 0.5보다 크므로 "위험군"으로 분류됩니다.

    개념 2: 훈련/테스트 분할 — "시험 문제를 미리 보면 안 된다"¶

    🎭 비유로 시작

    시험 공부를 할 때, 기출문제로 연습한 다음 실전 시험을 봅니다. 만약 실전 시험 문제를 미리 알고 있었다면? 100점을 맞겠지만, 진짜 실력은 알 수 없죠. 머신러닝도 마찬가지입니다. 모델이 학습에 사용한 데이터로 성능을 측정하면, 실제 성능보다 과대평가됩니다.

    📖 정확한 정의

    훈련/테스트 분할(Train/Test Split)은 전체 데이터를 두 부분으로 나누는 것입니다.

    • 훈련 세트(Train Set): 모델이 패턴을 학습하는 데이터 (보통 전체의 70~80%)
    • 테스트 세트(Test Set): 모델의 진짜 실력을 측정하는 데이터 (보통 전체의 20~30%)
    flowchart LR A["📊 전체 데이터<br/>768명"] --> B["✂️ 분할"] B --> C["📘 훈련 세트<br/>614명 (80%)"] B --> D["📗 테스트 세트<br/>154명 (20%)"] C --> E["🤖 모델 학습"] E --> F["📗 테스트로 평가"] D --> F

    ✏️ 예시로 확인

    768명의 건강 데이터가 있다면, 614명의 데이터로 모델을 훈련시키고, 나머지 154명의 데이터로 "이 환자가 당뇨인지" 맞추는지 확인합니다. 614명의 답은 이미 알려줬지만, 154명의 답은 모델이 모르는 상태에서 예측하게 합니다.

    💡 알아보기: 왜 하필 80:20으로 나눌까요? 훈련 데이터가 너무 적으면 학습이 부족하고, 테스트 데이터가 너무 적으면 평가가 불안정합니다. 80:20 또는 70:30이 경험적으로 좋은 균형입니다.

    개념 3: 성능 평가 지표 — "모델이 얼마나 잘했나?"¶

    🎭 비유로 시작

    야구 선수의 실력을 평가할 때 타율 하나만 보나요? 아닙니다. 타율, 출루율, 장타율, 타점 등 여러 지표를 종합합니다. 모델도 마찬가지로, 여러 지표를 함께 봐야 진짜 성능을 알 수 있습니다.

    📖 정확한 정의

    분류 모델의 성능을 평가하는 핵심 지표 네 가지입니다.

    • 정확도(Accuracy): 전체 예측 중 맞춘 비율. "100명 중 85명을 맞췄다 → 85%"
    • 정밀도(Precision): "위험군이라고 예측한 사람 중" 실제 위험군인 비율. "위험군이라고 한 40명 중 35명이 진짜 위험군 → 87.5%"
    • 재현율(Recall): "실제 위험군 중" 모델이 찾아낸 비율. "실제 위험군 50명 중 35명을 찾음 → 70%"
    • F1 점수(F1 Score): 정밀도와 재현율의 조화 평균. 두 지표의 균형을 봅니다
    flowchart TD A["🔍 모델의 예측 결과"] --> B["✅ 진양성 TP<br/>위험군이라 했고, 실제로 위험군"] A --> C["❌ 거짓양성 FP<br/>위험군이라 했지만, 실제론 정상"] A --> D["❌ 거짓음성 FN<br/>정상이라 했지만, 실제론 위험군"] A --> E["✅ 진음성 TN<br/>정상이라 했고, 실제로 정상"]

    ⚠️ 생각해보기: 의료 분야에서 "거짓음성(FN)"은 특히 위험합니다. 실제로 아픈 사람을 "정상"이라고 잘못 판단하는 것이니까요! 그래서 의료 AI에서는 재현율을 특히 중요하게 봅니다.

    ✏️ 예시로 확인

    테스트 데이터 154명에 대한 모델 결과가 이렇다고 합시다.

    • 진양성(TP): 40명 — 위험군을 위험군으로 올바르게 예측
    • 거짓양성(FP): 10명 — 정상인을 위험군으로 잘못 예측
    • 거짓음성(FN): 12명 — 위험군을 정상으로 잘못 예측
    • 진음성(TN): 92명 — 정상인을 정상으로 올바르게 예측

    이 경우 각 지표를 계산하면 다음과 같습니다.

    • 정확도 = (40 + 92) / 154 = 85.7%
    • 정밀도 = 40 / (40 + 10) = 80.0%
    • 재현율 = 40 / (40 + 12) = 76.9%
    • F1 점수 = 2 × (80.0 × 76.9) / (80.0 + 76.9) = 78.4%

    개념 4: Feature Importance — "어떤 요인이 가장 중요한가?"¶

    🎭 비유로 시작

    축구 경기에서 승리에 가장 크게 기여한 선수는 누구일까요? 골을 넣은 공격수? 어시스트한 미드필더? 아니면 결정적인 세이브를 한 골키퍼? Feature Importance는 예측 결과에 각 변수(선수)가 얼마나 기여했는지를 수치로 보여줍니다.

    📖 정확한 정의

    Feature Importance(변수 중요도)는 모델이 예측할 때 각 입력 변수가 결과에 미치는 영향력의 크기입니다. 값이 클수록 해당 변수가 예측에 더 큰 역할을 했다는 뜻입니다.

    확인하는 방법은 모델마다 다릅니다.

    • 로지스틱 회귀: 각 변수의 회귀 계수(coefficient) 절대값으로 판단
    • 결정 트리 / 랜덤 포레스트: 각 변수가 데이터를 얼마나 잘 나누는지(불순도 감소량)로 계산
    • 공통: 막대 그래프로 시각화하여 한눈에 비교

    ✏️ 예시로 확인

    당뇨 예측 모델에서 Feature Importance 결과가 이렇게 나왔다면:

    • 혈당(Glucose): 0.35 — 가장 중요!
    • BMI: 0.22
    • 나이(Age): 0.15
    • 혈압(BloodPressure): 0.10
    • 기타 변수들: 0.18

    이 결과는 "당뇨 예측에 혈당 수치가 가장 큰 영향을 미친다"는 의미입니다. 의학적으로도 당연한 결과이죠! 이처럼 Feature Importance는 모델이 내린 판단의 근거를 설명해 줍니다.

    Step 1: 데이터 준비와 라이브러리 불러오기¶

    먼저 필요한 라이브러리를 불러오고, 데이터를 준비합니다.

    # 필요한 라이브러리 불러오기
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 머신러닝 관련 라이브러리
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import (accuracy_score, precision_score, 
                             recall_score, f1_score,
                             confusion_matrix, classification_report)

# 한글 폰트 설정 (코랩용)
plt.rcParams['font.family'] = 'DejaVu Sans'
plt.rcParams['figure.figsize'] = (10, 6)

# 시드 고정 (같은 결과를 재현하기 위해)
np.random.seed(42)

print("✅ 라이브러리 로드 완료!")

    # Pima Indians 당뇨 데이터셋 로드
url = "https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv"

# 컬럼 이름 지정
columns = ['Pregnancies', 'Glucose', 'BloodPressure', 'SkinThickness',
           'Insulin', 'BMI', 'DiabetesPedigreeFunction', 'Age', 'Outcome']

df = pd.read_csv(url, names=columns)

print(f"📊 데이터 크기: {df.shape[0]}명, {df.shape[1]}개 변수")
print(f"\n🏷️ 타깃 변수(Outcome) 분포:")
print(f"   정상(0): {(df['Outcome'] == 0).sum()}명")
print(f"   당뇨(1): {(df['Outcome'] == 1).sum()}명")
df.head()

    💡 알아보기: Outcome 열이 우리가 예측할 타깃 변수입니다. 0은 당뇨가 아닌 사람, 1은 당뇨인 사람을 의미합니다.

    # 17장에서 배운 전처리: 0값을 중앙값으로 대체
zero_columns = ['Glucose', 'BloodPressure', 'SkinThickness', 'Insulin', 'BMI']

for col in zero_columns:
    zero_count = (df[col] == 0).sum()
    if zero_count > 0:
        median_val = df[col][df[col] != 0].median()
        df[col] = df[col].replace(0, median_val)
        print(f"  {col}: {zero_count}개의 0값 → 중앙값({median_val})으로 대체")

print("\n✅ 전처리 완료!")

    Step 2: 훈련/테스트 분할 및 스케일링¶

    데이터를 모델이 학습할 부분과 평가할 부분으로 나눕니다.

    # 특성(X)과 타깃(y) 분리
X = df.drop('Outcome', axis=1)  # Outcome 열을 제외한 나머지가 입력
y = df['Outcome']                # Outcome 열이 예측 대상

print(f"📥 입력 변수(X): {X.shape} — {list(X.columns)}")
print(f"🎯 타깃 변수(y): {y.shape}")

    # 80:20으로 훈련/테스트 분할
X_train, X_test, y_train, y_test = train_test_split(
    X, y, 
    test_size=0.2,      # 20%를 테스트용으로
    random_state=42,     # 재현 가능하도록 시드 고정
    stratify=y           # 당뇨/정상 비율을 유지하며 분할
)

print(f"📘 훈련 세트: {X_train.shape[0]}명")
print(f"📗 테스트 세트: {X_test.shape[0]}명")
print(f"\n📊 훈련 세트 당뇨 비율: {y_train.mean():.1%}")
print(f"📊 테스트 세트 당뇨 비율: {y_test.mean():.1%}")

    💡 알아보기: stratify=y는 무엇일까요? 원본 데이터에서 당뇨 환자 비율이 35%라면, 훈련 세트와 테스트 세트 모두 약 35%가 되도록 분할하는 옵션입니다. 이렇게 하지 않으면, 운 나쁘게 테스트 세트에 당뇨 환자가 거의 없을 수도 있습니다.

    # 스케일링: 변수들의 단위를 통일
scaler = StandardScaler()

# 훈련 데이터로 기준을 정하고(fit), 변환(transform)
X_train_scaled = scaler.fit_transform(X_train)
# 테스트 데이터는 훈련 기준으로 변환만(transform)
X_test_scaled = scaler.transform(X_test)

print("✅ 스케일링 완료!")
print(f"   스케일링 전 Glucose 평균: {X_train['Glucose'].mean():.1f}")
print(f"   스케일링 후 Glucose 평균: {X_train_scaled[:, 1].mean():.4f}")

    ⚠️ 주의: 스케일링할 때 fit_transform은 훈련 데이터에만 사용합니다. 테스트 데이터에는 transform만 사용해야 합니다. 왜냐하면, 테스트 데이터의 정보가 훈련 과정에 새어들어가면("데이터 누수") 평가가 부정확해지기 때문입니다.

    Step 3: 로지스틱 회귀 모델 학습¶

    이제 본격적으로 모델을 만들고 학습시킵니다.

    # 로지스틱 회귀 모델 생성 및 학습
model_lr = LogisticRegression(max_iter=1000, random_state=42)
model_lr.fit(X_train_scaled, y_train)

print("✅ 로지스틱 회귀 모델 학습 완료!")
print(f"   학습에 사용된 데이터: {X_train_scaled.shape[0]}명")

    # 테스트 데이터로 예측
y_pred = model_lr.predict(X_test_scaled)         # 0 또는 1로 예측
y_prob = model_lr.predict_proba(X_test_scaled)[:, 1]  # 당뇨일 확률

# 처음 10명의 예측 결과 확인
print("🔍 처음 10명의 예측 결과:\n")
print(f"{'번호':>4}  {'실제':>4}  {'예측':>4}  {'확률':>8}")
print("-" * 28)
for i in range(10):
    actual = '당뇨' if y_test.iloc[i] == 1 else '정상'
    predicted = '당뇨' if y_pred[i] == 1 else '정상'
    match = '✅' if y_test.iloc[i] == y_pred[i] else '❌'
    print(f"{i+1:>4}  {actual:>4}  {predicted:>4}  {y_prob[i]:>7.1%}  {match}")

    💡 알아보기: predict_proba는 각 클래스에 속할 확률을 알려줍니다. 단순히 0/1이 아니라 "이 환자가 당뇨일 확률이 73%입니다"처럼 확신의 정도를 알 수 있어서, 의료 현장에서 매우 유용합니다.

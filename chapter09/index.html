    Chapter 09. 데이터 속성 간의 관계 파악¶

    Part 2 | [1권] 데이터 준비와 분석 — 9차시

    🎯 이 장에서 배우는 것¶

    • 산점도를 그려 두 변수 사이의 관계를 시각적으로 확인할 수 있다
    • 상관계수(corr)를 계산하고 양의 상관·음의 상관·무상관을 판별할 수 있다
    • seaborn heatmap으로 여러 변수의 상관관계를 한눈에 파악할 수 있다
    • 상관관계와 인과관계의 차이를 사례를 들어 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    "아이스크림 판매량이 늘어나면 익사 사고도 늘어난다." 그렇다면… 아이스크림이 위험한 걸까요?

    당연히 아닙니다! 여름이 되면 아이스크림도 많이 먹고, 물놀이도 많이 하니까 두 숫자가 동시에 올라갈 뿐이죠. 진짜 원인은 "더운 날씨" 입니다.

    데이터를 다루다 보면 "A가 올라가면 B도 올라가네?"처럼 속성들 사이의 관계(패턴)를 발견하게 됩니다. 이 관계를 제대로 파악하면 예측 모델의 기초를 쌓을 수 있고, 잘못 해석하면 아이스크림이 익사의 원인이라는 엉뚱한 결론을 내리게 됩니다.

    이 장에서는 관계를 눈으로 보고(산점도), 숫자로 측정하고(상관계수), 올바르게 해석하는(인과 vs 상관) 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 산점도 — 점 찍기 놀이 🎯¶

    ① 비유로 시작

    교실에서 "키 vs 발 크기"를 조사한다고 상상해 보세요. 칠판에 가로축을 키, 세로축을 발 크기로 잡고, 친구 한 명당 점 하나를 찍습니다. 점들이 모이면 "키가 클수록 발도 크구나!" 같은 패턴이 보이죠. 이것이 바로 산점도(Scatter Plot)입니다.

    ② 정확한 정의

    산점도란 두 개의 수치형 변수를 각각 가로축(x)과 세로축(y)에 놓고, 데이터 한 건을 한 개의 점으로 표현한 그래프입니다.

    ③ 예시로 확인

    • 점들이 오른쪽 위로 올라가는 패턴 → 양의 관계 (공부 시간↑ → 점수↑)
    • 점들이 오른쪽 아래로 내려가는 패턴 → 음의 관계 (게임 시간↑ → 점수↓)
    • 점들이 흩어져 있으면 → 뚜렷한 관계 없음
    graph LR A["점이 우상향 ↗"] -->|"양의 관계"| B["예: 공부 시간 vs 점수"] C["점이 우하향 ↘"] -->|"음의 관계"| D["예: 결석 일수 vs 점수"] E["점이 흩어짐 ••"] -->|"무상관"| F["예: 신발 크기 vs 점수"]

    개념 2: 상관계수 — 관계의 강도를 숫자로 📏¶

    ① 비유로 시작

    산점도가 "눈으로 보는 관계"라면, 상관계수는 "관계에 점수를 매기는 채점표" 입니다. 시험 점수처럼 딱 숫자 하나로 "얼마나 강한 관계인지" 알려 줍니다.

    ② 정확한 정의

    피어슨 상관계수(r)는 두 변수 사이의 직선적 관계의 강도와 방향을 나타내는 값으로, -1부터 +1 사이의 숫자입니다.

    • r = +1 : 완벽한 양의 직선 관계
    • r = 0 : 직선 관계 없음
    • r = -1 : 완벽한 음의 직선 관계

    ③ 해석 기준 (대략적)

    • |r| ≥ 0.7 → 강한 상관
    • 0.3 ≤ |r| < 0.7 → 보통 상관
    • |r| < 0.3 → 약한 상관 (거의 없음)

    알아보기 📌

    |r|은 절댓값입니다. r이 -0.8이면 음의 방향으로 강한 상관이라는 뜻이에요. 부호는 방향, 절댓값은 강도!

    개념 3: 히트맵 — 상관관계 지도 🗺️¶

    ① 비유로 시작

    날씨 앱의 기온 지도를 떠올려 보세요. 빨간 지역은 더운 곳, 파란 지역은 추운 곳이죠. 히트맵(Heatmap)도 같은 원리입니다. 상관계수를 색깔 강도로 바꿔서, 변수들 사이의 관계를 한눈에 볼 수 있게 합니다.

    ② 정확한 정의

    히트맵은 행과 열에 변수를 배치하고, 셀마다 상관계수 값을 색상으로 표현한 시각화입니다. 변수가 5개면 5×5 = 25칸의 색상 격자가 만들어지죠.

    ③ 예시로 확인

    • 짙은 빨강/파랑 → 강한 상관 (주목할 관계!)
    • 연한 색 / 흰색 → 약한 상관 (별 관계 없음)

    개념 4: 상관관계 ≠ 인과관계 ⚠️¶

    ① 비유로 시작

    "소방차가 많이 출동할수록 피해 금액이 크다." 그러면 소방차를 안 보내면 피해가 줄까요? 🚒 아닙니다. 큰 불이 나면 소방차도 많이 가고, 피해도 커지는 것뿐입니다.

    ② 정확한 정의

    • 상관관계(Correlation) : 두 변수가 함께 변하는 패턴이 있다는 것
    • 인과관계(Causation) : 한 변수가 다른 변수의 원인이 된다는 것

    상관관계가 있다고 해서 인과관계가 반드시 있는 것은 아닙니다!

    ③ 대표적인 혼동 사례

    graph TD subgraph 진짜_원인["🌡️ 숨은 변수: 더운 날씨"] H["기온 상승"] end H --> I["🍦 아이스크림 판매 ↑"] H --> J["🏊 물놀이 증가 → 익사 사고 ↑"] I -. "상관관계<br/>(인과 아님!)" .-> J

    🔨 따라하기¶

    Google Colab을 열고, 아래 코드를 한 단계씩 실행해 봅시다.

    Step 1: 데이터 준비하기¶

    학생 20명의 성적 데이터를 직접 만듭니다.

    import pandas as pd
import numpy as np

# 재현 가능하도록 시드 고정
np.random.seed(42)

n = 20
study_hours = np.random.uniform(1, 8, n).round(1)       # 공부 시간(h)
sleep_hours = np.random.uniform(4, 9, n).round(1)        # 수면 시간(h)
score = (study_hours * 8 + sleep_hours * 3
         + np.random.normal(0, 5, n)).round(0)            # 시험 점수
shoe_size = np.random.uniform(230, 280, n).round(0)      # 신발 크기(mm)

df = pd.DataFrame({
    '공부시간': study_hours,
    '수면시간': sleep_hours,
    '시험점수': score,
    '신발크기': shoe_size
})

print(df.head(10))

    알아보기 📌

    score를 만들 때 study_hours * 8을 넣었으므로, 공부 시간과 점수는 양의 상관이 나올 것입니다. 반면 신발 크기는 점수와 아무 관련 없이 랜덤으로 만들었으니 무상관에 가까울 거예요.

    Step 2: 산점도 그리기¶

    import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))

# 왼쪽: 공부시간 vs 시험점수
plt.subplot(1, 2, 1)
plt.scatter(df['공부시간'], df['시험점수'], color='royalblue', s=60)
plt.xlabel('공부시간 (h)')
plt.ylabel('시험점수')
plt.title('공부시간 vs 시험점수')

# 오른쪽: 신발크기 vs 시험점수
plt.subplot(1, 2, 2)
plt.scatter(df['신발크기'], df['시험점수'], color='tomato', s=60)
plt.xlabel('신발크기 (mm)')
plt.ylabel('시험점수')
plt.title('신발크기 vs 시험점수')

plt.tight_layout()
plt.show()

    실행 결과 해석하기

    • 왼쪽 그래프: 점들이 오른쪽 위로 모이는 패턴 → 공부할수록 점수가 높은 양의 관계
    • 오른쪽 그래프: 점들이 흩어져 있음 → 신발 크기와 점수는 관계 없음

    Step 3: 상관계수 계산하기¶

    # 전체 상관계수 행렬
corr_matrix = df.corr()
print(corr_matrix)

    출력 예시를 보면 공부시간-시험점수의 상관계수는 0.7~0.9 사이 (강한 양의 상관), 신발크기-시험점수는 0 근처 (무상관)로 나타납니다.

    생각해보기 🤔

    수면시간-시험점수의 상관계수는 어떤 값이 나왔나요? 양수인가요, 음수인가요? 값이 0.3보다 큰가요? 결과를 해석해 보세요.

    Step 4: 히트맵으로 시각화하기¶

    import seaborn as sns

plt.figure(figsize=(6, 5))
sns.heatmap(
    corr_matrix,
    annot=True,       # 셀에 숫자 표시
    fmt='.2f',        # 소수점 2자리
    cmap='coolwarm',  # 파랑(-1) ~ 빨강(+1)
    vmin=-1, vmax=1,  # 색상 범위 고정
    square=True       # 정사각형 셀
)
plt.title('상관관계 히트맵')
plt.show()

    읽는 법

    • 대각선은 항상 1.00 (자기 자신과의 상관)
    • 빨간색이 진할수록 강한 양의 상관
    • 파란색이 진할수록 강한 음의 상관
    • 흰색에 가까우면 무상관

    Step 5: 특정 변수 쌍 심화 분석¶

    seaborn의 regplot을 사용하면 산점도 위에 추세선(회귀선)까지 함께 그릴 수 있습니다.

    plt.figure(figsize=(5, 4))
sns.regplot(
    x='공부시간', y='시험점수', data=df,
    scatter_kws={'s': 60},
    line_kws={'color': 'red'}
)
plt.title('공부시간 vs 시험점수 (추세선 포함)')
plt.show()

    추세선이 오른쪽 위로 기울어져 있다면 양의 상관을 시각적으로 한 번 더 확인한 것입니다.

    아래 코드를 하나의 Colab 셀에 복사하면 이 장의 모든 실습을 한 번에 실행할 수 있습니다.

import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 한글 폰트 설정 (Colab 기준)
plt.rcParams['font.family'] = 'NanumGothic'
plt.rcParams['axes.unicode_minus'] = False

# --- 1. 데이터 준비 ---
np.random.seed(42)
n = 20
study_hours = np.random.uniform(1, 8, n).round(1)
sleep_hours = np.random.uniform(4, 9, n).round(1)
score = (study_hours * 8 + sleep_hours * 3
         + np.random.normal(0, 5, n)).round(0)
shoe_size = np.random.uniform(230, 280, n).round(0)

    상관계수는 함께 변하는 패턴만 알려줄 뿐, 원인-결과를 증명하지 않습니다. 항상 숨은 변수(제3의 변수)가 있는지 생각하세요.

    실수 2: 문자열 열이 포함된 상태에서 .corr() 호출하기 🔧

    # ❌ 이름, 성별 같은 문자열 열이 있으면 경고 또는 오류
df_with_name = df.copy()
df_with_name['이름'] = ['학생' + str(i) for i in range(n)]
df_with_name.corr()  # '이름' 열은 자동 제외되지만 혼란 가능

    .corr()는 숫자형 열만 계산합니다. 문자열 열이 섞여 있으면 먼저 select_dtypes(include='number')로 숫자 열만 골라내는 습관을 들이세요.

    # ✅ 안전한 방법
df_with_name.select_dtypes(include='number').corr()

    실수 3: 상관계수의 부호와 강도를 혼동하기 🔢

    r = -0.9는 r = +0.5보다 더 강한 상관입니다! 부호(+/-)는 방향이고, 강도는 절댓값으로 판단하세요.

    • -0.9 → 강한 음의 상관
    • +0.5 → 보통 수준의 양의 상관
    • 강도 비교: |-0.9| = 0.9 > |+0.5| = 0.5 → -0.9가 더 강함

    정답 확인

    1. 음(의 상관)
    2. |−0.3| = 0.3 → 약한 상관 (기준 경계에 해당)
    3. 숫자형(수치형) 열
    4. (b) -0.82 (절댓값 0.82가 가장 큼)
    5. 자기 자신과의 상관은 완벽히 같은 값이므로 항상 1
    6. 숨은 변수: 교통량(차량 통행량). 차가 많이 다니는 곳에 학교 보호를 위해 신호등도 많이 설치하고, 차가 많으니 사고도 많을 뿐입니다. 신호등을 줄이면 사고가 줄어드는 게 아니라 오히려 늘어날 수 있습니다.

    도전 과제: 스포츠 데이터에서 의외의 상관관계 찾기 ⚽

    아래 코드로 가상의 축구 선수 데이터를 만들어 보세요. 어떤 변수들 사이에 의외의 상관관계가 숨어 있을까요?

    np.random.seed(7)
m = 30
age = np.random.randint(18, 36, m)
height = np.random.normal(178, 6, m).round(1)
sprint_speed = (95 - age * 0.5 + np.random.normal(0, 3, m)).round(1)
goals = (sprint_speed * 0.3 + np.random.normal(0, 2, m)).round(0).astype(int)
salary = (goals * 500 + age * 100 + np.random.normal(0, 500, m)).round(0)

sports_df = pd.DataFrame({
    '나이': age, '키': height,
    '스프린트속도': sprint_speed,
    '골수': goals, '연봉(만원)': salary
})

# 히트맵 그리기
plt.figure(figsize=(6, 5))
sns.heatmap(sports_df.corr(), annot=True, fmt='.2f',
            cmap='coolwarm', vmin=-1, vmax=1, square=True)
plt.title('축구 선수 데이터 상관관계')
plt.show()

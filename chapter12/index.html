    Chapter 12: 연관 분석 — 함께 등장하는 패턴 찾기¶

    🎯 이 장에서 배우는 것¶

    • 연관 분석의 핵심 지표(지지도·신뢰도·향상도)를 정의하고 직접 계산할 수 있다
    • 장바구니 분석 사례를 통해 연관 규칙의 비즈니스 활용을 설명할 수 있다
    • Python(mlxtend)을 활용하여 연관 규칙을 추출하고 해석할 수 있다
    • 추출된 규칙을 지표 기준으로 필터링하여 유의미한 패턴을 선별할 수 있다

    💡 왜 이걸 배우나요?¶

    🤔 생각해보기: 편의점에서 라면을 집어 든 사람이 계란도 함께 살 확률은 얼마나 될까요?

    여러분이 편의점 점주라고 상상해보세요. 하루에 수백 건의 거래가 일어납니다. 어떤 손님은 라면과 계란을, 어떤 손님은 과자와 음료를, 또 어떤 손님은 삼각김밥과 우유를 함께 삽니다. 이런 "함께 구매하는 패턴" 을 알아낼 수 있다면 어떨까요?

    • 라면 옆에 계란을 진열하면 매출이 올라갈 수 있습니다
    • "라면 + 계란 세트" 할인 행사를 기획할 수 있습니다
    • 온라인 쇼핑몰에서 "이 상품을 산 사람이 함께 산 상품"을 추천할 수 있습니다

    이것이 바로 연관 분석(Association Analysis) 입니다. 아마존의 "이 상품을 구매한 고객이 함께 구매한 상품", 넷플릭스의 "이 영화를 본 사용자가 좋아한 영화"가 모두 연관 분석에서 출발합니다.

    이번 장에서는 세 가지 핵심 지표를 배우고, 실제 데이터에서 숨겨진 패턴을 코드로 찾아내는 방법을 익힙니다.

    📚 핵심 개념¶

    개념 1: 연관 규칙이란?¶

    🍱 비유로 시작 — 급식 메뉴 조합

    학교 급식에서 떡볶이가 나오는 날, 유독 우유 소비량이 늘어난다는 걸 영양사 선생님이 발견했다고 합시다. 이것을 규칙으로 표현하면 이렇습니다.

    "떡볶이를 먹으면 → 우유도 마신다"

    이것이 바로 연관 규칙(Association Rule) 입니다.

    📖 정확한 정의

    연관 규칙은 "A가 일어나면 B도 함께 일어나는 경향이 있다" 는 패턴을 표현한 것입니다.

    • 선행 항목(Antecedent): 조건이 되는 항목 → "떡볶이" (if 부분)
    • 후행 항목(Consequent): 결과가 되는 항목 → "우유" (then 부분)
    • 표기: {떡볶이} → {우유}

    ✅ 예시로 확인

    편의점 거래 데이터에서 찾을 수 있는 연관 규칙 예시입니다.

    • {라면} → {계란}: "라면을 사는 사람은 계란도 산다"
    • {맥주, 기저귀} → {과자}: "맥주와 기저귀를 사는 사람은 과자도 산다"
    • {콜라} → {팝콘}: "콜라를 사는 사람은 팝콘도 산다"

    📌 알아보기: 연관 규칙은 인과관계(원인→결과)가 아니라 동시 발생 패턴입니다. "라면을 사서 계란을 산다"가 아니라 "라면과 계란이 함께 등장하는 빈도가 높다"는 의미입니다. 이 차이를 꼭 기억하세요!

    개념 2: 지지도(Support) — "얼마나 자주?"¶

    🍱 비유로 시작

    전교생 100명 중에서 떡볶이와 우유를 둘 다 선택한 학생이 30명이라면, 이 조합의 인기도는 30%입니다. 이것이 지지도입니다.

    📖 정확한 정의

    지지도는 전체 거래 중에서 A와 B가 함께 등장하는 거래의 비율입니다.

    Support(A → B) = (A와 B가 함께 포함된 거래 수) / (전체 거래 수)

    ✅ 예시로 확인

    편의점에서 하루 동안 총 10건의 거래가 있었습니다.

    • 거래 1: 라면, 계란, 음료
    • 거래 2: 과자, 음료
    • 거래 3: 라면, 계란
    • 거래 4: 빵, 우유
    • 거래 5: 라면, 음료
    • 거래 6: 계란, 빵
    • 거래 7: 라면, 계란, 과자
    • 거래 8: 음료, 과자
    • 거래 9: 라면, 계란
    • 거래 10: 빵, 우유, 음료

    {라면, 계란}이 함께 등장한 거래: 1, 3, 7, 9번 → 4건

    Support({라면} → {계란}) = 4 / 10 = 0.4 (40%)

    💡 지지도의 의미: 지지도가 높을수록 이 조합이 자주 등장한다는 뜻입니다. 하지만 지지도만으로는 규칙이 강한지 약한지 알 수 없습니다. 라면을 사는 사람 중 정말 계란도 같이 사는 비율이 높은 건지를 알려면 신뢰도가 필요합니다.

    개념 3: 신뢰도(Confidence) — "얼마나 확실히?"¶

    🍱 비유로 시작

    떡볶이를 선택한 학생이 50명인데, 그중 30명이 우유도 선택했다면? "떡볶이를 고른 학생이 우유도 고를 확률"은 60%입니다. 이것이 신뢰도입니다.

    📖 정확한 정의

    신뢰도는 A를 포함하는 거래 중에서 B도 함께 포함하는 거래의 비율입니다.

    Confidence(A → B) = Support(A와 B) / Support(A)

    ✅ 예시로 확인

    위의 편의점 데이터에서 계속해봅시다.

    • 라면이 포함된 거래: 1, 3, 5, 7, 9번 → 5건 → Support(라면) = 5/10 = 0.5
    • 라면과 계란이 함께 포함된 거래: 1, 3, 7, 9번 → 4건 → Support(라면, 계란) = 4/10 = 0.4
    Confidence({라면} → {계란}) = 0.4 / 0.5 = 0.8 (80%)

    해석: 라면을 산 사람 중 80%가 계란도 함께 구매합니다!

    ⚠️ 주의: 신뢰도의 방향에 따라 값이 달라집니다. {라면} → {계란}의 신뢰도와 {계란} → {라면}의 신뢰도는 다릅니다! 계란이 포함된 거래는 1, 3, 6, 7, 9번으로 5건이므로, Confidence({계란} → {라면}) = 0.4 / 0.5 = 0.8 (80%)... 이 경우는 우연히 같지만, 일반적으로는 다릅니다.

    개념 4: 향상도(Lift) — "우연보다 얼마나 강한지?"¶

    🍱 비유로 시작

    전교생의 60%가 우유를 마신다고 합시다. 떡볶이를 고른 학생 중 60%가 우유도 마신다면? 이건 떡볶이 때문이 아니라 원래 우유 소비가 많은 것일 뿐입니다. 그런데 떡볶이를 고른 학생 중 90%가 우유를 마신다면? 이건 우연이 아니라 진짜 연관이 있는 겁니다! 이 "우연 대비 강도"를 측정하는 것이 향상도입니다.

    📖 정확한 정의

    향상도는 A와 B가 함께 등장하는 비율이, 독립적으로 등장할 때의 기대 비율보다 얼마나 높은지를 나타냅니다.

    Lift(A → B) = Confidence(A → B) / Support(B)

    향상도 해석 기준:

    • Lift = 1: A와 B는 독립 (우연의 수준)
    • Lift > 1: A와 B는 양의 연관 (함께 나타나는 경향)
    • Lift < 1: A와 B는 음의 연관 (하나가 나타나면 다른 하나는 덜 나타남)

    ✅ 예시로 확인

    • 계란이 포함된 거래: 1, 3, 6, 7, 9번 → 5건 → Support(계란) = 5/10 = 0.5
    • Confidence({라면} → {계란}) = 0.8
    Lift({라면} → {계란}) = 0.8 / 0.5 = 1.6

    해석: 라면과 계란이 함께 등장하는 빈도는 우연보다 1.6배 높습니다. 즉, 이 둘 사이에는 의미 있는 연관이 존재합니다!

    🧠 정리하기: 세 지표의 역할을 한마디로 요약하면 이렇습니다. - 지지도: 이 조합이 얼마나 자주 등장하나? (인기도) - 신뢰도: A가 나타났을 때 B도 나타날 가능성이 얼마나 확실한가? (예측력) - 향상도: 이 연관이 우연이 아닌 진짜인가? (강도)

    아래 다이어그램으로 세 지표의 관계를 정리합니다.

    flowchart TD A["🛒 전체 거래 데이터"] --> B["지지도 Support\n전체 중 A∩B 비율\n'얼마나 자주?'"] A --> C["신뢰도 Confidence\nA 중 A∩B 비율\n'얼마나 확실히?'"] A --> D["향상도 Lift\n신뢰도 ÷ B의 지지도\n'우연보다 강한가?'"] B -->|"낮으면"| E["❌ 너무 드문 조합\n분석 가치 낮음"] B -->|"적절하면"| C C -->|"높으면"| D D -->|"Lift > 1"| F["✅ 의미 있는 연관 규칙!"] D -->|"Lift ≤ 1"| G["❌ 우연이거나\n음의 연관"]

    📐 손으로 풀어보는 연습¶

    아래 5건의 거래 데이터로 직접 계산해봅시다.

    • 거래 1: 빵, 우유, 쿠키
    • 거래 2: 빵, 우유
    • 거래 3: 빵, 쿠키
    • 거래 4: 우유, 쿠키
    • 거래 5: 빵, 우유, 쿠키

    문제: {빵} → {우유} 규칙의 지지도, 신뢰도, 향상도를 구하세요.

    풀이: - 빵과 우유가 함께 등장: 거래 1, 2, 5 → 3건 - 지지도 = 3/5 = 0.6 (60%) - 빵이 등장하는 거래: 1, 2, 3, 5 → 4건 → Support(빵) = 4/5 = 0.8 - 신뢰도 = 0.6 / 0.8 = 0.75 (75%) - 우유가 등장하는 거래: 1, 2, 4, 5 → 4건 → Support(우유) = 4/5 = 0.8 - 향상도 = 0.75 / 0.8 = 0.9375

    해석: 향상도가 1보다 작으므로, 빵과 우유의 연관은 우연 수준보다 약간 약합니다. 빵을 산다고 해서 우유를 특별히 더 사는 것은 아닙니다.

    Step 4: 빈번 항목집합 찾기 (Apriori 알고리즘)¶

    모든 상품 조합을 다 계산하면 너무 오래 걸립니다. Apriori 알고리즘은 "지지도가 낮은 조합은 일찍 버리자"는 전략으로 효율적으로 빈번 항목집합을 찾습니다.

    # 최소 지지도 0.2(20%) 이상인 항목집합 찾기
frequent_itemsets = apriori(
    df, 
    min_support=0.2,      # 최소 지지도: 전체 15건 중 3건(20%) 이상
    use_colnames=True      # 상품명 표시
)

# 항목 수 기준으로 정렬
frequent_itemsets['길이'] = frequent_itemsets['itemsets'].apply(len)
result = frequent_itemsets.sort_values(['길이', 'support'], ascending=[True, False])

print("=== 빈번 항목집합 (지지도 20% 이상) ===")
print(result.to_string(index=False))

    Step 5: 연관 규칙 생성 및 해석¶

    빈번 항목집합에서 연관 규칙을 만들고, 세 가지 지표를 확인합니다.

    # 연관 규칙 생성 (최소 신뢰도 60% 이상)
rules = association_rules(
    frequent_itemsets, 
    metric="confidence",   # 기준 지표
    min_threshold=0.6      # 최소 신뢰도 60%
)

# 주요 열만 선택하고 향상도 기준으로 정렬
rules_display = rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']]
rules_sorted = rules_display.sort_values('lift', ascending=False)

print("=== 연관 규칙 (신뢰도 60% 이상, 향상도 순) ===")
for idx, row in rules_sorted.head(10).iterrows():
    ant = ', '.join(list(row['antecedents']))
    con = ', '.join(list(row['consequents']))
    print(f"  {ant} → {con}")
    print(f"    지지도: {row['support']:.1%}, "
          f"신뢰도: {row['confidence']:.1%}, "
          f"향상도: {row['lift']:.2f}")
    print()

    ⚠️ 자주 하는 실수¶

    실수 1: 연관을 인과관계로 해석 🚫¶

    틀린 해석: "라면을 사면 계란을 사게 된다" (인과관계) 올바른 해석: "라면과 계란이 함께 구매되는 경향이 있다" (동시 발생 패턴)

    연관 규칙은 상관관계(correlation) 를 보여줄 뿐, 원인과 결과를 알려주지 않습니다. "아이스크림 매출과 익사 사고가 동시에 높아진다"고 해서 아이스크림이 익사를 유발하는 것이 아닌 것처럼요 (둘 다 여름에 높아지는 것).

    실수 2: 지지도만 보고 판단하기 🚫¶

    지지도가 높다고 반드시 좋은 규칙은 아닙니다. 예를 들어, 편의점에서 거의 모든 사람이 비닐봉투를 구매한다면 {아무 상품} → {비닐봉투}의 지지도는 매우 높지만, 이건 의미 없는 규칙입니다. 반드시 향상도(Lift)가 1보다 큰지 확인하세요.

    실수 3: min_support를 너무 낮게 설정하기 🚫¶

    # ❌ 이렇게 하면 너무 많은 규칙이 나옴
frequent_itemsets = apriori(df, min_support=0.01)  # 1%

# ✅ 적절한 수준에서 시작하고 점차 조정
frequent_itemsets = apriori(df, min_support=0.1)   # 10%

    최소 지지도를 너무 낮게 잡으면 수천~수만 개의 규칙이 쏟아져 나와 해석이 불가능합니다. 데이터 크기에 따라 5%~20% 사이에서 시작하는 것을 추천합니다.

    실수 4: 신뢰도의 방향을 무시하기 🚫¶

    # {A} → {B} 의 신뢰도 ≠ {B} → {A} 의 신뢰도!
# "라면을 사면 계란도 산다"와 "계란을 사면 라면도 산다"는 다른 규칙

    비즈니스 맥락에 맞는 방향의 규칙을 선택해야 합니다. "라면 구매자에게 계란을 추천"하려면 {라면} → {계란}의 신뢰도를 봐야 합니다.

    • 거래 4: 콜라, 팝콘, 사탕
    • 거래 5: 콜라, 팝콘

    정답: - 콜라 ∩ 팝콘: 1, 4, 5번 → 3건 → 지지도 = 3/5 = 0.6 - 콜라: 1, 2, 4, 5번 → 4건 → Support(콜라) = 4/5 = 0.8 - 신뢰도 = 0.6 / 0.8 = 0.75 (75%) - 팝콘: 1, 3, 4, 5번 → 4건 → Support(팝콘) = 4/5 = 0.8 - 향상도 = 0.75 / 0.8 = 0.9375 - 해석: 향상도 < 1이므로, 의미 있는 양의 연관은 아닙니다.

    문제 2. 다음 중 올바른 설명을 모두 고르세요.

    • (가) 향상도가 2라면 우연보다 2배 강한 연관이다 ✅
    • (나) 신뢰도가 높으면 반드시 좋은 규칙이다 ❌ (지지도나 향상도도 봐야 함)
    • (다) 연관 규칙은 인과관계를 의미한다 ❌ (동시 발생 패턴일 뿐)
    • (라) 지지도는 방향성이 없다 (A→B와 B→A가 같다) ✅

    응용 문제¶

    문제 3. 어떤 온라인 쇼핑몰에서 다음 연관 규칙을 발견했습니다.

    • 규칙 A: {노트북} → {마우스}, 지지도 5%, 신뢰도 70%, 향상도 3.5
    • 규칙 B: {키보드} → {마우스}, 지지도 15%, 신뢰도 60%, 향상도 1.2

    마케팅 팀에 추천 규칙을 하나만 골라야 한다면 어떤 것을 고르겠습니까? 이유를 설명하세요.

    예시 답안: 목적에 따라 다릅니다. - 정밀한 추천(전환율) 이 목표라면 → 규칙 A. 향상도가 3.5로 매우 높아, 노트북 구매자에게 마우스를 추천하면 효과적일 확률이 높습니다. - 대량 마케팅(커버리지) 이 목표라면 → 규칙 B. 지지도가 15%로 더 높아, 더 많은 고객에게 적용할 수 있습니다. - 일반적으로는 향상도가 월등히 높은 규칙 A를 추천합니다.

    심화 문제¶

    문제 4. min_support=0.3, min_confidence=0.7로 설정했을 때, 왜 일부 "진짜 의미 있는" 규칙을 놓칠 수 있는지 설명하세요.

    예시 답안: 특정 니치(niche) 상품 조합은 지지도가 낮을 수 있습니다. 예를 들어, "프로틴 바 → 아몬드 우유"는 전체 거래에서 드물게 등장하지만(지지도 5%), 프로틴 바를 사는 사람 중 90%가 아몬드 우유도 사고(신뢰도 90%), 향상도가 5.0일 수 있습니다. min_support=0.3으로 설정하면 이 규칙은 지지도 기준에서 걸러져 발견되지 않습니다. 따라서 높은 지지도 기준은 희귀하지만 강력한 규칙을 놓칠 위험이 있습니다.

    flowchart LR A["📊 12장\n연관 분석\n함께 등장하는 패턴"] --> B["📊 13장\n군집 분석\n비슷한 것끼리 묶기"] style A fill:#4CAF50,stroke:#333,color:#fff style B fill:#2196F3,stroke:#333,color:#fff

    핵심 요약:

    • 지지도: 전체 중 함께 등장하는 비율 → "얼마나 자주?"
    • 신뢰도: A가 있을 때 B도 있을 확률 → "얼마나 확실히?"
    • 향상도: 우연 대비 강도 → "진짜 연관인가?"
    • Apriori 알고리즘: 효율적으로 빈번 항목집합을 찾는 방법
    • 실전 활용: 상품 추천, 진열 배치, 마케팅 전략

    다음 장에서는 군집 분석(Clustering) 을 배웁니다. 연관 분석이 "함께 등장하는 아이템"을 찾았다면, 군집 분석은 "비슷한 고객/데이터를 그룹으로 묶는" 방법입니다. K-Means 알고리즘으로 데이터를 자동으로 그룹핑하는 방법을 실습합니다! 🚀

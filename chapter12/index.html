    📖 Chapter 12: 연관 분석 - 함께 등장하는 패턴 찾기¶

    Part 3 | [2권] 데이터 모델링과 평가

    🎯 이 장에서 배우는 것¶

    • 연관 분석의 핵심 지표(지지도·신뢰도·향상도)를 정의하고 직접 계산할 수 있다
    • 장바구니 분석 사례를 통해 연관 규칙의 비즈니스 활용을 설명할 수 있다
    • Python(mlxtend)을 활용하여 연관 규칙을 추출하고 해석할 수 있다
    • 지지도-신뢰도 기준으로 유의미한 규칙을 필터링할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분, 편의점에서 라면을 집어 들었을 때 자연스럽게 계란도 함께 담은 경험이 있나요? 혹시 유튜브에서 영상을 보다가 "이 영상을 본 사람들이 함께 본 영상" 추천을 클릭한 적은요?

    이런 것들이 모두 연관 분석(Association Analysis) 의 결과물입니다.

    🤔 생각해보기: 편의점 사장님 입장에서 "라면 사는 사람의 70%가 계란도 산다"는 정보를 알면 어떻게 활용할 수 있을까요? 라면 옆에 계란을 진열하면 매출이 올라가겠죠!

    연관 분석은 대량의 거래 데이터에서 "함께 등장하는 패턴"을 자동으로 찾아주는 기법입니다. 유통, 추천 시스템, 의료 진단 등 다양한 분야에서 실제로 사용됩니다. 이번 장에서 그 원리를 배우고, 직접 코드로 구현해 봅시다!

    📚 핵심 개념¶

    개념 1: 연관 분석이란?¶

    1. 비유로 시작 🍱

    학교 급식을 떠올려 봅시다. 급식 메뉴 조합을 오랜 기간 관찰하면 패턴이 보입니다.

    • 김치찌개가 나오는 날에는 계란말이가 함께 나온다
    • 카레가 나오는 날에는 단무지가 빠지지 않는다

    이처럼 "A가 등장하면 B도 함께 등장하는 경향" 을 데이터에서 자동으로 찾아내는 것이 연관 분석입니다.

    2. 정확한 정의 📖

    연관 분석(Association Analysis) 은 대규모 데이터셋에서 항목들 사이의 흥미로운 관계(연관 규칙)를 발견하는 비지도 학습 기법입니다. 가장 대표적인 응용이 장바구니 분석(Market Basket Analysis) 입니다.

    연관 규칙은 다음과 같은 형태입니다:

    {라면} → {계란} : "라면을 사는 사람은 계란도 산다"

    여기서 왼쪽({라면})을 선행 항목(Antecedent), 오른쪽({계란})을 후행 항목(Consequent) 이라고 합니다.

    3. 예시로 확인 🛒

    5명의 고객이 편의점에서 구매한 내역을 봅시다:

    • 고객 1: 라면, 계란, 음료
    • 고객 2: 라면, 계란
    • 고객 3: 라면, 과자
    • 고객 4: 계란, 우유
    • 고객 5: 라면, 계란, 과자

    라면을 산 사람은 4명(고객 1, 2, 3, 5), 그중 계란도 함께 산 사람은 3명(고객 1, 2, 5)입니다. 이런 패턴을 숫자로 표현하는 것이 바로 다음에 배울 세 가지 지표입니다.

    개념 2: 지지도(Support) - "얼마나 자주?"¶

    1. 비유로 시작 🎵

    학교에서 "점심시간에 운동장에 나가는 학생이 얼마나 되나요?"라고 물어보는 것과 같습니다. 전체 중에서 해당 사건이 얼마나 자주 일어나는지 를 측정합니다.

    2. 정확한 정의 📖

    지지도(Support) 는 전체 거래 중 특정 항목(조합)이 포함된 거래의 비율입니다.

    지지도({라면, 계란}) = {라면, 계란}이 함께 등장한 거래 수 / 전체 거래 수

    3. 예시로 확인 🔢

    위의 5건 거래 데이터에서:

    • 지지도({라면}) = 4/5 = 0.8 (80%)
    • 지지도({계란}) = 3/5 = 0.6 (60%) ← 고객 1, 2, 4, 5 중... 잠깐! 고객 4도 계란을 샀으니 4/5 = 0.8이네요? 아닙니다. 다시 세봅시다: 고객 1(✓), 2(✓), 4(✓), 5(✓) → 4명! 지지도({계란}) = 4/5 = 0.8
    • 지지도({라면, 계란}) = 3/5 = 0.6 (60%) ← 함께 산 고객: 1, 2, 5

    📌 알아보기: 지지도가 너무 낮은 규칙은 우연히 한두 번 발생한 것일 수 있어서, 보통 최소 지지도(min_support) 를 설정해 걸러냅니다.

    개념 3: 신뢰도(Confidence) - "얼마나 확실히?"¶

    1. 비유로 시작 🌂

    "구름이 끼면 비가 올 확률은?"과 비슷합니다. 구름이 낀 날 중에서 실제로 비가 온 비율이 신뢰도입니다.

    2. 정확한 정의 📖

    신뢰도(Confidence) 는 선행 항목을 포함한 거래 중에서 후행 항목도 함께 포함된 비율입니다.

    신뢰도({라면} → {계란}) = 지지도({라면, 계란}) / 지지도({라면})

    3. 예시로 확인 🔢

    신뢰도({라면} → {계란}) = 0.6 / 0.8 = 0.75 (75%)

    "라면을 산 사람 중 75%가 계란도 함께 샀다" 는 뜻입니다.

    반대 방향도 계산해 봅시다:

    신뢰도({계란} → {라면}) = 0.6 / 0.8 = 0.75 (75%)

    ⚠️ 주의! 신뢰도만으로는 부족합니다. 만약 계란 자체가 원래 인기 상품이어서 80%의 고객이 구매한다면, 라면과의 연관성이 실제로는 별로 없을 수도 있습니다. 이를 보완하는 것이 향상도입니다.

    개념 4: 향상도(Lift) - "우연보다 얼마나 강한가?"¶

    1. 비유로 시작 ⚖️

    급식에서 김치가 나올 확률이 원래 90%라면, "카레 나오는 날 김치도 나올 확률 92%"는 별로 의미가 없겠죠? 하지만 원래 확률이 30%인데 특정 메뉴와 함께할 때 80%로 뛴다면? 그것이 진짜 연관성입니다.

    2. 정확한 정의 📖

    향상도(Lift) 는 두 항목이 독립적일 때 예상되는 빈도 대비 실제 함께 등장하는 빈도의 비율입니다.

    향상도({라면} → {계란}) = 신뢰도({라면} → {계란}) / 지지도({계란})
    • 향상도 = 1: 두 항목은 독립(우연의 일치)
    • 향상도 > 1: 양의 연관성(함께 등장하는 경향)
    • 향상도 < 1: 음의 연관성(함께 등장하지 않는 경향)

    3. 예시로 확인 🔢

    향상도({라면} → {계란}) = 0.75 / 0.8 = 0.9375

    향상도가 1보다 약간 작습니다. 이는 라면과 계란의 동시 구매가 우연히 기대되는 수준보다 오히려 살짝 낮다는 의미입니다! (데이터가 5건뿐이라 이런 결과가 나왔습니다. 실제 분석에서는 훨씬 많은 데이터를 사용합니다.)

    flowchart LR A["🛒 거래 데이터"] --> B["지지도\n(Support)\n얼마나 자주?"] A --> C["신뢰도\n(Confidence)\n얼마나 확실히?"] A --> D["향상도\n(Lift)\n우연보다 강한가?"] B --> E["빈번한 항목 조합\n필터링"] C --> E D --> F["진짜 의미 있는\n연관 규칙 선별"] E --> F

    📌 정리하기: 세 지표를 한 문장으로 기억하세요! - 지지도: 전체에서 얼마나 자주 함께 나타나는가 - 신뢰도: A를 샀을 때 B도 살 확률은 얼마인가 - 향상도: 이 규칙이 우연이 아닌 진짜인가

    🔨 따라하기: 편의점 거래 데이터로 연관 규칙 추출하기¶

    🖥️ Google Colab에서 따라해 봅시다!

    Step 1: 라이브러리 설치 및 불러오기¶

    mlxtend는 연관 분석을 쉽게 할 수 있게 해주는 Python 라이브러리입니다.

    # mlxtend 설치 (Colab에서 실행)
!pip install mlxtend -q

import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

    Step 2: 편의점 거래 데이터 만들기¶

    실제 편의점처럼 15건의 거래 데이터를 만들어 봅시다.

    # 15명의 고객 구매 내역
transactions = [
    ['라면', '계란', '음료'],
    ['라면', '계란', '과자'],
    ['라면', '계란'],
    ['라면', '과자', '음료'],
    ['계란', '우유', '빵'],
    ['라면', '계란', '과자', '음료'],
    ['과자', '음료', '빵'],
    ['라면', '음료'],
    ['계란', '우유'],
    ['라면', '계란', '음료'],
    ['과자', '빵', '우유'],
    ['라면', '과자'],
    ['라면', '계란', '과자'],
    ['계란', '빵'],
    ['라면', '계란', '음료', '과자'],
]

print(f"총 거래 수: {len(transactions)}건")
print(f"첫 번째 거래: {transactions[0]}")

    Step 3: 데이터를 분석 가능한 형태로 변환¶

    연관 분석을 하려면 거래 데이터를 True/False 표 형태로 바꿔야 합니다.

    # TransactionEncoder로 변환
te = TransactionEncoder()
te_array = te.fit(transactions).transform(transactions)

# DataFrame으로 변환
df = pd.DataFrame(te_array, columns=te.columns_)
print("변환된 데이터 (처음 5행):")
print(df.head())

    출력 결과를 보면, 각 행(거래)마다 해당 상품을 샀으면 True, 안 샀으면 False로 표시됩니다.

    Step 4: 빈번한 항목 조합 찾기 (Apriori 알고리즘)¶

    Apriori 알고리즘은 최소 지지도를 만족하는 항목 조합을 효율적으로 찾아주는 알고리즘입니다.

    # 최소 지지도 0.2 (20%) 이상인 항목 조합 찾기
frequent_items = apriori(df, min_support=0.2, use_colnames=True)

# 지지도 기준 내림차순 정렬
frequent_items = frequent_items.sort_values('support', ascending=False)
print("빈번한 항목 조합:")
print(frequent_items.to_string(index=False))

    📌 알아보기: min_support=0.2는 "전체 15건 중 최소 3건(20%) 이상에서 등장하는 조합만 보겠다"는 뜻입니다. 이 값을 너무 낮추면 의미 없는 규칙이 쏟아지고, 너무 높이면 규칙이 거의 안 나옵니다.

    Step 5: 연관 규칙 추출 및 필터링¶

    이제 빈번한 조합에서 연관 규칙을 만들고, 의미 있는 규칙만 골라봅시다.

    # 연관 규칙 생성 (최소 신뢰도 0.5 이상)
rules = association_rules(frequent_items, metric="confidence", min_threshold=0.5)

# 주요 열만 선택하여 보기
result = rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']]
result = result.sort_values('lift', ascending=False)

print("연관 규칙 (신뢰도 0.5 이상, 향상도 순):")
print(result.to_string(index=False))

    Step 6: 결과 해석하기¶

    출력된 규칙 중 향상도가 높은 것을 골라 해석해 봅시다.

    # 향상도가 1보다 큰 규칙만 필터링 (진짜 연관성이 있는 것)
meaningful_rules = result[result['lift'] > 1.0]
print("\n✨ 의미 있는 연관 규칙 (향상도 > 1):")

for idx, row in meaningful_rules.iterrows():
    ant = ', '.join(list(row['antecedents']))
    con = ', '.join(list(row['consequents']))
    print(f"\n  {ant} → {con}")
    print(f"    지지도: {row['support']:.2f} | 신뢰도: {row['confidence']:.2f} | 향상도: {row['lift']:.2f}")

    # 해석 자동 생성
    conf_pct = row['confidence'] * 100
    print(f"    → '{ant}'을(를) 산 고객의 {conf_pct:.0f}%가 '{con}'도 함께 구매")

    🤔 생각해보기: 만약 여러분이 편의점 사장님이라면, 이 결과를 보고 어떤 상품을 나란히 진열하겠습니까?

    📝 전체 코드¶

    아래 코드를 Colab에 복사하면 처음부터 끝까지 한 번에 실행할 수 있습니다.

    # ==============================
# 연관 분석 전체 코드
# ==============================

# 1. 설치 및 임포트
!pip install mlxtend -q

import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

# 2. 거래 데이터 생성
transactions = [
    ['라면', '계란', '음료'],
    ['라면', '계란', '과자'],
    ['라면', '계란'],
    ['라면', '과자', '음료'],
    ['계란', '우유', '빵'],
    ['라면', '계란', '과자', '음료'],
    ['과자', '음료', '빵'],
    ['라면', '음료'],
    ['계란', '우유'],
    ['라면', '계란', '음료'],
    ['과자', '빵', '우유'],
    ['라면', '과자'],
    ['라면', '계란', '과자'],
    ['계란', '빵'],
    ['라면', '계란', '음료', '과자'],
]

# 3. 데이터 변환
te = TransactionEncoder()
te_array = te.fit(transactions).transform(transactions)
df = pd.DataFrame(te_array, columns=te.columns_)

# 4. Apriori로 빈번한 항목 조합 찾기
frequent_items = apriori(df, min_support=0.2, use_colnames=True)
frequent_items = frequent_items.sort_values('support', ascending=False)
print("=== 빈번한 항목 조합 ===")
print(frequent_items.to_string(index=False))

# 5. 연관 규칙 추출
rules = association_rules(frequent_items, metric="confidence", min_threshold=0.5)
result = rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']]
result = result.sort_values('lift', ascending=False)

# 6. 의미 있는 규칙 해석
meaningful_rules = result[result['lift'] > 1.0]
print("\n=== ✨ 의미 있는 연관 규칙 (향상도 > 1) ===")
for idx, row in meaningful_rules.iterrows():
    ant = ', '.join(list(row['antecedents']))
    con = ', '.join(list(row['consequents']))
    conf_pct = row['confidence'] * 100
    print(f"  {ant} → {con}")
    print(f"    지지도: {row['support']:.2f} | 신뢰도: {row['confidence']:.2f} | 향상도: {row['lift']:.2f}")
    print(f"    → '{ant}'을(를) 산 고객의 {conf_pct:.0f}%가 '{con}'도 함께 구매\n")

    ⚠️ 자주 하는 실수¶

    실수 1: 신뢰도만 보고 판단하기 🚫

    신뢰도가 90%라도 향상도가 1 이하면 의미 없습니다! 예를 들어 물을 사는 고객이 전체의 95%라면, 어떤 상품을 사든 물과의 신뢰도는 높게 나옵니다. 반드시 향상도를 함께 확인하세요.

    실수 2: min_support를 너무 낮게 설정하기 🔍

    min_support=0.01처럼 너무 낮게 잡으면 거의 모든 조합이 나와서 계산 시간이 폭증하고 의미 없는 규칙이 쏟아집니다. 데이터 크기에 따라 0.01~0.1 사이에서 시작해 조절하세요.

    실수 3: 연관 규칙을 인과관계로 해석하기 ⚡

    {라면} → {계란}은 "라면을 사면 계란도 산다"는 동시 발생 패턴이지, "라면이 계란 구매를 유발한다"는 인과관계가 아닙니다. 상관관계와 인과관계의 차이를 항상 기억하세요!

    실수 4: 데이터 변환을 잊는 경우 🔧

    TransactionEncoder로 True/False 형태로 변환하지 않으면 apriori() 함수가 작동하지 않습니다. 리스트 형태의 거래 데이터를 반드시 변환 후 사용하세요.

    ✅ 스스로 점검하기¶

    기본 문제 📗¶

    문제 1. 다음 거래 데이터에서 지지도({빵, 우유})를 계산하세요.

    • 거래 1: 빵, 우유
    • 거래 2: 빵, 과자
    • 거래 3: 우유, 과자
    • 거래 4: 빵, 우유, 과자
    • 거래 5: 빵, 우유
    정답 확인 {빵, 우유}가 함께 등장한 거래: 1, 4, 5 → **3건** 전체 거래: **5건** 지지도 = 3/5 = **0.6 (60%)**

    문제 2. 위 데이터에서 신뢰도({빵} → {우유})를 계산하세요.

    정답 확인 지지도({빵, 우유}) = 3/5 = 0.6 지지도({빵}) = 4/5 = 0.8 (거래 1, 2, 4, 5) 신뢰도 = 0.6 / 0.8 = **0.75 (75%)** "빵을 산 사람 중 75%가 우유도 함께 샀다"

    응용 문제 📘¶

    문제 3. 향상도가 1.2라는 것은 무엇을 의미하나요? 편의점 사장님에게 설명하듯이 서술하세요.

    정답 확인 "이 두 상품이 아무 관련 없이 우연히 함께 팔릴 확률보다 **20% 더 자주** 함께 팔리고 있습니다. 즉, 이 두 상품 사이에 실제 연관성이 있으므로, 가까이 진열하면 매출 향상을 기대할 수 있습니다."

    심화 문제 📕¶

    문제 4. 향상도가 0.8인 규칙 {콜라} → {다이어트 식품}이 있다면, 이를 어떻게 해석하고 비즈니스에 어떻게 활용할 수 있을까요?

    정답 확인 향상도 0.8은 1보다 작으므로 **음의 연관성**을 의미합니다. 콜라를 사는 사람은 다이어트 식품을 **우연히 기대되는 것보다 덜** 삽니다. 두 상품의 타겟 고객이 다르다는 뜻이므로, 나란히 진열하는 것보다 **각각의 타겟에 맞는 상품 옆에 배치**하는 것이 효과적입니다.

    ['어벤져스', '아이언맨'],

# 직접 연관 규칙을 추출해 보세요!
# 힌트: min_support=0.25, min_threshold=0.6으로 시작해 보세요
te2 = TransactionEncoder()
te2_array = te2.fit(viewing_history).transform(viewing_history)
df2 = pd.DataFrame(te2_array, columns=te2.columns_)

freq2 = apriori(df2, min_support=0.25, use_colnames=True)

for idx, row in rules2[rules2['lift'] > 1.0].iterrows():

    이번 장에서는 "함께 등장하는 패턴" 을 찾는 연관 분석을 배웠습니다. 지지도·신뢰도·향상도라는 세 가지 렌즈로 데이터 속 숨겨진 관계를 발견하는 방법을 익혔죠.

    핵심 요약 - 지지도 → 전체에서 얼마나 자주 함께 나타나는가 - 신뢰도 → A가 있을 때 B도 있을 확률은 얼마인가 - 향상도 → 이 패턴이 우연이 아닌 진짜 연관인가 - Apriori 알고리즘 + mlxtend 라이브러리로 실제 규칙 추출

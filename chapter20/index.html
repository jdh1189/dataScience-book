    Chapter 20. 지혜로운 어부 생활 (2) — 모델링과 결과 해석¶

    Part 4 | [2권] 데이터 과학 프로젝트 — 교과서 주제 실습

    🎯 이 장에서 배우는 것¶

    • 환경 변수(수온, 풍속, 계절 등)를 활용해 어획량 예측 회귀 모델을 구축할 수 있다
    • K-Means 군집 분석으로 '풍어 조건'과 '불어 조건'을 구분할 수 있다
    • 모델 결과를 히트맵·시각화로 표현하여 최적 조업 인사이트를 도출할 수 있다
    • 의사 프로젝트와 어부 프로젝트를 비교하며 데이터 과학 프로세스의 공통 구조를 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 시간(19차시)에 우리는 어부의 조업 데이터를 수집·정제·탐색하는 작업을 했습니다. 데이터를 깨끗하게 준비하는 것만으로는 "내일 어디서 고기를 잡아야 할까?"라는 질문에 답할 수 없습니다.

    🎣 실제 어부의 고민을 떠올려 봅시다.

    "수온이 18도이고 풍속이 3m/s인 날, 동해 앞바다에 나가면 얼마나 잡힐까?"

    이 질문에 답하려면 데이터로부터 패턴을 학습하는 모델이 필요합니다. 이번 시간에는 준비된 데이터에 모델을 씌우고, 결과를 해석해서 "언제, 어디서, 어떤 조건에서 잡아야 효율적인지" 구체적인 제안을 만들어 봅니다.

    그리고 마지막에는 17~18차시의 '현명한 의사 생활' 프로젝트와 이번 '어부' 프로젝트를 나란히 놓고 비교합니다. "문제는 달라도, 데이터 과학의 프로세스는 같다"는 핵심 통찰을 직접 확인하게 될 것입니다.

    📚 핵심 개념¶

    개념 1: 회귀 모델 — "숫자를 예측하는 기계"¶

    1) 비유로 시작

    시험 공부 시간과 성적의 관계를 생각해 봅시다. "3시간 공부하면 대략 75점, 5시간이면 85점쯤 나온다"라고 예측할 수 있다면, 여러분의 머릿속에 이미 회귀 모델이 있는 겁니다. 입력(공부 시간)을 넣으면 출력(성적)이라는 연속적인 숫자가 나오는 관계식이죠.

    어부 프로젝트에서는 이렇게 바뀝니다.

    • 입력(특성, Feature): 수온, 풍속, 조류 속도, 월(계절), 해역 코드 …
    • 출력(목표, Target): 어획량(kg)

    2) 정확한 정의

    회귀(Regression): 하나 이상의 입력 변수로부터 연속적인 수치 출력을 예측하는 지도학습 기법. 가장 기본적인 형태가 선형 회귀(Linear Regression)이며, 복잡한 관계를 잡기 위해 랜덤 포레스트 회귀(Random Forest Regressor) 같은 앙상블 기법을 쓸 수 있습니다.

    3) 예시로 확인

    수온=18°C, 풍속=3m/s, 월=7, 해역=동해
  → 회귀 모델 → 예측 어획량: 약 320kg

    모델이 학습 데이터에서 "수온 18도, 여름, 동해 조합이면 대체로 300~350kg" 패턴을 배웠기 때문에 이 숫자가 나옵니다.

    📌 알아보기: 선형 회귀는 y = w₁x₁ + w₂x₂ + ... + b 형태의 직선(또는 초평면)을 찾습니다. 여기서 w는 각 특성의 가중치(weight), b는 절편(bias)입니다. 가중치가 크면 해당 특성이 어획량에 미치는 영향이 크다는 뜻입니다.

    개념 2: K-Means 군집 분석 — "비슷한 조건끼리 묶기"¶

    1) 비유로 시작

    교실에 30명의 학생이 있습니다. 선생님이 "취미가 비슷한 사람끼리 3모둠으로 나눠 보세요"라고 하면, 자연스럽게 운동 좋아하는 그룹, 게임 좋아하는 그룹, 독서 좋아하는 그룹 등으로 모입니다. K-Means는 컴퓨터가 이 과정을 수행하는 알고리즘입니다.

    2) 정확한 정의

    K-Means 군집화(Clustering): 데이터를 K개의 그룹(군집)으로 나누되, 같은 군집 안의 데이터끼리는 최대한 가깝고, 다른 군집의 데이터와는 최대한 멀도록 반복 계산하는 비지도학습 기법.

    3) 어부 프로젝트에서의 활용

    조업 기록을 3개 군집으로 나누면 다음과 같은 결과를 기대할 수 있습니다.

    • 군집 0 — 풍어 조건: 수온 높음, 풍속 낮음, 여름~가을 → 평균 어획량 400kg↑
    • 군집 1 — 보통 조건: 중간 수온, 중간 풍속 → 평균 어획량 200kg 내외
    • 군집 2 — 불어 조건: 수온 낮음, 풍속 높음, 겨울 → 평균 어획량 80kg↓
    flowchart LR A["전체 조업 데이터\n(360건)"] --> B["K-Means\nK=3"] B --> C["🟢 군집 0\n풍어"] B --> D["🟡 군집 1\n보통"] B --> E["🔴 군집 2\n불어"]

    💡 생각해보기: 회귀 모델은 "숫자를 예측"하고, 군집 분석은 "조건을 분류"합니다. 두 가지를 함께 사용하면 어부에게 더 풍부한 정보를 줄 수 있습니다. "이 조건은 풍어 군집에 해당하고, 예상 어획량은 약 350kg입니다" 처럼요!

    개념 3: 모델 평가 지표 — "이 예측, 얼마나 믿을 수 있어?"¶

    1) 비유로 시작

    친구 A가 "내일 시험 점수 85점 나올 거야"라고 했는데 실제 83점이면 꽤 정확합니다. 친구 B가 "85점!"이라고 했는데 실제 52점이면 전혀 못 믿겠죠. 모델도 마찬가지입니다. 예측과 실제가 얼마나 가까운지 측정하는 것이 평가 지표입니다.

    2) 핵심 지표 세 가지

    • MAE (Mean Absolute Error, 평균 절대 오차): 예측값과 실제값 차이의 절댓값을 평균. 단위가 원래 데이터와 같아서 직관적 ("평균적으로 약 45kg 정도 틀린다")
    • R² Score (결정 계수): 모델이 데이터 변동의 몇 %를 설명하는지. 1에 가까울수록 좋고, 0이면 평균으로 찍는 것과 같음
    • 실루엣 점수(Silhouette Score): 군집 분석 전용. -1~1 범위이며, 1에 가까울수록 군집이 잘 나뉨

    3) 예시

    회귀 모델 결과:
  MAE = 42.3kg  →  "평균적으로 42kg 정도 오차"
  R²  = 0.78   →  "어획량 변동의 78%를 환경 변수로 설명"

군집 분석 결과:
  실루엣 점수 = 0.54  →  "군집이 적당히 잘 구분됨"

    📌 알아보기: R² = 0.78이면 "꽤 괜찮은 모델"입니다. 자연 현상(날씨, 물고기 이동 등)에는 측정할 수 없는 변수가 많으므로, R²가 0.7 이상이면 실용적으로 활용 가능한 수준이라 봅니다.

    개념 4: 데이터 과학 프로세스의 보편성 — "문제는 달라도 절차는 같다"¶

    1) 비유로 시작

    요리사가 한식을 만들든 양식을 만들든 "재료 준비 → 손질 → 조리 → 플레이팅 → 시식" 절차는 같습니다. 데이터 과학도 마찬가지입니다.

    2) 의사 프로젝트 vs 어부 프로젝트 비교

    flowchart TB subgraph 공통_프로세스["🔄 데이터 과학 공통 프로세스"] direction TB S1["1️⃣ 문제 정의"] S2["2️⃣ 데이터 수집·정제"] S3["3️⃣ 탐색적 분석 EDA"] S4["4️⃣ 모델링"] S5["5️⃣ 결과 해석·시각화"] S6["6️⃣ 의사결정 제안"] S1 --> S2 --> S3 --> S4 --> S5 --> S6 end subgraph 의사["🩺 의사 프로젝트"] D1["질병 예측"] D2["환자 건강 데이터"] D3["분류 모델"] end subgraph 어부["🎣 어부 프로젝트"] F1["어획량 예측"] F2["환경·조업 데이터"] F3["회귀 + 군집 모델"] end

    3) 핵심 정리

    두 프로젝트에서 바뀌는 것은 도메인(의학 vs 수산업)과 데이터뿐입니다. 문제 정의 → 데이터 준비 → EDA → 모델링 → 해석 → 제안이라는 6단계 프로세스는 동일합니다. 이것이 데이터 과학의 힘입니다. 한 번 프로세스를 익히면, 어떤 분야에도 적용할 수 있습니다.

    🔨 따라하기: 어획량 예측 모델 구축부터 보고서까지¶

    ⏱️ 예상 소요: 약 80분 (전체 2.5시간 중 핵심 실습)

    Step 0: 데이터 준비 — 가상 어부 데이터 생성¶

    지난 시간에 정제한 데이터가 있다면 그대로 사용합니다. 없다면 아래 코드로 가상 데이터를 생성합니다.

    import numpy as np
import pandas as pd
np.random.seed(42)

n = 360  # 1년간 매일 조업 기록 (일부 휴일 제외)

# 환경 변수 생성
months = np.random.choice(range(1, 13), n)
water_temp = 10 + 8 * np.sin((months - 1) * np.pi / 6) + np.random.normal(0, 1.5, n)
wind_speed = np.random.uniform(0.5, 12, n)
current_speed = np.random.uniform(0.1, 2.5, n)
regions = np.random.choice(['동해', '서해', '남해'], n)

# 해역별 기본 어획량 차이
region_bonus = {'동해': 50, '서해': 30, '남해': 70}
base = np.array([region_bonus[r] for r in regions])

# 어획량 = 수온 영향 + 해역 보너스 - 풍속 페널티 + 조류 효과 + 노이즈
catch = (
    base
    + 15 * water_temp
    - 8 * wind_speed
    + 20 * current_speed
    + np.random.normal(0, 30, n)
)
catch = np.clip(catch, 10, None)  # 최소 10kg

df = pd.DataFrame({
    '월': months,
    '수온': np.round(water_temp, 1),
    '풍속': np.round(wind_speed, 1),
    '조류속도': np.round(current_speed, 2),
    '해역': regions,
    '어획량': np.round(catch, 1)
})

print(f"데이터 크기: {df.shape}")
print(df.head(10))

    Step 2: 회귀 모델 학습 — 어획량 예측하기¶

    from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

y = df[target]

    X, y, test_size=0.2, random_state=42
)
print(f"학습 데이터: {X_train.shape[0]}건, 테스트 데이터: {X_test.shape[0]}건")

# --- 모델 1: 선형 회귀 ---
lr = LinearRegression()
lr.fit(X_train, y_train)
pred_lr = lr.predict(X_test)

# --- 모델 2: 랜덤 포레스트 회귀 ---
rf = RandomForestRegressor(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)
pred_rf = rf.predict(X_test)

# 평가
print("\n📊 모델 성능 비교")
print(f"{'선형 회귀':>12} | MAE: {mean_absolute_error(y_test, pred_lr):.1f}kg | R²: {r2_score(y_test, pred_lr):.3f}")
print(f"{'랜덤 포레스트':>12} | MAE: {mean_absolute_error(y_test, pred_rf):.1f}kg | R²: {r2_score(y_test, pred_rf):.3f}")

    from sklearn.preprocessing import StandardScaler

from sklearn.metrics import silhouette_score

# 군집 분석에 사용할 변수 (어획량도 포함하여 '조업 결과 패턴'을 찾음)

scaler = StandardScaler()

# 최적 K 찾기 (실루엣 점수 비교)
print("🔍 K값별 실루엣 점수:")
for k in range(2, 6):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_scaled)
    sil = silhouette_score(X_scaled, labels)
    print(f"  K={k}: 실루엣 점수 = {sil:.3f}")

# K=3으로 결정
km_final = KMeans(n_clusters=3, random_state=42, n_init=10)
df['군집'] = km_final.fit_predict(X_scaled)

    Chapter 06. 데이터 전처리 - 깨끗한 데이터 만들기¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다.

    • 결측치(빈 데이터)를 탐지하고, 삭제·대체·보간 중 적절한 방법을 선택하여 처리할 수 있다
    • 이상치(비정상적으로 튀는 데이터)를 식별하고 처리하는 기준을 설명할 수 있다
    • 데이터 타입 변환, 중복 제거, 정규화 등 전처리 기법을 코드로 구현할 수 있다
    • 전처리 전후 데이터를 비교하여 데이터 품질 개선을 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    우리 반 30명의 시험 성적표에서 3명의 점수가 빈칸으로 남아있다면, 반 평균은 어떻게 계산해야 할까요? 빈칸을 0점으로 치면 평균이 확 낮아지고, 빈칸을 무시하면 27명만의 평균이 됩니다. 어떤 게 맞는 걸까요?

    현실 세계의 데이터는 완벽하지 않습니다. 설문조사에서 응답자가 질문을 건너뛰기도 하고, 센서가 오작동해서 엉뚱한 숫자가 들어오기도 하고, 같은 데이터가 두 번 입력되기도 합니다.

    이런 "더러운" 데이터를 그대로 분석하면 결과를 신뢰할 수 없습니다. 데이터 분석가들은 전체 업무 시간의 60~80%를 데이터 전처리에 쓴다고 알려져 있습니다. 그만큼 중요한 단계입니다.

    이번 장에서는 데이터를 분석 가능한 "깨끗한" 상태로 만드는 방법을 배웁니다.

    flowchart LR A["🗑️ 더러운 데이터\n빈칸, 오류, 중복"] --> B["🔧 전처리"] B --> C["✨ 깨끗한 데이터\n분석 준비 완료"] B --- D["결측치 처리"] B --- E["이상치 처리"] B --- F["타입 변환·중복 제거"]

    📚 핵심 개념¶

    개념 1: 결측치(Missing Value) — 빈 답안지 📝¶

    ① 비유로 시작

    시험을 보는데 5번 문제를 풀지 않고 넘겼다고 상상해보세요. 채점표에는 5번 칸이 비어있습니다. 이 빈칸이 바로 결측치입니다. 빈칸을 0점으로 처리할 수도 있고, 아예 그 문제를 채점에서 빼버릴 수도 있습니다. 어떻게 처리하느냐에 따라 총점이 달라지겠죠?

    ② 정확한 정의

    결측치(Missing Value) 란 데이터에서 값이 비어있거나 기록되지 않은 것을 말합니다. pandas에서는 이를 NaN(Not a Number)으로 표시합니다. None도 결측치로 취급됩니다.

    ③ 예시로 확인

    import pandas as pd
import numpy as np

# 시험 성적 데이터 만들기
data = {
    '이름': ['민수', '지영', '현우', '수아', '태호'],
    '국어': [85, 92, np.nan, 78, 90],      # 현우의 국어 점수가 비어있음
    '수학': [90, np.nan, 88, 95, np.nan],   # 지영, 태호의 수학 점수가 비어있음
    '영어': [78, 85, 92, np.nan, 87]        # 수아의 영어 점수가 비어있음
}

df = pd.DataFrame(data)
print(df)

    출력 결과:

       이름    국어    수학    영어
0  민수  85.0  90.0  78.0
1  지영  92.0   NaN  85.0
2  현우   NaN  88.0  92.0
3  수아  78.0  95.0   NaN
4  태호  90.0   NaN  87.0

    NaN이라고 표시된 곳이 바로 결측치입니다.

    알아보기 📖

    결측치가 생기는 이유 - 수집 오류: 센서 고장, 네트워크 끊김 - 응답 거부: 설문에서 민감한 질문 건너뜀 - 데이터 병합: 서로 다른 출처의 데이터를 합칠 때 항목 불일치 - 입력 실수: 사람이 직접 입력하다가 빠뜨림

    개념 2: 결측치 처리 3가지 방법 — 삭제, 대체, 보간 🔧¶

    결측치를 발견했다면 어떻게 처리할까요? 크게 3가지 방법이 있습니다.

    flowchart TD A["결측치 발견!"] --> B{"데이터가 충분한가?"} B -- "충분하다" --> C["🗑️ 삭제\ndropna()"] B -- "부족하다" --> D{"패턴이 있는가?"} D -- "없다" --> E["🔄 대체\nfillna()"] D -- "시간순 등\n패턴 있다" --> F["📈 보간\ninterpolate()"]

    방법 1: 삭제(Drop) — 결측치가 있는 행이나 열을 통째로 지우기

    • 언제?: 데이터가 충분히 많고, 결측치 비율이 낮을 때 (전체의 5% 이하 권장)
    • 장점: 간단하고 확실함
    • 단점: 데이터 손실 발생

    방법 2: 대체(Fill) — 빈칸을 특정 값으로 채우기

    • 언제?: 결측치를 지우기엔 데이터가 아깝고, 적절한 대표값이 있을 때
    • 대표적 채움값: 평균(mean), 중앙값(median), 최빈값(mode), 특정 값(0 등)
    • 장점: 데이터 수 유지
    • 단점: 채운 값이 실제와 다를 수 있음

    방법 3: 보간(Interpolate) — 앞뒤 값을 이용해 추정하기

    • 언제?: 시간순 데이터처럼 연속적인 패턴이 있을 때
    • 예시: 월요일 기온 20°C, 수요일 기온 24°C → 화요일은 약 22°C로 추정
    • 장점: 데이터의 흐름을 반영
    • 단점: 패턴이 없으면 부정확

    정리하기 ✏️

    결측치 처리, 이렇게 선택하세요 - 결측치가 소수이고 데이터가 충분히 많다 → 삭제 - 결측치가 많지만 뚜렷한 시간 패턴이 없다 → 대체(평균, 중앙값 등) - 데이터가 시간순/연속적이다 → 보간

    개념 3: 이상치(Outlier) — 100m을 1초에 뛴 사람? 🏃¶

    ① 비유로 시작

    체육 시간에 100m 달리기 기록을 쟀습니다. 대부분 13~18초 사이인데, 한 명의 기록이 1초라고 적혀 있습니다. 우사인 볼트의 세계 기록이 9.58초인데 1초라니? 이건 스톱워치 오류이거나 잘못 기록한 것이 분명합니다. 이렇게 다른 데이터와 동떨어진 극단적인 값이 이상치입니다.

    ② 정확한 정의

    이상치(Outlier) 란 대부분의 데이터 분포에서 크게 벗어난 비정상적인 값을 말합니다. 입력 오류, 측정 장비 고장, 또는 정말로 특이한 경우에 발생합니다.

    ③ 이상치 탐지 방법: IQR 방식

    가장 널리 쓰이는 탐지 방법은 IQR(사분위 범위) 을 이용하는 것입니다.

    flowchart LR A["Q1\n(25번째 백분위)"] --- B["IQR\n= Q3 - Q1"] B --- C["Q3\n(75번째 백분위)"] D["이상치 기준"] --- E["하한: Q1 - 1.5 × IQR\n상한: Q3 + 1.5 × IQR"]

    쉽게 설명하면, 데이터를 크기순으로 나열했을 때:

    • Q1: 아래에서 25% 위치의 값
    • Q3: 아래에서 75% 위치의 값
    • IQR: Q3 - Q1 (데이터의 중간 50%가 퍼진 폭)
    • 이상치 판단: Q1 - 1.5×IQR보다 작거나, Q3 + 1.5×IQR보다 크면 이상치

    알아보기 📖

    이상치라고 해서 무조건 삭제하면 안 됩니다! - 입력 오류로 인한 이상치 → 삭제 또는 수정 - 진짜 특이한 값인 이상치 → 별도로 분석할 가치가 있음 - 예: 쇼핑몰 데이터에서 한 사람이 1억 원 구매 → 오류? VIP 고객?

    항상 "왜 이상한지"를 먼저 생각하세요!

    개념 4: 데이터 타입 변환과 중복 제거 — 마무리 정리 🧹¶

    전처리의 마무리 단계로, 두 가지를 더 확인해야 합니다.

    데이터 타입 변환

    숫자가 문자열(텍스트)로 저장되어 있으면 계산이 안 됩니다.

    • "85" (문자열) → 85 (정수): astype(int) 또는 pd.to_numeric()
    • "2024-01-15" (문자열) → 날짜형: pd.to_datetime()

    중복 데이터 제거

    같은 데이터가 두 번 이상 들어가 있으면 분석 결과가 왜곡됩니다.

    • 중복 확인: duplicated()
    • 중복 제거: drop_duplicates()

    정규화(Normalization)

    키(150~190cm)와 몸무게(40~100kg)처럼 단위와 범위가 다른 데이터를 비교 가능한 범위로 맞추는 것입니다.

    • Min-Max 정규화: 모든 값을 0~1 사이로 변환
    • 공식: (값 - 최솟값) / (최댓값 - 최솟값)
    flowchart LR A["전처리 파이프라인"] --> B["1. 결측치 처리"] B --> C["2. 이상치 처리"] C --> D["3. 타입 변환"] D --> E["4. 중복 제거"] E --> F["5. 정규화"] F --> G["✨ 깨끗한 데이터"]

    🔨 따라하기¶

    우리 반 학생들의 체력검사 데이터를 직접 전처리해 봅시다. 이 데이터에는 결측치, 이상치, 잘못된 타입, 중복까지 다양한 문제가 숨어 있습니다.

    Step 1: 문제가 있는 데이터 만들기 🏗️¶

    먼저 일부러 "더러운" 데이터를 만들어 보겠습니다.

    import pandas as pd
import numpy as np

# 체력검사 데이터 (일부러 문제를 넣음)
data = {
    '이름': ['민수', '지영', '현우', '수아', '태호', '예린', '민수', '지훈'],
    '달리기_100m': [14.2, 13.8, 1.0, 15.1, np.nan, 14.5, 14.2, 16.3],
    '윗몸일으키기': [42, np.nan, 38, 45, 40, np.nan, 42, 35],
    '키': ['170', '162', '175', '158', '180', '165', '170', '173'],
    '반': [1, 1, 1, 2, 2, 2, 1, 2]
}

import numpy as np

# ========================================
# 1. 데이터 준비
# ========================================
data = {
    '이름': ['민수', '지영', '현우', '수아', '태호', '예린', '민수', '지훈'],
    '달리기_100m': [14.2, 13.8, 1.0, 15.1, np.nan, 14.5, 14.2, 16.3],
    '윗몸일으키기': [42, np.nan, 38, 45, 40, np.nan, 42, 35],
    '키': ['170', '162', '175', '158', '180', '165', '170', '173'],
    '반': [1, 1, 1, 2, 2, 2, 1, 2]

# ========================================

print("[2단계] 키 타입 변환 완료: object → int64\n")

# ========================================
# 3. 중복 제거
# ========================================
df = df.drop_duplicates()
print(f"[3단계] 중복 제거 완료: {len(df)}행 남음\n")

# ========================================
# 4. 이상치 처리 (결측치 채우기 전에 수행)
# ========================================
col = '달리기_100m'
Q1 = df[col].quantile(0.25)
Q3 = df[col].quantile(0.75)
IQR = Q3 - Q1
하한, 상한 = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR

이상치_mask = (df[col] < 하한) | (df[col] > 상한)
중앙값 = df.loc[~이상치_mask, col].median()  # 이상치 제외 중앙값
df.loc[이상치_mask, col] = 중앙값
print(f"[4단계] 이상치 처리 완료 (정상 범위: {하한:.1f}~{상한:.1f})\n")

# ========================================
# 5. 결측치 처리
# ========================================
df['달리기_100m'] = df['달리기_100m'].fillna(df['달리기_100m'].median())
df['윗몸일으키기'] = df['윗몸일으키기'].fillna(df['윗몸일으키기'].median())
print(f"[5단계] 결측치 처리 완료: 남은 결측치 {df.isnull().sum().sum()}개\n")

# ========================================
# 6. 정규화
# ========================================
for c in ['달리기_100m', '윗몸일으키기', '키']:
    df[f'{c}_norm'] = ((df[c] - df[c].min()) / (df[c].max() - df[c].min())).round(2)
print("[6단계] 정규화 완료\n")

# ========================================
# 최종 결과
# ========================================
print("=== 최종 깨끗한 데이터 ===")
print(df)
print(f"\n✅ 결측치: {df.isnull().sum().sum()}개")
print(f"✅ 중복: {df.duplicated().sum()}개")
print(f"✅ 데이터 크기: {df.shape}")

    미션 3: 전처리 함수 만들기 ⚡

    자주 쓰는 전처리 과정을 하나의 함수로 만들어보세요.

    def clean_dataframe(df):
    """데이터프레임 기본 전처리 함수"""
    df = df.copy()
    df = df.drop_duplicates()
    # 숫자 열의 결측치를 중앙값으로 채우기
    for col in df.select_dtypes(include='number').columns:
        df[col] = df[col].fillna(df[col].median())
    return df

    Chapter 06: 데이터 전처리 — 깨끗한 데이터 만들기¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 결측치(비어 있는 데이터)를 탐지하고, 삭제·대체·보간 중 적절한 방법을 선택하여 처리할 수 있다
    • 이상치(비정상적으로 크거나 작은 값)를 식별하고 처리 기준을 설명할 수 있다
    • 데이터 타입 변환, 중복 제거, 정규화 등 전처리 기법을 코드로 구현할 수 있다
    • 전처리 파이프라인을 구성하여 "더러운 데이터"를 "분석 가능한 데이터"로 변환할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    시험 성적표에 빈칸이 있으면 평균은 어떻게 계산할까요? - 빈칸을 0점으로 치면? → 평균이 크게 낮아집니다. - 빈칸을 무시하면? → 실제 응시 인원과 달라집니다. - 빈칸을 다른 과목 평균으로 채우면? → 가장 그럴듯하지만, 정확하지는 않습니다.

    현실의 데이터는 완벽하지 않습니다. 설문 응답이 빠져 있거나, 센서 오류로 이상한 값이 들어가거나, 같은 데이터가 두 번 기록되기도 합니다. 이런 "더러운 데이터"를 그대로 분석하면 결과를 신뢰할 수 없습니다.

    데이터 과학자들은 업무 시간의 60~80%를 데이터 전처리에 사용한다고 합니다. 그만큼 중요하고, 그만큼 자주 필요한 기술입니다. 이 장에서 배우는 전처리 기법은 앞으로 어떤 데이터 분석 프로젝트를 하든 가장 먼저 적용하게 될 핵심 기술입니다.

    flowchart LR A["🗂️ 원본 데이터\n(더러운 상태)"] --> B["🧹 데이터 전처리"] B --> C["✨ 깨끗한 데이터\n(분석 가능)"] B --> B1["결측치 처리"] B --> B2["이상치 처리"] B --> B3["타입 변환·중복 제거"] B --> B4["정규화"]

    📚 핵심 개념¶

    개념 1: 결측치(Missing Value) — 빈 시험 답안지 📄¶

    1. 비유로 시작

    시험지를 걷었는데, 한 학생이 3번 문제를 아예 비워두고 냈습니다. 선생님은 이 빈칸을 어떻게 채점할까요? 0점을 줄 수도 있고, 아예 해당 문제를 채점에서 제외할 수도 있습니다. 데이터의 결측치가 바로 이 "빈 답안지"입니다.

    2. 정확한 정의

    결측치(Missing Value)란 데이터에서 값이 기록되지 않은 빈 자리를 말합니다. pandas에서는 NaN(Not a Number)이라는 특별한 표시로 나타납니다.

    3. 예시로 확인

    import pandas as pd
import numpy as np

# 학생 성적 데이터 — 일부 값이 비어 있습니다
data = {
    '이름': ['민수', '지영', '현우', '서연', '태호'],
    '국어': [85, 92, np.nan, 78, 90],
    '수학': [90, np.nan, 76, 88, np.nan],
    '영어': [78, 85, 92, np.nan, 86]
}
df = pd.DataFrame(data)
print(df)

    실행 결과:

       이름    국어    수학    영어
0  민수  85.0  90.0  78.0
1  지영  92.0   NaN  85.0
2  현우   NaN  76.0  92.0
3  서연  78.0  88.0   NaN
4  태호  90.0   NaN  86.0

    NaN이 보이는 곳이 바로 결측치입니다. 지영이의 수학 점수, 현우의 국어 점수 등이 비어 있습니다.

    알아보기 📌

    결측치가 발생하는 이유는 다양합니다. - 입력 누락: 설문 응답자가 질문을 건너뜀 - 시스템 오류: 센서가 고장 나서 값을 기록하지 못함 - 데이터 통합: 서로 다른 출처의 데이터를 합치면서 항목이 안 맞음 - 의도적 비공개: 응답자가 개인정보를 밝히기 싫어서 비워둠

    개념 2: 결측치 처리 3가지 방법 — 삭제·대체·보간 🔧¶

    결측치를 발견했다면, 처리 방법을 선택해야 합니다. 크게 세 가지가 있습니다.

    1. 비유로 시작

    요리를 하는데 재료 하나가 빠졌다고 생각해 봅시다. - 삭제: "이 재료 없으면 이 요리는 안 만들어!" → 해당 메뉴를 포기 - 대체: "비슷한 재료로 바꿔서 만들자" → 대체 재료 사용 - 보간: "앞뒤 맛을 참고해서 중간 맛을 만들자" → 주변 재료를 보고 추정

    2. 정확한 정의

    • 삭제(Drop): 결측치가 있는 행이나 열을 통째로 제거
    • 대체(Fill): 결측치를 특정 값(평균, 중앙값, 최빈값 등)으로 채움
    • 보간(Interpolate): 주변 값의 패턴을 이용해 결측치를 추정하여 채움

    3. 예시로 확인

    # 결측치 탐지
print("=== 결측치 확인 ===")
print(df.isnull())         # 각 셀이 비어있는지 True/False로 표시
print()
print("=== 열별 결측치 개수 ===")
print(df.isnull().sum())   # 열별로 NaN이 몇 개인지 세기

    실행 결과:

    === 결측치 확인 ===
    이름    국어    수학    영어
0  False  False  False  False
1  False  False   True  False
2  False   True  False  False
3  False  False  False   True
4  False  False   True  False

=== 열별 결측치 개수 ===
이름    0
국어    1
수학    2
영어    1
dtype: int64
    flowchart TD Q["결측치 발견!"] --> D1{"데이터가\n충분한가?"} D1 -->|"예, 충분하다"| M1["🗑️ 삭제\ndropna()"] D1 -->|"아니오, 부족하다"| D2{"시간 순서\n데이터인가?"} D2 -->|"예"| M3["📈 보간\ninterpolate()"] D2 -->|"아니오"| M2["✏️ 대체\nfillna(평균/중앙값)"]

    알아보기 📌

    어떤 방법을 선택해야 할까요? - 결측치가 소수(전체의 5% 이하)이고, 데이터가 충분하면 → 삭제 - 결측치가 많고, 데이터를 버리기 아까우면 → 대체 (평균, 중앙값 등) - 데이터가 시간 순서로 나열되어 있으면 → 보간 (앞뒤 값으로 추정)

    개념 3: 이상치(Outlier) — 100m 달리기를 1초에? 🏃‍♂️¶

    1. 비유로 시작

    체육 시간에 100m 달리기 기록을 측정했습니다. 대부분 13~16초인데, 한 학생의 기록이 1초로 찍혀 있습니다. 우사인 볼트 세계 기록이 9.58초인데 1초라니! 이건 스톱워치 오류가 분명합니다. 이렇게 나머지 데이터와 동떨어진 비정상적인 값을 이상치라고 합니다.

    2. 정확한 정의

    이상치(Outlier)란 데이터의 전반적인 패턴에서 극단적으로 벗어난 값을 말합니다. 측정 오류, 입력 실수, 또는 실제로 극단적인 사례일 수 있습니다.

    3. 예시로 확인 — IQR 방법

    가장 널리 사용되는 이상치 탐지 방법은 IQR(사분위 범위)을 이용하는 것입니다.

    • Q1: 하위 25% 지점 (1사분위수)
    • Q3: 상위 25% 지점 (3사분위수)
    • IQR: Q3 - Q1 (데이터의 중간 50%가 분포하는 범위)
    • 이상치 기준: Q1 - 1.5×IQR보다 작거나, Q3 + 1.5×IQR보다 크면 이상치
    flowchart LR subgraph 정상 범위 direction LR L["Q1 - 1.5×IQR\n(하한)"] ~~~ Q1["Q1\n(25%)"] ~~~ Q3["Q3\n(75%)"] ~~~ U["Q3 + 1.5×IQR\n(상한)"] end OL["🚨 이상치\n(하한 미만)"] -.-> L U -.-> OR["🚨 이상치\n(상한 초과)"]

    개념 4: 데이터 다듬기 — 타입 변환·중복 제거·정규화 🧹¶

    1. 비유로 시작

    도서관에서 책을 정리한다고 생각해 봅시다. - 타입 변환: "2023"이라는 숫자가 문자로 저장되어 있으면, 숫자로 바꿔야 연도 계산이 가능합니다 → 라벨을 올바르게 붙이기 - 중복 제거: 같은 책이 두 번 등록되어 있으면 하나를 제거 → 중복 카드 치우기 - 정규화: 키는 cm, 몸무게는 kg으로 단위가 다르면 비교가 어렵습니다 → 모든 척도를 0~1 사이로 통일

    2. 정확한 정의

    • 타입 변환: 문자열을 숫자로, 숫자를 날짜로 등 데이터의 자료형을 바꾸는 것
    • 중복 제거: 완전히 동일한 행(레코드)을 찾아서 하나만 남기는 것
    • 정규화(Normalization): 서로 다른 범위의 데이터를 0~1 사이로 스케일을 맞추는 것

    3. 정규화 공식 (Min-Max 정규화)

    정규화된 값 = (원래 값 - 최솟값) / (최댓값 - 최솟값)

    예를 들어, 수학 점수가 60~100점 범위인데, 현우가 76점이라면:

    (76 - 60) / (100 - 60) = 16 / 40 = 0.4

    생각해보기 🤔

    키(150~180cm)와 몸무게(40~90kg)를 그래프에 함께 그리면 어떤 문제가 생길까요? 범위가 다르면 키 변화가 과장되어 보이고, 몸무게 변화는 작아 보입니다. 정규화를 하면 둘 다 0~1 사이가 되어 공정하게 비교할 수 있습니다.

    Step 1: 문제가 있는 데이터 만들기¶

    알아보기 📌

    왜 달리기에는 평균, 윗몸일으키기에는 중앙값을 사용했을까요? - 평균(mean): 데이터가 고르게 분포할 때 적합 - 중앙값(median): 이상치가 있어서 평균이 왜곡될 수 있을 때 안전한 선택

    실제로 달리기 데이터에는 이상치(1초, 200초)가 있어서 평균이 왜곡되었습니다. 이상치를 먼저 처리한 후 결측치를 대체하는 것이 더 좋은 순서입니다!

    return (series - series.min()) / (series.max() - series.min())

    실수 1: 결측치를 무조건 0으로 채우기 🚫¶

    # ❌ 잘못된 방법
df['국어'] = df['국어'].fillna(0)
# → "시험을 안 본 것"과 "0점을 받은 것"은 전혀 다릅니다!
# → 평균이 크게 왜곡됩니다.

# ✅ 올바른 방법
df['국어'] = df['국어'].fillna(df['국어'].mean())  # 또는 median()

    실수 2: 이상치를 무조건 삭제하기 🚫¶

    # ❌ 생각 없이 삭제
df = df[(df['점수'] > 50) & (df['점수'] < 100)]
# → "왜 50 이하를 이상치로 봤는가?"에 대한 근거가 없습니다.

# ✅ IQR 같은 통계적 기준 사용
Q1 = df['점수'].quantile(0.25)
Q3 = df['점수'].quantile(0.75)
IQR = Q3 - Q1
df_clean = df[(df['점수'] >= Q1 - 1.5*IQR) & (df['점수'] <= Q3 + 1.5*IQR)]

    핵심: 이상치 판단에는 반드시 통계적 근거가 있어야 합니다. 또한 이상치가 진짜 오류인지, 의미 있는 극단값인지 판단하는 것이 중요합니다. (예: 쇼핑몰에서 100만 원짜리 구매 — 오류가 아니라 VIP 고객일 수 있음!)

    실수 3: 원본 데이터를 직접 수정하기 🚫¶

    # ❌ 원본을 직접 수정 → 되돌릴 수 없음!
df['달리기'] = df['달리기'].fillna(0)

df_clean = df.copy()  # 원본 보존!

    왜 중요한가요? 전처리 중 실수를 발견했을 때, 원본이 있어야 처음부터 다시 시작할 수 있습니다. .copy()를 습관처럼 사용하세요!

    심화 문제¶

    문제 4. 전처리의 올바른 순서를 나열하고, 그 이유를 설명하세요.

    (가) 정규화  (나) 이상치 처리  (다) 결측치 처리  (라) 중복 제거  (마) 타입 변환

    정답: (마) → (라) → (다) → (나) → (가)

    이유: - 타입 변환이 먼저여야 숫자 계산(평균, IQR 등)이 가능합니다 - 중복이 있으면 평균/IQR 계산이 왜곡되므로 먼저 제거합니다 - 결측치를 채울 때 이상치가 있으면 평균이 왜곡되므로... 실제로는 결측치와 이상치 순서가 상황에 따라 달라질 수 있습니다. 핵심은 정규화는 반드시 마지막이라는 것입니다!

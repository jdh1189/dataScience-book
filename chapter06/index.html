    Chapter 06. 데이터 수집 및 특성 분석 (2) — 기술통계와 시각화¶

    Part 2 | [1권] 데이터 준비와 분석

    🎯 이 장에서 배우는 것¶

    • 평균, 중앙값, 최빈값의 차이를 설명하고 Python으로 계산할 수 있다
    • 표준편차의 의미를 이해하고, 데이터가 얼마나 흩어져 있는지 수치로 표현할 수 있다
    • 박스플롯을 그려 사분위수와 이상치를 시각적으로 파악할 수 있다
    • 기술통계 결과를 바탕으로 데이터의 특성을 문장으로 서술할 수 있다

    💡 왜 이걸 배우나요?¶

    🤔 생각해보기: A반과 B반의 수학 시험 평균이 모두 75점입니다. 두 반의 성적 분포는 같을까요?

    A반 점수: 70, 72, 74, 76, 78, 80 B반 점수: 30, 50, 75, 80, 95, 120(만점 초과 오류!)

    평균은 똑같지만, A반은 고르게 모여 있고 B반은 들쭉날쭉합니다. 심지어 이상한 값(120점)도 섞여 있죠. 평균 하나만 보면 이런 차이를 절대 알 수 없습니다.

    데이터를 제대로 파악하려면 "대표값"뿐 아니라 "흩어진 정도"와 "이상한 값"까지 살펴야 합니다. 이것이 바로 기술통계(Descriptive Statistics) 의 역할입니다. 이번 장에서는 숫자로 요약하고, 그래프로 눈에 보이게 만드는 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 대표값 — 평균, 중앙값, 최빈값¶

    1) 비유로 시작¶

    교실에서 학생 5명의 키를 잰다고 상상해 보세요. "이 반 키가 대충 어느 정도야?"라는 질문에 답하는 방법이 하나가 아닙니다.

    • 평균(Mean): 모든 키를 더한 뒤 사람 수로 나눈 값 → "전체를 골고루 나누면?"
    • 중앙값(Median): 키 순서대로 줄 세운 뒤 한가운데 사람의 키 → "줄의 정중앙은?"
    • 최빈값(Mode): 가장 많이 나타나는 키 → "제일 흔한 값은?"

    2) 정확한 정의¶

    • 평균 = 모든 값의 합 ÷ 값의 개수
    • 중앙값 = 값을 크기순으로 정렬했을 때 정가운데 위치한 값 (짝수 개이면 가운데 두 값의 평균)
    • 최빈값 = 데이터에서 가장 자주 등장하는 값

    3) 예시로 확인¶

    데이터: [60, 70, 70, 80, 100]

    • 평균 = (60+70+70+80+100) ÷ 5 = 76
    • 중앙값 = 세 번째 값 = 70
    • 최빈값 = 두 번 나타난 70

    💡 알아보기: 평균은 극단적으로 큰(또는 작은) 값에 크게 흔들립니다. 위 데이터에서 100이 1000으로 바뀌면 평균은 254로 폭등하지만, 중앙값은 여전히 70입니다. 이것이 "평균의 함정" 입니다.

    개념 2: 흩어진 정도 — 표준편차¶

    1) 비유로 시작¶

    과녁에 화살 5개를 쐈다고 합시다. 두 사람 모두 평균 적중 위치가 과녁 중심이더라도, 한 명은 화살이 중심 근처에 모여 있고 다른 한 명은 사방으로 흩어져 있습니다. 표준편차는 "화살이 얼마나 흩어져 있는가"를 숫자 하나로 알려줍니다.

    2) 정확한 정의¶

    • 분산(Variance): 각 값과 평균 사이 거리(차이)를 제곱하여 평균 낸 것
    • 표준편차(Standard Deviation): 분산에 제곱근(√)을 씌운 것 → 원래 단위로 돌려놓은 흩어짐 지표
    표준편차가 작다 → 데이터가 평균 근처에 모여 있다
표준편차가 크다 → 데이터가 평균에서 멀리 흩어져 있다

    3) 예시로 확인¶

    • A반 [73, 74, 75, 76, 77] → 표준편차 ≈ 1.4 (촘촘!)
    • B반 [50, 60, 75, 90, 100] → 표준편차 ≈ 18.7 (넓게 퍼짐!)

    두 반 평균은 모두 75이지만, 표준편차가 완전히 다릅니다.

    개념 3: 사분위수와 박스플롯¶

    1) 비유로 시작¶

    "줄 세우기" 를 떠올려 보세요. 학생 100명을 시험 점수 순서대로 한 줄로 세웁니다.

    • 맨 앞에서 25번째 사람이 서 있는 위치 → 1사분위수(Q1)
    • 50번째 사람 → 2사분위수(Q2) = 중앙값
    • 75번째 사람 → 3사분위수(Q3)

    이 세 지점으로 줄을 네 구간(4분의 1씩)으로 나눕니다.

    2) 정확한 정의¶

    • Q1(25%): 하위 25% 지점의 값
    • Q2(50%): 중앙값
    • Q3(75%): 상위 25% 지점의 값
    • IQR(사분위 범위): Q3 − Q1 → 가운데 50% 데이터가 차지하는 폭

    3) 박스플롯(상자 그림)의 구조¶

    graph LR A["최솟값<br>(Q1 - 1.5×IQR 이상)"] --- B["Q1<br>(25%)"] B --- C["Q2<br>중앙값(50%)"] C --- D["Q3<br>(75%)"] D --- E["최댓값<br>(Q3 + 1.5×IQR 이하)"] F["● 이상치<br>(범위 밖의 점)"] -.-> E
    • 상자(Box): Q1부터 Q3까지 — 가운데 50%의 데이터가 들어 있는 구간
    • 수염(Whisker): 상자 양 끝에서 1.5×IQR 범위까지 뻗은 선
    • 이상치(Outlier): 수염 바깥에 찍히는 점 — 비정상적으로 크거나 작은 값

    💡 알아보기: 이상치는 입력 오류일 수도 있고, 정말 특별한 데이터일 수도 있습니다. 무조건 삭제하지 말고, 왜 이상치인지 먼저 확인하는 습관이 중요합니다.

    개념 4: 기술통계를 "문장"으로 쓰기¶

    숫자를 구했다고 끝이 아닙니다. "이 데이터가 어떤 특성을 갖는지" 말이나 글로 설명할 수 있어야 진짜 분석입니다.

    나쁜 예시: "평균 72.3, 표준편차 8.1이다."

    좋은 예시: "선수들의 종합 레이팅은 평균 72.3점이며, 표준편차 8.1로 대부분 64~80점 사이에 분포한다. 단, Q3 이상에서 90점을 넘는 소수의 스타 선수가 이상치로 나타난다."

    정리하기: 기술통계 서술의 공식 1. 대표값(평균 또는 중앙값)을 먼저 제시 2. 흩어짐(표준편차 또는 IQR)으로 분포 폭 설명 3. 특이사항(이상치, 치우침 방향) 언급

    🔨 따라하기¶

    FIFA 선수 레이팅 데이터를 직접 만들어 기술통계를 계산하고 박스플롯을 그려봅시다.

    Step 1: 라이브러리 불러오기와 데이터 준비¶

    import pandas as pd
import matplotlib.pyplot as plt

# 축구 선수 샘플 데이터 (포지션별 종합 레이팅)
data = {
    '선수': ['손흥민', '김민재', '이강인', '황희찬', '정우영',
            '홍철', '조규성', '박지수', '이재성', '설영우',
            '백승호', '권창훈', '나상호', '송민규', '오세훈'],
    '종합레이팅': [87, 86, 80, 76, 72, 70, 69, 68, 74, 66,
                71, 73, 72, 67, 70],
    '리그': ['EPL', '세리에A', '라리가', 'EPL', '분데스',
            'K리그', 'K리그', 'K리그', '분데스', 'K리그',
            '분데스', 'K리그', 'K리그', 'K리그', 'K리그']
}

df = pd.DataFrame(data)
print(df.head())

    Step 2: 기술통계량 한 번에 계산하기¶

    # describe()로 주요 통계량 한 번에 확인
stats = df['종합레이팅'].describe()
print(stats)

    실행하면 다음과 같은 항목이 출력됩니다.

    • count: 데이터 개수
    • mean: 평균
    • std: 표준편차
    • min: 최솟값
    • 25%: Q1 (1사분위수)
    • 50%: 중앙값 (Q2)
    • 75%: Q3 (3사분위수)
    • max: 최댓값

    Step 3: 개별 통계량 직접 구하기¶

    mean_val = df['종합레이팅'].mean()       # 평균
median_val = df['종합레이팅'].median()   # 중앙값
mode_val = df['종합레이팅'].mode()[0]    # 최빈값
std_val = df['종합레이팅'].std()         # 표준편차

print(f"평균: {mean_val:.1f}")
print(f"중앙값: {median_val}")
print(f"최빈값: {mode_val}")
print(f"표준편차: {std_val:.1f}")

    🤔 생각해보기: 평균과 중앙값이 다르다면, 데이터가 한쪽으로 치우쳐(skew) 있다는 신호입니다. 위 결과에서 평균이 중앙값보다 크다면, 높은 레이팅 쪽으로 일부 값이 끌어올리고 있다는 뜻이에요.

    Step 4: 박스플롯 그리기¶

    plt.figure(figsize=(8, 5))
plt.boxplot(df['종합레이팅'], vert=True, patch_artist=True,
            boxprops=dict(facecolor='skyblue'))
plt.title('Korean Players - Overall Rating Boxplot', fontsize=14)
plt.ylabel('Overall Rating')
plt.grid(axis='y', alpha=0.3)
plt.show()

    그래프에서 확인할 것: - 상자의 위치: 가운데 50%가 어디에 몰려 있는지 - 중앙선: 중앙값의 위치 - 수염의 길이: 데이터가 얼마나 뻗어 있는지 - 점(●): 이상치가 있는지

    Step 5: 리그별 비교 박스플롯¶

    # 리그별로 나눠서 박스플롯 비교
leagues = df['리그'].unique()
data_by_league = [df[df['리그'] == lg]['종합레이팅'].values for lg in leagues]

plt.figure(figsize=(10, 5))
plt.boxplot(data_by_league, labels=leagues, patch_artist=True,
            boxprops=dict(facecolor='lightyellow'))
plt.title('League Comparison - Overall Rating', fontsize=14)
plt.ylabel('Overall Rating')

    import pandas as pd
import matplotlib.pyplot as plt

# ── 1. 데이터 준비 ──
data = {
    '선수': ['손흥민', '김민재', '이강인', '황희찬', '정우영',

            '백승호', '권창훈', '나상호', '송민규', '오세훈'],

    ⚠️ 자주 하는 실수¶

    실수 1: 평균만 보고 판단하기 🚫

    # 두 데이터의 평균이 같아도 분포는 완전히 다를 수 있다!
a = [50, 50, 50, 50, 50]   # 평균 50, 표준편차 0
b = [10, 20, 50, 80, 90]   # 평균 50, 표준편차 약 31.6
    평균만 비교하면 같아 보이지만, std()까지 확인하면 전혀 다른 데이터임을 알 수 있습니다.

    실수 2: mode()의 반환값이 시리즈라는 것을 잊기 🚫

    # 잘못된 코드
mode_val = df['종합레이팅'].mode()  # Series가 반환됨

# 올바른 코드
mode_val = df['종합레이팅'].mode()[0]  # [0]으로 값 꺼내기
    최빈값이 여러 개일 수 있기 때문에 Pandas는 Series로 반환합니다. 첫 번째 값을 쓰려면 [0]을 붙이세요.

    실수 3: 이상치를 무조건 삭제하기 🚫

    박스플롯에서 점으로 표시된 이상치를 보면 바로 지우고 싶어집니다. 하지만 이상치가 진짜 특별한 데이터(예: 손흥민처럼 실력이 뛰어난 선수)일 수 있습니다. 삭제 전에 반드시 "왜 이 값이 튀었는지" 확인하세요.

    실수 4: describe() 결과의 std와 직접 계산한 std가 다르게 느껴지는 경우 🚫

    Pandas의 std()는 기본적으로 표본 표준편차(ddof=1)를 계산합니다. 수학 교과서에서 배운 공식(모표준편차, ddof=0)과 살짝 다를 수 있으니 당황하지 마세요.

    ✅ 스스로 점검하기¶

    기본 문제¶

    Q1. 다음 데이터의 평균, 중앙값, 최빈값을 각각 구하세요.

    [4, 7, 7, 10, 12, 7, 15]

    정답: 평균 = (4+7+7+10+12+7+15) ÷ 7 = 8.86, 중앙값 = 정렬 후 4번째 = 7, 최빈값 = 7

    Q2. "표준편차가 0이다"는 무슨 뜻인가요?

    정답: 모든 데이터 값이 완전히 동일하다는 뜻입니다. 흩어짐이 전혀 없습니다.

    응용 문제¶

    Q3. 어느 반 시험 점수의 describe() 결과가 다음과 같습니다.

    • mean: 70 / 50%: 65 / std: 15 / min: 30 / max: 100

    이 데이터의 특성을 2~3문장으로 서술하세요.

    예시 답: "이 반의 평균 점수는 70점이지만, 중앙값은 65점으로 평균보다 낮아 오른쪽으로 치우친(right-skewed) 분포이다. 표준편차 15로 대략 55~85점 사이에 대부분의 학생이 분포하며, 30점부터 100점까지 폭넓은 점수 범위를 보인다."

    Q4. 박스플롯에서 상자가 위쪽으로 치우쳐 있고 아래쪽 수염이 길다면, 데이터 분포는 어떤 모양일까요?

    정답: 낮은 점수 쪽으로 긴 꼬리가 있는 왼쪽 치우침(left-skewed) 분포입니다. 대부분 높은 값에 몰려 있지만, 일부 낮은 값이 아래로 길게 늘어져 있습니다.

    심화 문제¶

    Q5. 아래 코드를 실행하면 이상치가 몇 개 표시될지 예측하고, 직접 실행해서 확인하세요.

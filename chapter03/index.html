    📘 Chapter 3: 데이터셋과 데이터베이스¶

    🎯 이 장에서 배우는 것¶

    이 장을 마치면 다음을 할 수 있습니다:

    • 데이터셋의 구조(행과 열)를 설명하고, 직접 데이터셋을 만들 수 있다
    • 데이터베이스가 무엇인지 이해하고, 데이터셋과의 차이를 구분할 수 있다
    • SQL의 기본 명령어로 데이터베이스에서 원하는 데이터를 조회할 수 있다
    • Python으로 CSV 파일과 SQLite 데이터베이스를 다루는 기초 코드를 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 스마트폰으로 음악 앱을 열면, 수천만 곡 중에서 내가 좋아할 만한 노래를 추천해줍니다. 온라인 쇼핑몰은 수백만 개 상품 중에서 내 취향에 맞는 것을 골라 보여줍니다.

    이 모든 것의 출발점은 "데이터를 어떻게 정리하고 저장하느냐"입니다.

    아무리 뛰어난 인공지능 모델이라도, 데이터가 엉망으로 저장되어 있으면 아무것도 할 수 없습니다. 데이터를 깔끔하게 정리한 것이 데이터셋이고, 이를 효율적으로 저장하고 꺼내 쓰는 시스템이 데이터베이스입니다.

    이번 장에서는 데이터 과학의 원재료 창고를 직접 만들고 다루는 법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 데이터셋 (Dataset)¶

    🎒 비유로 시작하기

    학교 반의 출석부를 떠올려보세요. 출석부에는 세로로 학생 이름이 쭉 나열되고, 가로로 출석번호, 이름, 전화번호 같은 정보가 적혀 있습니다. 데이터셋은 바로 이 출석부와 같은 구조입니다.

    📖 정확한 정의

    데이터셋(Dataset): 분석이나 처리를 위해 체계적으로 정리된 데이터의 모음. 보통 행(row)과 열(column)로 이루어진 표 형태를 가집니다.

    핵심 용어를 정리해봅시다:

    • 행(Row): 하나의 관측값 또는 레코드. 출석부에서 "한 명의 학생 정보" 한 줄에 해당
    • 열(Column): 하나의 속성 또는 변수. "이름", "나이" 같은 정보의 종류
    • 값(Value): 특정 행과 열이 만나는 지점의 실제 데이터

    ✏️ 예시로 확인

    학생 성적 데이터셋:
─────────────────────────────
행1: 김하늘 | 17세 | 수학 92점
행2: 이바다 | 18세 | 수학 85점
행3: 박숲길 | 17세 | 수학 78점

    여기서 "이름", "나이", "수학점수"가 열(Column)이고, 김하늘의 정보 전체가 하나의 행(Row)입니다.

    graph TB subgraph 데이터셋의 구조 direction TB A["열 Column = 속성"] --> B["이름 열"] A --> C["나이 열"] A --> D["점수 열"] E["행 Row = 관측값"] --> F["김하늘, 17, 92"] E --> G["이바다, 18, 85"] E --> H["박숲길, 17, 78"] end

    📌 알아보기: 데이터셋의 가장 대표적인 파일 형식은 CSV(Comma-Separated Values)입니다. 말 그대로 쉼표(,)로 값을 구분하는 텍스트 파일이에요. 메모장으로 열어도 내용을 확인할 수 있을 만큼 단순합니다.

    개념 2: 데이터베이스 (Database)¶

    🎒 비유로 시작하기

    데이터셋이 종이 출석부 한 장이라면, 데이터베이스는 학교 행정실의 거대한 캐비닛 시스템입니다. 학생 정보, 성적, 출결, 동아리 활동 등 여러 종류의 서류가 각각의 서랍에 분류되어 있고, 필요한 서류를 빠르게 찾을 수 있는 색인(Index)까지 갖추고 있습니다. 그리고 여러 선생님이 동시에 서류를 열람하거나 수정할 수 있죠.

    📖 정확한 정의

    데이터베이스(Database): 여러 사용자가 공유하여 사용할 수 있도록 체계적으로 조직하고 관리하는 데이터의 집합. 보통 DBMS(Database Management System, 데이터베이스 관리 시스템)를 통해 운영됩니다.

    데이터베이스의 핵심 특징:

    • 체계적 저장: 여러 개의 테이블(표)이 서로 관계를 맺으며 저장됨
    • 동시 접근: 여러 사용자가 동시에 데이터를 읽고 쓸 수 있음
    • 데이터 무결성: 잘못된 데이터가 들어가지 않도록 규칙을 설정할 수 있음
    • 빠른 검색: 수백만 건의 데이터에서도 원하는 정보를 빠르게 찾음

    ✏️ 예시로 확인

    학교 데이터베이스에는 여러 테이블이 존재할 수 있습니다:

    erDiagram STUDENT ||--o{ GRADE : "성적을 가짐" STUDENT ||--o{ ATTENDANCE : "출결 기록을 가짐" STUDENT { int student_id string name int age string class_name } GRADE { int grade_id int student_id string subject int score } ATTENDANCE { int record_id int student_id string date string status }

    이처럼 학생 테이블, 성적 테이블, 출결 테이블이 student_id라는 공통 키로 연결되어 있습니다. 이런 구조를 관계형 데이터베이스(Relational Database)라고 합니다.

    📌 알아보기: 대표적인 관계형 데이터베이스에는 MySQL, PostgreSQL, SQLite 등이 있습니다. 이 중 SQLite는 설치 없이 파일 하나로 동작해서 학습용으로 가장 좋습니다.

    개념 3: 데이터셋 vs 데이터베이스¶

    💭 생각해보기: "엑셀 파일에 데이터를 저장하면 되는데, 왜 데이터베이스를 따로 쓸까요?"

    둘의 차이를 명확히 이해해봅시다.

    graph LR subgraph 데이터셋 A1["📄 하나의 파일"] A2["단순한 표 구조"] A3["소규모 데이터에 적합"] A4["개인 작업에 적합"] end subgraph 데이터베이스 B1["🗄️ 관리 시스템"] B2["여러 테이블이 연결"] B3["대규모 데이터에 적합"] B4["다수 사용자 동시 접근"] end A1 -.->|규모가 커지면| B1

    핵심 비교:

    • 데이터셋: 분석을 위해 준비된 "재료" → CSV, Excel 파일 한 장
    • 데이터베이스: 데이터를 안전하게 보관하고 관리하는 "창고 시스템" → 여러 테이블 + 관리 기능

    실무에서는 데이터베이스에서 필요한 데이터를 꺼내서 → 데이터셋으로 만들어 → 분석하는 흐름이 일반적입니다.

    flowchart LR DB["🗄️ 데이터베이스"] -->|SQL로 추출| DS["📄 데이터셋"] DS -->|Python으로 분석| RESULT["📊 분석 결과"]

    개념 4: SQL 기초¶

    🎒 비유로 시작하기

    도서관에서 책을 찾을 때 사서에게 "2023년에 나온 소설 중에서 평점 4점 이상인 것 좀 찾아주세요"라고 말하죠? SQL(Structured Query Language, 구조화 질의 언어)은 데이터베이스에게 이런 요청을 하는 공식 언어입니다.

    📖 정확한 정의

    SQL: 관계형 데이터베이스에서 데이터를 조회, 삽입, 수정, 삭제하기 위한 표준 프로그래밍 언어

    가장 많이 쓰는 SQL 명령어 4가지:

    • SELECT: 데이터 조회 (가장 자주 사용!)
    • INSERT: 새 데이터 추가
    • UPDATE: 기존 데이터 수정
    • DELETE: 데이터 삭제

    ✏️ 예시로 확인

    -- 모든 학생 정보를 조회
SELECT * FROM students;

-- 나이가 17세인 학생의 이름만 조회
SELECT name FROM students WHERE age = 17;

-- 수학 점수가 80점 이상인 학생을 점수 높은 순으로 조회
SELECT name, score FROM grades 
WHERE subject = '수학' AND score >= 80 
ORDER BY score DESC;

    📌 알아보기: SQL은 대소문자를 구분하지 않습니다. SELECT와 select는 같습니다. 하지만 관례적으로 SQL 명령어는 대문자, 테이블/열 이름은 소문자로 씁니다.

    🔨 따라하기: 데이터셋 만들고 데이터베이스에 저장하기¶

    지금부터 Python으로 직접 데이터셋을 만들고, 데이터베이스에 저장한 뒤, SQL로 조회하는 전 과정을 실습합니다.

    Step 1: CSV 데이터셋 만들기¶

    먼저 Python의 pandas 라이브러리로 데이터셋을 만들어봅시다.

    import pandas as pd

# 학생 성적 데이터셋 만들기
data = {
    'name': ['김하늘', '이바다', '박숲길', '최별빛', '정새벽'],
    'age': [17, 18, 17, 18, 17],
    'subject': ['수학', '수학', '수학', '수학', '수학'],
    'score': [92, 85, 78, 95, 88]
}

df = pd.DataFrame(data)
print(df)

    실행 결과:

      name  age subject  score
0  김하늘   17      수학     92
1  이바다   18      수학     85
2  박숲길   17      수학     78
3  최별빛   18      수학     95
4  정새벽   17      수학     88

    Step 2: CSV 파일로 저장하고 불러오기¶

    # CSV 파일로 저장
df.to_csv('students.csv', index=False, encoding='utf-8-sig')
print("✅ students.csv 파일이 저장되었습니다!")

# 저장된 CSV 파일 다시 불러오기
df_loaded = pd.read_csv('students.csv')
print(df_loaded)

    💭 생각해보기: index=False를 쓰는 이유는 무엇일까요? 빼고 실행해보면, 0, 1, 2… 같은 불필요한 인덱스 번호가 파일에 함께 저장됩니다.

    Step 3: SQLite 데이터베이스 생성하기¶

    이제 CSV의 데이터를 데이터베이스에 넣어봅시다. Python에는 sqlite3가 기본 내장되어 있어 설치가 필요 없습니다.

    import sqlite3

# 데이터베이스 연결 (파일이 없으면 자동 생성)
conn = sqlite3.connect('school.db')
cursor = conn.cursor()

# 테이블 생성
cursor.execute('''
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        age INTEGER,
        subject TEXT,
        score INTEGER
    )
''')

print("✅ students 테이블이 생성되었습니다!")
conn.commit()

    Step 4: 데이터베이스에 데이터 넣기¶

    # pandas DataFrame을 SQLite에 한 번에 저장
df.to_sql('students', conn, if_exists='replace', index=False)
print("✅ 데이터가 데이터베이스에 저장되었습니다!")

    Step 5: SQL로 데이터 조회하기¶

    # 전체 데이터 조회
print("📋 전체 학생 목록:")
result = pd.read_sql("SELECT * FROM students", conn)
print(result)
print()

    import pandas as pd
import sqlite3

# ── 1. 데이터셋 만들기 ──
data = {

df.to_csv('students.csv', index=False, encoding='utf-8-sig')

# ── 3. SQLite 데이터베이스에 저장 ──
conn = sqlite3.connect('school.db')
df.to_sql('students', conn, if_exists='replace', index=False)

# ── 4. SQL로 조회 ──
# 전체 조회
print("📋 전체 학생:")
print(pd.read_sql("SELECT * FROM students", conn))
print()

# 조건 조회
print("🏆 85점 이상:")
print(pd.read_sql(
    "SELECT name, score FROM students WHERE score >= 85 ORDER BY score DESC",
    conn

print()

# 통계 조회
avg = pd.read_sql("SELECT AVG(score) as avg_score FROM students", conn)

# ── 5. 연결 종료 ──
conn.close()

    ⚠️ 자주 하는 실수¶

    실수 1: CSV 파일 한글 깨짐¶

    # ❌ 잘못된 방법 — Windows에서 엑셀로 열면 한글이 깨짐
df.to_csv('data.csv', index=False)

# ✅ 올바른 방법 — encoding='utf-8-sig' 추가
df.to_csv('data.csv', index=False, encoding='utf-8-sig')

    utf-8-sig는 파일 앞에 BOM(Byte Order Mark)이라는 표식을 붙여서, 엑셀이 "이 파일은 UTF-8이구나!"하고 제대로 인식하게 해줍니다.

    실수 2: 데이터베이스 연결을 닫지 않음¶

    # ❌ 잘못된 방법 — conn.close()를 빼먹으면 파일이 잠길 수 있음
conn = sqlite3.connect('school.db')
df.to_sql('students', conn, if_exists='replace', index=False)
# ... 그냥 프로그램 종료

# ✅ 올바른 방법 — 반드시 닫아주기
conn = sqlite3.connect('school.db')
try:
    df.to_sql('students', conn, if_exists='replace', index=False)
finally:
    conn.close()  # 에러가 나도 반드시 실행됨

    실수 3: SQL에서 문자열 비교 시 따옴표 누락¶

    # ❌ 잘못된 SQL — 문자열에 따옴표가 없으면 에러 발생
"SELECT * FROM students WHERE subject = 수학"

# ✅ 올바른 SQL — 문자열은 반드시 작은따옴표로 감싸기
"SELECT * FROM students WHERE subject = '수학'"

    실수 4: if_exists 옵션을 모르고 데이터 덮어쓰기¶

    # ⚠️ 'replace'는 기존 테이블을 삭제하고 새로 만듦
df.to_sql('students', conn, if_exists='replace', index=False)

# 💡 기존 데이터에 추가하고 싶으면 'append' 사용
df.to_sql('students', conn, if_exists='append', index=False)

    기본 문제¶

    문제 1. 데이터셋에서 '행(Row)'과 '열(Column)'이 각각 무엇을 의미하는지 자신의 말로 설명해보세요.

    정답 확인 **행(Row)**은 하나의 관측 대상에 대한 전체 정보입니다. 예를 들어, 한 학생의 이름, 나이, 점수 등 모든 정보를 담은 한 줄이 하나의 행입니다. **열(Column)**은 하나의 속성(특성)입니다. "이름"이라는 열에는 모든 학생의 이름이, "점수"라는 열에는 모든 학생의 점수가 들어있습니다.

    문제 2. 다음 SQL 문이 하는 일을 설명하세요.

    SELECT name, score FROM students WHERE age = 17 ORDER BY score DESC;
    정답 확인 students 테이블에서 **나이가 17세인** 학생들의 **이름과 점수**를 **점수가 높은 순서(내림차순)**로 조회합니다. `DESC`는 Descending(내림차순)의 약자입니다.

    import pandas as pd
import sqlite3

math_data = {
    'name': ['김하늘', '이바다', '박숲길'],
    'subject': ['수학', '수학', '수학'],
    'score': [92, 85, 78]
}

eng_data = {
    'name': ['김하늘', '이바다', '박숲길'],
    'subject': ['영어', '영어', '영어'],
    'score': [88, 91, 82]
}

df_math = pd.DataFrame(math_data)
df_eng = pd.DataFrame(eng_data)
df_all = pd.concat([df_math, df_eng], ignore_index=True)

conn = sqlite3.connect('school2.db')
df_all.to_sql('scores', conn, if_exists='replace', index=False)

result = pd.read_sql(

    conn

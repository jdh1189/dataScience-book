    📖 Chapter 03. 데이터셋과 데이터베이스¶

    🎯 이 장에서 배우는 것¶

    • 데이터셋의 구조(행·열·레코드·필드)를 정확히 설명할 수 있다
    • 데이터셋과 데이터베이스의 차이점과 관계를 비교할 수 있다
    • CSV 파일을 코랩에서 불러와 기본 구조를 확인할 수 있다

    💬 생각해보기: 학교 성적표는 데이터셋일까, 데이터베이스일까? 잠시 생각해보고, 이 장을 다 읽은 뒤 다시 답해봅시다.

    📚 핵심 개념¶

    개념 1: 데이터셋 — 한 장의 스프레드시트¶

    비유로 시작 🧩

    "데이터셋은 마치 엑셀 시트 한 장과 같아요."

    시험이 끝나면 선생님이 성적표를 보여주시죠? 세로 방향으로 학생 이름이 쭉 나열되고, 가로 방향으로 국어·영어·수학 점수가 적혀 있습니다. 이 성적표 전체가 바로 데이터셋(Dataset) 입니다.

    정확한 정의

    데이터셋이란 하나의 주제에 대해 일정한 형식으로 정리된 데이터 모음입니다. 네 가지 핵심 용어를 기억하세요.

    • 행(Row) = 레코드(Record): 한 건의 데이터. 예) 학생 한 명의 전체 정보
    • 열(Column) = 필드(Field): 데이터의 속성 항목. 예) "수학 점수"라는 항목
    • 값(Value): 행과 열이 만나는 곳의 실제 데이터. 예) 95점
    • 헤더(Header): 각 열의 이름이 적힌 맨 윗줄

    예시로 확인

    graph LR A["📋 성적 데이터셋"] --- B["열(필드): 이름, 국어, 영어, 수학"] A --- C["행(레코드): 학생 1명의 전체 성적"] A --- D["값: 김민수의 수학 점수 = 95"]

    📌 알아보기: CSV는 Comma-Separated Values의 약자입니다. 말 그대로 값들을 쉼표(,)로 구분해 저장한 텍스트 파일이에요. 엑셀 없이도 어디서든 열 수 있어서 데이터 과학에서 가장 많이 쓰이는 파일 형식입니다.

    개념 2: 데이터베이스 — 도서관 서가 시스템¶

    비유로 시작 📚

    "데이터베이스는 마치 도서관 전체 관리 시스템과 같아요."

    도서관에는 수만 권의 책이 있습니다. 이 책들을 분류번호로 정리하고, 검색 시스템으로 원하는 책을 찾고, 대출·반납을 관리하죠. 데이터베이스(Database) 는 이처럼 여러 데이터셋을 저장하고, 검색하고, 관리하는 체계적인 시스템입니다.

    정확한 정의

    데이터베이스란 여러 데이터를 구조화하여 저장하고, 효율적으로 검색·수정·삭제할 수 있게 만든 시스템입니다.

    • 저장: 수천만 건의 데이터도 안전하게 보관
    • 검색: 조건에 맞는 데이터를 빠르게 찾기 (예: "서울 카페만 보여줘")
    • 관리: 여러 사람이 동시에 사용해도 데이터가 꼬이지 않게 제어

    개념 3: 데이터셋 vs 데이터베이스¶

    flowchart TB DB["🗄️ 데이터베이스<br/>도서관 전체 시스템"] DS1["📋 데이터셋 1<br/>학생 정보"] DS2["📋 데이터셋 2<br/>성적 정보"] DS3["📋 데이터셋 3<br/>출석 정보"] DB --> DS1 DB --> DS2 DB --> DS3 style DB fill:#4A90D9,color:#fff,stroke:#2C5F8A style DS1 fill:#F5A623,color:#fff,stroke:#C47D0E style DS2 fill:#F5A623,color:#fff,stroke:#C47D0E style DS3 fill:#F5A623,color:#fff,stroke:#C47D0E

    핵심 차이를 정리하면 이렇습니다.

    • 데이터셋 → 데이터 그 자체 (엑셀 시트 한 장, CSV 파일 하나)
    • 데이터베이스 → 데이터셋들을 담고 관리하는 시스템 (도서관 전체)

    쉽게 말해, 데이터셋은 "내용물", 데이터베이스는 "내용물 + 관리 체계" 입니다.

    💡 정리하기: 성적표 한 장은 데이터셋이고, 학교 전체 학생의 성적·출결·인적사항을 통합 관리하는 학교 행정 시스템은 데이터베이스입니다. 처음 질문의 답이 보이시나요?

    ⚠️ 주의할 점¶

    1. CSV 파일의 인코딩 문제: 한글이 포함된 CSV 파일을 불러올 때 글자가 깨지면 encoding="cp949" 또는 encoding="euc-kr"로 바꿔보세요.
    2. 데이터셋 ≠ 데이터베이스: 둘을 같은 의미로 쓰는 경우가 많지만, 엄밀히 다릅니다. 데이터셋은 "데이터 파일 하나", 데이터베이스는 "여러 데이터를 관리하는 시스템"으로 구분하세요.

    ✅ 점검하기¶

    1. (기본) 빈칸을 채우세요.

    데이터셋에서 한 명의 학생 정보처럼 가로 한 줄을 __이라 하고, "수학 점수"처럼 세로 한 줄의 속성 항목을 ____이라 한다.

    정답 확인 가로 한 줄 = **행(Row)** 또는 **레코드(Record)** 세로 한 줄 = **열(Column)** 또는 **필드(Field)**

    2. (응용) 다음 중 데이터베이스에 해당하는 것을 모두 고르세요.

    • ⓐ 반 친구 연락처를 적은 엑셀 파일 한 장
    • ⓑ 네이버 회원 정보를 저장·검색·관리하는 시스템
    • ⓒ USB에 저장된 CSV 파일 하나
    • ⓓ 학교 도서관의 도서 대출 관리 프로그램
    정답 확인 **ⓑ, ⓓ** ⓐ과 ⓒ는 데이터셋(파일 하나)이고, ⓑ과 ⓓ는 저장·검색·관리 기능을 갖춘 데이터베이스 시스템입니다.

    3. (심화) df.shape의 결과가 (1200, 8)이었습니다. 이 데이터셋에는 몇 개의 레코드와 몇 개의 필드가 있나요?

    정답 확인 **1,200개의 레코드(행)** 와 **8개의 필드(열)** 가 있습니다. `shape`는 항상 **(행 수, 열 수)** 순서로 출력됩니다.

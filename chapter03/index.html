    Chapter 03. 데이터셋과 데이터베이스¶

    🎯 이 장에서 배우는 것¶

    • 데이터셋의 구조(행·열·값)를 이해하고 용어를 정확히 사용할 수 있다
    • CSV, Excel 등 파일 형태의 데이터셋을 pandas로 불러오고 저장할 수 있다
    • head(), shape, info() 등으로 데이터를 탐색할 수 있다
    • 데이터베이스의 개념을 이해하고, 데이터셋과의 차이를 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    여러분 학교 도서관에는 수천 권의 책이 있습니다. 이 책들의 목록을 관리한다고 생각해보세요.

    "엑셀 파일 하나면 충분할까요? 아니면 더 체계적인 시스템이 필요할까요?"

    우리는 매일 데이터와 함께 살고 있습니다. 시험 성적표, 출석부, 급식 메뉴표, 음악 플레이리스트… 이 모든 것이 데이터입니다. 그런데 이 데이터가 어디에, 어떤 모양으로 저장되어 있느냐에 따라 활용 방법이 완전히 달라집니다.

    친구 5명의 연락처를 저장할 때는 메모장이면 충분하지만, 전교생 1,000명의 정보를 관리하려면 더 체계적인 도구가 필요합니다. 이번 장에서는 데이터를 담는 두 가지 대표적인 그릇인 데이터셋과 데이터베이스를 배웁니다. 이것을 이해하면, 앞으로 어떤 데이터를 만나도 "아, 이건 이런 구조구나!"라고 바로 파악할 수 있게 됩니다.

    📚 핵심 개념¶

    개념 1: 데이터셋의 구조 — 행, 열, 값¶

    1) 비유로 시작 📖¶

    여러분의 시험 성적표를 떠올려보세요.

    • 세로로 쭉 나열된 학생 이름이 있고
    • 가로로 쭉 나열된 과목이 있고
    • 그 교차점에 점수가 적혀 있죠

    이것이 바로 데이터셋의 구조입니다! 성적표는 사실 완벽한 데이터셋이었던 거예요.

    2) 정확한 정의 📐¶

    데이터셋(Dataset) 이란 분석을 위해 체계적으로 정리된 데이터의 모음입니다. 데이터셋은 다음 세 가지 요소로 구성됩니다.

    • 행(Row) — 관측치(Observation)라고도 부릅니다. 하나의 대상에 대한 정보 묶음입니다. 성적표에서 "김민수" 한 줄 전체가 하나의 행입니다.
    • 열(Column) — 변수(Variable)라고도 부릅니다. 측정하거나 기록한 항목의 종류입니다. "국어", "수학", "영어" 같은 과목명이 열에 해당합니다.
    • 값(Value) — 특정 행과 열이 만나는 지점의 데이터입니다. "김민수의 국어 점수 = 85"에서 "85"가 값입니다.
    graph TB subgraph 데이터셋의_구조 direction TB A["📊 데이터셋<br/>(Dataset)"] --> B["↔️ 열 = 변수<br/>(Column = Variable)<br/>예: 이름, 국어, 수학"] A --> C["↕️ 행 = 관측치<br/>(Row = Observation)<br/>예: 학생 한 명의 정보"] A --> D["⭐ 값<br/>(Value)<br/>예: 85점, 92점"] end

    3) 예시로 확인 ✅¶

    우리 반 성적 데이터셋을 예로 들어보겠습니다.

    # 성적 데이터셋을 파이썬으로 표현하면 이렇습니다
import pandas as pd

data = {
    '이름': ['김민수', '이서연', '박지호', '최유진'],
    '국어': [85, 92, 78, 95],
    '수학': [90, 88, 95, 82],
    '영어': [88, 95, 80, 90]
}
df = pd.DataFrame(data)
print(df)

    실행 결과:

       이름  국어  수학  영어
0  김민수  85  90  88
1  이서연  92  88  95
2  박지호  78  95  80
3  최유진  95  82  90

    이 데이터셋에서 각 요소를 짚어보면 다음과 같습니다.

    • 행 수: 4개 (학생 4명 = 관측치 4개)
    • 열 수: 4개 (이름, 국어, 수학, 영어 = 변수 4개)
    • 값의 예: 1행 2열의 값은 90 (김민수의 수학 점수)

    알아보기 💡

    같은 것을 다른 말로 부르는 경우가 많아서 헷갈릴 수 있습니다. 정리하면 이렇습니다.

    • 행 = 관측치 = 레코드(record) = 샘플(sample) → 모두 "가로 한 줄"
    • 열 = 변수 = 필드(field) = 속성(attribute) = 특성(feature) → 모두 "세로 한 줄"

    분야마다 선호하는 용어가 다르지만, 가리키는 것은 같습니다!

    개념 2: 데이터 파일 형식 — CSV와 Excel¶

    1) 비유로 시작 📖¶

    사진을 저장할 때 JPG, PNG, GIF 등 다양한 형식이 있듯이, 데이터를 저장하는 파일 형식도 여러 가지입니다. 그중 가장 많이 쓰이는 두 가지가 CSV와 Excel입니다.

    2) 정확한 정의 📐¶

    CSV (Comma-Separated Values)

    • 데이터를 쉼표(,) 로 구분하여 저장하는 텍스트 파일입니다
    • 확장자: .csv
    • 메모장으로 열어보면 내용을 직접 읽을 수 있습니다
    • 가장 보편적이고 가벼운 데이터 교환 형식입니다

    CSV 파일을 메모장으로 열면 이렇게 생겼습니다.

    이름,국어,수학,영어
김민수,85,90,88
이서연,92,88,95
박지호,78,95,80
최유진,95,82,90

    쉼표로 구분되어 있기 때문에 "Comma-Separated Values(쉼표로 분리된 값)"이라는 이름이 붙었습니다.

    Excel 파일

    • 마이크로소프트 엑셀 전용 형식입니다
    • 확장자: .xlsx 또는 .xls
    • 셀 서식, 수식, 여러 시트 등 다양한 기능을 포함할 수 있습니다
    • CSV보다 파일 크기가 크지만, 기능이 풍부합니다

    3) 예시로 확인 ✅¶

    두 형식의 핵심 차이를 정리하면 이렇습니다.

    graph LR subgraph CSV A1["📄 텍스트 파일"] A2["가볍고 빠름"] A3["어디서든 열림"] A4["서식 정보 없음"] end subgraph Excel B1["📗 전용 파일"] B2["기능이 풍부"] B3["엑셀 필요"] B4["서식·수식 포함"] end CSV -- "데이터만 필요하면" --> A2 Excel -- "서식도 필요하면" --> B4

    알아보기 💡

    데이터 과학에서는 CSV 파일을 압도적으로 많이 사용합니다. 이유는 간단합니다. - 가볍습니다 (같은 데이터라도 파일 크기가 작음) - 어떤 프로그래밍 언어에서든 쉽게 읽을 수 있습니다 - 공공데이터 포털, 캐글(Kaggle) 등에서 제공하는 표준 형식입니다

    그래서 이번 장에서도 CSV를 중심으로 배우겠습니다!

    개념 3: pandas로 데이터 불러오기와 탐색¶

    1) 비유로 시작 📖¶

    CSV 파일은 재료이고, pandas는 그 재료를 다루는 요리 도구입니다. 아무리 좋은 식재료가 있어도 칼과 도마가 없으면 요리를 할 수 없듯이, 데이터 파일이 있어도 pandas가 없으면 분석을 시작할 수 없습니다.

    2) 정확한 정의 📐¶

    pandas는 파이썬에서 데이터를 불러오고, 탐색하고, 가공하는 데 사용하는 라이브러리(도구 모음)입니다.

    pandas에서 데이터를 다루는 핵심 도구가 DataFrame(데이터프레임) 입니다. 데이터프레임은 앞에서 배운 데이터셋을 파이썬 안에서 표현한 것이라고 생각하면 됩니다. 행과 열로 이루어진 2차원 표 구조를 그대로 가지고 있습니다.

    데이터를 다루는 핵심 함수 4가지를 알아보겠습니다.

    • pd.read_csv('파일명') — CSV 파일을 읽어서 DataFrame으로 만듭니다
    • df.head(n) — 위에서 n개 행만 미리보기 합니다 (기본값 5)
    • df.shape — (행 수, 열 수)를 알려줍니다
    • df.info() — 열 이름, 데이터 타입, 비어있는 값 개수 등 전체 요약 정보를 보여줍니다

    3) 예시로 확인 ✅¶

    import pandas as pd

# 예시: 위에서 만든 데이터를 CSV로 저장 후 다시 읽기
df = pd.DataFrame({
    '이름': ['김민수', '이서연', '박지호', '최유진'],
    '국어': [85, 92, 78, 95],
    '수학': [90, 88, 95, 82],
    '영어': [88, 95, 80, 90]
})

# CSV로 저장
df.to_csv('성적표.csv', index=False)

# CSV 읽기
df_loaded = pd.read_csv('성적표.csv')

# 탐색하기
print(df_loaded.head())     # 처음 5행 보기
print(df_loaded.shape)      # (4, 4) → 4행 4열
print(df_loaded.info())     # 전체 구조 요약

    알아보기 💡

    to_csv()에서 index=False를 쓰는 이유가 궁금하죠?

    pandas는 자동으로 행 번호(0, 1, 2, ...)를 만들어주는데, 이걸 인덱스(index) 라고 합니다. index=False를 안 쓰면 CSV 파일에 이 행 번호가 별도 열로 저장되어 나중에 읽을 때 불필요한 열이 하나 더 생깁니다.

    개념 4: 데이터베이스 — 데이터셋과 무엇이 다를까?¶

    1) 비유로 시작 📖¶

    학교 도서관을 생각해봅시다.

    • CSV 파일 = 종이에 손으로 쓴 도서 목록표 📋: 한 사람이 보기엔 괜찮지만, 여러 사람이 동시에 수정하면 엉망이 됩니다. 책이 1만 권이면 원하는 책을 찾기도 힘듭니다.

    • 데이터베이스 = 도서관 검색 컴퓨터 시스템 🖥️: 여러 학생이 동시에 검색해도 문제없고, "2024년에 출판된 과학 분야 도서"처럼 복잡한 조건으로도 빠르게 찾아줍니다.

    2) 정확한 정의 📐¶

    데이터베이스(Database) 란 데이터를 체계적으로 저장하고 효율적으로 관리·검색할 수 있게 해주는 시스템입니다.

    단순한 파일이 아니라 다음과 같은 기능을 갖춘 소프트웨어 시스템입니다.

    • 대용량 처리: 수백만, 수억 건의 데이터도 빠르게 처리합니다
    • 동시 접근: 여러 사용자가 동시에 데이터를 읽고 쓸 수 있습니다
    • 검색 최적화: 원하는 데이터를 조건에 맞게 빠르게 찾아줍니다
    • 안전성: 데이터가 손상되거나 유실되지 않도록 보호합니다

    데이터베이스를 관리하는 소프트웨어를 DBMS(Database Management System) 라고 하며, MySQL, PostgreSQL, SQLite, Oracle 등이 대표적입니다.

    3) 예시로 확인 ✅¶

    데이터셋(파일)과 데이터베이스의 차이를 비교해보겠습니다.

    생각해보기 🤔

    다음 상황에서 데이터셋(CSV)과 데이터베이스 중 어떤 것이 더 적합할까요?

    1. 과학 실험 결과 30건을 정리해서 분석하기 → CSV가 적합! (소규모, 혼자 사용)
    2. 전국 학교 급식 메뉴를 매일 업데이트하고 학생·학부모가 검색하기 → 데이터베이스가 적합! (대규모, 다수 사용)
    3. 캐글에서 다운로드한 데이터로 분석 연습하기 → CSV가 적합!

    이 수업에서는 주로 CSV 파일 형태의 데이터셋을 다룹니다. 데이터베이스는 나중에 더 깊이 배우게 됩니다.

    Step 1: 실습용 데이터 준비하기¶

    실제 공공데이터 포털에서 데이터를 다운로드하는 방법도 있지만, 이번 실습에서는 코랩에서 바로 실행할 수 있도록 샘플 데이터를 직접 만들어 사용하겠습니다. 이 데이터는 실제 서울시 공공도서관 데이터의 형식을 따른 것입니다.

    Google Colab에 접속하여 새 노트북을 열고, 아래 코드를 첫 번째 셀에 입력하세요.

    import pandas as pd

# 서울시 공공도서관 샘플 데이터 만들기

             '서대문구', '양천구'],

    Step 3: head()로 미리보기¶

    데이터가 수천, 수만 행이라면 전부 출력하면 화면이 가득 차버립니다. head()를 사용하면 앞부분만 살짝 볼 수 있습니다.

    # 처음 3개 행만 보기
print(df.head(3))

    실행 결과:

          도서관명  자치구    장서수  좌석수  개관연도
0    서울도서관   중구  268130   824  2012
1    남산도서관  용산구  215000   512  1965
2    강남도서관  강남구  189500   680  2003

    # 기본값은 5개 행
print(df.head())

    # 반대로 마지막 행을 보고 싶다면 tail() 사용
print(df.tail(3))

    실행 결과:

          도서관명   자치구    장서수  좌석수  개관연도
7    도봉도서관   도봉구  167300   340  2012
8   서대문도서관  서대문구  156800   420  1976
9    양천도서관   양천구  143900   360  2008

    알아보기 💡

    • head(n) — 위에서 n개 행 (기본 5개)
    • tail(n) — 아래에서 n개 행 (기본 5개)

    데이터를 처음 받았을 때 head()로 "이 데이터가 어떻게 생겼나?" 확인하는 것은 데이터 분석의 첫걸음입니다!

    Step 4: shape으로 크기 확인하기¶

    데이터가 몇 행 몇 열인지 숫자로 한눈에 파악해봅시다.

    # 데이터셋의 크기 확인
print(df.shape)

    실행 결과:

    (10, 5)

    이 결과는 (행 수, 열 수) 를 의미합니다.

    • 10: 관측치(도서관)가 10개
    • 5: 변수(도서관명, 자치구, 장서수, 좌석수, 개관연도)가 5개
    # 행 수만 따로 알고 싶을 때
print(f"행 수: {df.shape[0]}")
print(f"열 수: {df.shape[1]}")

    실행 결과:

    행 수: 10
열 수: 5

    주의 ⚠️

    shape는 함수가 아니라 속성(property) 이므로 괄호 ()를 붙이지 않습니다! - ✅ df.shape (올바름) - ❌ df.shape() (오류 발생)

    Step 5: info()로 상세 정보 확인하기¶

    info()는 데이터셋의 "건강 진단서" 같은 역할을 합니다. 각 열의 이름, 데이터 타입, 비어있는 값이 있는지 한꺼번에 알려줍니다.

    # 데이터셋 상세 정보
df.info()

    실행 결과:

    <class 'pandas.core.frame.DataFrame'>
RangeIndex: 10 entries, 0 to 9
Data columns (total 5 columns):
 #   Column  Non-Null Count  Dtype
---  ------  --------------  -----
 0   도서관명    10 non-null     object
 1   자치구     10 non-null     object
 2   장서수     10 non-null     int64
 3   좌석수     10 non-null     int64
 4   개관연도    10 non-null     int64
dtypes: int64(3), object(2)
memory usage: 528.0+ bytes

    이 결과를 해석해봅시다.

    • RangeIndex: 10 entries → 행이 10개 (0번~9번)
    • total 5 columns → 열이 5개
    • Non-Null Count → 비어있지 않은 값의 수 (10 non-null이면 빈 값 없음 ✅)
    • Dtype → 데이터 타입
    • object → 문자열 (도서관명, 자치구)
    • int64 → 정수 (장서수, 좌석수, 개관연도)

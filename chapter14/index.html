    제14장: 군집 분석¶

    🎯 이 장에서 배우는 것¶

    • 군집 분석의 개념을 이해하고, 실생활 활용 사례(고객 세분화, 이미지 분류 등)를 설명할 수 있다.
    • K-Means 알고리즘의 동작 원리를 4단계로 설명할 수 있다.
    • scikit-learn을 사용하여 K-Means 군집 분석을 직접 실행할 수 있다.
    • K값을 변경하며 결과를 비교하고, 엘보우 기법으로 적절한 K를 선택할 수 있다.

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    반 친구 30명을 "취미", "좋아하는 음악 장르", "식습관"으로 그룹을 나눈다면, 몇 개의 그룹이 나올까요? 운동을 좋아하고 힙합을 듣는 친구들끼리, 독서를 좋아하고 클래식을 듣는 친구들끼리 자연스럽게 묶이지 않을까요?

    우리는 일상에서 끊임없이 "비슷한 것끼리 묶는" 일을 합니다.

    • 🎵 음악 스트리밍 앱이 "당신과 비슷한 취향의 사용자들이 듣는 플레이리스트"를 추천할 때
    • 🛒 쇼핑몰이 고객을 "VIP / 일반 / 휴면"으로 나누어 다른 쿠폰을 보낼 때
    • 📸 사진 앱이 수천 장의 사진을 자동으로 "여행", "음식", "친구" 폴더로 분류할 때

    이 모든 것의 뒤에는 군집 분석(Clustering)이라는 기술이 숨어 있습니다.

    지금까지 우리가 배운 분류(Classification)는 정답 라벨이 있는 지도학습이었습니다. "이 이메일은 스팸이다/아니다"처럼 미리 정해진 카테고리가 있었죠. 하지만 군집 분석은 정답이 없는 상태에서 데이터 스스로 비슷한 것끼리 묶이도록 하는 비지도학습(Unsupervised Learning)입니다.

    이번 장에서는 가장 대표적인 군집 알고리즘인 K-Means를 배우고, 실제 데이터에 적용해 봅니다.

    📚 핵심 개념¶

    개념 1: 군집 분석이란? 🧩¶

    1. 비유로 시작¶

    체육 시간에 선생님이 이렇게 말합니다.

    "자, 비슷한 실력끼리 알아서 3팀으로 나눠봐!"

    아무런 기준표 없이도 학생들은 서로의 실력을 대략 알고 있어서, 자연스럽게 비슷한 수준끼리 모입니다. 이것이 바로 군집 분석의 핵심 아이디어입니다. 미리 정해진 "정답 라벨" 없이, 데이터가 가진 특성만으로 비슷한 것끼리 그룹을 만드는 것입니다.

    2. 정확한 정의¶

    군집 분석(Cluster Analysis)이란, 레이블(정답)이 없는 데이터를 유사도(similarity)에 기반하여 여러 개의 그룹(군집, cluster)으로 나누는 비지도학습 기법입니다.

    핵심 원칙은 두 가지입니다.

    • 같은 군집 내부: 데이터끼리 최대한 비슷하게 (유사도 높게)
    • 다른 군집 사이: 데이터끼리 최대한 다르게 (유사도 낮게)
    graph LR subgraph 지도학습 A["분류(Classification)"] --> B["정답 라벨 있음 ✅"] B --> C["예: 스팸/정상 분류"] end subgraph 비지도학습 D["군집(Clustering)"] --> E["정답 라벨 없음 ❌"] E --> F["예: 고객 그룹 발견"] end

    3. 예시로 확인¶

    실생활 활용 사례

    • 고객 세분화(Customer Segmentation) 🛍️: 온라인 쇼핑몰에서 구매 금액, 방문 빈도, 구매 카테고리를 기준으로 고객을 5개 그룹으로 나눕니다. 각 그룹에 맞는 맞춤형 마케팅 전략을 세울 수 있습니다.
    • 이미지 압축 🖼️: 수백만 가지 색상을 16가지 대표 색상 군집으로 줄여서, 파일 크기를 획기적으로 줄입니다.
    • 문서 분류 📄: 뉴스 기사 수천 건을 주제별(정치, 경제, 스포츠, 연예)로 자동 묶습니다.
    • 이상 탐지 🚨: 대부분의 데이터가 속한 군집에서 멀리 떨어진 데이터를 "이상치"로 감지합니다.

    정리하기 📌

    군집 분석 = 정답 없이, 비슷한 데이터끼리 자동으로 그룹 짓기. 핵심은 "같은 그룹은 비슷하게, 다른 그룹은 다르게"입니다.

    개념 2: K-Means 알고리즘의 동작 원리 ⚙️¶

    1. 비유로 시작¶

    "교실에서 모둠 자리 배치하기"를 상상해 봅시다.

    선생님이 교실에서 3개의 모둠을 만들려고 합니다.

    1. Step 1 — 선생님이 교실 안 임의의 3곳에 깃발을 꽂습니다. (초기 중심점 설정)
    2. Step 2 — 각 학생은 자기에게 가장 가까운 깃발 쪽으로 갑니다. (할당)
    3. Step 3 — 각 모둠에서 학생들이 모인 정중앙 위치로 깃발을 옮깁니다. (중심점 재계산)
    4. Step 4 — 깃발이 옮겨졌으니, 다시 학생들이 가장 가까운 깃발로 이동합니다. 깃발이 더 이상 움직이지 않을 때까지 2~3번을 반복합니다. (수렴)

    이것이 K-Means의 전부입니다!

    2. 정확한 정의¶

    K-Means 알고리즘은 데이터를 K개의 군집으로 나누는 알고리즘입니다. 여기서 K는 우리가 미리 지정하는 군집의 수입니다.

    flowchart TD A["1️⃣ K개의 초기 중심점을\n무작위로 설정"] --> B["2️⃣ 각 데이터를\n가장 가까운 중심점에 할당"] B --> C["3️⃣ 각 군집의\n평균 위치로 중심점 이동"] C --> D{"중심점이\n변했는가?"} D -- "예 ✅" --> B D -- "아니오 ❌\n(수렴!)" --> E["4️⃣ 완료!\n군집 확정"]

    각 단계를 좀 더 자세히 살펴보겠습니다.

    1️⃣ 초기 중심점(centroid) 설정 - K개의 점을 데이터 중에서 무작위로 선택합니다. - 이 점들이 각 군집의 "대표"(중심점) 역할을 합니다. - "centroid(센트로이드)"란 군집의 중심 좌표를 뜻합니다.

    2️⃣ 할당(Assignment) - 모든 데이터 포인트에 대해, 각 중심점까지의 거리를 계산합니다. - 가장 가까운 중심점의 군집에 해당 데이터를 배정합니다. - 거리는 보통 유클리드 거리(두 점 사이의 직선 거리)를 사용합니다.

    3️⃣ 중심점 재계산(Update) - 각 군집에 속한 데이터들의 평균 좌표를 새 중심점으로 합니다. - 예를 들어 군집 A에 (1,2), (3,4), (2,3)이 속하면 새 중심점은 (2, 3)입니다.

    4️⃣ 수렴(Convergence) 확인 - 중심점이 이전과 달라졌으면 2~3번을 반복합니다. - 중심점이 더 이상 변하지 않으면(또는 변화가 매우 작으면) 종료합니다.

    3. 예시로 확인¶

    아주 간단한 숫자 예시를 하나 살펴봅시다. 1차원 데이터 6개가 있습니다.

    데이터: 2, 3, 10, 12, 20, 22

    K=2로 설정하고, 초기 중심점을 3과 20으로 잡았다면:

    반복 1회차 - 할당: {2, 3, 10, 12} → 중심점 3에 가까움, {20, 22} → 중심점 20에 가까움 - 재계산: 그룹1 평균 = (2+3+10+12)/4 = 6.75, 그룹2 평균 = (20+22)/2 = 21

    반복 2회차 - 할당: {2, 3} → 6.75에 가까움, {10, 12, 20, 22} → 여기서 10은 6.75와 거리 3.25, 21과 거리 11이므로 그룹1. 12는 6.75와 거리 5.25, 21과 거리 9이므로 그룹1. 결국 {2, 3, 10, 12} → 그룹1, {20, 22} → 그룹2 - 재계산: 그룹1 평균 = 6.75, 그룹2 평균 = 21 (변화 없음!)

    수렴 완료! ✨ 최종 군집: {2, 3, 10, 12}와 {20, 22}

    알아보기 🔍

    유클리드 거리란? 두 점 (x₁, y₁)과 (x₂, y₂) 사이의 직선 거리입니다. 공식: √((x₂-x₁)² + (y₂-y₁)²) 중학교 수학의 "두 점 사이의 거리" 공식과 동일합니다!

    개념 3: K값 선택 — 엘보우 기법 📐¶

    1. 비유로 시작¶

    피자를 나눠 먹을 때를 생각해 봅시다. 🍕

    • 2조각으로 나누면? 한 조각이 너무 큽니다.
    • 4조각으로 나누면? 적당합니다!
    • 8조각으로 나누면? 먹기 편하지만 나누는 의미가 줄어듭니다.
    • 100조각으로 나누면? 거의 부스러기입니다. 의미 없죠.

    군집도 마찬가지입니다. K를 너무 작게 하면 다른 성격의 데이터가 한 그룹에 섞이고, K를 너무 크게 하면 의미 있는 그룹이 만들어지지 않습니다. 적절한 K를 찾는 것이 핵심입니다.

    2. 정확한 정의¶

    엘보우 기법(Elbow Method)은 K값에 따른 이너셔(Inertia)의 변화를 그래프로 그려서, 그래프가 팔꿈치(elbow)처럼 꺾이는 지점을 최적의 K로 선택하는 방법입니다.

    이너셔(Inertia)란 각 데이터 포인트에서 자신이 속한 군집의 중심점까지의 거리 제곱의 합입니다. 쉽게 말하면, 군집 내부가 얼마나 빡빡하게 모여 있는지를 나타내는 숫자입니다.

    • 이너셔가 작을수록 → 군집 내부가 촘촘 → 좋은 군집
    • K를 늘리면 이너셔는 항상 줄어듭니다 (극단적으로 K=데이터 수이면 이너셔=0)
    • 하지만 어느 시점부터 줄어드는 폭이 확 줄어듭니다 → 그 지점이 엘보우!
    graph LR A["K=1<br/>이너셔 매우 큼"] --> B["K=2<br/>확 줄어듦"] B --> C["K=3<br/>또 줄어듦"] C --> D["K=4 ← 엘보우!<br/>여기서 꺾임"] D --> E["K=5<br/>조금만 줄어듦"] E --> F["K=6<br/>거의 안 줄어듦"]

    3. 예시로 확인¶

    엘보우 그래프를 해석하는 방법:

    • K=1에서 K=2로 갈 때 이너셔가 1000에서 400으로 크게 감소
    • K=2에서 K=3으로 갈 때 400에서 200으로 꽤 감소
    • K=3에서 K=4로 갈 때 200에서 180으로 조금 감소
    • K=4 이후로는 거의 변화 없음

    → K=3이 엘보우 포인트! 여기가 최적의 K입니다.

    정리하기 📌

    K값 선택은 "감소폭이 급격히 줄어드는 지점"을 찾는 것입니다. 엘보우 기법은 완벽한 답을 주는 것이 아니라, 합리적인 출발점을 제시합니다.

    개념 4: 군집 분석의 한계와 주의사항 ⚠️¶

    1. 비유로 시작¶

    K-Means를 "자석"으로 비유할 수 있습니다. 🧲 교실 바닥에 3개의 자석을 놓으면 철가루가 가까운 자석으로 끌려가죠. 하지만:

    • 자석을 처음에 어디에 놓느냐에 따라 결과가 달라질 수 있고
    • 철가루가 동그란 형태가 아니라 반달 모양으로 흩어져 있으면 잘 안 됩니다

    2. 정확한 정의¶

    K-Means의 주요 한계점:

    • 초기 중심점 의존성: 무작위로 시작하기 때문에, 실행할 때마다 결과가 달라질 수 있습니다. 이를 해결하기 위해 scikit-learn은 K-Means++라는 똑똑한 초기화 방법을 기본으로 사용합니다.
    • 구형(둥근 형태) 군집 가정: K-Means는 군집이 원형으로 퍼져 있다고 가정합니다. 초승달 모양이나 고리 모양의 군집은 잘 찾지 못합니다.
    • K를 미리 정해야 함: 군집 수를 우리가 사전에 지정해야 하는데, 실제 데이터에서는 군집이 몇 개인지 모르는 경우가 대부분입니다.
    • 이상치에 민감: 극단적인 값이 있으면 중심점이 크게 끌려갑니다.

    3. 예시로 확인¶

    같은 데이터에 K-Means를 3번 실행했는데, 결과가 미묘하게 달라지는 경우가 생길 수 있습니다. 이를 방지하기 위해:

    • n_init=10 옵션: 10번 실행해서 가장 좋은 결과를 자동으로 선택 (scikit-learn 기본값)
    • random_state=42: 결과를 고정하여 재현 가능하게 만듦

    알아보기 🔍

    K-Means 말고 다른 군집 알고리즘은 없나요? 있습니다! DBSCAN(밀도 기반), 계층적 군집 분석 등이 있습니다. 이들은 K를 미리 정하지 않아도 되거나, 비구형 군집도 찾을 수 있습니다. 하지만 K-Means가 가장 직관적이고 빠르기 때문에, 먼저 K-Means로 시작하는 것이 일반적입니다.

    🔨 따라하기: 아이돌 그룹 멤버 데이터로 군집 분석 실습¶

    이번 실습에서는 가상의 아이돌 그룹 멤버 데이터를 만들어서, K-Means 군집 분석을 직접 수행합니다. Google Colab에서 바로 실행할 수 있습니다.

    Step 1: 데이터 준비하기 📦¶

    먼저 필요한 라이브러리를 불러오고, 아이돌 멤버 데이터를 생성합니다.

    # 라이브러리 불러오기
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 한글 폰트 설정 (Colab 환경)
plt.rc('font', family='DejaVu Sans')

# 가상 아이돌 멤버 데이터 생성
np.random.seed(42)

data = {
    'name': [
        '민지', '하니', '다니엘', '해린', '혜인',
        '카리나', '윈터', '지젤', '닝닝',
        '은비', '사쿠라', '채원', '민주', '유리',
        '지수', '제니', '로제', '리사',
        '나연', '정연', '모모', '사나', '지효', '미나', '다현', '채영', '쯔위'
    ],
    'height': [
        169, 170, 165, 165, 170,
        168, 167, 163, 165,
        160, 163, 164, 162, 160,
        162, 163, 169, 167,
        163, 167, 162, 163, 160, 163, 159, 159, 170
    ],
    'age': [
        20, 20, 19, 18, 17,
        24, 23, 23, 22,
        27, 26, 24, 23, 24,
        29, 28, 27, 27,
        29, 28, 27, 27, 27, 26, 25, 24, 25
    ],
    'career_years': [
        2, 2, 2, 2, 2,
        4, 4, 4, 4,
        6, 6, 5, 5, 6,
        9, 9, 9, 9,
        8, 8, 8, 8, 8, 8, 8, 8, 8
    ]
}

df = pd.DataFrame(data)
print("🎤 아이돌 멤버 데이터 (처음 10명)")
print(df.head(10))
print(f"\n전체 멤버 수: {len(df)}명")

    알아보기 🔍

    실습 데이터는 실제 아이돌 멤버 정보를 참고한 가상 데이터입니다. 키(cm), 나이(세), 활동 기간(년)의 3가지 특성(feature)을 사용합니다.

    Step 2: 데이터 전처리 — 스케일링 📏¶

    K-Means는 거리를 기반으로 동작합니다. 키는 159~170 범위이고, 활동 기간은 2~9 범위입니다. 이렇게 단위와 범위가 다르면, 값이 큰 특성(키)이 결과를 지배하게 됩니다.

    이를 방지하기 위해 표준화(Standardization)를 해야 합니다.

    # 군집 분석에 사용할 수치 특성만 선택
features = df[['height', 'age', 'career_years']]

# StandardScaler로 표준화 (평균=0, 표준편차=1로 변환)
scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)

# 결과 확인
df_scaled = pd.DataFrame(features_scaled, columns=['height', 'age', 'career_years'])
print("📊 표준화 전 (처음 5명)")
print(features.head())
print("\n📊 표준화 후 (처음 5명)")
print(df_scaled.head().round(2))

    생각해보기 🤔

    표준화를 하지 않으면 어떻게 될까요? 키 값의 차이(최대 11cm 차이)가 활동 기간의 차이(최대 7년 차이)보다 수치적으로 크기 때문에, 군집이 거의 "키" 하나만으로 결정될 수 있습니다. 표준화를 통해 모든 특성이 동등한 영향력을 갖게 합니다.

    Step 3: K-Means 실행하기 (K=3) 🚀¶

    이제 K-Means를 실행합니다. 먼저 K=3으로 시작해 봅시다.

    # K=3으로 K-Means 실행
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['cluster'] = kmeans.fit_predict(features_scaled)

# 각 군집별 멤버 확인
for i in range(3):
    members = df[df['cluster'] == i]['name'].tolist()
    print(f"\n🟢 군집 {i}: {len(members)}명")
    print(f"   멤버: {', '.join(members)}")

# 각 군집의 평균 특성 확인
print("\n📊 군집별 평균 특성")
cluster_summary = df.groupby('cluster')[['height', 'age', 'career_years']].mean().round(1)
print(cluster_summary)

    코드를 한 줄씩 이해해 봅시다.

    • KMeans(n_clusters=3) → K=3, 즉 3개 군집으로 나눠라
    • random_state=42 → 결과를 고정 (재현 가능하게)
    • n_init=10 → 초기 중심점을 10번 다르게 시도해서 가장 좋은 결과 선택
    • fit_predict() → 모델 학습과 예측(군집 할당)을 동시에 수행

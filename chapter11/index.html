    Chapter 11. 군집 분석 — 비슷한 것끼리 모으자¶

    🎯 이 장에서 배우는 것¶

    • 군집 분석의 개념과 비지도 학습에서의 위치를 설명할 수 있다
    • K-Means 알고리즘의 동작 원리를 단계별로 설명할 수 있다
    • 엘보우 기법으로 적절한 군집 수(K)를 결정할 수 있다
    • Python으로 군집 분석을 수행하고 결과를 시각화할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    반 친구 30명을 취미가 비슷한 그룹으로 나눈다면 몇 그룹이 될까요? 게임을 좋아하는 친구들, 운동을 좋아하는 친구들, 독서를 좋아하는 친구들… 우리는 본능적으로 비슷한 것끼리 묶는 작업을 합니다.

    이것이 바로 군집 분석(Clustering)입니다. 실제로 이 기술은 우리 생활 곳곳에서 사용됩니다.

    • 🎵 음악 스트리밍 서비스: "비슷한 취향의 사용자"를 묶어서 플레이리스트 추천
    • 🛒 쇼핑몰: 고객을 구매 패턴별로 나누어 맞춤 할인 쿠폰 발송
    • 🏥 의료: 환자를 증상 패턴으로 그룹화하여 치료 방향 결정
    • 📰 뉴스: 비슷한 주제의 기사를 자동으로 묶어서 카테고리 생성

    지금까지 우리가 배운 분류(Classification)나 회귀(Regression)는 정답 라벨이 있는 지도 학습이었습니다. 하지만 군집 분석은 정답이 없는 데이터에서 스스로 패턴을 찾아내는 비지도 학습입니다. 데이터만 주고 "알아서 비슷한 것끼리 묶어봐!"라고 하는 것이죠. 이번 장에서 가장 대표적인 군집 알고리즘인 K-Means를 마스터해봅시다!

    📚 핵심 개념¶

    개념 1: 군집 분석이란?¶

    1️⃣ 비유로 시작¶

    체육 시간에 선생님이 이렇게 말씀하셨다고 상상해보세요.

    "자, 운동장에 흩어져 서 있는 학생들! 가까이 있는 친구들끼리 알아서 모여봐!"

    아무런 기준(정답)을 알려주지 않았지만, 학생들은 자연스럽게 가까운 사람끼리 모여서 몇 개의 그룹을 형성합니다. 이것이 군집 분석의 핵심입니다.

    2️⃣ 정확한 정의¶

    군집 분석(Cluster Analysis)이란, 라벨(정답)이 없는 데이터에서 서로 유사한 데이터끼리 그룹(군집)으로 묶는 비지도 학습 기법입니다.

    • 같은 군집 안의 데이터는 서로 최대한 비슷하게
    • 다른 군집 간의 데이터는 서로 최대한 다르게

    이 두 가지 목표를 동시에 달성하는 것이 좋은 군집 분석입니다.

    3️⃣ 지도 학습 vs 비지도 학습¶

    flowchart LR A[머신러닝] --> B[지도 학습] A --> C[비지도 학습] B --> D[분류: 정답 O<br/>예: 스팸 vs 정상] B --> E[회귀: 정답 O<br/>예: 집값 예측] C --> F[군집 분석: 정답 X<br/>예: 고객 세분화] C --> G[차원 축소: 정답 X<br/>예: 데이터 압축] style F fill:#FF6B6B,color:#fff,stroke:#333

    정리하기 📌

    군집 분석은 정답 없이 데이터 자체의 패턴만으로 그룹을 만드는 비지도 학습입니다. "이 데이터가 어떤 그룹인지 나도 몰라. 네가 찾아봐!"라고 컴퓨터에게 맡기는 것이죠.

    개념 2: K-Means 알고리즘¶

    1️⃣ 비유로 시작 — 교실 자리 배치 게임 🎮¶

    교실에 30명의 학생이 아무렇게나 앉아 있습니다. 선생님이 3개 조를 만들려고 합니다.

    1. 선생님이 교실 아무 곳에나 깃발 3개를 꽂습니다 → 초기 중심점 설정
    2. 각 학생은 자기에게 가장 가까운 깃발로 이동합니다 → 가장 가까운 중심에 할당
    3. 각 그룹의 정중앙에 깃발을 다시 꽂습니다 → 중심점 재계산
    4. 학생들이 다시 가장 가까운 깃발로 이동합니다 → 재할당
    5. 더 이상 이동이 없을 때까지 3~4를 반복합니다 → 수렴

    이것이 바로 K-Means의 전체 과정입니다!

    2️⃣ 정확한 정의¶

    K-Means는 데이터를 K개의 군집으로 나누는 알고리즘으로, 각 군집의 중심점(centroid)과 데이터 포인트 사이의 거리를 최소화하는 방향으로 반복 학습합니다.

    • K: 우리가 미리 정하는 군집의 개수
    • Means: 각 군집의 평균(중심점)

    3️⃣ 단계별 동작 원리¶

    flowchart TD S[시작: K값 결정] --> A[Step 1<br/>무작위로 K개 중심점 선택] A --> B[Step 2<br/>각 데이터를 가장 가까운<br/>중심점에 할당] B --> C[Step 3<br/>각 군집의 평균 위치로<br/>중심점 이동] C --> D{중심점이<br/>변했는가?} D -->|예| B D -->|아니오| E[완료!<br/>군집 확정] style E fill:#2ECC71,color:#fff

    구체적인 숫자로 살펴봅시다. 5명의 학생이 있고, 좌표가 다음과 같습니다.

    • 학생 A: (1, 2)
    • 학생 B: (2, 1)
    • 학생 C: (8, 8)
    • 학생 D: (9, 7)
    • 학생 E: (5, 5)

    K=2로 군집을 만들어 봅니다.

    [반복 1] - 초기 중심점을 무작위 선택: C₁=(1,2), C₂=(8,8) - 각 학생과 중심점 사이 거리를 계산하여 더 가까운 쪽에 배정 - A(1,2) → C₁에 가까움 → 군집 1 - B(2,1) → C₁에 가까움 → 군집 1 - E(5,5) → C₂에 가까움 → 군집 2 - C(8,8) → C₂에 가까움 → 군집 2 - D(9,7) → C₂에 가까움 → 군집 2 - 중심점 재계산: C₁ = (1.5, 1.5), C₂ = (7.33, 6.67)

    [반복 2] - 다시 거리 계산하여 재배정 → E(5,5)는 여전히 C₂에 가까움 - 중심점 재계산 → 변화 없음 → 수렴 완료!

    알아보기 🔍

    K-Means에서 "거리"는 기본적으로 유클리드 거리(직선 거리)를 사용합니다. 두 점 (x₁, y₁)과 (x₂, y₂) 사이의 거리는 √((x₁-x₂)² + (y₁-y₂)²) 입니다. 중학교 수학에서 배운 피타고라스 정리와 같은 원리입니다!

    개념 3: 최적의 K 찾기 — 엘보우 기법¶

    1️⃣ 비유로 시작¶

    피자를 자를 때, 2조각으로 자르면 한 조각이 너무 크고, 100조각으로 자르면 의미가 없습니다. 적당한 조각 수를 찾아야 하죠. K-Means에서도 K를 몇으로 할지가 매우 중요합니다.

    2️⃣ 정확한 정의¶

    엘보우 기법(Elbow Method)은 K를 1부터 점점 늘려가면서 각 K에 대한 이너셔(Inertia)를 그래프로 그린 뒤, 꺾이는 지점(팔꿈치)을 최적의 K로 선택하는 방법입니다.

    이너셔(Inertia)란 각 데이터 포인트가 자기가 속한 군집의 중심점과 얼마나 떨어져 있는지를 합산한 값입니다. 이너셔가 작을수록 군집 내부가 촘촘하게 모여 있다는 뜻입니다.

    3️⃣ 예시로 확인¶

    flowchart LR A["K=1<br/>이너셔: 매우 큼"] --> B["K=2<br/>이너셔: 확 줄어듦"] B --> C["K=3<br/>이너셔: 꽤 줄어듦"] C --> D["K=4<br/>이너셔: 조금 줄어듦"] D --> E["K=5<br/>이너셔: 거의 안 줄어듦"] style C fill:#FF6B6B,color:#fff

    위 흐름에서 K=3 지점이 바로 팔꿈치(Elbow)입니다. K를 3에서 4로 늘려도 이너셔가 크게 줄지 않으므로, K=3이 최적이라고 판단합니다.

    생각해보기 🤔

    K를 데이터 개수와 같게 하면 어떻게 될까요? 모든 데이터가 각자 하나의 군집이 되어 이너셔는 0이 됩니다. 하지만 이건 아무것도 묶지 않은 것과 같으므로 의미가 없겠죠!

    개념 4: 군집 결과 시각화와 해석¶

    1️⃣ 비유로 시작¶

    지도 위에 서울, 부산, 대구 등 도시를 색깔별로 표시하면 한눈에 "어디에 어떤 도시들이 모여 있는지" 파악할 수 있습니다. 군집 결과도 마찬가지로 산점도(Scatter Plot)에 색깔을 입히면 패턴이 보입니다.

    2️⃣ 시각화의 핵심 요소¶

    • 데이터 포인트: 각 데이터를 점으로 표시
    • 색상: 같은 군집은 같은 색
    • 중심점(centroid): 각 군집의 중심을 ★ 등으로 강조
    • 해석: "이 군집은 어떤 특성을 가진 그룹인가?"를 파악

    3️⃣ 해석의 중요성¶

    군집을 만드는 것 자체는 기계가 하지만, "이 군집이 무엇을 의미하는가"를 해석하는 것은 사람의 몫입니다. 예를 들어 음악 스트리밍 데이터를 군집화한 결과가 3개 그룹이라면:

    • 군집 0: 팝·댄스 장르를 많이 듣는 그룹 → "트렌디 리스너"
    • 군집 1: 클래식·재즈를 많이 듣는 그룹 → "감성 리스너"
    • 군집 2: 힙합·R&B를 많이 듣는 그룹 → "리듬 리스너"

    이렇게 군집에 이름을 붙이는 작업이 군집 분석의 마무리 단계입니다.

    🔨 따라하기: 음악 스트리밍 사용자 군집 분석¶

    Google Colab에서 바로 실행할 수 있는 실습입니다. 음악 스트리밍 서비스의 사용자 데이터(장르별 청취 시간)를 활용하여 K-Means 군집 분석을 수행합니다.

    Step 1: 데이터 준비하기¶

    # 필요한 라이브러리 불러오기
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 한글 폰트 설정 (Colab 환경)
plt.rcParams['font.family'] = 'DejaVu Sans'

# 랜덤 시드 고정 (결과 재현을 위해)
np.random.seed(42)

# 가상 음악 스트리밍 사용자 데이터 생성
# 30명의 사용자, 3개 장르(Pop, Classic, HipHop)의 주간 청취 시간(분)
n_users = 30

# 그룹 1: Pop 많이 듣는 사용자 (10명)
pop_lovers = np.column_stack([
    np.random.normal(120, 15, 10),  # Pop: 평균 120분
    np.random.normal(20, 10, 10),   # Classic: 평균 20분
    np.random.normal(30, 10, 10)    # HipHop: 평균 30분
])

# 그룹 2: Classic 많이 듣는 사용자 (10명)
classic_lovers = np.column_stack([
    np.random.normal(25, 10, 10),   # Pop: 평균 25분
    np.random.normal(110, 20, 10),  # Classic: 평균 110분
    np.random.normal(15, 8, 10)     # HipHop: 평균 15분
])

# 그룹 3: HipHop 많이 듣는 사용자 (10명)
hiphop_lovers = np.column_stack([
    np.random.normal(40, 12, 10),   # Pop: 평균 40분
    np.random.normal(10, 8, 10),    # Classic: 평균 10분
    np.random.normal(130, 20, 10)   # HipHop: 평균 130분
])

# 데이터 합치기
data = np.vstack([pop_lovers, classic_lovers, hiphop_lovers])
data = np.clip(data, 0, None)  # 음수 제거

df = pd.DataFrame(data, columns=['Pop_min', 'Classic_min', 'HipHop_min'])
df.index = [f'User_{i+1}' for i in range(30)]

print("=== 음악 스트리밍 사용자 데이터 (상위 5명) ===")
print(df.head())
print(f"\n전체 사용자 수: {len(df)}명")
print(f"\n=== 기본 통계 ===")
print(df.describe().round(1))

    알아보기 🔍

    실제 데이터를 사용하면 좋겠지만, 학습 목적으로 가상 데이터를 생성했습니다. np.random.normal(평균, 표준편차, 개수)로 정규분포를 따르는 데이터를 만들었습니다. 실제 서비스에서는 수백만 명의 데이터를 다루게 됩니다!

    Step 2: 데이터 전처리 — 스케일링¶

    # 스케일링: 모든 특성의 크기를 맞춰주기
scaler = StandardScaler()
data_scaled = scaler.fit_transform(df)

df_scaled = pd.DataFrame(data_scaled, 
                          columns=['Pop_min', 'Classic_min', 'HipHop_min'],
                          index=df.index)

print("=== 스케일링 전 (원본) ===")
print(df.head(3).round(1))
print("\n=== 스케일링 후 ===")
print(df_scaled.head(3).round(2))

    알아보기 🔍

    StandardScaler는 각 특성의 평균을 0, 표준편차를 1로 맞춰줍니다. 만약 어떤 장르의 청취 시간이 0~10분이고 다른 장르가 0~200분이라면, 큰 값을 가진 장르가 거리 계산을 지배해버립니다. 스케일링으로 모든 특성을 동등한 기준으로 맞춰야 공정한 군집화가 됩니다.

    Step 3: 엘보우 기법으로 최적 K 찾기¶

    # K를 1부터 10까지 바꿔가며 이너셔 계산
inertias = []
K_range = range(1, 11)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(data_scaled)
    inertias.append(kmeans.inertia_)
    print(f"K={k}: Inertia = {kmeans.inertia_:.2f}")

# 엘보우 그래프 그리기
plt.figure(figsize=(8, 5))
plt.plot(K_range, inertias, 'bo-', linewidth=2, markersize=8)
plt.axvline(x=3, color='red', linestyle='--', label='Elbow Point (K=3)')
plt.xlabel('Number of Clusters (K)', fontsize=12)
plt.ylabel('Inertia', fontsize=12)
plt.title('Elbow Method - Finding Optimal K', fontsize=14)
plt.legend(fontsize=11)
plt.grid(True, alpha=0.3)
plt.xticks(K_range)
plt.tight_layout()
plt.show()

    실행하면 K=3 부근에서 그래프가 팔꿈치처럼 꺾이는 것을 확인할 수 있습니다. K=3 이후로는 이너셔가 크게 줄지 않으므로, K=3이 최적입니다.

    Step 4: K-Means 모델 학습하기¶

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)

    ⚠️ 자주 하는 실수¶

    실수 1: 스케일링을 하지 않고 K-Means 적용하기 ❌¶

    # 잘못된 방법
kmeans = KMeans(n_clusters=3)
kmeans.fit(df[['Pop_min', 'Classic_min', 'HipHop_min']])  # 원본 그대로!

# 올바른 방법
scaler = StandardScaler()
data_scaled = scaler.fit_transform(df[['Pop_min', 'Classic_min', 'HipHop_min']])
kmeans = KMeans(n_clusters=3)
kmeans.fit(data_scaled)  # 스케일링된 데이터 사용!

    K-Means는 거리 기반 알고리즘이므로, 특성 간 단위 차이가 크면 큰 값을 가진 특성이 결과를 지배합니다. 반드시 스케일링 하세요!

    실수 2: K값을 아무렇게나 정하기 ❌¶

    "3개 정도면 되겠지?"라고 감으로 K를 정하면 안 됩니다. 엘보우 기법으로 근거를 만드세요. 다만 엘보우가 명확하지 않을 때도 있습니다. 그럴 때는 실루엣 점수(Silhouette Score) 등 추가 지표를 활용할 수 있습니다.

    실수 3: 군집 번호에 의미를 부여하기 ❌¶

    # Cluster 0이 "가장 좋은 그룹"이라는 의미가 아닙니다!
# 군집 번호는 단순 식별자일 뿐입니다.
# 실행할 때마다 번호가 바뀔 수 있어요.

    Cluster 0, 1, 2는 단순한 라벨입니다. "0번이 1번보다 낫다"와 같은 순서나 우열이 없습니다. 군집의 의미는 데이터를 분석하여 사람이 해석해야 합니다.

    실수 4: 초기 중심점에 따라 결과가 달라지는 것을 무시하기 ❌¶

    # n_init=10 을 설정하면 10번 다른 초기값으로 시도 후 최적 결과 선택
kmeans = KMeans(n_clusters=3, n_init=10, random_state=42)

    K-Means는 초기 중심점을 무작위로 선택하므로, 운이 나쁘면 나쁜 결과가 나올 수 있습니다. n_init 파라미터로 여러 번 시도하도록 설정하고, random_state로 결과를 고정하세요.

    ✅ 스스로 점검하기¶

    기본 문제 ⭐¶

    문제 1. 다음 빈칸을 채우세요.

    K-Means는 __ 학습의 대표적인 알고리즘으로, 데이터를 __개의 군집으로 나눈다. 각 군집의 ______(centroid)을 반복적으로 업데이트하며, 더 이상 변화가 없으면 학습을 멈춘다.

    문제 2. K-Means 알고리즘의 3단계를 순서대로 나열하세요.

    • (ㄱ) 각 군집의 평균 위치로 중심점 이동
    • (ㄴ) K개의 초기 중심점 선택
    • (ㄷ) 각 데이터를 가장 가까운 중심점에 할당

    응용 문제 ⭐⭐¶

    문제 3. 엘보우 그래프를 보고 최적 K를 결정하려 합니다. 이너셔 값이 다음과 같을 때 최적 K는 무엇일까요?

    • K=1: 500
    • K=2: 250
    • K=3: 120
    • K=4: 100
    • K=5: 95
    • K=6: 92

    문제 4. 스케일링 없이 K-Means를 적용하면 왜 문제가 발생하는지, "월 소득(만 원)"과 "나이(세)" 두 특성을 예로 들어 설명하세요.

    심화 문제 ⭐⭐⭐¶

    문제 5. 아래 코드에서 잘못된 부분을 모두 찾아 수정하세요.

    from sklearn.cluster import KMeans
import pandas as pd

df = pd.read_csv('customers.csv')
kmeans = KMeans(n_clusters=5)  # K를 그냥 5로 정함
kmeans.fit(df)                 # 스케일링 없이 원본 데이터
labels = kmeans.labels_
print(f"군집 0이 가장 좋은 고객 그룹입니다")  # 군집 번호 해석

    정답¶

    문제 1. 비지도 / K / 중심점

    문제 2. (ㄴ) → (ㄷ) → (ㄱ) (이후 ㄷ~ㄱ 반복)

    문제 3. K=3. K=2→3에서 130이 줄었지만, K=3→4에서는 20만 줄고, 이후 거의 변화 없음.

    문제 4. 월 소득은 100~1000 범위, 나이는 20~70 범위입니다. 스케일링 없이 거리를 계산하면 소득의 차이가 나이보다 수십 배 크므로, 실제로는 "나이만 비슷한 사람"도 "소득이 비슷한 사람"으로 묶이게 됩니다.

    문제 5. - K=5를 그냥 정하지 말고 → 엘보우 기법으로 최적 K 결정 - kmeans.fit(df) → StandardScaler로 스케일링 후 적용 - "군집 0이 가장 좋은" → 군집 번호에 우열 의미 없음, 데이터 분석으로 해석해야 함

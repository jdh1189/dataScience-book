    Chapter 11. 군집 분석 - 비슷한 것끼리 모으자¶

    Part 3 | [2권] 데이터 모델링과 평가

    🤔 생각해보기: 반 친구들을 취미가 비슷한 그룹으로 나눈다면 몇 그룹이 될까요? 게임을 좋아하는 친구들, 운동을 좋아하는 친구들, 음악을 좋아하는 친구들… 우리는 이미 일상에서 "비슷한 것끼리 묶기"를 자연스럽게 하고 있습니다. 컴퓨터에게 이걸 시키는 방법, 지금부터 배워봅시다!

    🎯 이 장에서 배우는 것¶

    • 군집 분석의 개념과 비지도학습의 특징을 설명할 수 있다
    • K-Means 알고리즘의 동작 원리를 단계별로 설명할 수 있다
    • 엘보우 기법으로 적절한 군집 수(K)를 결정할 수 있다
    • Python으로 군집 분석을 수행하고 결과를 시각화할 수 있다

    💡 왜 이걸 배우나요?¶

    넷플릭스는 어떻게 "당신이 좋아할 만한 영화"를 추천해줄까요? 편의점은 왜 삼각김밥 옆에 컵라면을 배치할까요?

    이 모든 것의 출발점이 바로 군집 분석(Clustering)입니다.

    • 🎵 음악 스트리밍 서비스: 비슷한 취향의 사용자끼리 묶어 플레이리스트 추천
    • 🛒 쇼핑몰: 구매 패턴이 비슷한 고객끼리 묶어 맞춤 할인 쿠폰 발송
    • 🏥 의료 분야: 증상이 비슷한 환자끼리 묶어 치료 방향 결정
    • 📱 SNS: 관심사가 비슷한 사용자끼리 묶어 친구 추천

    앞 장에서 배운 분류(Classification)는 정답이 있는 문제였습니다. "이 이메일이 스팸인가 아닌가?" 처럼요. 하지만 군집 분석은 정답이 없는 상태에서 데이터 스스로 패턴을 찾아냅니다. 이것이 바로 비지도학습(Unsupervised Learning)의 매력입니다!

    📚 핵심 개념¶

    개념 1: 군집 분석이란? 🧩¶

    ① 비유로 시작

    새 학기 첫날, 선생님이 이렇게 말합니다:

    "자, 여러분! 자유롭게 어울려서 3~4명씩 그룹을 만들어보세요."

    아무런 기준을 주지 않았는데도, 학생들은 자연스럽게 친한 친구끼리, 관심사가 비슷한 사람끼리 모입니다. 아무도 "너는 A그룹이야"라고 정답을 알려주지 않았는데 그룹이 만들어졌죠. 이것이 바로 군집 분석의 핵심 아이디어입니다.

    ② 정확한 정의

    📌 군집 분석(Cluster Analysis): 레이블(정답)이 없는 데이터에서, 서로 비슷한 데이터끼리 같은 그룹(군집)으로 묶는 비지도학습 기법

    ③ 예시로 확인 — 지도학습 vs 비지도학습

    flowchart LR A[머신러닝] --> B[지도학습] A --> C[비지도학습] B --> D["분류: 스팸/정상 구분<br/>정답 라벨 있음 ✅"] B --> E["회귀: 집값 예측<br/>정답 라벨 있음 ✅"] C --> F["군집 분석: 고객 세분화<br/>정답 라벨 없음 ❌"] C --> G["차원 축소: 데이터 압축<br/>정답 라벨 없음 ❌"]

    💡 알아보기: 분류(Classification)는 "이건 고양이, 이건 개"라고 정답표가 있는 상태에서 학습합니다. 반면 군집 분석은 "아무 정보 없이 비슷한 사진끼리 모아봐"라고 하는 것과 같습니다. 정답이 없으니, 알고리즘이 스스로 데이터의 구조를 파악해야 합니다.

    개념 2: K-Means 알고리즘 🎯¶

    ① 비유로 시작 — 교실 자리 배치 게임

    체육관에 학생 30명이 흩어져 서 있습니다. 선생님이 3명의 "조장"을 아무 위치에나 세웁니다. 그리고 게임 규칙을 알려줍니다:

    1. 학생 이동: 모든 학생은 자신에게 가장 가까운 조장에게 간다
    2. 조장 이동: 조장은 자기 조원들의 정가운데로 이동한다
    3. 반복: 더 이상 아무도 움직이지 않을 때까지 1~2를 반복한다

    이것이 바로 K-Means 알고리즘의 전체 동작 원리입니다!

    ② 정확한 정의

    📌 K-Means 알고리즘: K개의 중심점(centroid)을 기준으로 데이터를 가장 가까운 중심점의 군집에 배정하고, 중심점을 업데이트하는 과정을 반복하여 군집을 형성하는 알고리즘

    여기서 K는 만들고 싶은 그룹의 수입니다. K=3이면 3개 그룹, K=5이면 5개 그룹으로 나눕니다.

    ③ 단계별 동작 과정

    flowchart TD S["🎬 시작: K값 설정 (예: K=3)"] --> A A["Step 1️⃣<br/>K개의 중심점을 무작위 배치"] --> B B["Step 2️⃣<br/>각 데이터를 가장 가까운<br/>중심점의 군집에 배정"] --> C C["Step 3️⃣<br/>각 군집의 평균 위치로<br/>중심점 이동"] --> D D{"Step 4️⃣<br/>중심점이<br/>변했나?"} D -- "예 → 반복" --> B D -- "아니오 → 수렴 완료" --> E["🏁 완료: 군집 결과 출력"]

    🔍 정리하기: K-Means의 핵심은 딱 두 가지입니다. - 배정(Assignment): 각 데이터를 가장 가까운 중심점에 배정 - 업데이트(Update): 중심점을 군집의 평균 위치로 이동

    이 두 단계를 중심점이 더 이상 움직이지 않을 때까지(수렴) 반복합니다.

    개념 3: 적절한 K 결정하기 — 엘보우 기법 💪¶

    ① 비유로 시작

    팔을 쭉 펴고 천천히 구부려 보세요. 팔꿈치(elbow) 부분에서 확 꺾이죠? 엘보우 기법의 이름이 여기서 나왔습니다.

    ② 정확한 정의

    📌 엘보우 기법(Elbow Method): K 값을 1부터 늘려가며 각각의 관성(inertia, 군집 내 거리 합)을 측정하고, 그래프가 팔꿈치처럼 꺾이는 지점을 최적의 K로 선택하는 방법

    • 관성(Inertia): 각 데이터와 자기가 속한 중심점 사이의 거리 합. 작을수록 군집이 촘촘하게 잘 뭉쳐있다는 의미
    • K가 커질수록 관성은 당연히 줄어듬 (극단적으로 K=데이터 수이면 관성=0)
    • 핵심은 관성이 급격히 줄다가 완만해지는 지점을 찾는 것

    ③ 예시로 확인

    flowchart LR subgraph 엘보우 그래프 해석 A["K=1: 관성 매우 큼 📈"] --> B["K=2: 관성 크게 감소 📉"] B --> C["K=3: 관성 또 크게 감소 📉"] C --> D["K=4: 감소폭 둔화 ➡️ <br/>⬅️ 여기가 엘보우!"] D --> E["K=5: 거의 변화 없음 ➡️"] end

    위 그래프에서 K=3 또는 K=4 부근이 "팔꿈치"입니다. 이 지점이 군집 수 대비 효율이 가장 좋은 K 값입니다.

    💡 알아보기: K를 너무 작게 잡으면 서로 다른 특성의 데이터가 한 그룹에 섞이고, 너무 크게 잡으면 의미 없는 세분화가 됩니다. 엘보우 기법은 이 균형점을 찾아주는 실용적인 방법입니다.

    개념 4: 군집 결과 시각화와 해석 📊¶

    ① 비유로 시작

    군집 분석 결과를 숫자로만 보면 "그래서 뭐?"가 됩니다. 마치 지도 없이 길을 찾는 것과 같죠. 산점도(Scatter Plot)는 군집 분석의 지도 역할을 합니다. 색깔별로 그룹을 보여주면 한눈에 패턴이 보입니다.

    ② 정확한 정의

    📌 군집 시각화: 각 데이터 포인트를 2차원 평면에 점으로 표시하고, 소속 군집에 따라 다른 색상을 부여하여 군집 구조를 시각적으로 확인하는 방법

    ③ 시각화에서 확인할 것

    • 🔴🔵🟢 색상별 분포: 각 군집이 잘 분리되어 있는가?
    • ⭐ 중심점 위치: 군집의 대표 특성은 무엇인가?
    • 🔄 겹침 영역: 군집 경계가 모호한 데이터는 없는가?

    🔨 따라하기: 음악 스트리밍 사용자 군집 분석¶

    🎵 시나리오: 음악 스트리밍 서비스에서 사용자 50명의 장르별 청취 시간(시간/주) 데이터를 분석합니다. 비슷한 음악 취향을 가진 사용자끼리 그룹으로 묶어 맞춤형 플레이리스트를 추천하려 합니다.

    Step 1: 데이터 준비하기¶

    Google Colab에서 새 노트북을 열고 아래 코드를 실행하세요.

    # 필요한 라이브러리 불러오기
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 한글 폰트 설정 (Colab용)
plt.rc('font', family='DejaVu Sans')

# 재현 가능하도록 시드 고정
np.random.seed(42)

# 가상의 음악 스트리밍 사용자 데이터 생성
n_users = 50

# 그룹 A: 힙합+댄스 매니아 (15명)
hiphop_a = np.random.normal(8, 1.5, 15)
dance_a = np.random.normal(7, 1.5, 15)
ballad_a = np.random.normal(1, 0.8, 15)

# 그룹 B: 발라드+어쿠스틱 감성파 (20명)
hiphop_b = np.random.normal(1, 0.8, 20)
dance_b = np.random.normal(2, 1.0, 20)
ballad_b = np.random.normal(9, 1.5, 20)

# 그룹 C: 골고루 듣는 잡식파 (15명)
hiphop_c = np.random.normal(5, 1.0, 15)
dance_c = np.random.normal(5, 1.0, 15)
ballad_c = np.random.normal(5, 1.0, 15)

# 데이터프레임 생성
data = pd.DataFrame({
    'hiphop': np.clip(np.concatenate([hiphop_a, hiphop_b, hiphop_c]), 0, 15).round(1),
    'dance': np.clip(np.concatenate([dance_a, dance_b, dance_c]), 0, 15).round(1),
    'ballad': np.clip(np.concatenate([ballad_a, ballad_b, ballad_c]), 0, 15).round(1)
})

print("📊 음악 스트리밍 사용자 데이터 (주당 청취 시간)")
print(f"총 사용자 수: {len(data)}명")
print(f"장르: hiphop(힙합), dance(댄스), ballad(발라드)")
print()
print(data.head(10))

    💡 알아보기: np.clip()은 데이터 값을 0~15 사이로 제한합니다. 청취 시간이 음수가 되거나 비현실적으로 커지는 것을 방지하기 위해서입니다.

    Step 2: 데이터 전처리 — 표준화¶

    # 데이터 표준화 (스케일링)
scaler = StandardScaler()
data_scaled = scaler.fit_transform(data)

print("🔧 표준화 전 (원본 데이터 통계)")
print(data.describe().round(2))
print()
print("🔧 표준화 후 (평균≈0, 표준편차≈1)")
print(pd.DataFrame(data_scaled, columns=data.columns).describe().round(2))

    🤔 생각해보기: 왜 표준화가 필요할까요? K-Means는 거리를 기준으로 군집을 나눕니다. 만약 한 변수의 범위가 0~100이고 다른 변수가 0~1이라면, 범위가 큰 변수가 거리 계산을 지배하게 됩니다. 표준화는 모든 변수를 공정한 출발선에 세워주는 작업입니다.

    Step 3: 엘보우 기법으로 최적 K 찾기¶

    # 엘보우 기법: K=1~10까지 관성 계산
inertias = []
K_range = range(1, 11)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(data_scaled)
    inertias.append(kmeans.inertia_)

# 엘보우 그래프 그리기
plt.figure(figsize=(8, 5))
plt.plot(K_range, inertias, 'bo-', linewidth=2, markersize=8)
plt.xlabel('K (Number of Clusters)', fontsize=12)
plt.ylabel('Inertia', fontsize=12)
plt.title('Elbow Method', fontsize=14)
plt.xticks(K_range)
plt.grid(True, alpha=0.3)

# 엘보우 포인트 강조
plt.annotate('Elbow Point!',
             xy=(3, inertias[2]),
             xytext=(5, inertias[2] + 15),
             fontsize=12, color='red',
             arrowprops=dict(arrowstyle='->', color='red', lw=2))

plt.tight_layout()
plt.show()

print("📋 K별 Inertia 값:")
for k, inertia in zip(K_range, inertias):
    marker = " ◀ Elbow!" if k == 3 else ""
    print(f"  K={k:2d} → Inertia = {inertia:.2f}{marker}")

    실행하면 K=3 부근에서 그래프가 확 꺾이는 것을 확인할 수 있습니다. 따라서 K=3이 적절합니다.

    Step 4: K-Means 모델 학습¶

    # K=3으로 K-Means 모델 학습
optimal_k = 3
kmeans = KMeans(n_clusters=optimal_k, random_state=42, n_init=10)
clusters = kmeans.fit_predict(data_scaled)

# 원본 데이터에 군집 라벨 추가
data['cluster'] = clusters

print(f"🎯 K={optimal_k} 군집 분석 결과")
print(f"각 군집별 사용자 수:")
for i in range(optimal_k):
    count = (clusters == i).sum()
    print(f"  Cluster {i}: {count}명")

    💡 알아보기: fit_predict()는 fit()과 predict()를 한 번에 수행합니다. 모델을 학습시키고 동시에 각 데이터가 어떤 군집에 속하는지 라벨을 반환합니다.

    Step 5: 군집별 특성 분석¶

    # 군집별 평균 청취 시간 확인
print("📊 군집별 평균 청취 시간 (시간/주)")
print("=" * 50)

cluster_names = {0: '', 1: '', 2: ''}  # 이름은 결과 보고 붙이기

for i in range(optimal_k):
    cluster_data = data[data['cluster'] == i]
    print(f"\n🔸 Cluster {i} ({len(cluster_data)}명)")
    print(f"   힙합:   {cluster_data['hiphop'].mean():.1f}시간")
    print(f"   댄스:   {cluster_data['dance'].mean():.1f}시간")
    print(f"   발라드: {cluster_data['ballad'].mean():.1f}시간")

    # 특성에 맞는 이름 자동 부여
    means = cluster_data[['hiphop', 'dance', 'ballad']].mean()
    if means['hiphop'] > 6 and means['dance'] > 5:
        cluster_names[i] = 'HipHop & Dance Lover'
    elif means['ballad'] > 6:
        cluster_names[i] = 'Ballad Lover'
    else:
        cluster_names[i] = 'All-round Listener'

print("\n" + "=" * 50)
print("💡 군집 이름 부여:")
for i, name in cluster_names.items():
    print(f"   Cluster {i} → {name}")

    Step 6: 결과 시각화¶

    # 2차원 산점도로 군집 시각화 (힙합 vs 발라드)

# 5. 군집별 특성 출력
for i in range(3):

    실수 1: 표준화를 빼먹는다 🚫¶

    # ❌ 잘못된 방법: 원본 데이터에 바로 K-Means 적용

kmeans.fit(data[['hiphop', 'dance', 'ballad']])  # 스케일 차이 무시!

scaler = StandardScaler()
data_scaled = scaler.fit_transform(data[['hiphop', 'dance', 'ballad']])
kmeans = KMeans(n_clusters=3)

    실수 2: K 값을 감으로 정한다 🎲¶

    # ❌ "3개로 나누면 되겠지~" 라고 감으로 결정
kmeans = KMeans(n_clusters=3)

# ✅ 엘보우 기법으로 근거 있는 K 선택
for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(data_scaled)
    print(f"K={k}, Inertia={km.inertia_:.2f}")

for i in range(3):

    기본 문제 📗¶

    1. 빈칸 채우기

    군집 분석은 _ 학습의 대표적 기법으로, 데이터에 _ 이/가 없는 상태에서 비슷한 데이터끼리 그룹으로 묶는다.

    2. O/X 퀴즈

    • (a) K-Means에서 K 값은 알고리즘이 자동으로 결정한다. ( )
    • (b) K-Means는 중심점 이동이 멈출 때까지 반복한다. ( )
    • (c) 엘보우 기법에서 Inertia가 가장 작은 K를 선택한다. ( )

    3. 순서 맞추기: K-Means 알고리즘의 동작 순서를 나열하세요.

    • (ㄱ) 중심점이 변하지 않으면 종료
    • (ㄴ) 각 데이터를 가장 가까운 중심점에 배정
    • (ㄷ) K개의 중심점을 무작위로 설정
    • (ㄹ) 각 군집의 평균 위치로 중심점 이동

    응용 문제 📘¶

    4. 아래 엘보우 그래프 결과가 있습니다. 최적의 K는 몇인가요? 그 이유를 설명하세요.

    • K=1: Inertia=150
    • K=2: Inertia=80
    • K=3: Inertia=40

    5. 온라인 쇼핑몰에서 고객을 군집화하여 3개 그룹이 나왔습니다.

    • Cluster A: 평균 구매액 5만원, 구매 빈도 월 1회, 주로 생필품
    • Cluster B: 평균 구매액 30만원, 구매 빈도 월 8회, 주로 패션/전자기기
    • Cluster C: 평균 구매액 3만원, 구매 빈도 월 15회, 주로 식품/간식

    각 그룹에 어떤 마케팅 전략을 제안하겠습니까?

    정답¶

    • 1번: 비지도, 정답 라벨(레이블)
    • 2번: (a) X — K는 사용자가 지정합니다 / (b) O / (c) X — 가장 작은 K가 아니라 꺾이는 지점의 K
    • 3번: (ㄷ) → (ㄴ) → (ㄹ) → (ㄱ)
    • 4번: K=3. K=3까지 관성이 크게 줄어들지만(150→80→40), K=4부터는 감소폭이 매우 작아짐(40→35→33). 팔꿈치가 K=3 지점에서 형성됩니다.
    • 5번: (예시) Cluster A: 재방문 유도 할인쿠폰 / Cluster B: VIP 등급 및 신상품 조기 알림 / Cluster C: 정기배송 구독 서비스 제안
